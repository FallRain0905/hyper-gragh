Electrode materials that simultaneously exhibit high catalytic activity and effective hydrogen evolution suppression is crucial for high-performance vanadium flow bateries.In this work,we designa bifunctional catalyst composed of metallc Bi, bismuth oxide,and nitrogen-doped amorphous carbon. Metallic Bi provides hydrogen evolution inhibition,while oxygen vacancies in bismuth oxide serve as active sites for enhanced catalytic activity.Meanwhile,nitrogen-doped carbon furtherfacilitates catalysisand improves adhesion to the carbon felt substrate.The catalysts are prepared by hydrothermally converting a Bi-zeolitic imidazolate framework-8 precursor,followed by carbonization at various temperatures.Morphology,composition, electrochemical activity, andcharge-discharge performance are systematically analyzed.Itis found that: (i) The composite synthesized at $9 0 0 ^ { \circ } \mathrm { C }$ displayed uniform, finely dispersed particles,abundant oxygen vacancies,oxygen-containing functional groups,graphitic nitrogen,excellent hydrophilicity，and outstanding electrochemical performance;(ii it significantly improves coulombic effciency due to the hydrogen evolution suppression; (ii) it improves the energy efficiency by $8 . 5 \%$ compared to bare carbon felt electrodes at $1 0 0 \mathrm { \ m A c m ^ { - 2 } }$ ; (iv) it delivers marked enhancements incell capacity,applied voltage,power output,high curent density capabilityand cycling life. Overall,this work proposes a novel electrochemical catalyst that achieves synergistic catalysis and hydrogen evolution suppression,enabling high-performance vanadium flow batteries.

# 1． Introduction

The vanadium flow batter (VFB), benefited from its flexible battery design,high safety,rapid response time,long cycle life,and low cost [1], has become one of the most promising and competitive electrochemical systems for grid-scale energy storage applications [2].In VFB systems, the electrode serves as the site for electrochemical reactions and plays a vital role in the overall performance of VFBs [3].To date,carbon felts (CFs) is the most promising electrode materials for VFBs owing to their exceptional chemical stability,high conductivity,and robust mechanical properties.Nevertheless,the practical implementation of CF electrodes encounter ongoing challenges: their poor wettability and insufficient active sites result in suboptimal electrochemical activity [4]. Consequently,enhancing the electrochemical activity of electrodes has becomea key focus in the development of VFBs.

The methods for enhancing the activity of CF generally involve treating the substrate or modifying the surface.Common techniques for treating the CF substrate include plasma treatment [5],chemical etching [6,7],and electrochemical oxidation [8].Plasma treatment enables the directional introduction of specific functional groups onto CF surfaces to enhance catalytic performance;however,this selective functionalization can result in undesirable side reactions,structural degradation,and complex processing requirements [9]. Chemical etching creates porous defects that increase specific surface areas,but the corrosive nature of strong acids and alkalis raises environmental concerns,and excessive porosity may lead to electrolyte retention,resulting in concentration polarization [1O].Additionally,electrochemical oxidation encounters scalability limitations in industrial applications due to the need for specialized equipment and stringent control over current and voltage parameters [11].

For the surface modification,the introduction of metals or metal oxides as catalysts has been widely shown to significantly enhance charge transfer and mass transfer kinetics [l2]. This approach not only addresses the limitations associated with the aforementioned substrate treatment methods but also opens new avenues for optimizing the functional properties of carbon-based electrodes.Early research primarily focused on using precious metals and their oxides,for example Ir [13] and Pt [14],as catalysts for CF.However,their practical applicationsare hindered by high costs and sensitivity to hydrogen evolution [15].To address these issues,low-cost metals have gained considerable attention and have been extensively investigated in recent years, including Bi [16],Ti[17],Co [18],etc.Of them,Bi,as a non-toxic and cost-effective metal, exhibits excellent hydrogen evolution suppression capability and superior electrical conductivity,thereby attracting significant attention.Elemental bismuth can interact with $\mathrm { H } ^ { + }$ in the electrolyte to form the intermediate $\mathrm { B i H _ { x } } ,$ which not only suppresses the hydrogen evolution reaction (HER)—the primary contributor to coulombic efficiency loss in VFBs—but also promotes the reduction of $\mathrm { V } ^ { 3 + }$ [19]. Z. Gonzalez and R. Santamaria 2O] were the first to demonstrate that depositing elemental Bi on the positive electrode surface can improve charge transfer at the electrode/electrolyte interface.However, utilizing elemental Bi as the anode carries the risk of oxidation by $\mathsf { V } ^ { 5 + }$ ， which may lead to its detachment from the electrode surface.To address this, Seongeun Moon et al.explored the use of $\mathbf { B i } ^ { 3 + }$ to enhance the electrochemical activity of the positive electrode reaction [21]. Furthermore,Anas Mehmood et al. revealed that $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ can act as an efficient electrocatalyst, significantly improving the reaction kinetics of both the $\mathrm { V } ^ { 3 + } / \mathrm { V } ^ { 2 + }$ and $\mathrm { V O } ^ { 2 + } / \mathrm { V O } _ { 2 } ^ { + }$ redox couples [22]. Therefore, the preparation of ${ \bf B i } / { \bf B i } _ { 2 } { \bf O } _ { 3 }$ composites is anticipated to yield composite catalysts that notonly inhibitHERbutalso exhibit catalytic activity for both positive and negative electrode reactions in VFBs.

However,non-noble metal and metal oxides,such as Bi and $\mathrm { B i } _ { 2 } \mathrm { O } _ { 3 } ,$ still fail to match the catalytic performance of noble metal catalysts [23]. Additionally, the direct deposition of these metal or oxide catalysts onto carbon electrodes often leads to agglomeration and poor adhesion, which further hinders their catalytic performance [24].Hence, researchers have pursued ways to enhance their catalytic activity, such as introducing oxygen vacancies into these oxides.Oxygen vacancies are lattice site defects in oxides where oxygen atoms should theoretically be positioned.They can significantly enhance electrical conductivity and catalytic activity of materials.To date,oxygen vacancies have shown promising application prospects in various fields,including electrocatalysis [25] and energy storage [26]. In the realm of VFBs,relevant studies have confirmed that oxygen vacancies can facilitate the catalysis of electrode processes,primarily by providing sufficient active sites for redox reactions and improving hydrophilicity [27-29].

Metal-organic frameworks (MOFs) are porous structures composed of metal ions serving as central nodes linked by organic ligands. They possess high specific surface area,high porosity,and excellent designability.These superior properties render MOFs outstanding modifiers [30].Calcination using MOF precursors is an effective approach to generate oxygen vacancies [31,32]. Zeolitic Imidazolate Framework-8 (ZIF-8) is a unique subclass of MOFs,featuring a topological structure analogous to that of aluminosilicate zeolites.This distinctive architecture endows ZIF-8 with dual properties:it inherits the characteristic porous structure and high specific surface area of MOFs,while also possessing the high chemical stability of traditional zeolites.Thus,it effectively overcomes the limitations of insufficient thermal stability at elevated temperatures and susceptibility to degradation in strongly acidic environments [33].

Based on these insights,this study synthesizes a bifunctional catalyst, $\mathrm { B i - B i _ { 2 } O _ { 3 } } @ \mathrm { C } ,$ ，for VFBs by carbonizing the Bi-ZIF-8 precursor obtained through a hydrothermal method.In this catalyst,metallic Bi suppresses hydrogen evolution,reducing wasteful consumption of electrons and active sites,thereby creating a low-competition environment for the vanadium reactions.Meanwhile,oxygen vacancies improve conductivity and ion diffusion,and also enhance the adsorption energy of $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ for vanadium ions,which promote the main reaction and also suppress hydrogen evolution.Electrochemical analyses reveal that Bi $\mathbf { \partial } \cdot \mathbf { B i _ { 2 } O _ { 3 } @ C ^ { \alpha } }$ 900 exhibits optimal suppression of hydrogen evolution and superior catalytic performance.Charging-discharging tests demonstrate that the cells equipped with ] $\mathrm { 3 i - B i _ { 2 } O _ { 3 } @ C } .$ -modified electrodes demonstrated increased energy efficiency.Specifically,the energy eficiency of Bi-$\mathrm { B i } _ { 2 } \mathrm { O } _ { 3 } @ \mathrm { C } \cdot 9 0 0$ cell outperforms that of cells with bare carbon felts by $8 . 5 \%$ at $1 0 0 \mathrm { \ m A c m ^ { - 2 } }$ Moreover,the B $\mathbf { i } \mathbf { - B i } _ { 2 } \mathbf { O } _ { 3 } @ \mathbf { C } \mathbf { - } 9 0 0$ catalyst exhibits exceptional high current density performance along with excellent cycle stability.Thus,this study presents a novel bifunctional composite electrode material with high catalytic activityand effective hydrogen evolution suppression for VFBs,which significantly benefits the overall performance of these batteries.

# 2.2.Material synthesis

# 2.2.1.Preparation of ZIF-derived Bi-Bi2O3@Cs

As depicted in Fig.la, ZIF-derived $\mathtt { B i - B i _ { 2 } O _ { 3 } } @ \mathtt { C s }$ were prepared via conventional hydrothermal and calcination methods.To start with, $1 6 \mathrm { m m o l }$ of 2-methylimidazole was dissolved in $1 5 \mathrm { m L }$ of methanol with continuous stirring to prepare Solution A.Meanwhile, Solution B was prepared by gradually adding $0 . 4 \mathrm { m m o l }$ of $\mathrm { B i } ( \mathrm { N O } _ { 3 } ) _ { 3 }$ and 4 mmol of Zn $\mathrm { ( N O _ { 3 } ) _ { 2 } }$ to $3 0 \mathrm { m L }$ of methanol,after which it was ultrasonicated for $1 5 \mathrm { { m i n } }$ to ensure complete dissolution. Under vigorous stirring, Solution B was added dropwise to Solution Aata controlled slow rate,and the resulting mixture was continuously stirred at room temperature for $^ { 1 \mathrm { h } }$

The mixture was then placed into a $1 0 0 \mathrm { m L }$ Teflon-lined stainless steel autoclave and underwent hydrothermal treatmentat $1 2 0 ^ { \circ } \mathrm { C }$ for $4 \mathrm { h }$ in a convection oven. Subsequently，the product was isolated by centrifugation and washed three times with N,N-dimethylformamide (DMF) and twice with methanol.The purified product was subjected to vacuum drying at $7 0 ^ { \circ } \mathrm { C }$ overnight and designated as Bi-ZIF-8.

After drying,Bi-ZIF-8 was finely ground and placed into a ceramic boat.Finally, the samples were calcined in a tubular furnace at $8 5 0 ^ { \circ } \mathrm { C } ,$ $9 0 0 ^ { \circ } \mathrm { C } ,$ or $9 5 0 ^ { \circ } \mathrm { C }$ for $^ { 3 \mathrm { h } }$ under a nitrogen atmosphere to obtain Bi-$\mathrm { B i } _ { 2 } \mathrm { O } _ { 3 } @ \mathrm { C } s$ .The resulting products were labeled as $\mathbf { B i } – \mathbf { B i } _ { 2 } \mathbf { O } _ { 3 } @ \mathbf { C } – 8 5 0$ ,Bi-$\mathrm { B i } _ { 2 } \mathrm { O } _ { 3 } @ \mathrm { C } \cdot 9 0 0$ ,and $\mathbf { B i - B i _ { 2 } O _ { 3 } } @ \mathbf { C - } 9 5 0$ ,respectively.

To evaluate the charge-discharge performance of the Bi $- { \bf B i } _ { 2 } { \bf O } _ { 3 } @ { \bf C } /$ CFs,self-assembled laboratory VFB systems were tested using a Neware CT-3008 battery tester (5V/12A).The system,as illustrated in Fig.1b, consisted of two electrolyte reservoirs,a pipeline system and a flow cell. $$
\mathrm { C E } ( \% ) = \frac { \int I _ { \mathrm { d } } \mathrm { d t } } { \int I _ { \mathrm { c } } \mathrm { d t } } \times 1 0 0 \%
$$

$$
\mathrm { E E } ( \% ) = \frac { \int U _ { \mathrm { d } } I _ { \mathrm { d } } \mathrm { d t } } { \int U _ { \mathrm { c } } I _ { \mathrm { c } } \mathrm { d t } } \times 1 0 0 \%
$$

$$
\mathrm { V E } ( \% ) { = } \frac { \mathrm { E E } } { \mathrm { C E } } \times 1 0 0 \%

where I, t and $U$ respectively denote the current, time and voltage; the subscripts c and d are respectively the process of charging and discharging.

# 4. Conclusions

In this study,a bifunctional composite catalyst was first synthesized from a Bi-ZIF-8 precursor via a hydrothermal method followed by calcination.In this catalyst,metallic Bi plays a role in suppressing hydrogen evolution,while oxygen vacancies in $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ enhance catalytic activity.Subsequently,a systematic comparative analysis was performed on $\mathbf { B i - B i _ { 2 } O _ { 3 } @ C }$ samples carbonized at different temperatures, alongside bare carbon felt,to evaluate their performance. SEM images reveals that $\mathbf { B i - B i _ { 2 } O _ { 3 } @ C }$ carbonized at $9 0 0 ^ { \circ } \mathrm { C }$ exhibits a uniform and fine particle distribution. EDS analysis confirms the presence of C, O, N, and Bi elements in the l $\mathbf { 3 i - B i _ { 2 } O _ { 3 } @ C }$ composites.TEM characterization shows a structure of porous carbon-encapsulated metallic Bi nanoparticles.XRD results indicates that the composites mainly comprise nitrogen-doped amorphous carbon, $\mathrm { { B i _ { 2 } O _ { 3 } } , }$ and metallic Bi phases.XPS further verifies the elemental composition of the catalysts and reveals a higher concentration of oxygen-containing functional groups,graphitic nitrogen,and oxygen vacancies in I $\mathbf { 3 i - B i _ { 2 } O _ { 3 } } @ \mathbf { C - } 9 0 0$ .Contact angle and electrochemical measurements demonstrates that $\mathbf { B i - B i _ { 2 } O _ { 3 } } @ \mathbf { C } / \mathbf { C F - 9 } 0 0$ exhibits superior hydrophilicity,outstanding electrochemical activity, and effectively suppresses hydrogen evolution.Cell performance tests confirms the superior overall performance of $\mathbf { B i - B i _ { 2 } O _ { 3 } @ C / C F - 9 0 0 } ,$ achieving a coulombic efficiency of $9 7 . 3 \%$ and an energy efficiency $8 . 5 \%$ higher than that of bare carbon felt at a current density of $1 0 0 \mathrm { \ m A c m } ^ { - 2 }$ .Additionally,this catalyst enhances cell capacity,power output, high-current performance,and cycle stability.This work represents a significant advancement in VFB technology by developing an efficient catalyst that not only improves system performance but also facilitates broader practical applications.
