# 1．Introduction

Flow batteries [1-3],especially vanadium flow batteries (VFBs) [4-6],are regarded as one of the leading candidates for large-scale energy storage systems due to their advantages of safety and durability [7]. However,the commercial development of VFBs is hindered by the high price of the vanadium electrolyte [8].Therefore,researchers have increasingly focused on other sustainable and cost-effective flow battery systems.

Iron-titanium flow batteries (ITFBs) are one of the earliest flow batteries proposed by Thaller etal.,in 1974.The iron and titanium elements are abundant in nature, and $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ and $\mathrm { T i } ^ { 4 + } / \mathrm { T i } ^ { 3 + }$ couples exhibit good electrochemical activity.However, the titanium ion in $\mathrm { T i C l } _ { 4 }$ would hydrolyze into insoluble $\mathrm { T i O } _ { 2 }$ ,leading to the failure of the battery.The problem hindered their development for approximately 40 years.Until 2022,a new-generation ITFB was proposed by optimizing the electrolyte to address hydrolysis [9].The optimization markedly extended the cycle life of ITFBs,making ITFBs a promising candidate for flow batteries [10,11].

The membrane [12-16] is a crucial component in ITFBs,significantly influencing their performance. Commercialized Nafion membranes are extensively utilized in flow battery applications [17-19].However,their high cost and poor selectivity impede further development.Given the low-oxidizing environment of ITFBs,low-cost sulfonated poly (ether ketone）(SPEEK)[2O-23] is a promising candidate,which exhibits excellent stability in ITFBs.Regrettably,SPEEK membrane [24-28] with low sulfonation degree offers high ion selectivity yet low conductivity. High sulfonation degree enhances conductivity but decreases stability due to the severe swelling.To achieve high conductivity and high stability of SPEEK membranes [29-31],composite membranes are a

beneficial choice [12,32-34].

In this work,nanometer zirconium dioxide $\left( \mathrm { Z r O _ { 2 } } \right)$ [35] is doped into theSPEEK membrane to prepare the high-conductivityand high-stability composite membrane (Scheme 1).Benefiting from the high surface energy and abundant surface Lewis acid sites of nanometer $\mathrm { Z r O _ { 2 } }$ [36,37],rich hydroxyl(-OH) groups are observed on the surface of $\mathrm { Z r O } _ { 2 }$ ,so the hydrophilicity property of the SPEEK composite membrane is enhanced.Furthermore,the hydroxyl groups would be protonated and form positively charged “ $- \mathrm { [ O H _ { 2 } ] ^ { + , + , } }$ in the acidic electrolyte.The resultant“ $[ \mathrm { O H _ { 2 } } ] ^ { + , , }$ promotes the formation of hydrogen bonds and effectively accelerates proton transport via the Grotthuss mechanism. Meanwhile,the evenly distributed $\mathrm { Z r O _ { 2 } }$ in the pristine SPEEK membrane breaks the continuity of polymer chain segments,reducing swelling and enhancing the dimensional stability of the pristine SPEEK membrane. The SPEEK composite membrane exhibits higher proton conductivity and stability compared to the pristine SPEEK membrane.The ITFB assembled with the SPEEK composite membrane demonstrates excellent battery efficiency and cycling stabilityat high current densities.

For $S \mathrm { P } / \mathrm { Z r } { \mathrm { O } } _ { 2 }$ -X membranes in the electrolyte,“ $\mathrm { [ O H _ { 2 } ] ^ { + , } }$ groups of m-$\mathrm { Z r O _ { 2 } }$ would form hydrogen bonds with $_ \mathrm { H _ { 2 } O }$ or $\mathrm { \mathrm { ~ } } ^ { \ast } { \cdot } S \mathrm { O } _ { 3 } \mathrm { H } ^ { \prime }$ groups in SPEEK. Compared with the pristine SPEEK membrane,the addition of $\mathbf { m } { - } \mathbf { Z r } 0 _ { 2 }$ creates richer hydrogen bond networks by“ $\mathrm { [ O H _ { 2 } ] ^ { + , } }$ groups. Therefore, protons transfer quickly through hydrogen bond networks via the Grotthuss mechanism,which significantly reduces AR and improves proton conductivity.In addition,we compared the performance of ITFB with other low-cost flow batteries,as shown in Table S2,it can be seen that ITFB has excellent development prospects [44-51].

# 3．Conclusion

A high-conductivity and high-stability SPEEK composite membrane was prepared by introducing nanometer $\mathbf { m } { - } \mathbf { Z r } 0 _ { 2 }$ with rich Lewis acid sites.The introduction of $\mathbf { m } { - } \mathbf { Z r } 0 _ { 2 }$ improves the hydrophilicity and forms rich hydrogen bond networks in the SPEEK membrane by ‘ $\cdot _ { \mathrm { [ O H _ { 2 } ] } } + \cdot ,$ groups from the protonation of hydroxyl groups.The dense hydrogen bond networks provide more proton transfer channels,facilitating rapid proton transfer via the Grotthuss mechanism.Moreover,doped $\mathbf { m } { - } \mathbf { Z r } 0 _ { 2 }$ effectively regulates the distribution of SPEEK chain segments,inhibits excessive membrane swelling,and endows excellent stability. Consequently,the ITFB assembled with the SPEEK composite membrane exhibited excellent coulombic efficiency (CE, $9 9 ~ \%$ ）and voltage efficiency (VE, $8 1 . 7 \%$ ）at a current density of $4 0 \mathrm { m A } \mathrm { c m } ^ { - 2 }$ ,surpassing the performance of Nafion 115 (VE, $7 8 . 9 4 \ \%$ .During long-term cycling tests,the battery maintained stable VE over 5Oo charge-discharge cycles with no significant attenuation.All of these results indicate that the $\mathrm { Z r O _ { 2 } }$ -based SPEEK composite membrane is a promising candidate for the kW-level ITFB application.
