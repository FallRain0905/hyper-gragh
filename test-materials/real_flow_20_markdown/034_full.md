Iron-chromium redox flow battry (ICRFB)is cost-effective and stable,yet sufers from significant capacity decay due to the low redox reaction activity of $\mathrm { C r } ^ { 3 + } / \mathrm { C r } ^ { 2 + }$ and the hydrogen evolution reaction (HER). Herein, it is found that $0 . 2 \textbf { M }$ glycine as an electrolyte additive for ICRFB can effectively alleviate the capacity decay. Experimental tests and theoretical calculations demonstrate that glycine can regulate the solvation shellof $\mathrm { C r ^ { 3 + } }$ ， improving the redox reaction rate and difusion ability,thereby enhancing the ICRFB performance and reducing capacity decay.Glycine also displaces $\mathrm { H } ^ { + }$ ions on the surface of the negative electrode,thereby mitigating the HER. At $1 4 0 \mathrm { m A c m } ^ { - 2 }$ ,the ICRFB with pristine electrolyte ceased cycling after 190 cycles.In contrast, the ICRFB with $\mathbf { 0 . 2 M }$ glycine electrolyte can be cycled stably for 35O cycles,with energy efficiency decreasing by only $0 . 0 1 8 ~ \%$ per cycle and discharge capacity decreasing by only $1 . 2 5 \mathrm { \ m A h }$ per cycle.This study provides a promising strategy for developing long-life ICRFB and presents insights into the mechanism of action of the additives,thereby advancing research on ICRFB electrolyte additives.

# 1．Introduction

To solve the fossil energy crisis,the global demand for clean energy is increasing day by day [1]. Subsequently, large-scale,long-cycle,lowcost,and high-safety electrical energy storage devices have become the focus of the problem[2].Redox flow batteries (RFBs) are considered one of the best options for megawatt-scale energy storage [3].Unlike traditional battery systems [4],in RFBs,electrical energy is stored as chemical energy in a flowing electrolyte [5]. The energy storage capacity of RFBs is determined by the volume and concentration of the electrolyte,and the power of RFBs depends on the number of individual cells and the size of the electrodes [6].This ability to decouple the storage capacity and power of RFBs makes these devices particularly suitable for large-scale applications [7].Among these,the ironchromium redox flow battery (ICRFB) is highly cost-effective by utilizing low-cost and abundantly available ferrous chloride and chromium chloride as redox active materials,making it stand out among various RFBs [8].However, the reaction kinetic constant of the $\mathrm { C r } ^ { 3 + } / \mathrm { C r } ^ { 2 + }$ redox pair in ICRFB is $2 . 2 \times 1 0 ^ { - 5 } \mathrm { c m } s ^ { - 1 }$ [9], significantly lower than the $8 . 6 \times$ $\overline { { 1 0 ^ { - 2 } } } \mathrm { c m } s ^ { - 1 }$ of the $\mathrm { F e } ^ { 2 + } / \mathrm { F e } ^ { 3 + }$ redox pair [1O]. The low electrochemical activity of the $\mathrm { C r } ^ { 3 + } / \mathrm { C r } ^ { 2 + }$ redox pair and severe side reactions (hydrogen evolution reaction, HER) in ICRFB result in significant capacity decay and short cycle life for ICRFBs [11].

Various methods have been proposed to enhance the electrochemical kinetics of the $\mathrm { C r } ^ { 3 + } / \mathrm { C r } ^ { 2 + }$ redox pair. In 1983,NASA first proposed operating the ICRFB with a mixed electrolyte at $6 5 ~ ^ { \circ } \mathrm { C }$ [12]. While the electrochemical performance of the ICRFB has been somewhat enhanced,the slow kinetics of $\mathrm { C r } ^ { 3 + } / \mathrm { C r } ^ { 2 + }$ in the electrolyte and the significant HER,which severely limit the performance of the ICRFB,still need to be addressed.Many researchers enhanced the activity of the $\mathrm { C r } ^ { 3 + } / \mathrm { C r } ^ { 2 + }$ redox pair by modifying the electrode through heat treatment [13],acid treatment [14],or catalyst loading [15].However,heattreated and acid-treated electrodes still lead to severe HER.Meanwhile,the stability of the catalysts under strong acid conditions and the risk of blocking the channels during electrolyte flow limit the wide application of the catalysts [16].

In fact,electrochemical reactions occur at the electrode/electrolyte interface,and in addition to modifying the electrode,researchers have begun to modify the electrolyte to address these issues.According to previous studies,the electrochemical activity of the $\mathrm { C r } ^ { 3 + } / \mathrm { C r } 2 ^ { + }$ redox pair largely depends on its solvation shell[17].When the ligand of $\mathrm { C r } ^ { 3 + }$ changes from $\mathrm { C l ^ { - } }$ to $\mathrm { H _ { 2 } O _ { 3 } }$ ， $\mathrm { C r ^ { 3 + } }$ will be surrounded by $_ \mathrm { H _ { 2 } O }$ within the first solvation shell [18].Its charge transfer ability will be reduced, thereby leading to poor electrochemical activity.Therefore,to adjust the solvation shell of $\mathrm { C r ^ { 3 + } }$ , researchers have explored various approaches to reshape it.The first strategy involves adding additives to the electrolyte. Ye et al.optimized the electrolyte with appropriate inorganic salt additives,increasing the number of active species.The energy efficiency (EE)of ICRFB was increased from $7 8 . 4 6 ~ \%$ to $8 3 . 0 7 ~ \%$ at $4 0 \ \mathrm { m A } \ \mathrm { c m } ^ { - 2 }$ [19].However,the low current density during prolonged charging and discharging limits the further application of ICRFB.Li et al. used $0 . 4 \mathrm { M }$ guanidine hydrochloride as an electrolyte additive to modify the solvation shell of $\mathrm { C r ^ { 3 + } }$ and enhance its electrochemical reactivity [20]. Although the EE increased by $6 \%$ ,the rapid capacity decayhindered the long-term stability of the ICRFB.Su etal.enhanced the electrochemical performance of the ICRFB by incorporating high-entropy oxides into the electrolyte [21]．Although the charging and discharging capacity increased,the EE remained below $7 6 \ \%$ at $7 0 \ \mathrm { m A } \ \mathrm { c m } ^ { - 2 }$ ，significantly limiting the feasibility of large-scale ICRFB deployment. The second strategy involves adjusting the ratio of ${ \mathrm { F e C l } } _ { 2 } ,$ $\mathrm { C r C l } _ { 3 }$ ，and HCl in the electrolyte.Based on the capacity decay mechanism of ICRFB,Wu et al. increased active species content by adjusting the $\mathrm { F e C l _ { 2 } } / \mathrm { C r C l _ { 3 } }$ ratio, reducing capacity decay [22].Therefore,reshaping the solvation shell of $\mathrm { C r ^ { 3 + } }$ is crucial for enhancing its electrochemical activity [23].Additionally,the HER occurs at the electrode/electrolyte interface.The first step of HER,no matter how the consecutive reaction will proceed,is adsorption of $\mathrm { H } ^ { + }$ on the electrode surface by transferring a proton from the acid electrolyte that combines with an electron transferred through the electrode surface,known as the Volmer reaction [24].Therefore, modulating the concentration of $\mathrm { H } ^ { + }$ near the electrode is an effective strategy to regulate the HER.

Due to the low cost and simple operation,adding electrolyte additives appears to be an effective way to improve the performance of ICRFB. Organic additives have attracted attention due to their high solubility in aqueous media and unique regulatory mechanisms [25]. Generally speaking,most organic electrolyte additives have an affinity for metal ions,thereby modulating the solvation shell of metal ions [26]. Therefore,itis highly significant to develop a suitable organic substance asan additive for ICRFB electrolyte.

In this study,glycine (Gly) was selected as an electrolyte additive, and its regulatory mechanism in ICRFBs was systematically investigated. Through experimental tests and theoretical calculations,Gly demonstrated two synergistic mechanisms to enhance the $\mathrm { C r } ^ { 3 + }$ redox reaction rate and inhibit the HER.(1) Molecular dynamics (MD) simulations, density functional theory (DFT) calculations,and electrochemical tests indicated that Gly increased the diffusion coefficient of reactive ions in the electrolyte,reshaped the solvation shell of $\mathrm { C r ^ { 3 + } }$ ,and enhanced the electrochemical activity of the $\mathrm { C r } ^ { 3 + } / \mathrm { C r } ^ { 2 + }$ redox pair. (2) Constant potential MD simulations and linear sweep voltammetry (LSV) results confirmed that Gly preferentially adsorbs onto the negative electrode, displacing $\mathrm { H } ^ { + }$ from the electrode surface,thereby suppressing HER and mitigating capacity decay.Within the first 1Oo cycles,the capacity decay rate of ICRFB with $\mathbf { 0 . 2 M }$ Gly electrolyte $( 2 . 0 5 \mathrm { m A h }$ per cycle) was significantly lower than that with the pristine electrolyte ( $3 . 4 3 \mathrm { m A h }$ per cycle). Over 350 cycles,the EE of the ICRFB with $0 . 2 \mathrm { M }$ Gly electrolyte decreased by only $0 . 0 1 8 ~ \%$ per cycle,while capacity decayed by 1.25 mAh per cycle.However,the ICRFB with the pristine electrolyte ceased cycling after 190 cycles.The addition of Gly significantly enhances ICRFB cycling performance and reduces capacity decay.This provides a promising avenue for the development of electrolyte additives for the ICRFB.

# 2.Methods and experiments

# 2.1． Preparation of electrolytes

All reagents used in this study were of analytical grade or guaranteed purity.Electrolytes were prepared using tetrahydrate ferrous (II) chloride $\mathrm { ( F e C l _ { 2 } { \cdot } 4 H _ { 2 } O }$ ，AR,Macklin Co.,Ltd.),hexahydrate chromium (III) chloride $\mathrm { ( C r C l _ { 3 } . 6 H _ { 2 } O }$ ,AR,Macklin Co.,Ltd.),glycine (Gly,AR,Macklin Co.,Ltd.) and hydrochloric acid (HCl,AR, Sinopharm Co.,Ltd.). The cathode and anode electrolytes contained $1 . 0 \mathrm { ~ M ~ }$ $\mathrm { F e C l } _ { 2 } { \cdot } 4 \mathrm { H } _ { 2 } 0$ ， $1 . 3 \mathrm { ~ M ~ }$ $\mathrm { C r C l } _ { 3 } { \cdot } 6 \mathrm { H } _ { 2 } 0$ ,and 3 MHCl. Subsequently,Gly at concentrations of $0 . 1 \mathbf { M }$ ， $0 . 2 \ : \mathrm { M } , 0 . 3 \ : \mathrm { M }$ and $\mathbf { 0 . 4 M }$ was added to the pristine electrolyte to prepare both cathode and anode electrolytes.Each electrolyte was sealed and stirred at room temperature $( 2 5 ^ { \circ } \mathsf { C } )$ for $^ { 2 \mathrm { ~ h ~ } }$

# 2.2.Physicochemical characterizations

Electrolyte viscosity was measured using a Ubbelohde viscometer at $6 5 \pm 2 { \mathrm { ~ } } ^ { \circ } \mathrm { C } .$ 、At the same temperature,conductivity meter (DDSJ-308F, Shanghai Thunder Magnetic Instrument) was used to measure electrolyte conductivity.The FTIR (FTIR-150o,JOSVOK) which was conducted in the range of $4 0 0 { - } 4 0 0 0 ~ \mathrm { c m } ^ { - 1 }$ was used to characterize different electrolytes and verify the coordination structure of the sample.

# 2.3.Electrochemical measurements

All electrochemical tests were conducted on the Chenhua Electrochemical Workstation (CHI 76OE,Shanghai,China) to evaluate the electrochemical performance.Glassy carbon electrode (diameter of 3 mm) was used as the working electrode,platinum electrode was used as the counter electrode,and saturated calomel electrode was used as the reference electrode. Cyclic voltammetry (CV),linear sweep voltammetry (LSV),and electrochemical impedance spectroscopy (EIS) measurements were conducted in $8 0 ~ \mathrm { m L }$ of electrolyte at $6 5 \pm 2 ^ { \circ } \mathrm { C }$ in air. LSV plots were recorded at a scan rate of $1 0 \mathrm { m V } s ^ { - 1 }$ .EIS measurements were conducted at the DC voltages of $- 0 . 4 5 \mathrm { ~ V ~ }$ and $_ { 0 . 5 \mathrm { ~ V ~ } }$ ,with a frequency range of $1 0 0 ~ \mathrm { k H z }$ to $0 . 0 1 ~ \mathrm { H z }$ and a $5 \ \mathrm { m V }$ amplitude.The results were fitted using ZView software.

# 2.4.ICRFB single cell test

The single cell of the ICRFB included two polytetrafluoroethylene (PTFE) backplates,two floating frames,two graphite bipolar plates,and two copper current collectors.Nafion 212 membrane served as the separator and was soaked in deionized water for $^ { 1 2 \mathrm { ~ h ~ } }$ prior to use to facilitate swelling. Carbon cloth (size: $5 \ \mathrm { c m } \times 2 \ \mathrm { c m } )$ ）was used as the electrodes,which were pretreated at $5 0 0 ~ ^ { \circ } \mathrm { C }$ in a tube furnace for $^ { 5 \mathrm { ~ h ~ } }$ before use.The cell was connected to two electrolyte storage bottles. The volume of both positive and negative electrolytes was $3 0 ~ \mathrm { m L }$ .Electrolytes were pumped on both sides ata flow rate of $2 0 \mathrm { m L } \mathrm { m i n } ^ { - 1 }$ . The cell was tested within a voltage range of 0.7 to $1 . 2 \mathrm { V }$ ,with a current density of $1 4 0 \mathrm { \ m A \ c m ^ { - 2 } }$ and test temperature of $6 5 \pm 0 . 5 ^ { \circ } \mathrm { C }$

The coordination number of $\mathrm { C r ^ { 3 + } { - } C l ^ { - } }$ decreased to 3.78,while that of $\mathrm { C r ^ { 3 + } }$ $_ \mathrm { H _ { 2 } O }$ decreased to O.74 after theaddition of 0.2MGly.The number of $\mathrm { C l ^ { - } }$ ions in the first solvation shell of $\mathrm { C r ^ { 3 + } }$ is largely unaffected by the addition of Gly.However, the first sharp peak of $\mathrm { C r } ^ { 3 + } { - } \mathrm { C l } ^ { - }$ shifts from $2 . 3 5 \mathring { \mathrm { A } }$ to $2 . 1 5 { \overset { \circ } { \mathrm { A } } } .$ This is due to a significant reduction of $_ \mathrm { H _ { 2 } O }$ in the first solvation shell of $\mathrm { C r ^ { 3 + } }$ ,which decreases the site-blocking effect,making $\mathrm { C l ^ { - } }$ easier to approach $\mathrm { C r ^ { 3 + } }$ .The loss of the charge transfer path, caused by $\mathrm { C r ^ { 3 + } }$ being tightly solvated by $\mathrm { H _ { 2 } O }$ ,reduces its electrochemical activity.Therefore,the reduction of the number of $_ \mathrm { H _ { 2 } O }$ in the first solvation shell of $\mathrm { C r } ^ { 3 + }$ enhances its electrochemical activity. As shown in Fig. S7a-b, the coordination number of $\mathrm { F e } ^ { 2 + }$ -Cl- in the solvation shell of $\mathrm { F e } ^ { 2 + }$ is largely unaffected by the addition of glycine.In contrast, the coordination number of $\mathrm { F e } ^ { 2 + } { \cdot } \mathrm { H } _ { 2 } \mathrm { O }$ slightly decreased with the addition of Gly.Therefore,Gly primarily affects the solvation shell of $\mathrm { C r ^ { 3 + } }$ and enhances its electrochemical activity.This explains the substantial decrease in charge transfer resistance of $\mathrm { C r ^ { 3 + } }$ observed in the EIS test in the presence of Gly.

The binding energies between $_ \mathrm { H _ { 2 } O }$ and $\mathrm { \ G l y ^ { + } }$ were further analyzed using DFT calculations.As shown in Fig.3c,the binding energy of $\mathrm { H _ { 2 } O } \cdot$ $_ \mathrm { H _ { 2 } O }$ $\left( - 1 0 . 6 4 \mathrm { k c a l / m o l } \right)$ is much larger than that of $\mathrm { H _ { 2 } O - G l y ^ { + } }$ (-16.42 $\mathbf { k c a l / m o l } \mathrm { \Omega }$ , suggesting a ligand interaction between the oxygen atoms of $\mathrm { \ G l y ^ { + } }$ and the hydrogen atoms of $_ \mathrm { H _ { 2 } O }$ (Fig.S8). This disruption of intrinsic $_ { \mathrm { H _ { 2 } O - H _ { 2 } O } }$ interactions improves the hydrogen bonding network of the electrolyte.The effect of Gly on the molecular structure of $_ \mathrm { H _ { 2 } O }$ was investigated by FTIR spectroscopy.As shown in Fig.3d and Table S3, the O-H stretching vibrational modes $( 3 2 0 0 - 3 4 0 0 \mathrm { c m } ^ { - 1 } . $ were blueshifted with increasing Gly concentration, indicating a significant strengthening of the O-H covalent bonds in $_ \mathrm { H _ { 2 } O }$ molecules [38].With the addition of Gly,the absorption intensity in the region of $3 0 0 0 \sim$ $3 4 0 0 ~ \mathrm { { c m } ^ { - 1 } }$ decreased and a shoulder peak gradually appeared at 3600 $\mathrm { c m } ^ { - 1 }$ ,indicating a weakening of hydrogen bonds and an increase in the number of free water molecules in the electrolyte.To further analyze the hydrogen bonding states,we classified the O-H stretching vibrations into three categories: strong $( 3 2 8 0 \mathrm { c m } ^ { - 1 } )$ ,moderate $( 3 4 7 0 ~ \mathrm { c m } ^ { - 1 } )$ ,and weak $( 3 5 9 0 ~ \mathrm { c m } ^ { - 1 } )$ hydrogen bonds and quantified their ratios based on the deconvolution peak areas [39]. In the pristine electrolyte,strong hydrogen bonds accounted for approximately $9 0 . 0 4 ~ \%$ of the total area (Fig.3e),suggesting the presence of a robust network that could influence ion mobility and electrochemical reaction kinetics.However,with the addition of $0 . 2 \mathrm { ~ M ~ }$ Gly,the proportion of strong hydrogen bonds decreased to $8 6 . 2 7 ~ \%$ (Fig.3f). These results suggest that the introduction of Gly effectively reconfigured the hydrogen bonding network in the aqueous solution of the electrolyte and enhanced the ion transfer kinetics.

Since the HER primarily occurs at the electrode/electrolyte interface, constant potential MD simulations were employed to model this interface.The model developed is shown in Fig.S9.To better illustrate the arrangement of $\mathrm { H } ^ { + }$ and $\mathrm { \ G l y ^ { + } }$ at the electrode/electrolyte interface,other molecules and ions were omitted from the final diagram.As shown in Fig.3g,the left side shows the pristine electrolyte,where a large number of $\mathrm { H } ^ { + }$ ions are arranged on the electrode surface.On the right side, containing $0 . 2 \textbf { M }$ Gly， $\mathrm { \ G l y ^ { + } }$ preferentially adsorbs onto the negative electrode surface,displacing $\mathrm { H } ^ { + }$ and reducing the local $\mathrm { H } ^ { + }$ number density.As shown in Fig.3h-i, the peak of $\mathrm { \ G l y ^ { + } }$ is located at $- 4 . 5 7 \ : \mathrm { n m }$ ， closer to the negative electrode than that of $\mathrm { H } ^ { + } \left( - 4 . 3 1 \mathrm { n m } \right)$ .The number of $\mathrm { H } ^ { + }$ ions near the negative electrode was significantly reduced when $\mathbf { 0 . 2 M }$ Gly was introduced.Thus, $\mathrm { { G l y } ^ { + } }$ reduces the number of $\mathrm { H } ^ { + }$ ions by occupying part of the negative electrode surface,thereby inhibiting HER by reducing the probability of proton-electron recombination at the electrode surface.

Cycling stability tests were conducted on the pristine electrolyte and the electrolyte with $0 . 2 \mathrm { ~ M ~ }$ Gly at a current density of $1 4 0 \mathrm { \ m A \ c m ^ { - 2 } }$ Fig.4a displays the charge/discharge curve at the 1ooth cycle.The discharge capacity of the ICRFB with $0 . 2 \mathrm { ~ M ~ }$ Gly $( 3 6 7 . 8 ~ \mathrm { { m A h } ) }$ was1.91 times that of the ICRFB with the pristine electrolyte $( 1 9 2 . 7 ~ \mathrm { m A h } )$ .The capacity decay rate of the ICRFB with $0 . 2 \mathrm { ~ M ~ }$ Gly (2.05 mAh per cycle) was significantly lower than that of the pristine electrolyte $( 3 . 4 3 ~ \mathrm { m A h }$ per cycle) (Fig.4b).After 1O0 cycles,the discharge capacity retention rate for the ICRFB with $0 . 2 \mathrm { ~ M ~ }$ Gly was $6 4 . 2 6 ~ \%$ ,markedly higher than the $3 5 . 9 6 ~ \%$ retention rate of the ICRFB with the pristine electrolyte. These results indicate that adding Gly to the electrolyte slows down the capacity decay of the ICRFB.The mean values of CE,VE,and EE for the first10O cycles are shown in Fig.4c.For the ICRFB with $_ { 0 . 2 \mathrm { ~ M ~ } }$ Gly, the mean CE,VE,and EE were $9 8 . 4 7 \%$ ， $8 3 . 6 6 \%$ ,and $8 2 . 3 8 \%$ ,respectively. In contrast,for the ICRFB with the pristine electrolyte,the mean CE, VE, and EE were $9 7 . 6 5 ~ \%$ ， $7 9 . 3 5 ~ \%$ ，and $7 7 . 4 8 ~ \%$ ,respectively.Long-term cycling stability is a critical factor for the practical application of ICRFBs.As shown in Fig.4d-e,long-cycle performance tests were performed on both the pristine electrolyte ICRFB and the ICRFB with $0 . 2 \mathrm { M }$ Gly electrolyte at $1 4 0 \mathrm { m A c m } ^ { - 2 }$ .The ICRFB with the pristine electrolyte ceased cycling after 190 cycles,showing an average decrease in EE of $0 . 0 3 9 6 \ \%$ percycle and a capacity decay of $2 . 1 7 \ \mathrm { m A h }$ per cycle.The ICRFB with $0 . 2 \mathrm { ~ M ~ }$ Gly electrolyte operated stably for over 350 cycles, with a stable CE.The EE decreased slightly from $8 3 . 5 9 ~ \%$ to $7 7 . 2 1 \ \%$ ， showing an average decrease of $0 . 0 1 8 ~ \%$ per cycle. Capacity decay remained stable,decreasing from $5 7 2 . 4 ~ \mathrm { m A h }$ to $1 3 4 . 3 ~ \mathrm { m A h }$ ，withan average decay of $1 . 2 5 ~ \mathrm { m A h }$ per cycle.The long-term cycling performance of the ICRFB with $0 . 2 \mathbf { M }$ Gly electrolyte is significantly superior to that of the pristine electrolyte ICRFB.A comparison of key performance parameters with the results of recent research on electrolyte modification in ICRFB (Fig.S1O) shows that the ICRFB with $0 . 2 \mathbf { M }$ Gly electrolyte holds great potential for electrochemical energy storage applications.

# 4.Conclusion

This paper systematically investigates the regulatory mechanism of Gly as an electrolyte additive for ICRFB through experimental tests and theoretical calculations.MD simulations calculated the difusion coefficients of various ions in electrolytes with varying Gly concentrations, showing enhanced diffusion coefficients for all three ions with the addition of Gly.The addition of Gly enhanced the electrochemical activity of $\mathrm { F e } ^ { 2 + } / \mathrm { F e } ^ { 3 + }$ and $\mathrm { C r } ^ { 3 + } / \mathrm { C r } ^ { 2 + }$ redox pairs,as confirmed by CV and EIS tests.EIS data analysis concluded that the enhancement of electrochemical activity resulted from the significant reduction of $\mathrm { R _ { c t } }$ and W with the addition of Gly.This effectively increased the charge transfer rate of $\mathrm { C r ^ { 3 + } }$ in the electrolyte.MD simulations also concluded that Gly reduced the average number of $_ \mathrm { H _ { 2 } O }$ in the first solvation shell of $\mathrm { C r } ^ { 3 + }$ This results in a more unbalanced charge around $\mathrm { C r ^ { 3 + } }$ ，promoting electron transfer and accelerating the redox reaction rate.The mechanism of HER mitigation by Gly was demonstrated through constant potential MD simulations and LSV curves.In the single cell test,the best performance was observed with the addition of $0 . 2 \mathrm { ~ M ~ }$ Gly.During the first 100 cycles,the capacity decay rate of the ICRFB with $0 . 2 \mathrm { ~ M ~ }$ Gly electrolyte( $2 . 0 5 \mathrm { m A h }$ per cycle) was significantly lower than that of the ICRFB with the pristine electrolyte $( 3 . 4 3 \mathrm { m A h }$ per cycle). Over 350 cycles,the EE of the ICRFB with $0 . 2 \mathrm { ~ M ~ }$ Gly electrolyte decreased by only $0 . 0 1 8 \%$ percycle.The discharge capacity decayed byonly $1 . 2 5 \mathrm { m A h }$ per cycle.This work systematically reveals the regulatory mechanism of ICRFB electrolyte additives and provides a new strategy for future optimization of ICRFB electrolytes.
