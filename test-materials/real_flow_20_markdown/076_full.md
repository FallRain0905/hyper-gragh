All-iron Redox Flow Batteries (AIRFBs)are promising large-scale energy storage systems due to their low cost and chemical symmetry.However,their performance is largely limited by the slow kinetics of the $\mathrm { F e } ^ { 3 + } | \mathrm { F e } ^ { 2 + }$ redox couple in the posolyte,and the posolyte's stability window.A good electrolyte for AIRFBs must combine fast and reversible charge-transfer kinetics,high selectivity toward the $\mathrm { F e } ^ { 3 + } | \mathrm { F e } ^ { 2 + }$ reaction, high ionic conductivity,and eficient mass transport.This study systematically investigates how the electrolyte type (chloride and sulphate)and acidity affect the key electrochemical parameters of the $\mathrm { F e } ^ { 3 + } | \mathrm { F e } ^ { 2 + }$ redox couple,namely the standard heterogeneous rate constant $( k ^ { 0 } )$ ,the charge transfer coeficient $( \alpha )$ ,the diffusion coefficient $( D )$ ,and theconductivity (A).A multifactorial experimental design was used,and an ANalysis Of VAriance (ANOVA) was carried out to identify the statistically significant efects ofboth factorsand their interaction on the aforementioned electrochemical parameters.The ANOVA results show a statistically significant difference in the chargetransfer process between chloride-and sulphate-based electrolytes: the electrolyte type primarily controls electron-transfer kinetics,with chloride medium markedly enhancing $k ^ { 0 }$ ；while acid concentration mainly affects $D$ and Λ.Among the tested formulations,1 M HCl exhibited the best compromise between $\mathrm { F e } ^ { 3 + } | \mathrm { F e } ^ { 2 + }$ kinetics, mass transport,and an adequate stability window.These insights provide a quantitative basis for electrolyte optimization and support the rational design of improved AIRFB posolytes.

# 1． Introduction

As the global demand for clean energy continues to grow,renewable energy sources such as solar and wind are becoming increasingly important [1].However,their intermittent nature poses challenges for reliable power supply,making efficient energy storage technologies critical [2]. The transition to a sustainable, renewables-based energy infrastructure demands scalable and cost-effective energy storage solutions.Among available options,Redox Flow Batteries(RFBs） have emerged as promising candidates for large-scale grid energy storage due to their flexible design,long cycle life,and the decoupling of energy and power [3-6].

Among the various chemistries explored for RFBs,All-Iron Redox Flow Batteries (AIRFBs) have garnered increasing attention due to the low cost, high abundance,safety and low environmental impact of iron [7,8].These features make iron an attractive alternative to other chemistries commonly used in RFBs,such as all-vanadium or cerium.In

AIRFBs,both half cells are based on redox couples involving iron in its different oxidation states,which minimizes cross-contamination and lowers the electrolyte cost [9].

During battery discharge,on the negolyte side,metallic iron $( \mathrm { F e } ^ { 0 } )$ is oxidized to ferrous iron $( { \mathrm { F e } } ^ { 2 + } )$ (Eq (1).,standard potential $E ^ { 0 }$ ： $- 0 . 4 4 \mathrm { ~ V ~ }$ vs RHE);while on the posolyte side,ferric iron $( { \mathrm { F e } } ^ { 3 + } )$ is reduced to ferrous iron $( { \mathrm { F e } ^ { 2 + } } ) ( { \mathrm { E q } } ( 2 )$ ,standard potential $E ^ { 0 }$ ： $+ 0 . 7 7 \mathrm { V }$ Vs RHE) [10]. Conversely,during battery charge,ferrous iron $( \mathrm { F e } ^ { 2 + } )$ is reduced to metallic iron $( \mathrm { F e } ^ { 0 } )$ in the negolyte and oxidized to ferric iron $( \mathrm { F e } ^ { 3 + } )$ in the posolyte,thereby storing electrical energy in the system.

$$
\begin{array} { l } { { F e {  } ~ F e ^ { ~ 2 + } + ~ 2 ~ e ^ { - } } } \\ { { \ } } \\ { { F e ^ { ~ 3 + } + ~ e ^ { - }  { } } } \end{array}
$$

However,AIRFBs face some limitations that hinder their performance and commercial viability,including the limited solubility of $\mathrm { F e } ^ { 3 + }$ ions in aqueous solutions,low energy density,and reduced coulombic efficiency due to parasitic side reactions [11-13].

The limited solubility of ferrc species in aqueous electrolytes con-strains the concentration of active material, resulting in low energy densities,typically below $2 5 \ \mathrm { W h { \cdot } L ^ { - 1 } }$ [11,12]. Moreover, $\mathrm { F e } ^ { 3 + }$ ions are only stable under strongly acidic conditions $\mathrm { ( p H } < 3 \mathrm { ) }$ ,since higher pH values promote hydrolysis and precipitation of iron hydroxides,thereby restricting the operational range [14].Another significant drawback of AIRFBS is their low coulombic efficiency $( \sim 6 5 - 8 0 \% )$ [15-18] which is mainly caused by parasitic side reactions such as hydrogen gas evolution in the posolyte half-cell during charging,which competes with the $\mathrm { F e } ^ { 3 + } |$ $\mathrm { F e } ^ { 2 + }$ redox process [12].

One possible way to address these challenges is to optimize the electrolyte,particularly the posolyte [16]. The desired properties of an AIRFB posolyte include:(1) fast and reversible kinetics of the $\mathrm { F e } ^ { 3 + } | \mathrm { F e } ^ { 2 + }$ electrochemical reaction,in order to minimize the activation overpotential; (2) high selectivity towards the $\mathrm { F e } ^ { 3 + } | \mathrm { F e } ^ { 2 + }$ reaction, in order to avoid parasitic side reactions such as gas evolution,and maximize the Faradaic efficiency;(3) high mass transport rates,in order to reduce concentration overpotentials;and (4) high ionic conductivity,in order to minimize the ohmic overpotential [19,20].

Chloride and sulphate-based electrolytes are the most widely investigated systems for AIRFBs due to their ability to stabilize iron species and influence their redox kinetics [12,18,21].Nevertheless,despite their widespread use,direct and systematic comparisons of the electrochemical behavior between chloride and sulphate electrolytes under different $\mathsf { p H }$ values remain scarce in the literature.Despite extensive research,the literature shows considerable variability in the reported kinetic parameters,even for the same electrode materials [l3].This variability complicates the identification of clear correlations between electrolyte composition,pH,and kinetic parameters.Reported standard heterogeneous rate constants for the $\mathrm { F e } ^ { 3 + } | \mathrm { F e } ^ { 2 + }$ reaction range from $1 0 ^ { - 5 }$ to $1 0 ^ { - 1 } \mathrm { c m } { \cdot } s ^ { - 1 }$ ,while the reported charge transfer coefficients also show a significant variation [22-26].This variability has been attributed to the strong dependence of the electrokinetic parameters on the electrode material, surface structure,and pretreatment,which are not consistently controlled or reported across studies [13,27].As a result,the intrinsic role of the electrolyte anion in modulating $\mathrm { F e } ^ { 3 + } | \mathrm { F e } ^ { 2 + }$ kinetics remains unresolved.To overcome these limitations,the present work performs a simultaneousandcontrolledcomparisonofchloride-and sulphate-based electrolytes using identical electrode materials,preparation protocols,and measurement conditions,thereby removing the major sources of variability highlighted in previous studies.Furthermore,a statistical analysis is applied to determine whether the differences observed between both electrolyte types are genuinely significant or fall within typical experimental noise.

The goal of this study is to investigate the effect of the electrolyte type (chloride and sulphate) and the $\mathtt { p H }$ on the $\mathrm { F e } ^ { 3 + } | \mathrm { F e } ^ { 2 + }$ redox reaction by examining their influence on 4 response variables: the standard heterogeneous rate constant $( k ^ { 0 } )$ and the charge transfer coefficient $( \alpha )$ ， which determine the kinetics and reversibility of the reaction; the diffusion coefficient $( D )$ ，which governs mass-transport;and the electrolyte conductivity $( \Lambda )$ ,which controls ohmic losses.

The main novelty of this work is the application of a statistical approach to address the significant variability introduced by the electrode surface state,which strongly aects the electrochemical parameters [13,28,29].By conducting a large number of repeated experiments under controlled conditions,a comprehensive dataset was experimentally generated and analyzed using ANalysis Of VAriance (ANOVA).This methodology enabled a rigorous and quantitative evaluation of the effect of the electrolyte type (sulphate and chloride)and the pH on the parameters that define the electrochemical performance of the electrolyte as AIRFB posolyte.

# 2.3.Electrochemical characterization

The electrochemical characterization was conducted using a threeelectrode configuration cell $( V = 1 0 0 ~ \mathrm { m L } )$ ,using a platinum counter electrode (CE) (Crison),a glassy carbon Working Electrode (WE),and a $3 \mathrm { M A g / A g C l }$ reference electrode (Metrohm).The working electrode had a surface area of $7 . 1 0 \mathrm { m m } ^ { 2 }$ ,while the counter electrode area was 113.10 $\mathrm { m m } ^ { 2 }$ .All the experiments were performed at a constant temperature of ${ 2 5 \ ^ { \circ } \mathrm { C } } ,$ ，that was controlled using a thermostatic bath (Digiterm-100, Selecta).All the electrochemical measurements were performed using anAutolab $^ \mathrm { \textregistered }$ PGSTAT302Npotentiostat/galvanostat(Metrohm) controlled with NOVA $1 . 1 0 \mathbb { R }$ software.

Given the high sensitivity of electrochemical kinetics to the electrode's surface condition,a pretreatment procedure was applied to ensure reproducibility [3O]:prior to each measurement, the WE was initially rinsed with DI for $5 \ \mathrm { m i n }$ .Then,the cell was filled with $^ { 3 \mathrm { ~ M ~ } }$ $\mathrm { H } _ { 2 } \mathrm { S O } _ { 4 }$ and an electrochemical activation was carried out [13,3O].This activation consisted in a first Cyclic Voltammetry (CV) scan of 100 cycles from $- 0 . 2 5 \mathrm { V }$ to $_ { 1 . 5 \mathrm { V } }$ vs.Ag/AgCl(3 M),at a scan rate of $2 0 0 \mathrm { m V } { \cdot } s ^ { - 1 }$ followed by a second CV of 20 cycles in an extended potential window from $- 0 . 2 5 \mathrm { V }$ to 1.7V vs.Ag/AgCl (3 M),at the same scan rate.After this pretreatment, the cell was filled with $1 0 0 \mathrm { m L }$ of the electrolyte that was going to be studied in that particular measurement.

CV was used to obtain kinetic and mass transport parameters $( k ^ { 0 } , \alpha$ and $D _ { \epsilon } ^ { \dagger }$ )，which were calculated using the theoretical framework described in the SI. CVs were recorded in a potential window ranging from $^ { - 0 . 1 }$ to $+ 1 . 0 \mathrm { V }$ vs. Ag/AgCl (3 M),at scan rates from 5 to $1 0 0 \mathrm { m V } { \cdot } s ^ { \cdot }$ 1.For each scan rate,three complete cycles were measured in order to obtain the limit cycle.All CVs were corrected for the ohmic drop (i-R correction).The uncompensated resistance $\left( \mathrm { R } _ { 0 } \right)$ that was used to perform the i-R correction,was measured by Electrochemical Impedance Spectroscopy (EIS).EIS measurements were performed at OCP using a $1 0 ~ \mathrm { m V }$ AC perturbation over a frequency range of $1 0 \mathrm { k H z }$ to 10 $\mathrm { m H z }$

In addition， linear sweep voltammetry (LV） was conducted to evaluate the electrochemical stability window of each electrolyte.LVs were measured at a scan rate of $1 \ \mathrm { m V } \cdot s ^ { - 1 }$ ,in order to obtain the steadystate LVs.

The conductivity of each electrolyte was measured using a Crison Basic 3O conductivity meter.Each reported value corresponds to the mean of five independent measurements.

# 2.4.Statistical analysis

Each response variable $( \alpha , \ k ^ { 0 }$ ， $D$ and $\Lambda$ ）was analyzed using a multifactor ANalysis Of VAriance (ANOVA) to evaluate whether the mean values of the response variables were significantly influenced by the main factors and their interaction. The full factorial design, including all the combinations of factor levels and 3 replications,provided sufficient residual degrees of freedom to ensure the statistical powerand reliability of the ANOVA models.

The validity of each ANOVA was assessed by verifying that the model meets the key assumptions of normality of the residuals, independence, and homoscedasticity.The independence of the observations was assessed by applying the Ljung-Box test to the residuals,to detect autocorrelation.The normality of the residuals was evaluated using the Shapiro-Wilk and Kolmogorov-Smirnov tests and further confirmed visually through Q-Qplots.And finally,the homoscedasticity (i.e.equal variance across groups) was tested by performing a multiway ANOVA on the squared residuals.

All the statistical analyses were conducted at a $9 5 \%$ confidence level using Statgraphics $^ { 1 9 \textcircled { \mathrm { R } } }$

# 3.1． Cyclic voltammetry analysis

The i-R corrected CVs obtained for the high acidic sulphate electrolyte (Electrolyte 1) display two well-defined redox peaks corresponding to the $\mathrm { F e } ^ { 3 + } | \mathrm { F e } ^ { 2 + }$ couple (Fig.la). The anodic peak, associated with the oxidation of $\mathrm { F e } ^ { 2 + }$ to $\mathrm { F e } ^ { 3 + }$ , appears at potentials around $0 . 5 7 \mathrm { - } 0 . 6 6 \mathrm { V }$ vs. $\mathbf { A g / A g C l }$ (3 M),whereas the cathodic peak,attributed to the reduction of $\mathrm { F e } ^ { 3 + } \mathrm { t o } \mathrm { F e } ^ { 2 + }$ ,is observed at 0.23-0.31 V vs. $\mathbf { A g / A g C l }$ (3 M).

In addition to the $\mathrm { F e } ^ { 3 + } | \mathrm { F e } ^ { 2 + }$ redox peaks, the voltammograms display a continuous rise in current at both the anodic and cathodic potential limits.This response corresponds to the onset of parasitic gasevolving reactions.Specifically,oxygen evolution (and chlorine evolution in the presence of chloride,Figures S6-S11) occurs on the anodic branch,whereas hydrogen evolution becomes significant at the most cathodic potentials.

With increasing scan rates,the voltammograms display broader and higher peaks,and a progressive shift of the anodic and cathodic peak potentials to more anodic and more cathodic values,respectively.For all the measured scan rates, the anodic and cathodic peak separation $( \Delta E _ { p } )$ increases with the scan rate,and exceeds $2 0 0 \mathrm { m V }$ (Fig. la). # 3.2.Statistical analysis

# 3.2.1. Charge transfer coeficient (α)

The electrolyte type has a statistically significant effect on $\alpha$ (p-value $= 0 . 0 0 1 3 )$ ,indicating that the type of anion (chloride vs.sulphate) strongly influences the symmetry of the charge-transfer process at the electrode-electrolyte interface (Table 2,Fig.2). This is consistent with the markedly different mean values obtained for each electrolyte type (Fig.2a):sulphate-based electrolytes yield significantly higher $\alpha$ values $( \sim 0 . 5 0 )$ compared to chloride electrolytes $( \sim 0 . 3 4 )$ . In contrast, the acid concentration factor (Fig.2b) has a slight effect on $\alpha$ $\mathrm { f r o m } 0 . 4 2$ in high acid concentration to O.44 in low acid concentration),but this effect is not statistically significant.

Additionally,in the interaction plot (Fig.2c),the non-parallel lines reveal an interaction between the acid concentration and the electrolyte type.The interaction between both factors is statistically significant (pvalue $= 0 . 0 0 9 3 $ ),suggesting that the effect of the acid concentration on $\alpha$ depends on the electrolyte type.The interaction effect is positive for chloride electrolytes,meaning that increasing acid concentration leads to slightly higher $\alpha$ values in chloride-based electrolytes (from 0.30 to 0.38).In contrast, the interaction is negative for sulphate electrolytes, where $\alpha$ decreases as acid concentration increases (from O.58 to 0.42). These opposite trends indicate that the symmetry of the electrontransfer barrier responds differently to acid concentration depending on the electrolyte type.Therefore,although acid concentration does not havea significant main effect,its influence becomes relevant when combined with the electrolyte composition.This is further supported by the Pareto plot (Fig.2d),showing a statistically significant interaction between electrolyte type and acid concentration that directly translates into variations in the charge transfer coefficient and,consequently, the symmetry of the electron transfer process.

The observed dependence of the charge transfer coeficient $( \alpha )$ on the electrolyte type can be rationalized by considering the distinct roles of chloride and sulphate anions in the interfacial kinetics.In sulphatebased media,the stronger complexation of Fe by $S O _ { 4 } ^ { 2 - }$ stabilizes the redox couple,resulting in $\alpha$ values close to O.5O,which indicates a symmetric distribution of the activation energy between oxidation and reduction [37].In contrast,chloride ions interact weaklier with Fe but adsorb stronglyat the electrode's surface,blocking active sites and enhancing competitive side processes such as localized corrosion and

hydrogen evolution [37].

As a result, $\alpha$ values are consistently higher in sulphate-based electrolytes (0.5O) than in chloride media (0.34),indicatinga less symmetric response to changes in potential between the anodic and cathodic branches.Furthermore,the effect of the acid concentration depends on the electrolyte type: in sulphate media,increasing proton concentration leads to a decrease in $\alpha ;$ ：while in chloride media the strong anion adsorption already dominates the interfacial mechanism,rendering the influence of acid concentration comparatively minor. Therefore, although proton activity alone has a minor main effect,its influence becomes relevant when considered in combination with the electrolyte type.

Among the electrolytes considered in this study, the most favorable charge transfer coeficient $( \alpha ~ \sim ~ 0 . 5 0 )$ was obtained in low acidic sulphate electrolyte (electrolyte 2),indicating that diluted sulfuric acid provides the most balanced distribution of potential between oxidation and reduction for the $\mathrm { F e } ^ { 3 + } | \mathrm { F e } ^ { 2 + }$ redox kinetics under the investigated conditions.

Higher $k ^ { 0 }$ values are observed in chloride media $( 7 . 9 { \cdot } 1 0 ^ { - 4 } \ \mathrm { c m } { \cdot } s ^ { - 1 } )$ ）compared to sulphate media $( 2 . 1 { \cdot } 1 0 ^ { - 4 } \ \mathrm { c m } { \cdot } s ^ { - 1 } )$ ,indicating that chloride electrolytes facilitate faster charge transfer,whereas sulphate electrolytes lead to slower kinetics (Fig.3a).Acid concentration also exerts an influence on $k ^ { 0 }$ (Fig.3b): higher acid concentrations,associated with higher proton activities,lead to larger $k ^ { 0 }$ values.

# 3.2.3. Difusion coefficient $( D )$

Acid concentration has a statistically significant effect on the diffusion coefficient $( \mathrm { p } \mathrm { - v a l u e } = 0 . 0 0 0 2 )$ (Table 4, Fig. 4) with higher concentrations leading to substantially greater $D$ values, increasing from $2 5 0 \mu \mathrm { m } ^ { 2 } { \cdot } s ^ { - 1 }$ $( 2 . 5 { \cdot } 1 \bar { 0 } ^ { - 6 } \mathrm { c m } ^ { 2 } { \cdot } s ^ { - 1 } )$ at low acid concentrations to $1 2 0 0 \mathrm { \bar { \mu m } } ^ { 2 } { \cdot } s ^ { - 1 }$ $( 1 . 2 { \cdot } 1 0 ^ { - 5 } \mathrm { c m } ^ { 2 } { \cdot } s ^ { - 1 } )$ at high acid concentrations (Fig. 4b). This trend can be attributed to the fact that higher proton concentrations enhance ionic conductivity and reduce electrostatic interactions,thereby increasing ion mobility and effective diffusivity [38].Moreover,pH strongly influences iron speciation and solubility,with more acidic environments favoring the formation of more labile complexes and faster $\mathrm { F e } ^ { 3 + } | \mathrm { F e } ^ { 2 + }$ transport [39].

In contrast, neither the electrolyte type,nor the interaction between both factors, have a statistically significant effect on $D$ (Table 4, Fig. 4). The nearly parallel lines in the interaction plot (Fig.4c) confirm the nonsignificant interaction observed in the ANOVA analysis.Acid concentration is the dominant factor affecting diffusion,whereas electrolyte type contributes minimally (Fig.4d).These findings indicate that the positive effect of acid concentration on diffusion is the same regardless of the electrolyte type.

# 3.2.4. Electrical conductivity $( \Lambda )$

Acid concentration has a significant effect on electrical conductivity $( \Lambda )$ (p-value $< 0 . 0 0 0 1 \dot { }$ ),with higher concentrations increasing conductivity (Fig.5b,Table 5).This behavior is consistent with the higher availability of mobile protons $( \mathrm { H } ^ { + } )$ ,whose molar conductivity at infinite dilution is much higher than that of any other ionic species present in the system (Table S8) [38].

Electrolyte type alone does not have a statistically significant effect on conductivity (p-value $= 0 . 1 4 0 8$ ),with minor differences in conductivity between chloride-based and sulphate-based electrolytes (Fig.5a). This is explained by the fact that the molar conductivities at infinite dilution of the $\mathrm { C l ^ { - } }$ and $S O _ { 4 } ^ { 2 - }$ anions (Table S8) are relatively similar, whereas the molar conductivity at infinite dilution of $\mathrm { H ^ { + } }$ is much higher. As a result, the contribution of the electrolyte anion to the total conductivity is minor compared to that of the acid.

However, the interaction between the electrolyte type and the acid concentration is statistically significant $( \mathrm { p } \mathrm { - v a l u e } = 0 . 0 0 7 8 )$ , indicating that the effect of acid concentration on conductivity significantly depends on the electrolyte type (Fig.5c).At low acid concentration, conductivities are similar for chloride- and sulfate-based media (78-83 $\mathrm { m } { \mathsf { S } } { \cdot } \mathrm { c m } ^ { - 1 } )$ ,whereas at high acid concentration the conductivity increase is larger in sulfate $( 2 1 0 ~ \mathrm { m } \mathrm { S } { \cdot } \mathrm { c m } ^ { - 1 } )$ than in chloride $( 1 1 0 ~ \mathrm { m } \mathrm { S } { \cdot } \mathrm { c m } ^ { - 1 } )$ .This can be explained by the lower effective molar conductivity of $S O _ { 4 } ^ { 2 - }$ per mole of acid compared to Cl-(Table S8),which makes the contribution of $\mathrm { H } ^ { + }$ relatively more important in sulfate media.As a result, increasing proton concentration leads to a larger increase in total conductivity in sulfate-based electrolytes.Acid concentration is the primary determinant of conductivity,with electrolyte type contributing minimally except through the observed interaction (Fig.5d).

Overall, these results demonstrate that increasing acid concentration is the most effective strategy to enhance the electrical conductivity of AIRFB electrolytes in order to reduce the ohmic overpotential.

# 3.3.Electrochemical stability window (ESW)

In the case of the iron-free low acidic sulphate electrolyte (electrolyte 2)(Fig.6a),in the anodic branch,the current remains low at potentials below $_ { 1 . 9 \mathrm { ~ V ~ } }$ vs Ag/AgCl (3 M),and then shows a sharp increase due to oxygen evolution,which defines the anodic limit of the electrochemical stability window (EsW).In the cathodic direction,Hydrogen Evolution Reaction (HER) occurs at negative potentials,starting near $- 1 . 8 \mathrm { V }$ Vs Ag/ AgCl (3 M).Based on these observations,the ESW of the iron-free low acidic sulphate electrolyte (electrolyte2) is estimated to be[-1.8;1.9] V vs Ag/AgCl (3 M).

When iron is present in the electrolyte,slight differences are observed.In the anodic branch at low potentials,currents are slightly higher due to the oxidation of $\mathrm { F e } ^ { 2 + }$ to $\mathrm { F e } ^ { 3 + }$ in addition to minor gas evolution,which is negligible in this range.At potentials above $_ { 1 . 9 \mathrm { V } }$ VS Ag/AgCl (3 M),both,iron-containing and iron-free electrolytes,show a sharp current increase due to oxygen evolution,with no significant differences,indicating that iron does not influence the anodic stability limit.In the cathodic branch, the presence of Fe leads to slightly higher currents because $\mathrm { F e } ^ { 3 + }$ reduction occurs concurrently with hydrogen evolution. In the iron-containing solution,hydrogen evolution appears near $- 1 . 1 \mathrm { V }$ vs Ag/AgCl (3 M),occurring at less cathodic potentials than in the iron-free electrolyte.Furthermore,at potentials slightly below $- 1 . 0 \mathrm { V }$ vs Ag/AgCl(3 M),the reduction of $\mathrm { F e } ^ { 2 + }$ to metallic Fe $( \mathrm { F e } ^ { 0 } )$ takes place alongside hydrogen evolution.The freshly deposited Fe acts as a catalyst for proton reduction,enhancing the rate of hydrogen evolution and resulting in a steeper slope of the current-potential curve [40,41].

Based on these results,the estimated ESW for the low acidic sulphate electrolyte (electrolyte 2) is [-1.0; 1.8] V vs $\mathrm { A g / A g C l }$ (3 M).

For the high acidic sulphate electrolyte (electrolyte 1) (Fig. 6b), the anodic response is similar to the one of the low acidic sulphate electrolyte (electrolyte 2),with oxygen evolution initiating above $_ { 1 . 9 \mathrm { ~ V ~ } }$ VS Ag/AgCl (3 M) in both cases,indicating that the anodic limit is largely independent of acid concentration.

In contrast,the cathodic branch is affected by $\mathrm { H _ { 2 } } S O _ { 4 }$ concentration. This behavior is expected, since increasing proton activity (i.e.arising froma higher acid concentration） enhances the hydrogen evolution reaction (HER),improving its kinetics and shifting the cathodic onset to less cathodic potentials.In the iron-free high acidic sulphate electrolyte (electrolyte 1),hydrogen evolution occurs at around $- 0 . 7 \mathrm { V }$ VS $\mathbf { A g / A g C l }$ (3M),a much less cathodic potential than in the low acidic sulphate electrolyte (electrolyte 2) $( - 1 . 8 \mathrm { ~ V ~ }$ VS $\mathbf { A g / A g C l }$ (3 M)),reflecting the higher HER rate in concentrated acid [42]. In the presence of Fe, $\mathrm { F e } ^ { 2 + }$ reduction to metallic Fe occurs concurrently with hydrogen evolution, shifting the cathodic onset slightly towards more negative potentials.In both electrolytes,metallic Fe catalyzes the HER;however,its relative influence is more pronounced at lower acid concentrations,where the reduced proton activity makes the overall HER kinetics more sensitive to the catalytic surface.As a result,the cathodic limit of the high acidic sulphate electrolyte (electrolyte 1) shifts only slightly in the presence of Fe,leading to an estimated ESW of [-1.1;1.9] V vs $\mathbf { A g / A g C l }$ (3 M).

# 4. Conclusions

The systematic evaluation of the effect of the electrolyte type and acid concentration on the $\mathrm { F e } ^ { 3 + } | \mathrm { F e } ^ { 2 + }$ reaction through factorial ANOVA demonstrated that the composition of the posolyte strongly influences the electrochemical performance of AIRFBs.

Thanks to the experimental design and the statistical study, the significance of each factor and their interaction was determined,despite the variability derived from the surface conditions of the electrodes.

The ANOVA results reveal that the electrolyte type is the dominant factor governing charge-transfer behavior.Sulphate electrolytes yield better charge-transfer coeficients $( \alpha )$ ，whereas chloride electrolytes enable faster standard heterogeneous rate constants $( k ^ { 0 } )$ , particularly at high acid concentrations.In contrast, the electrolyte type exerts a more modest influence on the transport phenomena,although it modulates the conductivity response through its interaction with acid concentration.

In contrast,the acid concentration primarily controls mass transfer and charge transport.Higher acidity consistently increases the diffusion coefficient, reflecting enhanced ion mobility,and significantly improves electrolyte conductivity.Acidity also contributes to charge-transfer kinetics,reinforcing the acceleration observed in chloride media.In several cases,particularly for the charge-transfer coefficient $( \alpha )$ and electrolyte conductivity,significant electrolyte type-acid concentration interactions indicate that the efect of one factor cannotbe interpreted independently of the other,underscoring the importance of a multifactorial approach when optimizing posolyte formulations in AIRFBs.

Based on the obtained electrochemical parameters,acidic chloride electrolyte is identified as the electrolyte with the best overall performance among the studied systems.It provides the fastest kinetics for the $\mathrm { F e } ^ { 3 + } | \mathrm { F e } ^ { 2 + }$ reaction,highmass transport rates,goodconductivityndan adequate electrochemical window.

Overall, this work demonstrates the power of ANOVA in quantitatively dissecting the influence of the electrolyte type and acid concentration on key electrochemical parameters.The findings provide a statistically robust foundation for the rational design of posolyte formulations in AIRFBs,highlighting the trade-off between kinetics and stability that must guide electrolyte selection for next-generation flow batteries.
