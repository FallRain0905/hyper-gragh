Theelectrolyte in the flow batery is thecarrier of energy storage,however,there arefew studieson electrolyte for iron-chromium redox flow batteries (ICRFB).The low utilization rate and rapid capacity decay of ICRFB electrolyte have always been a challenging problem.Herein,the effect of $\mathrm { F e / C r }$ molar ratio,and concentration of HCl on the performance of ICRFBs at high current density $( 1 4 0 \mathrm { \ m A } \mathrm { \ c m } ^ { - 2 } ) .$ ）are investigated. The average energy efficiency of the optimal electrolyte $\cdot 1 . 2 5 \mathrm { ~ M ~ F e C l _ { 2 } }$ 1.50M $\mathrm { C r C l } _ { 3 }$ ,3.0 M HCl) increases by $5 . 9 9 \%$ in the first 20 cycles,and the discharge capacity increases by $1 5 . 7 2 \%$ in the first cycle compared to the original commercial electrolyte ( $\cdot 1 . 0 \mathrm { M F e C l } _ { 2 } ,$ $1 . 0 \mathrm { M } \mathrm { C r } \mathrm { C l } _ { 3 }$ ， $3 . 0 \mathrm { M }$ HCl).This electrolyte also shows a longer cycle life.In addition, the COMSOL simulationon the concentration change of electrolyte in ICRFB is proposed,the effect of physical properties on the electrolyte is further explained.Through the simulationand analysis of this complex system, researchers can beter understand the performance of flow batery systems.It is important to consider various challenges andconstraints that might be encountered in practical applications.This work efectively saves the cost of ICRFB and further provides data support for their engineering applications.

# 1．Introduction

The flow battery can provide important help to realize the transformation of the traditional fossil energy structure to the new energy structure,which is characterized by separating the positive and negative electrolytes and circulating them respectively to realize the mutual conversion of electric energy and chemical energy [1-3].Redox flow battery (RFB) is an engineering that uses redox reactions in liquid electrolyte to store and release energy and can be used in large-scale energy storage systems [4-6].Its advantages include long cycle life,modular design,and high safety [7,8]. The iron-chromium redox flow batery (ICRFB) is a type of redox flow battery that uses the redox reaction between iron and chromium to store and release energy [9].ICRFBs use relatively inexpensive materials (iron and chromium) to reduce system costs[1O].The energy of the ICRFB is determined by the volume of the solution in the electrolyte and the concentration of the active substance [11,l2].The electrolyte of ICRFB use the same component,which effectively reduces the problem of transmembrane migration of active ions [13,l4].In the case of constant electrode area,increasing the working current density can achieve a faster and more eficient charge and discharge process and effectively improve the utilization rate of electrolyte [15].

Electrolyte storage tank,circulating pump,electrode,selective exchange membrane,and bipolar plate are the main components of ICRFB. However,in the field of ICRFB,the focus has been placed on the study of electrode modification [16] and the preparation of different proton exchange membranes [17].Different from the traditional battery carbon felt (CF) electrode,the carbon cloth (CC) made of carbon fiber is used as the battery electrode in the experiments in this paper,which has the characteristics of light weight, high strength,and excellent conductivity [18-2O].Modification of the carbon-based electrode can improve its electrochemical performance,only a simple heat treatment method was used in the experiment [21]. The research of ICRFB electrolyte is an immature technology at present.Robb et al.[22] used an electrolyte containing DTPA and PDTA for flow cell cycling,revealing the efects of chelating agents on the solubility and electrochemical properties of $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { \bar { 2 } + }$ redox reaction. Zeng et al.[23] explored the effect of adding $\mathbf { B i } ^ { 3 + }$ to the electrolyte on the performance of the battery. Compared with the practice of adding additives to the electrolyte,the concentration optimization of ICRFB electrolyte is a simpler and more effective way to improve battery performance [24-26].At a current density of $8 0 ~ \mathrm { \ m A }$ $\mathrm { c m } ^ { - 2 }$ ,Wu et al.[27] found that the battery's energy efficiency and electrochemical activity of negative active ions were highest when the molar ratio of iron to chromium is 1:1.3.Wang etal.[28] optimized the electrolyte of ICRFB.When the concentration of $\mathrm { F e C l } _ { 2 }$ ， $\mathrm { C r C l } _ { 3 }$ ，and HCl is 1.0 M,1.0 M,and $3 . 0 \mathrm { M }$ (1.00-1.0o-3.0O),respectively,the battery shows excellent energy efficiency. When the current density is $1 2 0 \mathrm { \ m A \ c m } ^ { - 2 }$ ， the energy efficiency is $8 1 . 5 \%$

During the charging process,the negative electrode has a side reaction: hydrogen evolution reaction (HER), while a part of ${ \mathrm { C r } } ^ { 3 + }$ cannot be reduced [29,30]. However, $\mathrm { F e } ^ { 2 + }$ in the positive electrolyte can react completely.When the molar ratio of iron to chromium is 1:1, the active substances of the positive and negative reactions do not match.It is also been proved that there are $\mathrm { C r } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 5 } \mathrm { C l } ^ { 2 + }$ ， $\mathrm { C r ( H _ { 2 } O ) _ { 4 } C l _ { 2 } ^ { + } }$ ,and $\mathrm { C r ( H _ { 2 } O ) } _ { 6 } ^ { 3 + }$ complex ions in hydrochloric acid aqueous solution of $\mathrm { C r C l } _ { 3 }$ ,and there is a dynamic equilibrium between the three complex ions: $\mathrm { C r ( H _ { 2 } O ) _ { 5 } C l ^ { 2 + } + }$ $2 \mathrm { C l ^ { - } + H _ { 2 } O }  C r ( \mathrm { H _ { 2 } O } ) _ { 6 } ^ { 3 + } \mathrm { ~ + ~ 3 \mathrm { C l ^ { - } }  C r ( H _ { 2 } O ) _ { 4 } \mathrm { C l _ { 2 } ^ { + } C l ^ { - } } \mathrm { ~ + ~ 2 H _ { 2 } O } }$ [31]. Increasing the concentration of chromium chloride in the mixed electrolyte is expected to change the ratio of the three complexes.Meanwhile,considering that the activity of chromium ions in the negative electrolyte is poor [32],the idea of increasing the concentration of negative active ions is proposed in this paper.At the operating temperature $( 6 0 \quad ^ { \circ } \mathbf { C } )$ ，the concentration of either 1.00-1.00-3.00or 1.00-1.30-3.oo is far from its saturation solubility.Both the economy and energy density of the electrolyte are not optimal products.

If the active ion concentration is constant, increasing the current density will lead toa decrease in energy efficiency [33].Therefore, Under the condition of working current density of $1 4 0 \mathrm { \ m A \ c m ^ { - 2 } }$ ,ascheme of increasing the concentration of $\mathrm { F e C l } _ { 2 }$ ， $\mathrm { C r C l } _ { 3 }$ ,and HCl is1.0 M,1.0 M,and $3 . 0 \mathrm { ~ M ~ }$ (1.00-1.00-3.00) respectively to 1.25 M, $1 . 2 5 \mathrm { ~ M ~ }$ ，and $3 . 0 \mathrm { ~ M ~ }$ (1.25-1.25-3.00) in this paper.Different from Wu's experimental conclusion [27],when the current density and the concentration of all active ions in the electrolyte increase at the same time,the energy efficiency reaches the highest and the capacity decay rate decreases to the minimum when the electrolyte concentration is 1.25-1.50-3.00.In addition,excellent performance of the electrolyte can be judged by the concentration of its composition [34] and its physical parameters [35]. The physical parameters will not only affect the loss of ohmic polarization,but also affect the cost in commercial production [36,37]. In this work，we also explored the effects of different concentrations of hydrogen ions on electrochemical performance and battery parameters. With the increase of current density and active ions concentration, the appropriate concentrations of hydrogen ions were selected to reduce the HERas much as possible.In addition,we experiment how the physical properties of the electrolyte change with the increase of concentration when the molar ratio of iron to chromium is 1:1.2.Under the same experimental conditions,compared with the commercial ICRFB electrolyte (1.0o-1.0o-3.oO),the electrolyte utilization rate of the optimized electrolyte increased from $6 1 . 1 0 \%$ to $8 2 . 0 5 \%$ ，and the cumulative discharge capacity of 6O cycles increased from $6 4 4 . 0 4 \mathrm { A h } \mathrm { L } ^ { - 1 }$ to 1336.79 Ah $\mathrm { L } ^ { - 1 }$

Most importantly,a three-dimensional multi-physics model is established by COMSOL,which is combined with the electrolyte of ICRFB with different concentration for the first time [38].Under the condition of current densityof $1 4 0 \mathrm { \textrm { ~ \textmu { ~ } } } \mathrm { c m } \mathrm { \textrm { ~ \textmu { ~ } } } \mathrm { c m } ^ { - 2 }$ ，theoptimal concentration (1.25-1.50-3.0O) is selected to construct the distribution cloud map.More comprehensive evaluation methods of physical propertyparameters for electrolyte were established.This model integrates the interactions between electrochemical reactions and fluid dynamics to simulate and analyze the behavior of the electrolyte within the interdigitated flow channels and its impact on battery performance [39]. By precisely seting and adjusting input parameters, such as the properties of the electrolyte, flow rate,temperature,and characteristics of the electrode materials,the model can predict performance variations under different operating conditions.In this work,the current density,velocity distribution,and pressure distribution of the electrolyte at different positions in the bipolar plate are calculated.The effects of other physicochemical properties besides viscosity and conductivity are further explained.The in-depth research of this work is expected to provide theoretical guidance for the engineering application of ICRFBs.

# 2.Experimental

# 2.1.Experimental principles and guidelines

In order to explore the electrolyte with better charge-discharge capacity and electrolyte utilization under the condition of high current density $( 1 4 0 \mathrm { m A } \mathrm { c m } ^ { - 2 } )$ , the optimum electrolyte is selected in this paper, as shown in Fig. la.

Different concentrations of $\mathrm { F e } ^ { 2 + }$ and ${ \mathrm { C r } } ^ { 3 + }$ in the electrolyte lead to different diffusion rates on the proton exchange membrane.We speculated that the diffusion rate would be affected by the medium density and viscosity of the solution.So different concentrations of electrolyte in the battery cycle test capacity decay is not consistent.We experimented with a series of electrolyte with different concentrations.The problem of the commercial electrolyte (1.0o-1.0o-3.0o) is that the reactive activity of the negative active ion $( \mathsf { C r } ^ { 3 + } )$ is poor,which is obviously not as good as the reactive activity of the positive active ion $( \mathrm { F e } ^ { 2 + } )$ .This makes the amount of substance in the positive and negative reactants much less than $1 \mathrm { \ m o l }$ .In order to make the concentration of the reactants close to the theoretical stoichiometric number,it is appropriate to increase the concentration of the negative reactants $( \mathsf { C r } ^ { 3 + } )$ .With the increase of current density,the low concentration of the electrolyte will cause more serious polarization problems,and the utilization rate of the electrolyte will be reduced.

As shown in Fig.1b,the model employs a single-inlet,dual-outlet interdigitated flow channel structure with dimensions of $2 0 \ \mathrm { m m }$ by $5 0 \ \mathrm { m m }$ ,which is particularly suitable for electrochemical flow coupling experiments.The design of the interdigitated flow channels allows the electrolyte to disperse into two outlets upon entering the battery,facilitating optimized flow distribution and reaction efficiency.

# 2.2.Materials

Ferrouschloride $\mathrm { ( F e C l _ { 2 } { \cdot } 4 H _ { 2 } O }$ ，AR） and chromium chloride $( \mathrm { C r C l } _ { 3 } { \cdot } 6 \mathrm { H } _ { 2 } 0 _ { : }$ ，AR) were purchased from Shanghai Macklin Biochemical Co.Ltd.Hydrochloric acid (HCl) provided by Sinopharm Chemical Reagent Co.Ltd.(Shanghai) was of analytical reagent grade.All chemical reagents were used directly without further treatment.Nafion 212 membrane was purchased from Suzhou Kerun New Materials Co.LTD. and soaked in deionized water for $2 4 \ \mathrm { h }$ before the experiment began. Carbon cloth (CC) was purchased from Jiangsu Guo-Hua New Material Co.Ltd.and the CC was heated at $5 0 0 ~ ^ { \circ } \mathrm { C }$ in a tube furnace for $^ { 5 \mathrm { ~ h ~ } }$ to prepare the electrode.

# 2.3.Battery tests

The battery and circulation pipeline are self-designed battery test system,as shown in Figs.S1 and S2.The battery system is placed in an oven at a temperature of $6 0 ~ ^ { \circ } \mathrm { C }$ ，For charge and discharge tests,the voltage window is $0 . 7 \mathrm { - } 1 . 2 \mathrm { ~ V ~ }$ and the flow rate of the electrolyte is $2 0 \mathrm { m L } \mathrm { m i n } ^ { - 1 }$

# 2.4.Preparation of electrolyte

The electrolyte of the blended solution with various concentration were prepared by dissolving $\mathrm { C r C l } _ { 3 } { \cdot } 6 \mathrm { H } _ { 2 } 0$ and $\mathrm { F e C l } _ { 2 } { \cdot } 4 \mathrm { H } _ { 2 } 0$ in concentrated HCl solution. The preparation of the electrolyte was carried out in deionized water at a constant temperature of $6 0 ~ ^ { \circ } \mathrm { C }$ After adding different weights of $\mathrm { C r C l } _ { 3 } { \cdot } 6 \mathrm { H } _ { 2 } 0$ into the water,it was stirred for $3 0 \mathrm { { m i n } }$ In order to reduce the oxidation of $\mathrm { F e C l } _ { 2 }$ ,we added HCl to seal the solution and continued stirring. Finally, $\mathrm { F e C l } _ { 2 } { \cdot } 4 \mathrm { H } _ { 2 } 0$ was added to obtain electrolyte of different concentrations.After the preparation of the electrolyte,the sample was taken for titration test.The concentration error was less than $0 . 0 5 { \mathrm { ~ M } }$

Group 1: The concentration of HCl is fixed at $3 . 0 \mathrm { { M } }$ ,while the concentration of $\mathrm { F e C l } _ { 2 }$ is set at1.25 M.The molar ratio of iron to chromium is varied as follows: $\mathrm { F e C l } _ { 2 } / \mathrm { C r C l } _ { 3 } = 1 { : } 1$ ,1:1.1,1:1.2,1:1.3. Group 2: The ${ \mathrm { F e C l } } _ { 2 } – { \mathrm { C r C l } } _ { 3 }$ molar ratio is chosen based on the equilibrium of the positive and negative reactions in the electrolyte.Subsequently,the acidity is adjusted with the following concentrations of $\mathrm { H } ^ { + }$ ions: $C ( \mathrm { H } ^ { + } ) = 2 . 0 ~ \mathrm { M }$ ， 2.5 M,3.0 M,3.5 M. Group 3:With a constant ${ \mathrm { F e C l } } _ { 2 } – { \mathrm { C r C l } } _ { 3 }$ molar ratio and acidity,the concentrations of $\mathrm { F e C l } _ { 2 }$ and $\mathrm { C r C l } _ { 3 }$ are varied concurrently to assess the effects of physical properties—such as solubility, viscosity, conductivity,and density—on the battery's performance.

# 2.5.Electrochemical test

The electrochemical tests were carried out on an electrochemical workstation.Platinum electrode was used as the reverse electrode, saturated calomel as the reference electrode,and glassy carbon electrode (diameter $3 \mathrm { m m }$ )as the working electrode.The scan rate of cyclic voltammetry (CV) test is $3 0 \ \mathrm { m V } \ s ^ { - 1 }$ ,and the voltage range is $- 1 . 0 { \sim } 1 . 0 \mathrm { V }$ (DH7001D-48,Jiangsu Donghua Instrument).The electrochemical impedance is in the frequency range of $0 . 0 1 { \sim } 1 0 ^ { 5 } \ \mathrm { H z }$ test (CHI760E, Shanghai Chenhua Instrument） and use Zview software to fit the impedance.

# 2.6.Physicochemical characterizations

The viscosity of the electrolyte was measured by the pipette viscometer at a temperature of $6 0 \pm 3 ^ { \circ } \mathrm { C }$ .Under the same temperature conditions,the electrical conductivity was tested with the conductivity meter (DDSJ-308F,Shanghai Leici Instrument),and the density was tested with the density meter.The concentration of vanadium ions in electrolyte with different concentration was determined by UV-Vis spectrophotometer (UH4150,HITACH),and the influence of the content of three kinds of active ions on ICRFB was analyzed.

# 3.3.COMsOL model and physicochemical properties

The designated Table S1 illustrates the parameters for the COMSOL model.These parameters form the foundation of the experiment, ensuring that the model accurately reflects the actual electrochemical and fluid dynamics characteristics.These contours offer a comprehensive view of the dynamic processes within the battery,providing vital insights into how modifications to the flow structure and electrolyte formulation can optimize performance.This analysis forms the basis for further refining the battery design to enhance overall efficiency.

Fig. 4a shows schematic diagrams of pressure drop, pump consumption,poltage efficiency,and pump-based voltage efficiency for four electrolytes in different concentrations:1.25-1.25-3.00 (1),1.25-1.375- 3.00 (2),1.25-1.50-3.00 (3),and 1.25-1.625-3.00 (4). The increasing concentration of $\mathrm { C r C l } _ { 3 }$ results in higher viscosity and lower conductivity of the electrolyte,which in turn leads to increased ohmic polarization. This heightened viscosity leads to increased pump consumption,which consequently reduces the energy effciency of the flow battery system. Previous optimization efforts for ICRFB focused primarily on energy efficiency,often neglecting the effects of electrolyte viscosity on pump consumption.In response to these challenges,this work innovatively proposes the use of COMsOL multiphysics to build an electrochemical flow coupling model that includes pressure drop,pump consumption, voltage efficiency,and pump-based voltage efficiency.By incorporating these factors,the pump-based voltage eficiency is compared across different concentrations of electrolyte,ultimately identifying the formulation that maximizes the energy Since conductivity is determined by the transfer rate of ions in the electrolyte,low conductivity will increase the ohmic resistance of the battery and affect the energy efficiency of the battery.The change of viscosity will also affect the electrochemical properties.As shown in Fig.4f,the selection of the appropriate concentration of electrolyte requires consideration of its viscosity and conductivity.The viscosity and conductivity of optimum electrolyte (1.25-1.50-3.00) are $2 . 2 2 \ \mathrm { m } \mathrm { \dot { m } } ^ { 2 } \ s ^ { - 1 }$ and $2 6 3 . 6 7 \mathrm { m s c m ^ { - 1 } }$ ,respectively.At this concentration,the viscosity and conductivity are more suitable,and itis also consistent with the results of electrochemical performance.As shown in Fig.S5, the conductivity of the electrolyte tends to decrease with the increase of $\mathrm { F e C l } _ { 2 }$ and $\mathrm { C r C l } _ { 3 }$ concentrations.With the increase of HCl concentration, the conductivity of the electrolyte show an increasing trend.It can be clearly observed that the viscosity of the solution tends to increase whether the concentrations of $\mathrm { F e C l } _ { 2 }$ and $\mathrm { C r C l } _ { 3 }$ is increased or the concentration of HCl is increased. The decrease of conductivity is related to the increase of proton concentration and electrolyte viscosity.The viscosity and conductivity of the electrolyte have a linear relationship with the change of concentration. However，there is no linear relationship between the charge and discharge capacity mentioned above. The reason for this phenomenon may be the excessive viscosity of the electrolyte,resulting in increased energy loss in the pump and pipeline flow.This leads to fluctuations in the charge-discharge process,which eventually causes fluctuations in capacity.The density of different concentrations of electrolyte are listed in Table 1. # 3.4.UV-Vis spectra of electrolyte

In order to directly display the trend of active substance concentration,UV-Vis spectrum scanning was performed.The influence of the concentration of ${ \mathrm { F e C l } } _ { 2 } ,$ $\mathrm { C r C l } _ { 3 }$ ，and HCl on the cyclic performance of ICRFB was further explained.The concentration of ${ \mathrm { C r } } ^ { 3 + }$ in the electrolyte was determined by UV-Vis spectrophotometer.All kinds of electrolyte are diluted 7O times and the absorbance is below 1.0.The absorbance is proportional to the concentration and the Beer law can be used to quantitatively calculate the concentration of $\mathrm { C r } ^ { 3 + }$ in the mixture. # 4.Conclusion

In summary,the system experimentof the electrolyte is carried out, the excellent electrolyte for engineering application is obtained,and the electrolyte is also studied by COMsOL simulation calculation in this work.The ingenious idea connects the COMsOL simulation calculation with different concentrations of electrolyte,effectively supplementing the evaluation standard of physicochemical properties from many aspects (pressure drop, pump consumption, voltage efficiency,and pumpbased voltage efficiency).Three groups of contrast electrolytes were evaluated by battery testing,including the different molarratio of iron and chromium, the concentration of HCl is different, the molar ratio of chromium and iron is 1.2.The CV and EIS results show that the electrolyte of 1.25-1.50-3.00 exhibited the best electrochemical properties due to the combined effects of viscosity,conductivity and electrochemical activity.The viscosity and density of the electrolyte increased with the increase of the concentration of ${ \mathrm { F e C l } } _ { 2 } ,$ $\mathrm { C r C l } _ { 3 }$ ，and HCl. The conductivity increased with the increase of the concentration of HCl and decreased with the increase of the concentration of $\mathrm { F e C l } _ { 2 }$ and $\mathrm { C r C l } _ { 3 }$ When the current density is $1 4 0 \mathrm { m A c m } ^ { - 2 }$ ,the average energy efficiency of the optimal electrolyte is $8 3 . 6 7 \%$ ,the utilization rate of electrolyte is up to $8 2 . 0 3 \%$ ,and the average capacity decays to $0 . 5 \%$ in the first 20 cycles.In addition,3oO cycles test was carried out to verify its long cycle life.The optimization of different concentrations of electrolyte not only provides data support for theoretical research,but also theoretical guidance for engineering application.
