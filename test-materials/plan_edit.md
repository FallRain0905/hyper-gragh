# 中文论文系统性编辑计划

## 当前问题分析
1. AI痕迹明显：高频套话、过强判断、固定结构
2. 格式硬伤：公式缺失、拼写错误、章节编号错误、图表编号不连续
3. 参考文献不足：仅20篇，需扩展到30-35篇
4. 缺少相关工作小节
5. 语言需更符合中文核心期刊风格

## 执行阶段

### Stage 1: 参考文献扩展（并行）
- 搜索并验证30-35篇真实文献
- 覆盖7个方向：RAG基础、Graph-RAG、超图/Hyper-RAG、科学文献抽取、化工KG、液流电池、PFAS

### Stage 2: 正文内容修改（并行）
- Agent A: 摘要+引言+相关工作
- Agent B: 方法部分(1.1-1.4)
- Agent C: 案例部分(液流电池+PFAS)
- Agent D: 讨论+结论+局限性

### Stage 3: 格式修复与组装
- 修复公式、拼写、编号
- 统一图表编号
- 统一术语
- 生成修改说明
