# ABSTRACT

Polybenzimidazole (PBI) membranes exhibit high structural stability and robust ion-blocking capabilities owing to their dense network structure.However,this compactnesshinders proton transport,restricting the application of PBI membranes in iron-chromium redox flow bateries (ICRFBs). Herein, we adopt a dual-regulation strategy employing hydrogen ions $( \mathrm { H } ^ { + } )$ and salt ions $\mathrm { { ( N a ^ { + } } }$ ， $\mathrm { K } ^ { + }$ ， $\mathsf { C a } ^ { 2 + } \mathsf { Y }$ to modulate the PBI matrix.This approach enables non-fluorinated membranes to achieve current densities of $2 0 0 \mathrm { \ m A \ c m ^ { - 2 } }$ while maintaining stable performance at $5 0 ~ ^ { \circ } \mathrm { C }$ Protonation of PBI via $^ { 2 \mathrm { ~ M ~ } }$ phosphoric acid introduces positive charges,generating interchain electrostatic repulsion.This process increases expands the polymer network.Notably, $\mathrm { N a ^ { + } }$ exhibits stronger π-interactions with the benzimidazole (BI) rings compared to $\mathrm { K } ^ { + }$ and $\mathsf { C a } ^ { 2 + }$ .These interactions promote chain alignment and enhance electrostatic associations with charge-balancing ions $( \mathbf { C l } ^ { - } )$ within the mPBI-Na membrane.The synergistic regulation by $\mathrm { H } ^ { + }$ and $\mathrm { N a ^ { + } }$ optimizes the membrane network structure, thereby facilitating proton conduction. Consequently,the mPBI-Na membrane demonstrates a low area-specific resistance of 51.7 $\mathrm { m } \Omega \mathrm { c m } ^ { 2 }$ and retains $7 0 \%$ energy efficiency over 40o cycles at $2 0 0 \mathrm { \ m A \ c m ^ { - 2 } }$ in ICRFBs.This study establishes a facile ion-tuning methodology,providing a viable route for optimizing PBI membrane network structure in advanced energy storage applications.

# 1．Introduction

The global energy system is undergoing a significant transition from conventional fossil fuels to renewable alternatives.However,the intermittency and variability of sources such as wind and solar pose substantial challenges to grid stability and reliability.Consequently, developing efficient, large-scale energy storage technologies is critical for the widespread integration of renewable energy.Redox flow batteries (RFBs) are considered promising candidates for large-scale electrochemical energy storage.Their unique architecture allows for the decoupling of power and energy capacity,while offering long cycle life and high safety.Although all-vanadium RFB(VRFB） technology is mature and has been deployed for grid load leveling,itswidespread adoption is impeded by the high cost and scarcity of vanadium[1].In contrast, iron-chromium RFBs (ICRFBs) employ low-cost,abundant iron and chromium as active species,presenting a viable alternative for long-duration energy storage.Nevertheless,technical challenges persist in ICRFBs,primarily the parasitic hydrogen evolution reaction (HER) and ion crossover through the membrane [2].

Membranes are critical components in RFBs,enabling efficient energy storage and conversion.Ideal membranes must exhibit high proton conductivity,low ionic permeability,and robust chemical stability under harsh operating conditions [3].Although perfluorosulfonic acid (PFSA)membranes dominate the commercial market, their high cost has driven extensive research into cost-effective alternatives [4].Polybenzimidazole (PBI),an aromatic heterocyclic polymer renowned for its exceptional thermal,chemical,and mechanical stability,is a promising next-generation material for RFBs[5].

PBI membrane formation is governed by pronounced π-π stacking and hydrogen bonding between molecular chains.These interactions create a dense,entangled network that imparts exceptional structural stability.However,this compact architecture restricts chain mobility and limits free volume, significantly hindering proton transport [6,7].A key challenge lies in modulating chain packing density to achieve a more open morphology,which is essential for broadening the applicability of PBI membranes in RFBs [8].Numerous modification strategies have been explored to improve proton conductivity while preserving the material's intrinsic mechanical and chemical robustness [9-12].

The most prevalent strategy involves chemically incorporating functional groups into PBI to tailor its structure.These modifications introduce ion-conducting sites,tune surface wettability，enhance porosity,and improve membrane stability [13-15].Common synthetic methods—such as sulfonation,carboxylation，phosphorylation,and amidation—introduce proton-conducting moieties (e.g. $- S O _ { 3 } \mathrm { H }$ -COOH) onto the polymer backbone or side chains,directly enhancing proton transfer efficiency[16-18].For instance,Li etal.design a branched PBI architecture using tricarboxylic acid monomers,enabling stable VRFB operation for over 1ooo cycles at $1 4 0 \mathrm { m A c m } ^ { - 2 }$ [19]. Chen et al. advance this approach by co-grafting sulfonic acid and phenolic groups, significantly increasing proton carrier density and achieving $8 0 . 1 \%$ energy efficiency (EE) at $1 0 0 \mathrm { \ m A c m ^ { - 2 } }$ with negligible capacity decay ${ \it { 0 . 1 \% } }$ per cycle) [2O]. Pang et al. show that the incorporation of quinone groups into PBI promotes their acid-catalyzed conversion to phenolic functionalities,thereby further enhancing the proton conduction rate [21].

Beyond chemical grafting，researchers have integrated porous materials—such as metal-organic frameworks (MOFs) and covalent organic frameworks (COFs)—as structural modifiers to optimize PBI membrane properties.These materials act as scaffolds for functional group immobilization and leverage their intrinsic nanoporosity to alleviate chain packing, thereby enhancing proton conductivity. Addressing COF aggregation,Xie et al.integrate freestanding COF nanofibers with sulfonated PBI to exploit the molecular-sieving capability of COFs [22]. The resulting continuous COF-PBI fibrous membrane is exhibited exceptional $\mathrm { H ^ { + } } / \mathrm { V O ^ { 2 + } }$ selectivity (threefold higher than Nafion 212)and an EE of 80.5% at 200 mA cm-2.

In contrast to these complex methods that may compromise structural stability,ion tuning offers a significantly simplified alternative [3]. This method involves simply immersing the PBI membrane in specific ionic solutions to modulate properties through controlled variations in ion type and concentration [23]. Owing to its simplicity and efficacy, this strategy holds considerable promise for applications in energy conversion and storage technologies [24].For example,Jiang etal.form a robust metal-coordination network via $\mathrm { F e } ^ { 3 + }$ coordination with imidazole groups,increasing intermolecular spacing [25]. These findings are further supported by additional studies,which have shown that divalent metal ions such as $\scriptstyle { \mathrm { Z n } } ^ { 2 + }$ and ${ \mathsf { C o } } ^ { 2 + }$ can effectively decrease the packing density of PBI polymer chains,thereby enhancing ion transport and material performance [26].

Despite the efficacy of various modification strategies,their application in ICRFBs remains limited. Notably,the typical ICRFB operating temperature $( 5 0 – 6 5 \ ^ { \circ } \mathrm { C } )$ aligns well with the high thermochemical stability of PBI membranes.However, the trade-off between membrane compactness and proton conductivity is critical in ICRFB systems.Since the electrolyte composition is identical on both sides,the membrane acts as the sole resistive component,making PBI's low proton transportation a significant limitation.State-of-the-art sulfonated PBI membranes enable ICRFBs to achieve $9 8 . 2 \%$ coulombic efficiency (CE) and $8 3 . 1 7 \%$ EE at $8 0 \ \mathrm { m A } \ \mathrm { c m } ^ { - 2 }$ ,with stable operation for over 1600 cycles [27,28].

Current modification strategies for PBI membranes mainly encompass chemical modification,physical modification,and ion-regulation, as presented in Table S1.The distinctive ICRFB necessitates that PBI membranes uphold thermal stability and resistance to strong acids during operation.Nevertheless,proton-conducting groups introduced through chemical modification frequently generate defect sites vulnerable to acid attack,thereby undermining both acid resistance and mechanical performance.Analogously, functional fillers employed in physical modification can deteriorate the thermal stability of PBI membranes in hydrochloric acid environments.In contrast to extant single-ion regulation strategies,the proposed dual-ion modulation (hydrogen ion and salt ion) presents novelty via synergistic effects and multiple mechanisms.Specifically,protonation induced by hydrogen ions enlarges the inter-chain spacing of PBI,while salt ions regulate molecular interactions to direct network reorganization. This synergy achieves a balance between proton conductivity and structural stability within the PBI membrane.Moreover,mechanisms such as acid-base, electrostatic,and $\pi \cdot \pi$ interactions induced by the dual ions enhance proton transport. As illustrated in Fig.1, $\mathrm { H } ^ { + }$ from phosphoric acid (PA) induce mild protonation of PBI chains.This initial protonation expands the dense polymer network, facilitating structural optimization by salt ions $( \mathrm { N a ^ { + } , K ^ { + } , \ C a ^ { 2 + } } )$ ,which modulate the network architecture.The selection of NaCl,KCl,and $\mathrm { C a C l } _ { 2 }$ is predominantly founded on their distinct charge types and ionic radii,with the objective of systematically exploring the impact of ion type on the doping behavior and subsequent properties of the PBI membrane.Moreover,these ions exhibit extensive prevalence in natural environments and biological systems,which serve as the crucial application contexts for this research.

This approach simultaneously improves proton transport eficiency and enables precise ion doping.The process begins with hydrogen ion regulation (Fig.la),followed by salt ion introduction to direct PBI network reorganization via non-covalent interactions (Fig.lb) [29]. Replacing organic solvents with an inorganic salt-based method enhances controllability and mitigates environmental and toxicological concerns associated with solvents like dimethylformamide [3O]. Critically,salt ions preferentially localize in BI rings,promoting a more ordered molecular arrangement.A critical finding is the preferential localization of salt ions in BI rings,which promotes a more ordered molecular arrangement. This enhanced ordering increases the reactivity of the -NH- functional groups,thereby strengthening electrostatic interactions with charge-balancing ions such as $\mathrm { C l ^ { - } }$ (Fig. 1c). Fundamentally， the strategy utilizeslow-cost precursors to achieve performance improvements,thus reinforcing the cost-effectiveness of ICRFB systems (Fig.1d) [31].

# 3．Results and discussion

# 3.1.Regulating of hydrogen ion doping

The ADL quantifies the extent of hydrogen ion doping within the PBI membrane.As shown in Fig.3a,ADL values of 6-9 are exhibited by PAdoped membranes,significantly higher than those doped with SA(2) or PyA(O.5),by which the superior doping efficiency of PA is demonstrated.The ADL for PA-doped system increases gradually,reaching saturation after approximately $4 0 \ \mathrm { h } ,$ indicating a stable doping equilibrium.The effect of PA concentration on the ASR is illustrated in Fig.3b-g,in which a systematic increase in final ASR with rising PA concentration is revealed.A notable increase is observed at $4 \mathbf { M }$ and 6M PA(Fig.3c and d),suggesting that the polymer matrix is expanded by enhanced hydrogen ion uptake.Progressively pronounced swelling is induced by increasing PA concentrations to 8-12 M(Fig. 3e-g). Notably, at $\bf { 1 2 \ M }$ PA,a sharp increase of ${ \sim } 2 . 4 \%$ in the ASR is recorded. Overswelling is indicated by this,where the network structure is disrupted and intermolecular spacing is increased by excessive acid, potentially leading to the mechanical integrity being compromised [35].

WU,SR,AU,and internal resistance of low-concentration (2-6 M) PA-doped membranes are compared with pristine mPBI and N115 membranes in Fig.3h. Compared to N115 membrane,a more compact network structure is exhibited by the undoped mPBI membrane, resulting in lower water/acid uptake and reduced swelling. Conversely, the opposite trend is followed by the internal resistance of complete cells (Fig.3i),with the highest resistance $\left( > 8 0 \ : \mathrm { m } \Omega \ : \mathrm { c m } ^ { 2 } \right)$ being displayed by the N115-based cell.Membrane hydrophilicity isprogressively improved with increasing PA concentration. Consequently,a systematic decrease is observed in the internal resistance of ICRFBs with PA-doped mPBI membranes,reaching $3 7 . 9 \ \mathrm { m } \Omega \ \mathrm { c m } ^ { 2 }$ at 6 M PA.This reduction is attributed to PA-induced swelling,by which intermolecular spacing is expanded and proton transport is facilitated.Thus,PBI chain packing is modulated by optimal low-concentration PA doping,whereby proton conductivity is balanced with mechanical integrity.

FT-IR spectra of mPBI,2 $\mathbf { M @ m P B I }$ ， $3 \ \mathrm { M @ m P B I }$ ，and $4 \ \mathrm { M @ m P B I }$ membranes are presented in Fig.3j, by which the influence of PA concentration on chemical structure is elucidated.Characteristic peaks at ${ \sim } 3 4 0 0 ~ \mathrm { c m } ^ { - 1 }$ and ${ \sim } 1 6 2 0 ~ \mathrm { c m } ^ { - 1 }$ are exhibited by all samples,corresponding to $\mathrm { N - H }$ stretching of the BI rings and $- \mathrm { N H } - \mathrm { \nabla } / = \mathrm { N } .$ within the BI moiety,respectively [28,36].While a shift in these spectral features is generally caused by acid doping [37],no significant alterations in peak position,intensity,full width at half maximum (FWHM) are detected in the $\mathbf { 2 } { \cdot } 4 \mathbf { M }$ PA doped membranes.This stability is likely attributed to the mild doping conditions ( ${ \mathrm { 1 5 0 ~ } } ^ { \circ } \mathrm { C } ,$ 2-4 M PA),by which the PBI backbone is not substantially modified.

SEM images of mPBI, $2 \ \mathbf { M @ m P B I }$ and $3 \ \mathrm { M @ m P B I }$ membranes are displayed in Fig.3k-m. Compared to pristine mPBI membrane (Fig. 3k), uniform,moderate swelling is exhibited by the $2 \ \mathrm { M @ m P B I }$ membrane (Fig.3l),a more pronounced swelling is observed in the $3 \ \mathrm { M @ m P B I }$ membrane (Fig.3m).It is suggested by these observations that polymer chain packing is optimized by low PA concentrations (e.g.2 M),while the structural integrity of the PBI framework is maintained.

# 3.3.Ion regulation mechanism

# 3.3.1．Hydrogen ion effect

It is well established that the doping of PBI with PA is driven by acidbase interactions [44-46].Specifically, the electron-rich nitrogen within the PBI-NH- group is identified as a photophilic site,while the role of proton donor is fulfilled by PA [47]. Consequently, the -NH- moiety is recognized as the primary active site for this interaction.This mechanism is corroborated by computed ESP distributions (Fig.6a),in which the -NH- group is identified as the energetically favored protonation site.As illustrated in Fig.6b,the-NH-group is converted into a cationic $- \mathrm { N H } _ { 2 } ^ { + }$ by protonation.Proton availability is raised by increasing PA concentration,whereby the degree of chain protonation is enhanced. Inter-chain spacing is expanded and packing density is reduced by the resulting electrostatic repulsion between adjacent charged molecular chains,by which a more open membrane structure is yielded.The increased WU,SR,and AU observed in $\mathrm { H } ^ { + }$ -doped membranes are accounted for by this structural relaxation.Notably,sufficient protons for partial chain protonation are provided even by low concentrations (e.g.,2 M).Crucially,the PBI backbone is not compromised by the dopinglevel，wherebyanoptimalbalancebetween conductivity-enhancing swelling and mechanical stability is achieved.

# 3.3.2. Salt ion effect

Weak interactions within mPBI and salt-doped membranes (mPBI-Na, mPBI-K, mPBI-Ca membranes) are computationally assessed using the reduced density gradient (RDG) method (Fig.7).No significant changes are shown by the red regions $( \mathrm { s i g n } ( \lambda 2 ) \rho > 0 )$ ,suggesting that strong steric repulsions are not introduced and the covalent framework is not altered by salt doping.This is aligned with FT-IR and XRD results, by which the absence of new chemical bond formation is confirmed. Compared to pristine mPBI membrane (Fig.7a),a notable increase in the density and extent of features in the blue-green region $( \mathrm { s i g n } ( \lambda 2 ) \mathrm {  p } < 0 )$ is displayed by the ion-doped membranes membranes (Fig.7b-d).Additionally,enhanced weak non-covalent interactions (e.g.,van der Waals forces)are suggested by increased point density in the near-zero region $( \mathsf { s i g n } ( \lambda 2 ) \rho { \approx } 0 )$ .Itis indicated by these observations that dense polymer chain packing is disrupted by salt ion incorporation,resulting in a more expanded, loosely structured network.It is revealed by further comparison that the order: mPBI $. \mathrm { C a } > \mathrm { m P B I - N a } > \mathrm { m P B I - K }$ is followed by cluster density in the blue region.It is implied that the strongest attractive interaction with BI rings is exerted by $\mathsf { C a } ^ { 2 + }$ ,followed by $\mathrm { N a ^ { + } }$ ， with the weakest effect being exhibited by $\mathrm { K } ^ { + }$ consistent with prior XPS analysis.

It is demonstrated by combined experimental and computational analyses that the strongest interaction with the BI rings is exhibited by $\mathrm { C a } ^ { 2 + }$ ，whereby the greatest influence on subsequent electrostatic interactions between-NH- groups and $\mathrm { C l ^ { - } }$ is exerted,whereas the weakest effect is exhibited by $\mathrm { K } ^ { + }$ .Notably,a moderate,balanced electrostatic effect on $\mathrm { C l ^ { - } }$ is induced by $\mathrm { N a ^ { + } }$ .Concurrently,a higher degree of molecular order is promoted by $\mathrm { N a ^ { + } }$ via robust interactions with $\pi$ -electrons,an effect comparatively weaker in $\mathrm { C a ^ { 2 + } }$ and $\mathrm { K } ^ { + }$ systems. Consequently,moderate electrostatic interactions with $\mathrm { C l ^ { - } }$ are uniquely facilitated by $\mathrm { N a ^ { + } }$ incorporation,while the PBI backbone's intrinsic stability is preserved.An optimal balance between accelerated proton transport and mechanical integrity is achieved by this synergy.

# 3.4. Single-cell performance

Hydrogen-ion-doped membranes (thickness: $4 0 0 ~ { \mu \mathrm { m } } )$ are fabricated and integrated into ICRFBs.The influence of PA concentration (2-6 M) on cell performance at $1 0 0 \mathrm { \ m A \ c m ^ { - 2 } }$ is illustrated in Fig.8a. Compared to undoped mPBI, improved CE and VE are exhibited by cells utilizing doped membranes.Notably,enhancements are observed to be most pronounced at lower concentrations (2-3 M) but are seen to diminish as PA concentration is increased to ${ \bf 4 } { \bf - } { \bf 6 } { \bf \Delta M }$ 、This decline is attributed to excessive swelling at high doping levels,by which ion selectivity is reduced and CE is impaired. Conversely,moderate interchain expansion is induced by lower PA concentrations,whereby proton conductivity is enhanced without structural or mechanical stability being compromised.Consequently,simultaneous improvements in CE and VE are achieved by moderate doping.

The performance of ICRFBs assembled with $2 \ \mathrm { M @ m P B I }$ and 3 $\mathbf { M @ m P B I }$ membranes of varying thicknesses (2oo and $4 0 0 ~ { \mu \mathrm { m } } )$ isevaluated at $2 0 0 \mathrm { \ m A \ c m ^ { - 2 } }$ (Fig. 8b). A CE of $9 1 \%$ is yielded by using a 200 $\mu \mathrm { m } 3 \mathrm { M @ m P B I }$ membrane.CE is boosted to $9 6 \%$ by increasing thickness to $4 0 0 ~ { \mu \mathrm { m } }$ ,bywhich the enhanced ion-blocking capability of thicker membranes is confirmed.Furthermore,the single-layer counterpart is outperformed by a trilayer configuration—featuring a 2 $\mathbf { M @ m P B I }$ membrane core sandwiched between two undoped mPBI layers —with improvements of $2 . 3 \%$ in CE, $3 . 8 \%$ in VE,and $4 . 9 \%$ in EE being shown. It is indicated by these results that eficient proton transport is effectively combined with selective ion rejection by the multilayer architecture, whereby conduction and blocking requirements are balanced.

Composite membranes doped with various salt ions are fabricated using optimized $2 \mathrm { \ : M @ m P B I }$ membrane as the base. Their performance in a trilayer ICRFB configuration (mPBI/salt-doped mPBI/mPBI membranes） is summarized in Fig.8c-e.Regarding CE (Figs. 8c), $8 8 \%$ is exhibited by the control mPBI-DL membrane,which is considerably lower than commercial N115 membrane $( 9 7 \% )$ .Swelling is promoted by salt ion incorporation,whereby barrier capability against active species $( \mathrm { C r } ^ { 3 + } , \mathrm { F e } ^ { 2 + } )$ is compromised, contributing to lower CE relative to N115 membrane.However,CE is consistently improved by salt ion doping relative to undoped mPBI-DL membrane.This enhancement is attributed to increased -NH- in BI rings reactivity,by which electrostatic interactions with $\mathrm { C l ^ { - } }$ are strengthened and charge retention is improved. Regarding VE (Fig.8d), N115 $( 7 9 . 5 \% )$ is surpassed by all salt-doped membranes,but values below mPBI-DL membrane $( 8 7 . 6 \% )$ are maintained.This reduction is attributed to elevated ohmic resistance from salt ions,bywhich energy conversion efficiency is negatively impacted. EE,the product of CE and VE,is utilized as a comprehensive performance metric (Fig. 8e). At $1 2 5 \mathrm { m A c m } ^ { - 2 }$ ,anEEof $7 9 . 9 6 \%$ is achieved by the mPBI-Na-equipped ICRFB.Optimal molecular chain rearrangement is facilitated by $\mathrm { N a ^ { + } }$ incorporation,whereby proton conductivity is significantly enhanced.A higher VE compared to other doped membranes is contributed to by this,by which overall system performance is maximized despite a slight reduction in CE.Notably,even at a high current density of $2 0 0 \mathrm { \ m A \ c m ^ { - 2 } }$ ,EE is observed to remain robust at $7 5 . 5 4 \%$ ,bywhich excellent suitability for high-power applications is demonstrated.It is indicated by these results that the inherently limited proton transport in the densely packed pristine mPBI membrane is mitigated by the moderate structural swelling induced by $\mathrm { N a ^ { + } }$ doping.

The deconvoluted spectra of N 1s in Fig. S4e suggest an increase in -NH- content and a decrease $\mathbf { i n } = \mathbf { N } .$ content for post-cycling mPBI-Na,leading to a higher $- \mathrm { N H } - \mathrm { \nabla } / = \mathrm { N } .$ peak area ratio (a detailed comparison is presented in Table S2).This observation implies the reactivity of the BI framework in mPBI-Na reduced after cycling,which weakens electrostatic interactions between BI rings and $\mathrm { C l ^ { - } }$ ,thereby hindering charge equilibrium within the membrane. # 4.Conclusion

A dual-ion modification strategy is presented in this study to tailor the physicochemical properties of PBI membranes.Molecular chain packing and interfacial architecture are effectively modulated by the sequential introduction of hydrogen ions derived from PA and specific salt ions $( \mathrm { N a ^ { + } , \ K ^ { + } , \ C a ^ { 2 + } } )$ . The underlying synergistic mechanism is revealed by combined experimental and theoretical analyses:Acid-base interactions with the BI rings are engaged in by hydrogen ions from PA, whereby the protonation of nitrogen sites is resulted in.Electrostatic repulsion is induced by the generation of positive charges along the polymer backbone,whereby interchain spacing is increased and the membrane free volume is expanded.Notably,proton conductivity is selectively enhanced by employing moderate PA concentrations (e.g.2, $3 \mathrm { { M } ) }$ ,while the mechanical integrity of the PBI matrixis preserved.

Based on these findings,the mPBI-Na membrane is selected from the three salt ions $( \mathrm { N a } ^ { + } , \mathrm { K } ^ { + }$ ,and $\mathsf { C a } ^ { 2 + }$ ) modified membranes due to its superior overall performance.Specifically,strong $\pi$ -interactions with the BI rings are promoted by the incorporation of $\mathrm { N a ^ { + } }$ ,whereby molecular chain alignment within the PBI matrix is facilitated.Furthermore,the activity of the -NH- sites is modulated and electrostatic associations between the BI rings and $\mathrm { C l ^ { - } }$ are enhanced by $\mathrm { N a ^ { + } }$ .Consequently,an optimal trade-off between proton conductivity and structural stability is achieved by the mPBI-Na membrane.When employed as a separator in ICRFBs operating at $2 0 0 \mathrm { \ m A c m ^ { - 2 } }$ and $5 0 ^ { \circ } \mathrm { C } ,$ a CEof $9 3 \%$ a VE of $8 1 \%$ ， and an EE of $7 6 \%$ are achieved by the mPBI-Na membrane. Notably,an EE above $6 4 . 7 8 ~ \%$ isretained by the device after 4Oo cycles,by which exceptional chemical stability and long-term durability are demonstrated.Compared to conventional methods like covalent grafting,this dual-ion regulation strategy is demonstrated to be simpler,more costeffective,and environmentally sustainable. Thus,a promising avenue for designing high-performance separators for next-generation RFBs is presented by it.
