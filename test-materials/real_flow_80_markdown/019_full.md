To address the sluggish reaction kinetics of the negative electrode in vanadium redox flow batteries (VRFBs), $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ nanoparticles are synthesized via a solvothermal method and then immobilized on mesoporous carbon (MC) to form $\mathrm { B i } _ { 2 } \mathrm { O } _ { 3 } @ \mathrm { M C }$ catalyst particles,which are subsequently anchored onto carbon felt (CF) to obtain the $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C / C F }$ composite electrode.The results show that the $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C / C F }$ electrode exhibits enhanced wettability,with a contact angle of $9 2 . 8 ^ { \circ }$ ,which is $3 7 . 6 ^ { \circ }$ lower than that of the pristine CF.At a current density of $2 0 0 \mathrm { \ m A \ c m ^ { - 2 } }$ ,the asymmetric cell using $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C / C F }$ as the negative electrode delivers an energy efficiency (EE)of $8 5 . 0 \%$ and an electrolyte utilization of $6 7 . 4 \%$ .These values represent improvements of $1 2 . 7 \%$ and $1 8 . 7 \%$ over the pristine CF,respectively.When the current density increases to $5 0 0 \mathrm { \ m A } \mathrm { c m } ^ { - 2 }$ ,the pristine CF cell cannot be charged or discharged due to severe polarization.In contrast, the $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C / C F }$ cell still maintains an EE of $6 9 . 4 \%$ ，Furthermore,the EE shows a slow decay over 40o charge and discharge cycles,indicating excelent cycling stability.This work provides a viable strategy for designing high-power VRFB electrodes.

# 1．Introduction

Rapid economic growth has driven the continued consumption of fossil fuels.The resulting environmental concerns have accelerated the deployment of renewable energy.However,the intermittency and variability of renewable resources,such as solar and wind,compromise power-system stability.Therefore,energy storage technologies must be adopted to improve power quality and supply reliability [1-4].Vanadium redox flow batteries (VRFB) are considered one of the most promising energy storage technologies due to their high safety,large energy capacity,and long cycle life [5-8].VRFB employ $\mathrm { V O } _ { 2 } ^ { + } / \mathrm { V O } ^ { 2 + }$ and $\mathrm { V } ^ { 3 + } / \mathrm { V } ^ { 2 + }$ redox couples in the positive and negative electrolytes, respectively.They store and release energy through changes in the oxidation states of vanadium ions during charge and discharge [9-11]. Asa key component of the VRFB,the electrode provides reaction sites for vanadium ions. Its structure and physicochemical properties critically influence the mass transport of electroactive species and the reaction kinetics [12-15].

Carbon felt (CF) is widely used as an electrode material in VRFB owing to its low cost,high electrical conductivity,and good chemical stability [16,17].However,when used as the negative electrode,CF exhibits sluggish $\mathrm { V } ^ { 3 + } / \mathrm { V } ^ { 2 + }$ redox kinetics.It is also prone to the hydrogen evolution side reaction.These issues hinder the further improvement of VRFB performance [18-21].Therefore,it is necessary to develop negative electrode materials with high catalytic activity to enhance the rate capability and energy efficiency of VRFB [22].

Surface modification with catalytically active metal oxides is an effective approach to enhance the electrochemical activity of CF [23-30].Chu et al. [31] prepared $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ modified carbon nanotube composites.The redox peak current of the resulting $\mathrm { B i _ { 2 } O _ { 3 } / C N T s }$ electrode showed a threefold increase.Its EE improved by about $5 \%$ Mehmood et al.[32] modified graphite felt with interconnected $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ nanowires.These nanowires were derived from a bismuth-based metal-organic framework via a solvothermal route.The resulting VRFB achieved an EE of $8 2 \%$ .This is $1 8 \%$ higher than that of the pristine graphite felt. Schneider et al.[33] decorated the CF surface with $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ using an impregnation method.The charge-transfer resistance of this electrode decreased by $2 2 . 7 \%$ .Meanwhile,its EE remained stable at $7 0 \%$ .Zhou et al.[34] fabricated a bismuth nanosphere/CF electrode via carbothermal reduction.At a current density of $4 0 0 \mathrm { \ m A \ c m ^ { - 2 } }$ ,theVRFB delivered an EE of $8 0 . 4 \%$ .Furthermore,the EE retention reached $9 8 . 2 \%$ after 1000 cycles.

Constructing carbon materials with ordered mesoporous structures to increase the specific surface area is another effective strategy.This approach improves the electrode performance of CF in VRFB [35-40]. Schmidt et al.[41] loaded MC onto CF via a sol-gel method.After annealing at $1 1 0 0 ~ ^ { \circ } \mathbf { C } ,$ ，the specific surface area of the CF increased by $8 4 3 \%$ .Additionally,the redox peak current of the $\mathrm { V O } _ { 2 } ^ { + } / \mathrm { V O } ^ { 2 + }$ couple increasedby $3 0 \%$ .Opar et al.[42] functionalized CF with three-dimensional N-doped mesoporous graphene synthesized through a facile hydrothermal route.At $1 5 0 \mathrm { \ m A \ c m ^ { - 2 } }$ ,the VRFB exhibited increases of $1 3 . 9 \%$ in EE and $8 \%$ in VE.Furthermore,it showed negligible EE decay over 1o0 cycles.Ji et al.[43] prepared a mesoporous N-doped carbon structure via a self-templating method.They then coated it onto graphite felt. At $1 2 0 \mathrm { \ m A \ c m ^ { - 2 } }$ ,the EE increased by $7 . 8 \%$ .After 300 cycles,the EE remained at $9 9 . 6 \%$ of its initial value.

These studies indicate that mesoporous carbon (MC) and $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ can increase the specific surface area and enhance the electrochemical activity of CF electrodes,thereby improving battery performance.However,MC exhibits limited intrinsic electrocatalytic activity.Meanwhile, owing to its high surface energy and strong van der Waals interactions, $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ tends to agglomerate on the CF.This agglomeration results in a substantial reduction in the effective catalytically active surface area [44].

To address the aforementioned issues, $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ nanoparticles were synthesized via a solvothermal method.Leveraging the high specific surface area and ordered pore channels of MC, these nanoparticles were confined within the mesopores and anchored onto the carbon surface. This physical confinement effectively mitigated particle agglomeration. Consequently,a $\mathrm { B i } _ { 2 } \mathrm { O } _ { 3 } @ \mathrm { M C }$ composite with a highly accessible active surface area was obtained. Subsequently, the $\mathrm { B i } _ { 2 } \mathrm { O } _ { 3 } @ \mathrm { M C }$ composite was immobilized on CF via impregnation to fabricate the $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C / C F }$ negative electrode (Fig.1 schematically illustrates the $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ synthesis and the assembly of the asymmetric VRFB).The physicochemical properties and electrochemical performance of the composite electrode were systematically characterized.Furthermore,an asymmetric cell was assembled using pristine CF as the positive electrode and $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C / C F }$ as the negative electrode to evaluate the cell performance.At a current density of $2 0 0 \mathrm { \ m A } \mathrm { c m } ^ { - 2 }$ ,this asymmetric cell delivered an EE of $8 5 . 0 \%$ This represents a $1 2 . 7 \%$ improvement over the pristine CF cell.Moreover,it exhibited excellent stability over 40o cycles.

# 2.2. Synthesis of the $B i _ { 2 } O _ { 3 } @ M C$ composite

$\mathrm { B i } ( \mathrm { N O } _ { 3 } ) _ { 3 } { \cdot } 5 \mathrm { H } _ { 2 } \mathrm { O }$ was dissolved in ethanol under continuous stirring, followed by the addition of ethylene glycol.After magnetic stiring for $1 0 \ \mathrm { m i n }$ ，the mixture was ultrasonicated for an additional $1 0 \ \mathrm { m i n }$ to obtain a uniform suspension,which was then transferred into a $1 0 0 ~ \mathrm { { m L } }$ Teflon-lined stainless steel autoclave (YC-1oo, Zhengzhou Boke Instrument Co.,Ltd.).The sealed autoclave was maintained at $1 6 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 5 \mathrm { h } }$ and then naturally cooled to room temperature.The precipitate was collected by vacuum filtration,washed,and dried to obtain the precursor.The precursor was subsequently annealed in a tube furnace (SGM.T8O/12,Luoyang Sigma High Temperature Furnace Co.,Ltd.)at $3 0 0 ^ { \circ } \mathrm { C }$ for $^ { 2 \mathrm { h } }$ under an $\Nu _ { 2 }$ atmosphere with a heating rate of $5 ^ { \circ } \mathrm { C } \operatorname* { m i n } ^ { - 1 }$ ， yielding $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ nanoparticles. $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ nanoparticles and MC were then mixed ata mass ratio of 1:1 and thoroughly ground in an agate mortar to obtain the $\mathrm { B i } _ { 2 } \mathrm { O } _ { 3 } @ \mathrm { M C }$ composite.

# 2.3. Synthesis of the $B i _ { 2 } O _ { 3 } @ M C / C F$ electrode

First, the CF was pretreated by washing it three times with deionized water and then ultrasonicating it in ethanol for $3 0 ~ \mathrm { { m i n } }$ . Subsequently, the CF was heat-treated in a muffle furnace at $3 5 0 ~ ^ { \circ } \mathrm { C }$ for $^ \textrm { \scriptsize 1 h }$ .After cooling,it was set aside for further use.Next, $5 0 ~ \mathrm { m } g$ of the $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 } @ \mathbf { M C }$ powder and $2 0 0 \mathrm { m } g$ of $5 \mathrm { w t } \%$ Nafion solution were added into $2 0 \mathrm { m L }$ of ethanol.This mixture wasultrasonicated for $3 0 \ \mathrm { m i n }$ to form a homogeneous suspension.The pretreated CF was then immersed into this suspension.Aftera dip-coating process,the CF was dried in a vacuum oven at $6 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 1 \mathrm { ~ h ~ } }$ .It was cooled naturally to obtain the $\mathrm { B i } _ { 2 } \mathrm { O } _ { 3 } @ \mathrm { M C } /$ CF composite electrode.The mass loading of $\mathrm { B i } _ { 2 } \mathrm { O } _ { 3 } @ \mathrm { M C }$ on the CF was determined to be $3 . 7 ~ \mathrm { m g ~ c m } ^ { - 2 }$

# 3.1.2.Wettability evaluation

The interfacial wettability between the electrodes (CF,MC/CF,and $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C / C F } )$ and the electrolyte $( 1 \mathrm { ~ M ~ V ~ } ^ { 3 . 5 + } + 3 \mathrm { ~ M ~ H } _ { 2 } S O _ { 4 } )$ was evaluated via contact angle measurements,with the results presented in Fig.2e-g.The pristine CF(Fig.2e) exhibits a highly hydrophobic nature with a contact angle of $1 3 0 . 4 ^ { \circ }$ .Upon the introduction of mesoporous carbon (MC),the contact angle of the MC/CF electrode (Fig.2f) decreases significantly to ${ } ^ { 1 0 2 ^ { \circ } }$ (a reduction of $2 8 . 4 ^ { \circ } \cdot$ ),indicating that the MCconsiderably improvesthe electrode wettability.Forthe $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C / C F }$ electrode (Fig.2g),the contact angle further drops to $9 2 . 8 ^ { \circ }$ ,which is $3 7 . 6 ^ { \circ }$ and $9 . 2 ^ { \circ }$ lower than those of the pristine CF and MC/CF,respectively.This demonstrates a strong synergistic effect of the $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ modification in enhancing the wettability.These results suggest that the introduction of MC not only provides a larger specific surface area via its mesoporous framework but also mitigates the surface hydrophobicity,thereby facilitating electrolyte penetration.Furthermore, the $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ modification introduces O-H and Bi-O-C active sites on the CF surface.This effectively minimizes the contact angle,providing robust interfacial support for the highly efficient transport of vanadium ions.

# 3.1.3.XRD and XPS analysis

The crystal structures of the MC and the $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 } @ \mathbf { M C }$ composite were examined via XRD to confirm the successful loading of $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ . As shown in Fig.3a, the MC exhibits broad diffraction features at $2 9 ^ { \circ }$ and $4 3 ^ { \circ }$ . In the XRD pattern of $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C } ,$ ,additional distinct peaks appear at $3 0 ^ { \circ }$ ， $4 5 ^ { \circ }$ ,and $5 2 ^ { \circ }$ ,which can be attributed to ${ \bf B i _ { 2 } O _ { 3 } }$ .This indicates that $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ issuccessfully loaded onto the MC matrix.Notably,the characteristic feature of MC at $4 3 ^ { \circ }$ remains evident in the composite,suggesting that the carbon framework is largely preserved after the $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ loading.

Fig.3b-e presents the XPS spectra of $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C }$ .The survey spectrum (Fig.3b) displays Bi, C,and O signals,confirming the successful integration of these elements.In the high-resolution C 1s spectrum (Fig.3c),the carbon species can be deconvoluted into four distinct peaks at $2 8 4 . 8 0 \ \mathrm { e V }$ ,286.40 eV,288.98 eV,and $2 9 1 . 8 8 \mathrm { e V }$ ,which correspond to C-C, C-O, $\scriptstyle \mathbf { C } = \mathbf { O }$ ，and $\pi - \pi$ conjugate bonds,respectively.The preservation of the $\pi - \pi$ peakimplies that the carbon framework of MC remains structurally intact.

More importantly, the high-resolution O1s and Bi 4f spectra reveal strong interfacial chemical interactions between $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ and the MC matrix.As shown in Fig.3e,the O 1s spectrum can be fitted into four peaks at 530.68 eV,532.08 eV, $5 3 3 . 3 8 \mathrm { e V }$ ,and $5 3 5 . 2 8 \mathrm { e V }$ ,assigned to Bi-O, $\mathrm { C } { = } \mathrm { O }$ ,COOH,and O-H bonds,respectively [45,46].In the Bi 4f spectrum (Fig.3d),two main peaks are located at $_ { 1 6 5 . 0 8 \ \mathrm { e V } }$ and $1 5 9 . 7 8 \ \mathrm { e V }$ ,corresponding to Bi $4 \mathrm { f } _ { 5 / 2 }$ and Bi $4 \mathrm { f } _ { 7 / 2 }$ of $\mathbf { B i } ^ { 3 + }$ ,respectively [47,48].

Notably,compared to the standard pure $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ reported in the literature where Bi $4 \mathrm { f } _ { 5 / 2 }$ and Bi $4 \mathrm { f } _ { 7 / 2 }$ are typically located at $1 6 6 . 0 \ \mathrm { e V }$ and $1 6 1 . 5 \mathrm { e V }$ ,and the lattice Bi-O bond is at $5 2 9 . 7 \mathrm { e V }$ ,the binding energies of the composite exhibit significant shifts [49]. Specifically,the Bi 4f peaks in the $\mathrm { B i } _ { 2 } \mathrm { O } _ { 3 } @ \mathrm { M C }$ composite shift to lower binding energies by approximately $0 . 9 2 \ \mathrm { e V }$ and $1 . 7 2 \ \mathrm { e V }$ ,respectively. Conversely,the Bi-O peak in the O 1s spectrum shifts to a higher binding energy (from $5 2 9 . 7 \mathrm { e V }$ to $5 3 0 . 6 8 \mathrm { e V } .$ ）[50].This prominent binding energy shift provides direct evidence of strong chemical coupling. This strong chemical interaction,likely formed via Bi-O-C interfacial linkages,not only tightly anchors the $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ nanoparticles to prevent detachment during electrolyte flushing but also constructs highly efficient electron transport pathways,thereby synergistically accelerating the redox kinetics of vanadium ions.

# 3.2.Electrochemical characterization

The electrocatalytic activity and reaction kinetics of the $\mathrm { B i } _ { 2 } \mathrm { O } _ { 3 } @ \mathrm { M C } /$ CF composite electrode toward the $\mathrm { V } ^ { 3 + } / \mathrm { V } ^ { 2 + }$ redox reaction were systematically investigated by cyclic voltammetry (CV）and electrochemical impedance spectroscopy (EIS).As shown in Fig. $^ { 4 } \mathbf { a }$ ,atascan rate of $1 0 \ \mathrm { m V } \ s ^ { - 1 }$ ，the $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C / C F }$ electrode exhibits the highest anodic and cathodic peak current densities $( \mathrm { I _ { p a } }$ and $\mathrm { I _ { p c } ] }$ .Meanwhile,its peak potential separation $\Delta \mathrm { E _ { p } } )$ decreases markedly to $0 . 2 8 \mathrm { V }$ ,compared with $0 . 5 4 \mathrm { ~ V ~ }$ for pristine CF.It is worth noting that this significant reduction in $\Delta \mathrm { E _ { p } }$ is a synergistic result of both accelerated intrinsic reaction kinetics and enhanced electrical conductivity. Specifically, the highly dispersed $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ nanoparticles serve as abundant electrocatalytic active sites that effectively lower the activation energy barrier for the $\mathrm { V } ^ { 3 + } / \mathrm { V } ^ { 2 + }$ redox reaction. Simultaneously，the interconnected MC network not only provides accessible interfaces for ion transport butalso actsas a highly conductive framework,which significantly mitigates the ohmic polarization of the composite electrode.Together,these dual benefits contribute to faster electron transfer and significantly improved electrochemical reversibility.

To further evaluate the mass-transport characteristics,Fig.4b and c shows the CV curves of the $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C / C F }$ electrode recorded at different scan rates $( 2 { - } 2 0 ~ \mathrm { m V } ~ s ^ { - 1 } )$ ）and the corresponding peak-current ratio $\mathrm { ( - I _ { p a } / I _ { p c } ) }$ .With increasing scan rate,both anodic and cathodic peak currents increase and the peak potentials shift systematically, which is consistent with a quasi-reversible redox process.Compared with pristine CF and MC/CF, $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C / C F }$ exhibits an $\mathrm { \partial \mathrm { - I _ { p a } / I _ { p c } } }$ ratio close to unity over the entire scan rate range with a weaker scan rate dependence,indicating improved electrochemical reversibility (Fig.4b and c). Fig.4d plots the peak current $( \mathrm { I _ { p } } )$ as a function of the square root of scan rate $( \nu ^ { 1 \bar { / } 2 } )$ . A good linear relationship is observed for $\mathrm { B i } _ { 2 } \mathrm { O } _ { 3 } @ \mathrm { M C } /$ CF,suggesting diffusion-influenced behavior in this scan-rate range.The fitted slope for $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C / C F }$ (0.81）is higher than that for MC/CF (0.79) and CF (0.42),indicating enhanced apparent mass transport of vanadium species in the $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C / C F }$ electrode.

Electrochemical impedance spectroscopy (EIS) was performed to probe the interfacial properties and reaction kinetics of the prepared electrodes,with the Nyquist plots and the fitted equivalent circuit model presented in Fig.4e.In this model, $\mathrm { R } _ { s }$ represents the total ohmic resistance,which includes the electrolyte resistance,the intrinsic resistance of the electrode,and the contact resistance.CPE stands for the constant phase element,corresponding to the double-layer capacitance at the porous electrolyte interface. $\operatorname { R } _ { \operatorname { c t } }$ denotes the charge transfer resistance associated with the $\mathrm { V } ^ { 3 + } / \mathrm { V } ^ { 2 + }$ redox reaction,and $\mathsf { W } _ { 0 }$ represents the Warburg impedance related to the mass diffusion of vanadium ions.

Based on the fitting results (Fig.4f),the $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C / C F }$ electrode exhibits a much lower charge transfer resistance $( \mathrm { R _ { c t } } = 1 5 . 3 ~ \Omega )$ than MC/CF $_ { ( 3 9 . 6 ~ \Omega ) }$ and pristine CF $\left( 3 4 5 . 4 ~ \Omega \right)$ ，indicating accelerated interfacial charge transfer kinetics.Additionally, the $\mathrm { R } _ { s }$ of the composite electrode remains ata remarkably low level,confirming that the introduction of the MC matrix effectively maintains the excellent electrical conductivity of the framework.Together with the reduced contact angle, the decreased $\operatorname { R } _ { \operatorname { c t } }$ can be associated with improved electrode wettability, which promotes electrolyte infiltration and creates more effective electrochemically active interfaces.

Overall, the $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C / C F }$ electrode shows the lowest impedance among the three electrodes,consistent with its higher peak currents and smaller $\Delta \mathrm { E _ { p } }$ in the CV results,thereby supporting its improved cell performance at high current densities.

# 3.3.Battery performance evaluation

Galvanostatic charge and discharge tests were performed to evaluate the cell performance of the C-C (CF),MC-C (MC/CF),and BMC-C $( \mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C / C F } )$ configurations at different current densities.Fig.5a and b shows the representative voltage capacity profiles.The BMC-C cell exhibits a lower charge plateau and a higher discharge plateau than the C-C and MC-C cells.For example,at $2 0 0 \ \mathrm { m A \ c m ^ { - 2 } }$ ,the charge plateau decreases from $1 . 6 4 \mathrm { ~ V ~ }$ (C-C) to $1 . 5 0 \mathrm { V }$ ,while the discharge plateau increases from $1 . 0 1 \mathrm { ~ V ~ }$ to $1 . 3 0 ~ \mathrm { V }$ .Accordingly,the charge and discharge voltage gap (△V) is reduced to $0 . 2 0 \mathrm { V }$ for BMC-C,compared with $0 . 6 3 \mathrm { V }$ for C-C and $0 . 3 4 \mathrm { V }$ for MC-C,consistent with the average voltage plots in Fig.5c.These results indicate that the $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 } @ \mathbf { M C }$ modification effectivelyalleviates electrode polarization.

Fig.5d-f detail the rate performance and the corresponding electrolyte utilization of the different cells,revealing that the BMC-C cell exhibits excellent high-rate capabilities.In the low current-density region $( 5 0 { \cdot } 7 5 \mathrm { \ m A } \mathrm { \ c m } ^ { - 2 } )$ ,the discharge capacity of the BMC-C cell is slightly lower than those of the C-C and MC-C reference cells.This phenomenon stems from the trade-off between kinetic activity and self discharge:although the high specific surface area of $\mathrm { B i } _ { 2 } \mathrm { O } _ { 3 } @ \mathrm { M C }$ accelerates the reaction kinetics,the prolonged charge and discharge duration at low current densities increases the risk of vanadium ion crossover through the membrane,leading to a minor capacity loss.However,when the current density exceeds $1 0 0 \mathrm { \ m A \ c m ^ { - 2 } }$ ,kinetic limitations become the dominant factor,and the advantages of the BMC-C cell become highly significant.As the current density increases to 2Oo and $3 0 0 \mathrm { \ m A c m ^ { - 2 } }$ ,the capacities of the C-C and MC-C cells decay sharply due to severe concentration and ohmic polarizations (with the C-C cell unable to operate stably at $3 0 0 \mathrm { \ m A \ c m ^ { - 2 } }$ .In contrast, the BMC-C cell maintains a high capacity retention. In addition to the excellent rate capability,the long-term operational stability of the electrode serves as the most direct metric for evaluating its practical engineering viability.Fig. 6a and Fig.S3 illustrate the longterm cycling performance of the BMC-C cell over 40o cycles at a high current density of $2 0 0 \mathrm { \ m A \ c m ^ { - 2 } }$ .Throughout the entire cycling process, the EE of the cellis consistently maintained at approximately $8 0 \%$ and the average charge and discharge voltages remained essentially unchanged.Remarkably, even after 4Oo cycles,the cell still delivers a high EEof $8 1 . 3 \%$ ,demonstrating outstanding cycling stability.

The stability of the $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C / C F }$ electrode was further assessed by post cycling characterizations. SEM and EDS analyses after 4Oo cycles (Fig. 6b and c) show that the $\mathrm { B i } _ { 2 } \mathrm { O } _ { 3 } @ \mathrm { M C }$ layer on the carbon fibers remains intact without noticeable detachment or agglomeration,even after prolonged electrolyte flow.This indicates robust anchoring between the $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 } @ \mathbf { M C }$ modifier and the carbon substrate.Inaddition, the three-dimensional framework of MC helps mitigate the loss of Bi containing active species during long-term cycling, thereby contributing to sustained catalytic activity.

Overall， the $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C / C F }$ electrode,combining good electrochemical reversibility with structural stability,is promising for long life, high-power operation of VRFB.

# 4.Conclusion

In summary, $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 }$ nanoparticles were synthesized via a solvothermal route and combined with MC to form a $\mathrm { B i } _ { 2 } \mathrm { O } _ { 3 } @ \mathrm { M C }$ composite,which was subsequently immobilized on CF to fabricate the $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C / C F }$ composite electrode.Compared with the pristine CF,the $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C / C F }$ exhibits enhanced electrocatalytic activity toward the $\mathrm { V } ^ { 3 + } / \mathrm { V } ^ { 2 + }$ redox reaction at the negative electrode. Furthermore, the contact angle with the electrolyte decreases by $3 7 . 6 ^ { \circ }$ ，indicating improved interfacial wettability. Consequently,at a current density of $2 0 0 \mathrm { \ m A c m } ^ { - 2 }$ ,the assembled celldelivers an EE of $8 5 . 0 \%$ ,representing a $1 2 . 7 \%$ absolute increase relative to the pristine CF cell. Even ata highrate of $5 0 0 \mathrm { \ m A \ c m ^ { - 2 } }$ ,an EE of $6 9 . 4 \%$ is still achieved. In addition, the cell displays only a slow EE decay over 4Oo charge and discharge cycles, demonstratinggood long-termcyclingstability.Overall, the $\mathrm { B i _ { 2 } O _ { 3 } } @ \mathrm { M C / C F }$ electrode synergistically improves the interfacial propertiesand mass-transport characteristics,thereby enhancing the flow battery performance under high-rate operation.This work provides a viable and highly effective strategy for the rational design of high-power VRFB electrodes.
