# ABSTRACT

Adventof membrane-less soluble lead flow bateries (SLFBs)are limited bylowareal capacity,low cycle-life and capacity fade associated with $\mathrm { P b O } _ { 2 }$ positive electrode passivation.In the present study,a soluble Lead Flow Battery (SLFB) with a specific capacity of $1 0 0 \mathrm { \ m A h / c m ^ { 2 } }$ is realized using physicochemically-modified graphite felts as electrode substrate.Single cellcomprising pristine graphite felt without additives has failed inthe first cycle,while with NaF and HDTMA $p$ -TS binary additives,the cell providesa cycle-life of 53-106 cycles depending upon its discharge cut-off voltage.Interestingly,cell employing binary additives,physicochemical modified negative,and activated graphite felt positive electrode exhibits a life-cycle of 275 to 310 without any maintenance with an average coulombic eficiency of ${ > } 9 7 \%$ $[ \mathrm { P b } ^ { 2 + } ]$ analysis of electrolyte using complexometric titration reveals that concentration of $\mathrm { P b } ^ { 2 + }$ -ions in the electrolyte gradually decreases due to accumulation of lead metalat negative and pasive crystal-gel like texture at positive electrode.XRD studies on wet crystal-gelaccumulated solids reveal presence of crystallized $\mathsf { \beta { - } P b O _ { 2 } }$ and traces of $\mathbf { \alpha _ { \alpha } } \mathbf { - } \mathbf { P } \mathbf { b } \mathbf { O } _ { 2 }$ phase along with $\mathsf { \beta { - } P b O _ { 2 } }$ of increased particle size upon drying.FESEM images of positive $\mathrm { P b } { \bf O } _ { 2 }$ electrode reveal micron and submicron size particulates with porous morphology depending upon discharge cut-offvoltage.XPS analysis confirms presence of non-stoichiometric $\mathrm { \bf P b 0 _ { x } }$ comprising a mixture of hydrous Pb(II) and Pb(IV) oxides. TEM,HRTEM,and SAED studies suggest submicron particulates comprising nanoparticles of amorphous hydrated $\mathrm { P b } { \bf O } _ { 2 }$ and $\mathsf { \beta { - } P b O _ { 2 } }$ Itis surmised that decrease in proton concentration in pores of positive $\mathrm { P b O _ { 2 } }$ electrode leads to polarization loss/ passivation towards the end of each discharge limiting complete reductive dissolution of $\mathrm { P b } { \cal O } _ { 2 }$ Evidence based schemes illustrating deposition and dissolution of $\mathrm { P b O } _ { 2 }$ along with factors influencing cycle-life of SLFBs are envisaged.

Charge reaction for SLFB is electrodeposition of lead metal and lead dioxide at negative and positive electrode,respectively, from lead methanesulphonate salt (PbMSA) dissolved in methanesulphonic acid (MSA) electrolyte while its discharge reaction relates to dissolution of lead and lead dioxide back into electrolyte.Thermodynamic reversible cell voltage of SLFB is $1 . 6 2 \mathrm { V }$ and theoretical capacity of a SLFB cell is $2 6 . 8 \ \mathrm { A h / m o l }$ of lead methanesulphonate dissolved in methanesulfonic acid.Theoretical volumetric energy density of SLFB cellis $4 3 . 4 \mathrm { W h / L }$ for $^ { 1 \mathrm { ~ M ~ } }$ solution of lead methanesulphonate. Since a common electrolyte is used for both negative and positive electrode,it does not require an ionexchange membrane to separate anolyte and catholyte unlike other membrane-based flow batteries which is a major advantage in developing SLFBs for large-scale ESS.

Although electrodeposition of lead metal and lead dioxide are well known reactions for over 1Oo years in various industrial applications, development of SLFB exploiting these reactions has not yet been realized [6,8].Development of soluble lead flow batteries with high areal capacity is desired for large-scale energy storage applications,particularly in integrating solar energy with the central grid [3].But evolution of SLFBs with high areal capacity is lacking due to use of 2D electrodes such as planar graphite sheets,plates,composites of graphite and polymers which limits the quantum of Pb and $\mathrm { P b } { \cal O } _ { 2 }$ that can be deposited at such electrodes.Furthermore,poor understanding on nature of electrode substrates,current collectors，effect of reaction kinetics, charge and discharge parameters,self-discharge,concentrations of methanesulphonic acid in electrolyte and utilization factor have also limited development of SLFBs with high areal capacity. One of the problems for failure of SLFBs is difference in coulombic efficiencies between negative and positive electrode reactions.It is known that Pb negative electrode charge and discharge reactions have nearly $1 0 0 \%$ faradaic efficiency while $\mathrm { P b O } _ { 2 }$ negative electrode reportedly suffers from poor faradaic efficiency while charging due to oxygen evolution reaction and passivation during discharge [9].Addition of suitable additives to electrolyte and deposition potential conditions can drive its faradaic efficiency close to $9 9 \%$ for charging reaction but passivation during discharge remains a problem [10].

Historically,Fritz Beck first patented soluble lead cell asa“lead perchlorate cell’using perchloric acid in 1977 and later in 1982 reported that passivation of $\mathrm { P b } { \bf O } _ { 2 }$ positive electrode observed in such cells is similar to their behaviour in lead-acid batteries [11,l2] He observed formation of $\mathrm { P b O } _ { \mathbf { x } }$ layer through SEM images after constant current charge and discharge cycling of positive electrode.Derek Pletcher etal. reported possibility of a soluble lead flow cell employing lead methanesulphonate in methane sulphonic acid encountering a similar problem with positive electrodes [13]. It has been reported that sludge accumulation in cell results in shorting between electrodes leading to its failure.Oury et.al have studied galvanostatic cycling of $\mathrm { P b } ^ { 2 + } / \mathrm { P b } 0 _ { 2 }$ electrode in methanesulphonic acid by EQCM,EIS,SEM and potential time responses,and reported formation of porous $\mathrm { P b O _ { x } }$ at end of first discharge and its partial reoxidation during second charge [14].Hence, it can be surmised that poor discharge efficiency of positive electrode is major cause for failure of SLFBs.Most of recent studies about SLFBs have areal capacity of 10 to $8 0 \ \mathrm { m A h / c m ^ { 2 } }$ with low cycle-life of 10 cycles at high areal capacity of $8 0 \mathrm { m A h } / \mathrm { c m } ^ { 2 }$ [13,15-24]. Present study is directed to performance of SLFB single cells having physiochemically modified graphite felt negative electrodes and activated positive electrode with areal capacity of $1 0 0 \mathrm { \ m A h / c m ^ { 2 } }$ ，their charge-discharge behaviour, cycle-life and study on understanding mechanism of passivation. It is noteworthy to mention that this is first ever studies on SLFB with an areal capacity of $1 0 0 \mathrm { m A h / c m ^ { 2 } }$ and its characteristics.

Recently,we reported development of perforated graphite feltand physiochemically modified graphite felt (PGF and PCGF)as negative electrode substrate and electrochemically modified graphite felt as $( \mathrm { E C G F  – P b O _ { 2 } } )$ as positive electrode substrate with an areal capacity of $1 0 0 \mathrm { \ m A h / c m ^ { 2 } }$ [25,26].In this study,efforts are made to (a) determine efficacy of combination of various modified graphite felts as negative electrode and positive electrode substrates so as to achieve a SLFB with an areal capacity $1 0 0 \mathrm { \ m A h / c m ^ { 2 } }$ alongside determining faradaic efficiency of charge and discharge reactions by gravimetric analysis and characterization of electrodes by FESEM and current- potential performance for peak power density,(b) performance characterization of best performing combination of modified graphite felt substrates through cycle-life studies by charging cell by galvanostatic constant current (CC) method and discharging by single-step CC,two-step constant currents (CCCC) and constant current and constant voltage (CCCV) methods,(c) rationalizing positive electrode post cycling by FESEM, XRD,XPS,and TEM-SAED,and (d) periodic determination of $\mathrm { P b } ^ { 2 + }$ -ions concentration in electrolyte,and (e) to realize factors affecting cycle-life of SLFBs.Two-step discharge protocol is used to study the effect of cut-off voltage on discharge efficiency of cell and to find optimum discharge parameters to extend its cycle-life.

# 2.3. Determination of $P b ^ { 2 + }$ ion concentration by complexometric titrations

Concentration of $\mathrm { P b } ^ { 2 + }$ -ions was determined by complexometric titrations using Eriochrome Black $\mathrm { T }$ as an indicator,as described elsewhere [27]. In brief,aliquots of $1 \ \mathrm { m l }$ of electrolyte were taken from electrolyte tank during cycling of single cells and diluted to $1 0 0 ~ \mathrm { { m l } }$ .10 ml of this diluted sample solution was taken into a conical flask.A spatula of powdered tartaric acid,a pinch of Eriochrome Black T indicator and $2 \mathrm { m l }$ of $\mathtt { p H } 1 0$ ammonium hydroxide were added in sequence to conical flask.This was titrated against a $0 . 0 0 5 \mathrm { m o l } / 1$ standard solution of EDTA,and lead ion concentration was determined using law of equivalence which is given by Eq. (7):

$$
\mathrm { C _ { E D T A } \times V _ { E D T A } = C _ { P b } ^ { 2 + } \times V _ { P b } ^ { 2 + } }
$$

where $\mathrm { C _ { E D T A } }$ is concentration of EDTA, VEDTA is volume of EDTA, $\mathrm { C _ { P b } ^ { 2 + } }$ is concentration of $\mathrm { P b } ^ { 2 + }$ ions in diluted sample solution and $\mathrm { V _ { P b } ^ { 2 + } }$ is volume of diluted sample solution.

# 3.1.Efficacy and cycle-life of physicochemically modified graphite felts as electrode substrates

# 3.3.5.Effect of change in $P b ^ { 2 + }$ ions concentration

One of the reasons for limited cycle-life is change in concentration of methanesulfonic acid in electrolyte.It has been observed that as concentration of $\mathrm { P b } ^ { 2 + }$ -ions decreases,two-fold methanesulfonate ions are released into electrolyte which increases acid concentration.Variation in $[ \mathrm { P b } ^ { 2 + } ]$ and MSA concentrations over cycles are estimated using complexometric EDTA titration and Eqs.(6） and $( 7 )$ derived and described in experimental section presented in Fig.8(a-f),Table S4 and Fig. S17. Faradaic charge eficiency is found to be $\sim 9 8 . 5 \%$ .Average coulombic efficiency for cells C6,C7 and C8 are $9 3 \%$ ， $9 6 \%$ and $9 7 \%$ Therefore,there is more lead and lead dioxide accumulation in case of cell C6 than cell C7 and cell C8. Most importantly, decrease in $\mathrm { P b } ^ { 2 + }$ -ions and increase in acid concentration in initial cycle is more in case of NGF due to low coulombic efficiency. Decrease in $\mathrm { P b } ^ { 2 + }$ -ions and increase in acid concentration in cell C9 is less compared to C1o due high average coulombic efficiency $9 7 . 4 \%$ .Average coulombic efficiency for cells C11, C12 and C13 are $9 6 \%$ ， $9 6 . 4 \%$ and $9 7 . 3 \%$ .Therefore,decrease in $\mathrm { P b } ^ { 2 + }$ ions and increase in acid concentration in cell C11 is more compared to cell C12 and cell C13.It is known that methanesulfonic acid is a weaker acid than sulphuric acid with low degree of dissociation at higher concentrations 44].In literature,it has been reported that concentration of free ions decreases with increase of acid concentration.According to Bescombe and Bell,degree of dissociation of methanesulfonic acid is $8 9 \%$ ， $8 6 \%$ ， $6 4 \%$ and $5 3 \%$ ,respectively,for0.5,1.0,2.0 and $3 . 0 1 \mathrm { { M } }$ MSA. Clarke and Woodward indicated a similar trend [45,46].Hence,as concentration of MSA increases,it is likely that free proton concentration also decreases.Owing to this,conductivity of electrolyte decreases and solubility of $\mathrm { P b } ^ { 2 + }$ -ions decreases.This is likely to be more pronounced inside pores of electrodes where acid concentration is likely to be higher.Furthermore,utilization co-efficient also gets affected by change in concentration. This is because of decrease in $\mathrm { P b } ^ { 2 + }$ -ions concentration in electrolyte as cycling progresses.Utilization factor is determined using Eq. (12).

# 3.3.6.Effect of discharge rate on SLFB

Rate of discharge is also found to influence discharge efficiency of SLRB cells.Cells discharged at $2 0 \mathrm { m A } / \mathrm { c m } ^ { 2 }$ exhibit faster deterioration of discharge efficiency than electrodes discharged at 10 or $5 \mathrm { m A } / \mathrm { c m } ^ { 2 }$ Best performance of cells is observed with $2 0 ~ \mathrm { m A } / \mathrm { c m } ^ { 2 }$ charge and $1 0 \mathrm { \ m A } /$ $\mathrm { { \bar { c } m } ^ { 2 } }$ discharge.

# 3.3.7.Self-discharge of SLFB

An important difference between negative electrode and positive electrode of SLFB is their self-discharge.While $\mathbf { P b }$ negative electrode undergoes self-discharge, $\mathrm { P b } { \bf O } _ { 2 }$ positive electrode is found to be stable [25,26]. This could contribute to accumulation of $\mathrm { P b } { \bf O } _ { 2 }$ at positive electrode particularly at slow rate of charging and discharging.

# 3.3.8. $P b O _ { 2 }$ shedding in SLFB

$\mathrm { P b } { \bf { O } } _ { 2 }$ shedding is another important factor that influences cell cyclelife.During initial cycles of SLFBs with $1 0 0 \mathrm { \ m A h / c m ^ { 2 } }$ ,no shedding of $\mathrm { P b } { \cal O } _ { 2 }$ is observed.However,after about 5O-75 cycles,traces of $\mathrm { P b } { \cal O } _ { 2 }$ particles are seen in electrolyte tank which increase towards end of cycle-life.Main reason for shedding of $\mathrm { P b } { \bf O } _ { 2 }$ particles is likely to be change in acid concentration [47].Other factors like stress cannot be ruled out [48].

# 4.Conclusion

Single cells of soluble lead flow-batteries are developed with areal capacity of $1 0 0 \mathrm { \ m A h / c m ^ { 2 } }$ employing untreated normal graphite felts (NGF)and physicochemically modified graphite felt electrodes.Efficacy for four different combinations of negative electrode and positive electrode graphite felts in cells,namely NGF//NGF,PGF//ECGF $\mathbf { \cdot P b O _ { 2 } }$ and PCGF//ECGF- $\mathbf { \cdot P b O _ { 2 } }$ and PCGF//CGF- $\mathrm { \ P b O _ { 2 } }$ are tested. Single cells with pristine graphite felt without any additives fail instantly in first cycle while in presence of NaF and HDTMA $p$ -TS binary additives,cells provides a cycle life of 1O6 cyclesat discharge cut-off voltage of $_ { 1 . 2 \mathrm { V } }$ and 53 cycles when cut-off voltage is $0 . 8 \mathrm { ~ V ~ }$ 、Interestingly,cells with perforated graphite feltas negative electrode and electrochemically modified graphite felt as positive electrode in presence of binary additives exhibit a life cycle of ${ > } 2 7 5 { - } 3 1 0$ cycles without any maintenance at an average coulombic efficiency ${ > } 9 7 \%$ due synergistic effect of additives and physicochemical modification of graphite felts.

$[ \mathrm { P b } ^ { 2 + } ]$ analysis of electrolyte using complexometric titration reveals that concentration of $\mathrm { P b } ^ { 2 + }$ -ions in electrolyte gradually decreases due to accumulation of solids at electrodes specifically at positive electrode. Accumulated solid at positive electrode is found to have a paste-like material with crystalline and gel-like texture.XRD analysis of accumulated solids in wet condition shows presence of crystalline $\mathrm { \beta \mathrm { - P b O _ { 2 } } }$ phase while dry electrodes show presence of $\mathbf { \alpha } \mathbf { \alpha } \mathbf { - } \mathbf { P } \mathbf { b } \mathbf { O } _ { 2 }$ phase along with $\mathsf { \beta { - } P b O _ { 2 } }$ with increased intensity and particle size.FESEM images show micron and submicron particulates with a porous morphology depending upon discharge protocol.HRTEM, EDS and SAED studies suggest submicron particulates to comprise nanoparticles of hydrated $\mathbf { \alpha } _ { \mathrm { ( \mathbf { \alpha } - \mathbf { P } b O _ { 2 } } }$ and $\mathsf { \beta { - } P b O _ { 2 } }$ ·

XRD,FESEM,and TEM results suggest that micron size particulates of paste are $\mathsf { \beta { - } P b O _ { 2 } }$ and submicron particulates could have evolved from gel part of paste.Cells galvanostatistically discharged to a $1 . 4 \mathrm { V }$ cut-off followed by constant-voltage discharge show non-porous particulates while cells deep discharged to 1.2 to $0 . 8 \mathrm { ~ V ~ }$ develop highly porous particulates at end of their cycling.Itis observed that deep discharge of cells and deep cut-off voltage reduce cycle-life.Various factors influencing cycle-life of SLFBs are also discussed.It is surmised that decrease in proton concentration in pores of positive electrode that are filled with amorphous hydrated $\mathrm { P b } { \bf O } _ { 2 }$ gel leads to polarization loss due to passivation towards end of each discharge and limits complete reductive dissolution of $\mathrm { P b } { \bf O } _ { 2 }$ .Scheme for deposition and dissolution of $\mathrm { P b } { \cal O } _ { 2 }$ are envisaged.
