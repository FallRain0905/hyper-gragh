Vanadium flow bateries (VFBs)have great potential for application in energy storage systems.However,the sluggish cathode redox kinetics still greatly restricts their operation athigh current densities.Herein,we boost cathode redox chemistry by modulating single-atom sulfur-vacancy (S-vacancy) defect of $\mathbf { M o S } _ { 2 \cdot \mathbf { x } }$ in-situ grown on carbon felts via a facile chemical etching method.Firstly,the optimized S-vacancy concentration is figured out via high throughput calculations based on D-band center theory. By precisely controlling etching duration, we achieve a tailored S-vacancy concentration,leading to highlydispersed S-vacancies,increased specific surface area,and improved hydrophilicity.Electrochemical characterizations demonstrate that optimized S-vacancy state can significantly facilitate the $\mathrm { V O } ^ { 2 + } / \mathrm { V O } _ { 2 } ^ { + }$ kinetics.Moreover,analysis of electron density difference and integratedcrystal orbital Hamiltoniangroup further reveals thatdispersed S-vacancy distribution also contribute to efficient surface electronic structure and enhanced adsorption process. Benefiting from enhanced $\mathrm { V O } ^ { 2 + } / \mathrm { V O } _ { 2 } ^ { + }$ kinetics,VFB single cell achieves a superior EE of $7 8 . 7 3 ~ \%$ at $3 0 0 \mathrm { \ m A \ c m ^ { - 2 } }$ and is able to last for 500 cycles without decay.This work demonstrates the promising potential of single-atom S-vacancies catalysts in the fabricationofflow battery electrodes and more importantly sheds light on the fundamental modulation essence of D-band center in $\mathbf { M o S } _ { 2 \cdot \mathbf { x } }$ towards enhanced cathode redox kinetics.

# 1．Introduction

The overuse of non-renewable energy sources has led to irreversible catastrophes such as global warming and sea level rising [1,2]. Thus, the exploration of renewable energyplaysa major role inalleviating the earth energy crisis and broadening the future of humanity [3-5]. Among the supporting energy storage devices,vanadium redox flow batteries have great potential for application in energy storage systems due to their excellent performance [6-8].Since the redox reaction takes place on the electrode surface,the electrode is the most important component of VFB,which determines the performance of the battery.In the past decades,carbon felt (CF) has been widely used in VFBs due to excellent conductivity,flexibility and corrosion resistance [9-11].However, the carbon fibers of CFhave fewredoxreaction sites,which limits the rapid reaction of vanadium ions on the electrode surface [12,l3].Meanwhile the cathode redox reaction $( \mathrm { V O ^ { 2 + } } / \mathrm { V O _ { 2 } ^ { + } } )$ , involving a one-electron and two-proton transfer,proceeds more sluggishly than the simpler anode redox reaction $( \mathrm { V } ^ { 2 + } / \mathrm { V } ^ { 3 + } )$ ,which involves a single electron transfer [14]. Therefore,it is crucial to develop highly active and efcient cathode CF electrodes to improve reaction kinetics of $\mathrm { V O } ^ { 2 + } / \mathrm { V O } _ { 2 } ^ { + }$

Defects have garnered considerable attention as a unique category of catalytically active sites,distinguished by their inherent distortion energy and distinct atomic configure rations compared to standard crystalline areas [15].The focal points of current defect engineering are to increase the catalytic active site exposure by altering the catalyst morphology and to increase intrinsic activity by altering the electronic structure [16]．Various defect engineering strategies，including controlled solvent thermal growth [17],heteroatom doping [18], chemical etching [19] and template synthesis [2O],have been invented and gained widespread adoption.Vacancies,as a limit state of defects, facilitate the adjustment of adjacent atomic arrangements and electronic structures across a broad range,therefore unleashing the great potential for catalytic performance enhancement [21]. $\mathbf { M o S } _ { 2 }$ nanosheets are promising material owing to typical graphite-like layered structure and high electrocatalytic activity [22],which has been used in many fields such as lithium-sulfur battery [23]. $\mathbf { M o S } _ { 2 }$ is considered to exhibit strong adsorption capacity to bromine and high catalytic activity for $\mathrm { B r } _ { 2 } / \mathrm { B r } ^ { - }$ ions in bromine-based flow batteries.And $\mathbf { M o S } _ { 2 }$ displays facilitation effect of electrolyte diffusion and high catalytic performance in the $\mathrm { I } _ { 3 } ^ { - } / I ^ { - }$ redox reaction zinc-polyiodide redox flow batteries.The unique structure and electronic properties have attracted attention to $\mathbf { M o S } _ { 2 }$ in the field of flow batteries [24,25].Meanwhile,due to the regular arrangement of Mo/S atoms in overall structure, $\mathbf { M o S } _ { 2 }$ is considered asa suitable precursor for the generation of sulfur-vacancy (S-vacancy) [26].Modification of $\mathbf { M o S } _ { 2 }$ onto carbon fibers can enhance electron transfer and increase its available active surface area. Subsequently,the construction of S-vacancy on the $\mathbf { M o S } _ { 2 }$ surface further promotes the reaction kinetics of $\mathrm { V O } ^ { 2 + } / \mathrm { V O } _ { 2 } ^ { + }$

For the purpose of overcoming the sluggish reaction kinetics of $\mathrm { V O } ^ { 2 + } / \mathrm { V O } _ { 2 } ^ { + }$ ,single-atom S-vacancies are introduced onto the surface of $\mathbf { M o S } _ { 2 }$ nanosheets in this paper via a simple and mild chemical etching method. The optimal S-vacancy concentration is initially determined by high throughput density functional theory (DFT) calculations.Subsequently,the individual S-vacancy concentration is precisely tuned by controlling the etch duration. The modulation of S-vacancy concentration on the catalytic performance of $\mathbf { M o S } _ { 2 }$ aligns precisely with the predicted trend by the DFT calculations.The S-vacancies on the carbon fiber surface lead to high electrocatalytic activity and fast electron transfer.The assembled battery using the modified cathode electrode delivers a superior energy efficiency of $7 8 . 7 3 \%$ at $3 0 0 \mathrm { \ m A } \mathrm { c m } ^ { - 2 }$ ,coupled with remarkable long-term cycling stability of over 5oo cycles at $3 0 0 \mathrm { m A }$ $\mathrm { c m } ^ { - 2 }$ . In addition, electron density difference and iCOHP further reveal that the advantage of dispersed S-vacancies over agglomerated S-vacancies stems due to a more efficient surface electronic structure.This work introduces single-atom vacancy catalysts into VFBs electrodes firstly and further explains the reason for the enhanced cathode redox chemistry, while offer good prospects for extending single-atom vacancy catalysts to other flow battery.

# 2.3.DFT calculations

All calculations were performed through density functional theory implemented on the Abinit package.The generalized gradient approximation (GGA) with Perdew-Burke-Ernzerhof (PBE) functional were chosen as the exchange correlation energy.Periodic boundary conditions were used in all directions and $1 5 \mathring { \mathrm { A } }$ of vacuum was used in the z direction to separate the slabs,which were 4 Mo atoms $\times ~ 4$ Mo atoms in size [27].Full structural relaxation was performed until the convergence criterion for the maximum force was O.05 eV $\mathring { A } ^ { - 1 }$ The k-point sampling of DOS calculation was set to $6 \times 6 \times 1$ and the d-band centers were calculated on the basis of projected density of states [28]. The vanadium adsorption energy on the electrode surface $E _ { a d s }$ was calculated by $\begin{array} { r } { E _ { a d s } = E _ { s u b + V } - E _ { s u b } - E _ { V } , } \end{array}$ where $E _ { s u b + V }$ and $E _ { s u b }$ were the total energies of the $\mathbf { M o S } _ { 2 \cdot \mathbf { x } }$ substrate surface with and without the vanadium adsorbed respectively,and $E _ { V }$ was the energy of an isolated vanadium. The crystal orbital Hamilton population (COHP） was developed to visualize energy-resolved chemical bonding,by partitioning the band structure energy into contributions from each orbital pair [29].

DFT calculations of d-band center were first carried out to highlight the significance of delicate modulation of S-vacancy concentration for $\mathbf { M o S } _ { 2 - \mathbf { X } } .$ Fig.l presents the variation of d-band center value with S-vacancy concentration.It should be noted that d-band center value, selected via high throughput calculations (Fig.S1-S7),serves as an essential parameter forcharacterizing catalytic activity.As seen, the dband center value undergoes a discernible shift with S-vacancy concentration, exhibiting a volcanic trend.Among a range of S-vacancy concentrations ( $0 \%$ to $1 8 . 7 5 ~ \% )$ ,the models with $1 2 . 5 0 ~ \%$ S-vacancy concentration reflects the highest d-band center value.According to perspective of d-band center theory,the projected electron density of states (PDOS) near $\mathrm { E _ { F } }$ is simulated,reflecting the d-band states of Mo atoms in different models,respectively [3O].As the number of electrons in anti-bonding states decreases,the binding strength undergoes an intensification due to the upward displacement of the d-band center. Due to a higher d-band center,the induction of electron filling in the anti-bonding states is reduced,which renders the vanadium ion more susceptible to react with the $\mathbf { M o S } _ { 2 }$ surface [31]. The above result provides valuable insights into the intricate interplay between S-vacancy concentration and electronic property of $\mathbf { M o S } _ { 2 \cdot \mathbf { x } } ,$ and offers the optimal theoretical S-vacancy concentration.

In addition, compared with heat treatment and $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ treatment,the modification of S-vacancy greatly enhances the ECSA of the electrode,which is crucial for the cathodic kinetic enhancement.

To further understand the strengthening of the $\mathrm { V O } ^ { 2 + } / \mathrm { V O } _ { 2 } ^ { + }$ kinetics and elucidate the modulation essence,electron density differences analysis for three representative models,namely $\mathbf { M o S } _ { 2 } ,$ $\mathbf { M o S } _ { 2 }$ -FGJK (with seriously agglomerate S-vacancies）and $\mathbf { M o S } _ { 2 }$ -EMGO (with dispersed S-vacancies) were first executed (Fig.5a).Comparing to the S atoms,itis clearly seen that the residual electrons at S-vacancies primarily favors movement towards the surrounding Mo atoms,implying that the local electron redistribution is induced owing to the formation of S-vacancies.Specifically,the electron redistribution leads to an electron-deficient state for S-vacancy and an electron-rich state for Mo atoms.Asa result, the adsorption of vanadium ions is facilitated by the presence of delocalized electrons around Mo atoms, thereby increasing the number of active sites on the ${ \bf M o S } _ { 2 \cdot \mathbf { x } }$ surface.Meanwhile,electron delocalization also induces higher conductivity through accelerating the electron transfer between the catalyst and the carbon felt substrate [45]. It is noteworthy that the electron delocalization in $\mathbf { M o S } _ { 2 }$ -EGMO is much more intensive than that in $\mathbf { M o S } _ { 2 }$ -FGJK,which impliesa more efficient electron redistribution based on the dispersed state of S-vacancies. Therefore,the dispersed S-vacancies induces a more efcient surface electronic structure when compared to agglomerate S-vacancies.In addition to electron structure,adsorption influence is also studied by adsorptionenergyandiCOHPanalysis.Consideringthe forced-convection state of the electrolyte in VFB,the adsorption process of $\mathrm { V O } _ { 2 } ^ { + }$ is more important than desorption.As seen,the calculated adsorption energy of $\mathbf { M o S } _ { 2 }$ ， $\mathbf { M o S } _ { 2 }$ -FGJK and $\mathbf { M o S } _ { 2 } – \mathbf { E M G O }$ are determined to be $- 1 . 2 2$ ， $- 3 . 5 7$ ，and $- 4 . 0 9 \ \mathrm { e V }$ ,respectively,which reveals that vanadium ions are significantly more inclined to adsorb on the ${ \bf M o S } _ { 2 \cdot \mathbf { x } }$ surfaces with dispersed S-vacancies rather than agglomerated S-vacancies (Fig.5b).Meanwhile, the above conclusion can also be verified from the integrated crystal orbital Hamiltonian group (iCOHP) of the Mo-V bond in Fig.5c.With the creation of S-vacancies,more anti-bonding states of Mo-V bond shift down below the Fermi level and the -iCOHP values keep decreasing [46].Therefore,it further indicates that Mo-V bond is enhanced,which contributes to a stable reaction process of vanadium ions on the surface.Finally,Fig.5d illustrates the catalytic mechanism of S-vacancies for $\mathrm { V O } ^ { 2 + } / \mathrm { V O } _ { 2 } ^ { + }$ redox couple on the atomic scale.By introducing S-vacancies into ${ \bf M o S } _ { 2 } .$ ，distortion of the original lattice occurs,accompanied bylocalized electron redistribution. Asaresult,Mo atoms at active centers exhibit heightened local electron density,leading to enhanced adsorption capabilities for vanadium ions on the $\mathbf { M o S } _ { 2 \cdot \mathbf { x } }$ surface,simultaneously facilitating electron transfer during the reaction process.Additionally，the presence of highly dispersed S-vacancies proves to be particularly eective in promoting the aforementioned processes.In conclusion,our findings underscore the vital role of S-vacancies in boosting cathode redox kinetics,attributing this enhancement to the efficient surface electronic structure and stable adsorption process engendered by the S-vacancies in $\mathbf { M o S } _ { 2 \cdot \mathbf { x } }$

# 4.Conclusion

In summary,we theoretically predict the optimal S-vacancy concentration towards enhanced $\mathrm { V O } ^ { 2 + } / \mathrm { V O } _ { 2 } ^ { + }$ redox kinetics via high throughput calculations.By precisely controlling the $\mathrm { H } _ { 2 } \mathrm { O } _ { 2 }$ etching duration,a tailored S-vacancy concentration of $1 1 . 9 3 ~ \%$ is achieved on ${ \bf M o S } _ { 2 \cdot \mathbf { x } }$ in-situ grown on carbon felts,resulting in highly dispersed Svacancies,increased specific surface area and improved hydrophilicity. Electrochemical characterizations further indicate that optimized Svacancy concentration in $\mathbf { M o S } _ { 2 \cdot \mathbf { x } }$ can significantly facilitate the $\mathrm { V O } ^ { 2 + } /$ $\mathrm { V O } _ { 2 } ^ { + }$ kinetics.Furthermore,the electron density difference and iCOHP revel that the advantage of dispersed S-vacancies over agglomerate Svacancies in virtue of a more efficient surface electronic structure.The assembled batteryusing the S-vacancies modified electrode achieves EE of $7 8 . 7 3 \%$ EEat $3 0 0 \mathrm { \ m A } \mathrm { c m } ^ { - 2 }$ and is able to sustain 5Oo cycles without decay. This work offers good prospects for single-atom S-vacancy catalysts in the construction of VFB electrodes and can be further extended to other flow batteries.
