# Abstract

The trade-off between chemical stability and proton selective conduction greatly influences energy efficiency and cycling stability of vanadium redox flow battries (VRFBs). Herein, the electron-withdrawing side chain protective engineering was proposed. Owing to the electron-withdrawing effect of the trifluoromethyl and carboxylic acid contained side chain, the sulfonic acid groups $\mathrm { ( - } \mathrm { { S O } } _ { 3 } \mathrm { { H } }$ ） were located on the main chain benzene ring with enhanced proton dissociation ability, the electrostatic potential of benzene hydrogen atoms increased to repel vanadium ions,and the HOMO-LUMO gap was enlarged for excellent oxidation energy barrier, simultaneously improving $\mathrm { H ^ { + } / V ^ { n + } }$ selectivity and chemical stability of the sulfonated poly(arylene) membrane (SPTPC). Both low area resistance ( $( 0 . 2 \Omega \mathrm { c m } ^ { 2 } )$ ） and vanadium permeability $( 1 . 1 { \times } 1 0 ^ { - 9 } \ \mathrm { c m } ^ { 2 } \ \mathrm { s } ^ { - 1 } )$ led to high $\mathrm { H ^ { + } / V ^ { n + } }$ selectivity $( 5 . 5 4 \times 1 0 ^ { 1 0 } ~ \mathrm { m S } ~ \mathrm { s } ~ \mathrm { c m } ^ { - 3 } )$ in the SPTPC membrane. The corresponding VRFB achieved high energy efficiency of $8 0 \% \textcircled { a } 2 8 0$ $\mathrm { \ m A \ c m ^ { - 2 } }$ , extremely low discharge capacity decay rate of $0 . 0 2 7 \%$ and long-term stable operation of 7Ooo charge-discharge cycles at $2 0 0 \mathrm { m A } \mathrm { c m } ^ { - 2 }$ . A degradation mechanism was proposed that attributed the excellent cycling stability to the preferential degradation of electron-withdrawing side chain as a sacrifice structure.

# Introduction

The large-scale application of sustainable renewable energy resources, such as wind and solar power generation, provides an effective solution to environmental problems caused by the emission of fossil fuels[1-3]. However, the intermittent and unstable nature of renewable energy resources must be mitigated through efficient energy storage systems to ensure a stable power output[4.5]. Vanadium redox flow batteries (VRFBs) have advantages of high safety, capacity-power decoupling, etc., making them the preferred choice for large-scale energy storage devices[6,7].

Energy efficiency, capacity decay rate and long-term charge-discharge cycling are key parameters of VRFBs, which greatly depend on the properties of proton conductive membrane[8-10l. As one of the key components of VRFBs, proton conductive membrane should cut off the vanadium ions permeation to reduce self-discharge side reaction, and improve proton conduction to maintain charge balancel[1,12]. However, the trade-off effect between $\mathrm { H ^ { + } / V ^ { n + } }$ selectivity, as well as the chemical stability of membrane under the harsh acidic and oxidative operating environments limit the practical application of VRFBs, becoming a major challenge of proton conductive membranes[13-15].

The chemical structure design of proton conductive membranes is a key to regulating the morphology of ion selective conduction channels and the chemical stability of the membranes[16,17]. The commercialized Nafion membranes posess extremely high chemical stability owing to C-F bond in the polymer main chain, and the flexible aliphatic sulfonated side chains effectively improve microphase separation, however the relatively large ionic cluster proton conductive channels lead to poor $\mathrm { H ^ { + } / V ^ { n + } }$ selectivity[18-20]. Non-fluorinated proton conductive membranes， such as sulfonated polyetheretherketone (SPEEK)[21]， sulfonated polysulfone (SPSF)[2] sulfonated polyimide (SPI)[23l，etc.， contain aromatic main chains with spatial hinderance to efectively block the permeation of vanadium ions, however the heteroatoms (sulfonyl group ( $scriptstyle \mathbf { O } = \mathbf { S } = \mathbf { O }$ ),ether bond (-O-), imide $scriptstyle ( \mathrm { O = C - N - C = O } )$ ，etc.) present relatively low bond energies, leading to fast membrane degradation and battery capacity decay, and poor cyclic performance[24,25]. Recently, the design of biphenyl and triphenyl poly(arylene) main chains has become a research frontier, which obtain chemical stability by removing heteroatoms and retaining stable benzene ring structures that follow the Huckel's rulel26,27].Despite the advantages，the recently reported poly(arylene） based proton conductive membranes, functionalized by grafting with different cationic, anionic or amphoteric functional side chains (Table S1),exhibited limited charge-discharge cycling stability (usually less than 2000 cycles)[28,29]. It is believed to be closely correlated to the degradation involving functional side chains, but the mechanism remains unclear for the poly(arylene) based proton conductive membranes[30-32]. And the energy eficiency, highly correlated to the $\mathrm { H ^ { + } / V ^ { n + } }$ selectivity of proton conductive channels, still needs improvement especially at high current density[16,3]l. The above-mentioned challenges make the design of functional side chains extremely important for precisely regulating both the chemical stability and the $\mathrm { H ^ { + } / V ^ { n + } }$ selective conductive channel in the poly(arylene) based proton conductive membranes[15,34]. 一

In this work, the electron-withdrawing side chain protective engineering was proposed for constructing highly stable and ion selective proton conductive membranes
in vanadium redox flow batteries application (Figure 1). Both trifluoromethyl $\left( \mathrm { - C F } _ { 3 } \right)$ and carboxylic acid (-COOH) electron-withdrawing side chains were grafted on the poly(arylene） to redistribute electron density. Owing to the electron-withdrawing effects of the side chain, the sulfonic acid groups $\mathrm { ( - S O 3 H ) }$ ） were located on the main chain benzene ring with enhanced proton dissociation ability, the electrostatic potentials of benzene hydrogen atoms were increased to repel vanadium ions, and the HOMO-LUMO gap was enlarged for excellent oxidation energy barrier, accordingly improving $\mathrm { H ^ { + } / V ^ { n + } }$ selectivity and chemical stability of the membrane.Both low area resistance $( 0 . 2 \Omega \mathrm { c m } ^ { 2 } )$ and vanadium permeability could be achieved $( 1 . 1 { \times } 1 0 ^ { - 9 } \ \mathrm { c m } ^ { 2 } \ \mathrm { s } ^ { - 1 } )$ in the SPTPC membrane with $2 . 5 9 \ \mathrm { m m o l \ g ^ { - 1 } }$ ion exchange capacity (SPTPC-2.59), which demonstrated a high $\mathrm { H ^ { + } / V ^ { n + } }$ selectivity of $5 . 5 4 { \times } 1 0 ^ { 1 0 } \mathrm { m S } \ \mathrm { s } \ \mathrm { c m } ^ { - 3 }$ . The energy efficiency of VRFB presented $80 \%$ $\textcircled { a } 2 8 0 \mathrm { \ m A } \mathrm { \ c m } ^ { - 2 }$ and discharge capacity decay rate of only $0 . 0 2 7 \%$ per cycle $\textcircled { a } 2 0 0 \mathrm { m A c m } ^ { - 2 }$ . The 700o charge-discharge cycles performed at 200 $\mathrm { \ m A } \mathrm { c m } ^ { - 2 }$ indicated high chemical stability of the SPTPC-2.59 membrane.A degradation

mechanism was proposed for the SPTPC membrane, illustrating the protective effect of the preferential degradation of electron-withdrawing side chain as a sacrifice structure. The results demonstrate that the design of electron-withdrawing side chains is a promising pathway for the next generation of proton conductive membranes.

The significant height changes in the AFM images indicated the well-formed micro-phase separation structure from two- and three-dimensions in the SPTPC membrane (Figure 3(d)-(f))[35]. The SPIPC membrane presented high $\mathrm { H ^ { + } / V ^ { n + } }$ selectivity and excellent chemical stability. As IEC of SPTPC membrane increased from $1 . 3 8 \mathrm { m m o l } \mathrm { g } ^ { - 1 }$ to $3 . 3 4 \mathrm { m m o l } \mathrm { g } ^ { - 1 }$ ， the water uptake (WU) increased from $6 . 5 ~ \%$ to $5 3 . 2 \%$ , while the swelling ratio (SR) was well restricted to lower than $1 8 . 0 \%$ (Figure 4(a). With good dimensional stability, the SPTPC membrane achieved high mechanical proprieties, i.e., tensile strength (TS) of 25.6-32.1 MPa and elongation at break (EG) of $5 . 1 0 . 1 \ \%$ (Figure 4(b)). With the increasing water uptake, proton conductivity (PC) increased from $3 . 2 5 \mathrm { m S } \mathrm { c m } ^ { - 1 }$ to 78.1 $\mathrm { m S \ c m ^ { - 1 } }$ at room temperature. Accordingly, low area resistance could be achieved in the SPTPC series membranes (from $1 . 2 4 \Omega \mathrm { c m } ^ { 2 }$ to $0 . 1 4 \Omega \mathrm { c m } ^ { 2 }$ , Figure 4(c)). Although the vanadium permeability (VP) increased from $0 . 2 1 \times 1 0 ^ { - 9 } \ \mathrm { c m \ s ^ { - 1 } }$ to $2 . 7 { \times } 1 0 ^ { - 9 } \mathrm { c m } \mathrm { s } ^ { - 1 }$ ,the values were two orders of magnitudelower than thalof Nafion212 membrane $( 3 . 2 5 { \times } 1 0 ^ { - 7 } \ \mathrm { c m \ s } ^ { - 1 }$ , Figure 4(d) and Figure S9). The excellent proton conductive and vanadium ion resistant abilities of the SPTPC membrane correlated to the electronwithdrawing ( ${ \mathrm { . C F } } _ { 3 }$ and -COOH) side chain design, which could not only wel disperse the electron density of $- \mathrm { S O } _ { 3 } \mathrm { H }$ to achieve high proton dissociation ability for proton conduction, but also decrease electron density of the main chains to better repel vanadium ions. The well-established proton selective conduction channel endowed the SPTPC membrane with exellent properties at rlatively lower IECs. The excellent balance between $\mathrm { H ^ { + } / V ^ { n + } }$ selectivity and chemical stability was derived from the high electron-withdrawing effect of the fluorinated (-CF3） and carboxylic acid (-COOH) contained side chains in SPTPC membrane. To illustrate the electron-withdrawing effect, simulation models were constructed for SPTPC, SPTP, SPTPCH and SPTPH, which possessed two, one, one and none electron-withdrawing groups on their side chains with the same sulfonation degree (Figure 5(a)). From the density functional theory (DFT) calculation (Figure 5(b)), with the increasing number of the electron-withdrawing group, the electric charge of the oxygen atom in sulfonic acid group $\left( - \mathbf { S } \mathbf { O } _ { 3 } ^ { - } \right)$ decreased from -0.762 a.u. to -0.773 a.u. The reduced negative charges in $- \mathrm { S O } _ { 3 } \mathrm { ^ { - } }$ group facilitates proton dissociation， resulting in high proton conductivity. As introducing more electron-withdrawing groups in side chain, the electrostatic potential of hydrogen atom increased in both main chain (from O.160 a.u. to 0.166 a.u.) and side chain (from 0.146 a.u. to 0.155 a.u.), indicating high vanadium ion repulsive ability. The electron-withdrawing groups also enlarged energy gap between the highest occupied molecular orbital (HOMO) and the lowest unoccupied molecular orbital (LOMO), increasing from $0 . 0 8 0 \ \mathrm { e V }$ to 0.087 eV (Figure 5(c)). Therefore, the excellent chemical stability could be achieved in the SPTPC membrane. The molecular dynamics (MD) simulation was further performed to illustrate the excellent $\mathrm { H ^ { + } / V ^ { n + } }$ selectivity of the SPTPC membrane.From the radial distribution function(RDF）simulation,the SPTPC membranewithtwoelectron-withdrawing groupsonthesidechainsexhibitedthehighesthydrogenbondformingabiltbetween ${ \cdot } \mathrm { S O } _ { 3 } \mathrm { H }$ group and hydrated protons (Figure 5(d) as wellas the lowest interaction force between $- \mathrm { { S O } } _ { 3 } \mathrm { { H } }$ group and hydrated vanadium ions (Figure 5(e)), comparing to the SPTP, SPTPCH and SPTPH with one or none electron-withdrawing groups. And the SPTPC membrane achieved the highest proton difusivity $( 6 . 1 4 \times 1 0 ^ { - 9 } \mathrm { m } \mathrm { s } ^ { - 1 }$ ,Figure 5(f)) and the lowest vanadium ion difusivity $( 5 . 0 3 { \times } 1 0 ^ { - 1 0 } \mathrm { ~ m ~ s } ^ { - 1 }$ ,Figure $5 ( \mathrm { g } )$ ), indicating the best proton selective difusion ability. In addition, it was experimentally demonstrated that the SPTPC membrane also exhibited higher $\mathrm { H } ^ { + }$ permeability than SPTP $( 2 . 2 1 \times 1 0 ^ { - }$ $^ 6 \mathrm { c m } ^ { 2 } \mathrm { s } ^ { - 1 } \mathrm { v s } \ 1 . 6 9 \mathrm { \times } 1 0 ^ { - 6 } \mathrm { c m } ^ { 2 } \mathrm { s } ^ { - 1 } )$ (Figure S14).According totheabove results,ashematic mechanism of the $\mathrm { H ^ { + } / V ^ { n + } }$ selectivity and chemical stability promoted by the electronwithdrawing effect of side chains was proposed (Figure 5(h)). The electronwithdrawing groups induced a redistribution of electron density in both the sulfonic acid group and the main chain.For the sulfonic acid group,the electron-withdrawing groups stabilized the negatively charged form of the sulfonic acid group $\left( - \mathbf { S } \mathbf { O } _ { 3 } ^ { - } \right)$ ， thereby enhancing the proton dissociation， diffusion abilities and water uptake. Meanwhile, the electron-withdrawing groups increased the positive charge density in both side chain and main chain,leading to higher electrostatic potential and larger energy gap between HOMO and LUMO for excellent vanadium ions exclusion and oxidation energy barrier. The simultaneously enhanced $\mathrm { H ^ { + } / V ^ { n + } }$ selectivity and chemical stability of the SPTPC membrane by the electron-withdrawing groups of side chains will greatly benefit for the efficiency and lifetime of VRFBs.

During the VRFBs operations， the SPTPC membranes achieved excellent chemical stability and high energy efficiency. At $6 0 { - } 3 0 0 ~ \mathrm { m A ~ c m ^ { - 2 } }$ , the low vanadium ions permeability induced high coulombic efficiency (CE, $9 8 . 0 { - } 9 9 . 6 \%$ ,Figure 6(a)) for the SPTPC based VRFBs. Meanwhile, the low area resistance contributed to a high voltage efficiency (VE, $6 6 . 5 – 9 2 . 9 \ \%$ ，Figure 6(b)). The high $\mathrm { H ^ { + } / V ^ { n + } }$ selectivity of SPTPC-2.59 membrane led to an excellent overall energy efficiency (EE), achieving EE of about $80 \%$ at a very high current density of $2 8 0 \mathrm { m A } \mathrm { c m } ^ { - 2 }$ and $8 3 . 3 \%$ at $2 0 0 \mathrm { m A }$ $\mathrm { c m } ^ { - 2 }$ (Figure 6(c) and Figure S15). The fascinating point was that the VRFB assembled with SPTPC-2.59 membrane also exhibited excellent charge-discharge cyclic stability, with extremely low discharge capacity decay rate ( $0 . 0 2 7 \%$ per cycle $\textcircled { a } 2 0 0 \mathrm { \ m A } \mathrm { c m } ^ { - 2 }$ ， 1500 cycles without refreshing the electrolyte, Figure 6(d)), while VRFB assembly with Nafion 212 membrane showed discharge capacity decay rate of $0 . 3 5 \%$ per cycle $\textcircled{ a} 2 0 0$ mA $\mathrm { c m } ^ { - 2 }$ and less than 200 cyclic life-time. The SPTPC-2.59 VRFB could keep stable efficiencies over 7000 cycles (Figure 6(e)), with intact membrane morphology shown in the SEM images (Figure S16) and the identical chemical characteristic peaks in both $^ 1 \mathrm { H } \cdot$ -NMR and FTIR spectra (Figure S17 and S18) after cycling. After cycling, the SPTPC-2.59 membrane also showed nearly identical mechanical properties and IEC (Figure S19 and S20). Compared with the recent reported literature, the SPTPC-2.59 membrane exhibited higher energy efficiency at high current density, as well as lower capacity decay rate and higher chemical stability (Figure 6(f)). The excellent long-term battery performance of the SPTPC-2.59 membrane proved the feasibility of the electron-withdrawing side chain design for practical VRFB applications.

# Conclusions

In this work,the electron-withdrawing side chain protective engineering was proposed for constructing highly stable and selective proton conductive membranes in vanadium redox flow batteries application. The electron-withdrawing side chain contained poly(arylene) (SPTPC) was synthesized by the trifluoromethyl and carboxylic acid groups contained monomer polymerization and sulfonation to redistribute the electron density. Owing to the electron-withdrawing effects of the side chain, the sulfonic acid groups were located on the main chain benzene ring with enhanced proton dissociation ability, the electrostatic potentials of hydrogen atoms in main chain benzene rings were increased to repel vanadium ions, and the HOMO-LUMO gap was enlarged for excellent oxidation energy barrier, accordingly improving $\mathrm { H ^ { + } / V ^ { n + } }$ selectivity and chemical stability in the membrane. The SPTPC-2.59 membrane with ion exchange capacity of $2 . 5 9 \mathrm { \ m m o l \ g ^ { - 1 } }$ achieved low area resistance $( 0 . 2 \ \Omega \ \mathrm { c m } ^ { 2 } )$ and vanadium permeability $( 1 . 1 { \times } 1 0 ^ { - 9 } \mathrm { c m } ^ { 2 } \mathrm { s } ^ { - 1 } )$ , and high $\mathrm { H ^ { + } / V ^ { n + } }$ selectivity ( $\cdot 5 . 5 4 \times 1 0 ^ { 1 0 } \mathrm { m } \mathrm { S } \mathrm { s } \mathrm { c m } ^ { - 3 } .$ ). The energy efficiency of the SPTPC-2.59 VRFB presented $80 \%$ $\textcircled { a } 2 8 0 \mathrm { \ m A } \mathrm { \ c m } ^ { - 2 }$ and discharge capacity decay rate of only $0 . 0 2 7 \%$ per cycle $\textcircled { a } 2 0 0 \mathrm { m A c m } ^ { - 2 }$ . The long-term 7000 charge-discharge cycles were achieved at $2 0 0 \mathrm { \ m A } \ \mathrm { c m } ^ { - 2 }$ ， indicating excellent chemical stability of the SPTPC membrane. A degradation mechanism was proposed main chain, greatly enhancing the chemical stability and long operational lifetime of the membrane in VRFBs. High $\mathrm { H ^ { + } / V ^ { n + } }$ selectivity and chemical stability shown in the SPTPC membrane demonstrated that incorporating electron-withdrawing side chain structure is a promising pathway for the next generation of proton conductive membranes.
