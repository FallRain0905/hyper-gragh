# ABSTRACT

Keywords: Energy storage Cerium Flow batteries Redox kinetics Electrode

Iron-cerium redox flow bateries are compelling for grid-scale energy storage owing to their high operating voltage and material abundance.However,their practical deployment is currently hindered by the sluggish redox kinetics of the $\mathrm { C e } ^ { 3 + } / \mathrm { C e } ^ { 4 + }$ couple and the low oxidative stability of carbon electrodes in acidic media. In this study,we fabricated a $\mathrm { { M n } _ { 3 } \mathrm { { O } _ { 4 } } }$ -coated carbon felt $( \mathrm { M n _ { 3 } O _ { 4 } / C F } )$ electrode via electrodeposition and subsequent thermal annealing,applying it ina cerium-based flow battery.This surface modification transforms a hydrophobic surface into a superhydrophilic one,enhancing electrolyteaccesibilityand ion transportat the positive electrode.In an iron-cerium flow battery,the $\mathrm { M n _ { 3 } O _ { 4 } / C F }$ electrode achieves stable cycling with an average coulombic efficiency of $9 9 . 1 ~ \%$ and a high energy efficiency of $7 6 . 1 \ \%$ at a high current density of $6 0 \mathrm { \ m A \ c m ^ { - 2 } }$ Furthermore, the $\bf { M n } _ { 3 } \bf { O } _ { 4 }$ layer serves as a protective barrier against the aggressive acidic electrolyte,enabling stable operation forover 5Oo cycles with anegligible energy efciency decay.This work demonstrates that the synergistic increase in active sites,wettability and corrosion resistance makes $\mathrm { M n _ { 3 } O _ { 4 } / C F }$ a promising electrode platform for high-performance aqueous redox flow batteries.

# 1．Introduction

With fossil energy resources dwindling,the development of renewable energy has attracted global attention [1-3].However, the inherent intermittency and uneven distribution of renewable energy sources necessitates the development of energy storage systems to enhance grid stability [4-7].Among the emerging battery energy storage technologies,redox flow batteries (RFBs) have emerged as a premier solution for grid-scale applications,owing to advantages such as intrinsic safety, high reliability,decouplingof powerand energyratings,and flexibility in site deployment [8-1O].Currently,the all-vanadium redox flow battery (VRFB) stands as the most mature and widely commercialized RFB technology[11,12].Despite its success,the large-scale expansion of VRFBs is hampered by the toxicity and high cost of vanadium-based electrolytes,coupled with relatively low energy density [13-15]. Consequently,there is an urgent drive to explore alternative RFB chemistries based on more abundant and cost-effective active materials. The cerium redox flow battery (Ce-RFB) has emerged as a compelling candidate for energy storage technology.Cerium is a naturallyabundant and affordable rare-earth element,making it appealing for use in industry.Electrochemically, the $\mathrm { C e } ^ { 3 + } / \mathrm { C e } ^ { 4 + }$ redox couple offers a high standard potential (1.61 V vs.SHE),which sits near the upper limit of the potential window of a common aqueous electrolyte [16]. The combination of its high operating voltage and material abundance renders Ce-RFBs highly competitive for high power density and prolonged cycling performance [17,18].The Fe-Ce RFB system is based on the following chemical equations.

Positive electrode side:

$$
\mathbf { C e ^ { 3 + } } \overset { \mathrm { c h a r g e } } { \underset { d \mathrm { i c } \mathrm { c h a r o s e } } {  } } \mathbf { C e ^ { 4 + } } + \mathbf { e ^ { - } } , \mathbf { E ^ { \circ } } = 1 . 6 1 \lor \mathrm { v s . ~ N H E }
$$

Negative electrode side:

$$
\mathrm { F e ^ { 3 + } + e ^ { - } } \overset { \mathrm { c h a r g e } } { \underset { \mathrm { 4 i s e a b , s e a s } } {  } } \mathrm { F e } ^ { 2 + } , \mathrm { E } ^ { \circ } = 0 . 7 7 \mathrm { V ~ v s . ~ N H E }
$$

During charge and discharge,protons $( \mathrm { H } ^ { + } )$ migrate through the membrane to maintain charge neutrality.Potential side reactions include oxygen evolution at the positive electrode and hydrogen evolution at the negative electrode.

In a Ce-RFB,the electrode serves as the catalytic site for Ce ion redox reactions.Carbon-based materials are widely adopted due to their broad operating potential and low cost [19,2O].Nevertheless,the pristine carbon fibers exhibit inadequate wettability and sluggish kinetics toward the $\mathrm { C e } ^ { 3 + } / \mathrm { C e } ^ { 4 + }$ redox reaction, leading to an inefficient electrochemical reaction interface.More critically,the carbon electrode is prone to corrosion in the strongly acidic and oxidizing media,which compromises the long-term durability of the battery system [21,22].The strategies to enhance electrodes have been a long target,primarily divided into two approaches: the introduction of oxygen-containing functional groups,and the utilization of highly efficient catalysts. Although introducing oxygen-containing groups via thermal treatment [23],acid etching [24] or electrochemical processes [25] can increase hydrophilicity,their impact on overall electrochemical performance remains constrained, limiting their suitability for long-term applications.Consequently,catalysts that can significantly improve reaction kinetics and energy efficiency have been reported,including noble metals such as Pt,Ir,and Au [26].Therefore,research has shifted toward economically viable alternatives with high catalytic activity and high abundance.For instance,Wu and co-workers demonstrated that a $\mathrm { T i C / T i O _ { 2 } }$ heterojunction-coated carbon felt electrode significantly enhanced the kinetics of the $\mathrm { C e } ^ { 3 + } / \mathrm { C e } ^ { 4 + }$ redox reaction, achieving an energy efficiency of $6 6 . 2 ~ \%$ at $2 5 \mathrm { \ m A \ c m ^ { - 2 } }$ and superior corrosion resistance in a cerium-based flow battery [27].Na et al. reported molybdenum nitride nanoplate arrays on graphite felt,which drastically enhanced electrode wettability and cerium reaction kinetics,yielding a $4 6 . 8 ~ \%$ improvement in energy efficiency at $4 0 \ \mathrm { m A } \ \mathrm { c m } ^ { - 2 }$ for a Zn-Ce flow battery [28].Despite these advances,developing a scalable, low-cost electrode that simultaneously maximizes catalytic activity, ensures superhydrophilicity,and provides protection against carbon corrosion remains a critical challenge.

In this study,we propose a synergistic interfacial engineering strategy by fabricating a hausmannite-coated carbon felt electrode $\mathrm { ( M n _ { 3 } O _ { 4 } / }$ CF） via an electrodeposition and thermal annealing process.We demonstrate that the $\bf { M n } _ { 3 } \mathrm { O } _ { 4 }$ layer transforms the electrode surface from hydrophobic to superhydrophilic,drastically improving electrolyte accessibility and ion transport.Moreover,the coating serves as a synergistic electrocatalyst that accelerates the sluggish $\mathrm { C e } ^ { 3 + } / \mathrm { C e } ^ { 4 + }$ kinetics while acting as a protective barrier against acidic corrosion.This engineered architecture enables the iron-cerium flow battery to achieve stable cycling with high coulombic efficiency and energy eficiency at high current densities,offering a promising pathway for the development of next-generation aqueous redox flow batteries.

# 2.Experimental

# 2.1．Preparation of electrodes

Carbon felt (CF) with a thickness of $3 \ \mathrm { m m }$ was used as an experimental material. The raw carbon felt (CF) was washed with water and ethanol, dried at $6 0 ~ ^ { \circ } \mathrm { C }$ ,and then calcined ina muffle furnace at $5 0 0 ^ { \circ } \mathrm { C }$ for $^ { 4 \mathrm { h } }$ (heating rate: $5 ^ { \circ } \mathrm { C } \operatorname* { m i n } ^ { - 1 } $ )to yield TCF.The target electrode was prepared via an electrodeposition process on a TCF using a threeelectrode system,where the TCF served as the working electrode,an $\mathbf { A g / A g C l }$ (saturated KCl) electrode and a platinum (Pt) sheetacted as the reference electrode and counter electrode,respectively.The deposition electrolytewaspreparedbyfullydissolving $5 0 \mathrm { ~  ~ { ~ \ m M } ~ }$ Mn $\mathrm { ( C H _ { 3 } C O O ) _ { 2 } } { \cdot } 4 \mathrm { H _ { 2 } O }$ $9 9 ~ \%$ purity, Damao) in $5 0 ~ \mathrm { m L }$ of deionized water. After depositing $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ onto TCF at a constant voltage of $_ { 1 . 0 \mathrm { ~ V ~ } }$ for different durations (60 s,120 s,300 s),the samples were dried at $6 0 ^ { \circ } \mathrm { C }$ Subsequently,they were calcined at $7 0 0 ~ ^ { \circ } \mathrm { C }$ for $^ { 3 \mathrm { ~ h ~ } }$ in an inert argon atmosphere,yielding $\mathrm { M n _ { 3 } O _ { 4 } } / \mathrm { C F } { - } 6 0$ ， $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ ，and $\mathrm { M n _ { 3 } O _ { 4 } / C F } .$ 300,respectively.

# 2.2.Characterization

The crystalline phase compositions of the samples were determined viaan X-ray difraction (XRD,D8 FOCUS,Bruker) with $\mathrm { C u K } \alpha$ radiation. Morphological features and elemental distributions were characterized by a scanning electron microscope (SEM,Apreo S LoVac) and a transmission electron microscope (TEM, JEM-F200) equipped with an energy dispersive spectrometer (EDS).To evaluate the degree of graphitization, Raman spectroscopy (Horiba Scientific LabRAM HR evolution） was employed. Surface chemical states were analyzed through X-ray photoelectron spectra (XPS,Thermo Scientific ESCALAB 250Xi). $\Nu _ { 2 }$ adsorption-desorption isotherms were obtained using a Micromeritics ASAP 2460 instrument.Prior to the measurement,all samples were degassed at $1 2 0 ^ { \circ } \mathrm { C }$ for $^ { 8 \mathrm { ~ h ~ } }$ to ensure accuracy. The specific surface area and pore size distribution of the electrode were calculated using the Brunauer-Emmett-Teller (BET) method and the Barrett-Joyner-Halenda (BJH) methods.A contact angle measurement device (JC2oo0D3M, Powereach）was employed to analyze the wettability of electrode surface.

# 2.3.Electrochemical measurement

Cyclic voltammetry (CV) and electrochemical impedance spectroscopy (EIS) were conducted using a CHI 66O (Chenhua, China) electrochemical workstation in a standard three-electrode configuration. The working electrodes $( 0 . 5 \mathrm { c m } \times 1 . 0 \mathrm { c m } )$ were prepared from the respective samples.A platinum sheet and a saturated calomel electrode (SCE) served as the counter and reference electrodes,respectively.All measurements were performed in an aqueous electrolyte containing $0 . 0 5 { \mathrm { M } }$ $\mathrm { C e } ( \mathrm { S O } _ { 4 } ) _ { 2 }$ and 1 M $\mathrm { H _ { 2 } S O _ { 4 } }$ .CV profiles were recorded at a scan rate of 20 $\operatorname* { m V } s ^ { - 1 }$ .EIS spectra were acquired over a frequency range of $1 0 ^ { 5 }$ to $1 0 ^ { - 1 }$ Hz with an AC potential amplitude of $1 0 \mathrm { m V }$ at the open-circuit potential (OCP).The electric double layer capacitance $\mathrm { ( C _ { d l } ) }$ of the electrodes was explored using CVs in the potential range of $0 { - } 0 . 1 \mathrm { ~ V ~ }$ at different scan rates from 20 to $1 0 0 \mathrm { m V } s ^ { - 1 }$ .

# 2.4. Charge and discharge test

The electrode performance was characterized through galvanostatic charge-discharge tests ina full cell at ambient temperature.The cell was assembled using a symmetrical architecture,with each half-cell sequentially comprising an end plate, Teflon gasket,gold-plated copper current collector,titanium plate,and flow frame [29].The flow frame is equipped with a serpentine flow channel.TCF was employed for all negative half-cells,while either $\mathrm { M n _ { 3 } O _ { 4 } / C F }$ or TCF served as the corresponding positive electrode.All electrodes featured a geometric active area of $4 \mathrm { c m } ^ { 2 }$ （ $2 \mathsf { c m } \times 2 \mathsf { c m } )$ and a compression ratio of $3 3 . 3 ~ \%$ [30].The separation of electrolytes was accomplished through the utilization of a Nafion 115 membrane.The catholyte consisted of $2 0 ~ \mathrm { m L }$ of $0 . 5 \mathrm { M C e } ( \mathrm { S O } _ { 4 } ) _ { 2 }$ in 1 M $\mathrm { H } _ { 2 } S 0 _ { 4 }$ ,and the anolyte comprised $2 0 \mathrm { m L }$ of $0 . 5 { \mathrm { M } }$ $\mathrm { F e S O } _ { 4 }$ in 1 M $\mathrm { H _ { 2 } } S O _ { 4 }$ .Both electrolytes were circulated through the flow cell at a flow rate of $2 0 ~ \mathrm { m L } ~ \mathrm { m i n } ^ { - 1 }$ using peristaltic pumps. During the cycling tests,the battery was charged fora fixed duration of 2O minutes, followed by discharge until reaching a cutoff potential of $_ { 0 . 2 \mathrm { ~ V ~ } }$

The microstructure was further investigated by TEM. Distinct latice fringes with measured spacings of $0 . 2 7 7 \mathrm { n m }$ and $0 . 3 0 9 \mathrm { n m }$ can be clearly observed in the HRTEM image,which corresponds well to the distance between the (l03) and (1l2) planes of $\bf { M n } _ { 3 } \mathrm { O } _ { 4 }$ ,respectively (Fig.2e). X-ray photoelectron spectroscopy (XPS) was further employed to analyze the chemical composition of the $\mathrm { M n _ { 3 } O _ { 4 } / C F }$ electrodes.The XPS survey spectrum confirmed the presence of C,O,and Mn, indicating the successful coating of $\mathrm { M n } _ { 3 } \mathrm { O } _ { 4 }$ on the carbon felt surface.In the highresolution $\mathtt { M n 2 p }$ spectrum (Fig.3a),the fitted peaks for Mn $\boldsymbol { 2 } \mathsf { p } _ { 3 / 2 }$ and Mn $\boldsymbol { 2 } \mathsf { p } _ { 1 / 2 }$ revealed the coexistence of $\mathrm { M n } ^ { 3 + } ( 6 4 2 . 5 \mathrm { e V }$ and $6 5 4 . 3 \mathrm { e V }$ and $\mathrm { M n ^ { 2 + } }$ $6 4 0 . 9 \ \mathrm { e V }$ and $6 5 2 . 6 \ \mathrm { e V } )$ , which are characteristic of $\mathrm { { M n } _ { 3 } { O _ { 4 } } }$ [33, 34]. Raman spectroscopy displays characteristic peaks at approximately $1 5 8 0 ~ \mathrm { c m } ^ { - 1 }$ for the G-band and $1 3 5 0 ~ \mathrm { c m } ^ { - 1 }$ for the D-band of graphite (Fig. 3c). The G-band arises from the in-plane stretching of $\mathsf { s p } ^ { 2 }$ hybridized carbon atoms and serves as an indicator of the degree of ordered graphitic structure.Conversely,the D-band originates from graphitic defects induced by $\mathsf { s p } ^ { 3 }$ carbon and heteroatoms,signifying defect density and structural disorder.The intensity ratio $\mathrm { ( I _ { D } / I _ { G } ) }$ reflects the relative defect density of the samples.The peak intensity ratio of $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ demonstrates the highest value (1.21),which is higher than that of TCF (1.02),suggesting that the nanoparticle deposition on $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ offersa superior densityof defect-derived active sites to enhance overall catalytic activity [42,43].However, the $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 3 0 0 } }$ sample exhibited a reduced signal,as the excessively thick layer shielded the Raman signal from the substrate,potentially leading to increased electrode resistance.

# 3.2.Electrochemical performance

The catalytic activity of different electrodes toward the $\mathrm { C e } ^ { 3 + } / \mathrm { C e } ^ { 4 + }$ redox reaction was evaluated using CV and EIS.CV provides insights into the electrochemical reversibility and charge-transfer kinetics of the redox couple.High electrochemical reversibility signifies rapid electron transfer at the electrode-electrolyte interface,conversely,sluggish kinetics in irreversible reactions necessitate higher overpotentials and exacerbate cell polarization,ultimately hindering overall performance.

As illustrated in Fig.4a,the TCF and $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ electrodes display well-defined redox peaks,corresponding to the reversible faradaic processes of the $\mathrm { C e } ^ { 3 + } / \mathrm { C e } ^ { 4 + }$ redox couple in the acidic electrolyte. Compared to TCF, $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ exhibits a notably increased peak current density and a narrowed peak potential separation $( \Delta \mathrm { E _ { p } } )$ . Specifically,the TCF electrode exhibiteda potential difference of $0 . 6 4 \mathrm { ~ V } ,$ ， whereas $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ demonstrated a significantly reduced $\Delta \mathrm { E _ { p } }$ of $0 . 3 9 \mathrm { ~ V ~ }$ In addition, $\mathrm { M n _ { 3 } O _ { 4 } } / \mathrm { C F } { - } 6 0$ and $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 3 } 0 0 }$ showed higher $\Delta \mathrm { E _ { p } }$ values of $0 . 4 1 \mathrm { \ V }$ and $0 . 4 9 \mathrm { V } _ { : }$ ,respectively,which further highlights the optimal catalytic performance of the $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ electrode (Fig. S5).This confirms enhanced electrocatalytic activity and improved electrochemical reversibility,arising from the synergistic effect between the $\bf { M n } _ { 3 } \bf { O } _ { 4 }$ nanostructures and the conductive carbon fiber framework. Furthermore,the redox peak current ratio $\mathrm { ( I _ { p a } / I _ { p c } ) }$ of $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ approximates 1 much more closely than that of the pristine TCF,indicating superior chemical reversibility of the redox process [37].These results suggest that the introduction of $\bf { M n } _ { 3 } \mathrm { O } _ { 4 }$ on the carbon felt surface effectively reduces electrochemical polarization and increases the density of active sites for the cerium redox reaction.

To further elucidate the mass transport kinetics of the cerium ions on the three-dimensional porous $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ electrode, CV was conducted at various scan rates (Fig.S6).As shown in the Fig.4b,both anodic and cathodic peak current densities exhibit a strong linear positive correlation with the square root of the scan rate across the tested range suggesting that the $\mathrm { C e } ^ { 3 + } / \mathrm { C e } ^ { 4 + }$ redox process is primarily diffusion controlled reaction [45].Notably, $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ displays significantly steeper slopes for both the anodic and cathodic fitting lines compared to TCF，indicating accelerated ion masstransfer. Based on the Randles-Sevcik equation, the apparent diffusion coefficients (D) for the TCF electrode were calculated to be $1 . 0 \times 1 0 ^ { - 6 } \mathrm { c m } ^ { 2 } s ^ { - 1 }$ for oxidation and $5 . 8 \ \times \ 1 0 ^ { - 7 } \ \mathrm { c m } ^ { 2 } \ s ^ { - 1 }$ for reduction. In contrast, $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ exhibited substantially enhanced coeficients of $1 . 4 \times 1 0 ^ { - 6 } \mathrm { c m } ^ { 2 } s ^ { - 1 }$ and $1 . 2 \times 1 0 ^ { - 6 } \mathrm { ~ c m } ^ { 2 } s ^ { - 1 }$ ,respectively. This enhancement suggests that the $\bf { M n } _ { 3 } \bf { O } _ { 4 }$ modification effectively facilitates ion transport and expands the accessible electroactive surface area.Moreover,the ratio between the oxidation and reduction diffusion coefficients for $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ is significantly closer to 1 compared to the pristine TCF,providing quantitative evidence of the improved kinetic symmetry and superior electrochemical reversibility facilitated by the $\bf { M n } _ { 3 } \bf { O } _ { 4 }$ catalyst.

The electrochemical active surface area (ECSA) serves as a crucial indicator for understanding the accessible interfacial area between the electrode and electrolyte during battery cycling [37,46].To determine the double-layer capacitance $\mathrm { ( C _ { d l } ) }$ values,which are proportional to the ECSA，cyclic voltammetry measurements were performed in the non-Faradaic potential region at varying scan rates (Fig. S7). The $\mathrm { C _ { d l } }$ values were extracted from the slope of the plot of current density difference versus scan rate.As illustrated in Fig. $^ { 4 \mathrm { c } , }$ the $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ electrode exhibits a $\mathrm { C _ { d l } }$ of $1 . 9 9 \mathrm { m F } \mathrm { c m } ^ { - 2 }$ ,markedly higher than that of the pristine TCF electrode $( 1 . 7 1 \mathrm { m F } \mathrm { c m } ^ { - 2 } )$ , indicating an enlarged ECSA. This finding suggests that the growth of $\bf { M n } _ { 3 } \mathrm { O } _ { 4 }$ on the electrode exposes more electrochemically active sites.The increased ECSA reflects the synergistic effects of enhanced porosity and improved wettability,which facilitate electrolyte penetration and ion transport, thereby promoting the overall redoxkinetics of the electrode.

Electrochemical kinetics were further evaluated via EIS,with Nyquist plots recorded for all samples (Fig.4d).The spectra are characterized by a semicircle in the high frequency region, corresponding to the charge-transfer resistance $\mathrm { ( R _ { c t } ) }$ ,and a linear tail in the low-frequency regime,associated with the Warburg impedance and ion diffusion processes.As shown in Table S1,the fitted $\mathtt { R } _ { s }$ and $\operatorname { R } _ { \operatorname { c t } }$ values forall electrodes indicate that $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ displays the smallest semicircle diameter,signifying superior interfacial charge-transfer kinetics [47]. By contrast,TCF shows a significantly larger $\mathrm { R } _ { \mathrm { c t } } ,$ while $\mathrm { M n _ { 3 } O _ { 4 } } / \mathrm { C F } { - } 6 0$ demonstrates suboptimal performance,reflecting the lack of electroactive sites.The $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 3 0 0 } }$ sample exhibitsan increased semicircle diameter due to the excessive thickness of the loading layer,which compromised electrical conductivity and impeded charge transfer, aligning with the Raman spectroscopic results [31]. Furthermore, the steeper slope of the linear portion for $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ implies enhanced ion diffusion.The experimental data correlate well with the equivalent circuit fitting results,confirming that $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ provides an optimal configuration for accelerated redox reactions and efficient mass transport,outperforming the other samples in kinetic efficiency.This enhanced performance is attributed to the intimate contact between the $\bf { M n } _ { 3 } \bf { O } _ { 4 }$ nanoparticles and the conductive carbon framework,which facilitates the accessibility of ions to active sites and ensures continuous electron pathways.

# 3.3.Full redox flow-cell performance

To evaluate the electrocatalytic activity and practical viability of the $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ ,a Fe-Ce flow battery was constructed utilizing $\mathrm { M n } _ { 3 } \mathrm { O } _ { 4 } /$ CF-120 and TCF as the positive and negative $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 3 0 0 } } s$ ,respectively (Fig.1b).A series of galvanostatic charge and discharge tests were performed via a single-cell configuration.As illustrated in Fig.4e and f, the rate performance of the TCF and $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ electrode was systematically evaluated at current densities ranging from 20 to $6 0 ~ \mathrm { { m A } }$ $\mathrm { c m } ^ { - 2 }$ .The coulombic efficiency (CE） for both samples remains remarkably stable near $9 8 ~ \%$ across the tested range,indicating high faradaic reversibility and the absence of significant side reactions.In contrast,the voltage efficiency (VE) and energy efficiency (EE) exhibited a characteristic stepwise decline as the current density increased,a phenomenon primarily driven by the intensification of ohmic polarization and electrochemical overpotentials. It is noteworthy that $\mathrm { M n } _ { 3 } \mathrm { O } _ { 4 } /$ CF-120 consistently maintained superior VE and EE compared to TCF at all current densities.As the current density was incrementally elevated to $6 0 \ \mathrm { m A } \ \mathrm { c m } ^ { - 2 }$ ， $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 } } 2 0$ maintained a superior EE of $7 5 . 4 ~ \%$ ， markedly surpassing the $7 0 . 7 ~ \%$ recorded for TCF.This performance disparity underscores the efficacy of the $\bf { M n } _ { 3 } \mathrm { O } _ { 4 }$ modification in lowering the activation barrier for interfacial charge transfer and facilitating the redox kinetics of the cerium ions.Upon restoring the current density to $2 0 \mathrm { \ m A \ c m ^ { - 2 } }$ ,the efficiencies recover to their initial values,confirming the robust structural integrity and excellent kinetic reversibility of the modified electrode architecture.Notably, the $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ electrode demonstrates a lower charging voltage plateau and a superior discharge capacity compared to the TCF electrode across all tested current densities,reflecting the reduction in both electrochemical and concentration polarizations (Fig.S8).

Furthermore,the long-term stability of the electrodes was evaluated through extended cycling tests at $4 0 \mathrm { \ m A \ c m ^ { - 2 } }$ . As illustrated in Fig. 5a, while the TCF electrode suffered performance failure after only 194 cycles, the $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ electrode exhibited remarkable durability, operating stably over 5Oo cycles.Fig.S9 revealed that the TCF electrode exhibits rapid performance deterioration,with the cell voltage rising sharply and quickly reaching the cutoff threshold.This abrupt voltage surge is likely linked to the limited active sites and inferior structural stability of the pristine carbon felt. Conversely,the $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ electrode demonstrates exceptional durability with similar chargedischarge curves.As a result, the $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ system maintained a CE near $9 9 \%$ ,and the VE and EE were sustained at approximately $8 2 \%$ and $8 0 \%$ ,respectively.The modified electrode exhibited a remarkably low EE decay,underscoring the superior interfacial properties of the $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ ，such as enhanced wettability,more active sites,and enlarged specific surface area. These findings confirm the superior longterm reliability of the $\mathrm { M n _ { 3 } O _ { 4 } / C F }$ composite and substantiate its potential as a high-performance positive electrode for Fe-Ce flow batterie. The typical charge and discharge profiles of different electrodes at a current density of $4 0 \ \mathrm { m A } \ \mathrm { c m } ^ { - 2 }$ during the 1oth cycle are depicted in Fig.5b.The profiles exhibit well-defined voltage plateaus, with $\mathrm { M n } _ { 3 } \mathrm { O } _ { 4 } /$ CF-120 demonstrating a lower charging voltage and a reduced IR drop compared to the pristine TCF.This smaller interval between the charge and discharge plateau reflects a substantial mitigation of activation polarization and confirms the enhanced reversibility of the Ce redox couple,which was consistent with the data of CV and EIS. The $\mathrm { M n } _ { 3 } \mathrm { O } _ { 4 } /$ CF-12O electrode maintains its original hierarchical structure without significant morphological degradation after 5Oo cycles (Fig.S1O),indicating its stability against corrosion in the acidic environment.

The cycling stability data collected at an elevated current density of $6 0 \ \mathrm { m A } \ \mathrm { c m } ^ { - 2 }$ further highlights the performance gap between the two systems (Fig.5c and d).While both the TCF and $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ electrodes maintain stable CE,the CE of the $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ cell was consistently higher,signifying that the modification cell experienced higher charge transfer efficiency and fewer side reactions.Besides,a stark divergence is observed in voltage dependent metrics.Specifically, the battery assembled with $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ achievesa VE of $7 6 . 8 \%$ and an EE of $7 6 . 1 \ \%$ ,significantly outperforming the TCF electrode,which records values of $7 1 . 5 ~ \%$ and $7 0 . 6 \%$ ,respectively. The enhanced electrochemical performance stems from the increased density of active sites and expanded specific surface area. The structural merits facilitate rapid interfacial charge transfer and efficient ion transport,effectively mitigating the polarization losses that typically plague carbon-based anodes at high current densities.Additionally,by comparing the reported performance of other Ce-based flow batteries in key metrics such as energy efficiency,operating current density,and cycle life (Fig.5e), the excellent performance of $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ is confirmed,demonstrating the potential of $\mathrm { M n } _ { 3 } \mathrm { O } _ { 4 }$ coatings for optimizing the electrode and enhancing the battery performance [22,27,28,48-53].

The exceptional performance of the $\mathrm { M n _ { 3 } O _ { 4 } / C F ^ { - 1 2 0 } }$ originates from a synergistic integration of hierarchical surface engineering,interfacial electronic coupling and in-situ protection. Structurally,the electrodeposition of $\mathrm { M n } _ { 3 } \mathrm { O } _ { 4 }$ nanocrystals onto the carbon fiber substrate creates a three-dimensional architecture that expands the ECSA.This architecture provides an abundance of accessible active sites for the $\mathrm { C e } ^ { 3 + } / \mathrm { C e } ^ { 4 + }$ redox couple,effectively alleviating mass transfer limitations,while simultaneously transforming the electrode from a hydrophobic state to a superhydrophilic state to promote superior electrolyte accessibility. Furthermore,the electronic interaction between the $\bf { M n } _ { 3 } \bf { O } _ { 4 }$ catalystand the Ce ions plays a critical role in accelerating reaction kinetics.The presence of manganese oxides can facilitate an electron complementary effect [54]. This interaction may modulate the electron density at the electrode interface,the overlapping Mn 3d-Ce 4f density of states stabilizes the $\mathrm { C e } ^ { 3 + } / \mathrm { C e } ^ { 4 + }$ transition state,thus lowering the activation energy for interfacial electron transfer[55].This effect is evidenced by the substantial reduction in electrochemical overpotentials and the significant decrease in charge-transfer resistance.

The chemical stability of the electrode is equally vital to its long-term viability. In the aggressive acidic environment of the Fe-Ce flow battery, pristine carbon fibers are susceptible to oxidative degradation and surface passivation,particularly at the high operating potentials required for cerium redox chemistry.The $\mathrm { M n } _ { 3 } \mathrm { O } _ { 4 }$ layerserves as a protective and catalytic shield that prevents direct chemical erosion of the carbon substrate.By maintaining structural integrity and preventing the increase of charge transfer resistance,this modified architecture ensures stable energyefficiencyandaremarkablylowdecay rate over extended cycling. Consequently,these integrated merits substantiate the $\mathrm { M n } _ { 3 } \mathrm { O } _ { 4 } /$ CF composite as a superior and durable electrode platform for high performance Fe-Ce redox flow batteries.

# 4.Conclusion

In conclusion,this investigation demonstrates that the interfacial engineering of carbon felt with $\mathrm { M n } _ { 3 } \mathrm { O } _ { 4 }$ coatings provides a viable strategy to overcome the bottlenecks of sluggish kinetics and carbon corrosion in Fe-Ce redox flow batteries.The electrodeposited $\mathrm { M n } _ { 3 } \mathrm { O } _ { 4 }$ layer results in a transition to a superhydrophilic surface,facilitating superior electrolyte infiltration and enhancing the effective reaction area.These structural and interfacial modifications are associated with a significant decrease in the electrochemical overpotential for the $\mathsf { C e } ^ { 3 + } /$ Ce4+ redox couple and contribute to a robust protective mechanism that suppresses the oxidative degradation of the carbon felt fiber.The resulting improvement in energy efficiency,cycling longevity and stability validates the effectiveness of this functional electrode design.This work provides a scalable pathway for the development of durable electrode materials and highlights the importance of surface modification in advancing aqueous energy storage technologies for grid integration.Although the present study focuses on laboratory-scale validation,the low-cost materials combined with the mature electrodeposition manufacturing methodology make this system promising for large-scale application.Future efforts to optimize the surface properties and morphological features of oxide catalysts may further enhance the feasibility of cerium-based systems for large scale applications.
