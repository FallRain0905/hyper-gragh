ABSTRACT: Among battery technologies considered for large-scale energy storage, manganese-based redox flow batteries have been extremely attractive due to the low cost of materials. Impeding its industrial adoption is the precipitation of $\mathbf { M n O } _ { 2 }$ due to disproportionation of $\mathrm { M n } ^ { 3 + }$ . In this work， we overcome the formation of $\mathbf { M n O } _ { 2 }$ precipitates through complexation of $\mathrm { M n } ^ { 3 + }$ with $\mathrm { C l ^ { - } }$ ions. By virtue of the stable $[ \mathrm { M n } \mathrm { \hat { C } l } _ { 4 } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 2 } ] ^ { - }$ complex, an inexpensive and scalable $\mathrm { F e - M n }$ flow battery was demonstrated using $\mathrm { M n } ^ { 3 + } / \mathrm { M n } ^ { 2 + }$ and $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ redox couples as catholyte and anolyte, respectively. The flow battery achieved an output voltage of $0 . 7 ~ \mathrm { V }$ and current density of up to $1 6 0 \mathrm { \ m A } \mathrm { \ c m } ^ { - 2 }$

Aqueous redox flow batteries (ARFBs)are promising battery systems suitable for large-scale energy storage.ARFBs are safe and possess high salvage value,and costs of operation and maintenance are considerably lower compared to the competition.3-5 Among ARFBs, the vanadium flow battery (VFB） which utilizes ${ \mathrm { V O S O } } _ { 4 }$ as its active species is the most matureandwel-studied technology67Although VFBs are efficient, mining and extracting vanadium is costly and environmental harmful. Alternatives such as zinc-iron, zinciodine,iodine-sulfur, and aqueous organic flow batteries have been considered,yettheyareot without limitatios.4o provide some examples,dendrite formation occurs extensively in Zn metal anodes used in zinc-based flow batteries, polysulfide anions cause crossover effects，and redox-active organic molecules are notorious for structural degradation leading to capacity decay.15-18 Efforts to mitigate these problems include adding additives to zinc electrolytes to suppress the growth of zinc dendrites and constructing composite membranes to hinder crossover of polysulfide anions.920eseefortsecommendablebutdontight solve problems inherent with the design of these flow battery architectures.

A particularly interesting flow battery architecture involves manganese and iron，metals which are significantly more abundant and cheaper than vanadium.However, sluggish Fe deposition and $\mathbf { M n O } _ { 2 }$ precipitation have impeded the development of Fe- or Mn-based redox flow batteries.21-25 ${ \bf { M n O } } _ { 2 }$ precipitation，in particular，is problematic since formation and aggregation of these solids can cause blockages within the channels and degrade cycling performance of the flow battery. To improve the cycling performance of the cell, $\mathrm { I } ^ { - }$ was used as a mediator to restore capacity loss from the generation of $\mathbf { M n O } _ { 2 }$ solid.26 To avoid blockage of pipelines by $\mathrm { \bar { M } n O } _ { 2 }$ particles,a titanium-manganese single flow battery with a static manganese cathode has been proposed.27

Nevertheless, generation of $\mathbf { M n O } _ { 2 }$ has not yet been overcome. $\mathbf { M n O } _ { 2 }$ is formed due to disproportionation of $\mathrm { M n } ^ { 3 + }$ ions,and one way to prevent this is to introduce methanesulfonic acid (MSA）and ethylenediaminetetraacetic acid (EDTA） as ligands to complex with Mn3+28,29 However, MSA is bulky, and the current density of this battery system is only $1 0 \ \mathrm { m A }$ $\mathrm { c m } ^ { - 2 }$

In the current work, we have designed an iron-manganese $\left( \mathrm { M n - F e } \right)$ flow battery system which utilized soluble $\mathrm { \bar { M } n } ^ { 3 + } /$ $\mathrm { M n } ^ { 2 + }$ and $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ redox couples as catholyte and anolyte respectively (Figure 1). To circumvent problems with $\mathbf { M n O } _ { 2 }$ precipitation，HCl was introduced as an additive to the catholyte. Similar to how MSA was used as a complexing ligand, $\mathrm { C l ^ { - } }$ is used to complex with $\mathrm { M n } ^ { 3 + }$ to form the electrochemically reversible $\mathrm { [ M n C l _ { 4 } ( H _ { 2 } O ) _ { 2 } ] ^ { - } }$ .The output voltage and highest current density of the final assembled Mn-Fe flow battery were $0 . 7 \mathrm { V }$ and $\mathrm { \ i } 6 0 \mathrm { \ m A \ c m } ^ { - 2 }$ respectively.

Redox potentials of $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ and $\mathrm { M n } ^ { 3 + } / \mathrm { M n } ^ { \hat { 2 } + }$ redox couples were measured to be 0.44 and $1 . 1 4 \mathrm { ~ V ~ }$ vs SCE respectively (Figure 2a)，which collectively suggest an equilibrium output voltage of $0 . 7 \mathrm { ~ V ~ }$ ，To investigate the influence of ${ \mathrm { C l } } ^ { - }$ ions on $\mathbf { M n O } _ { 2 }$ precipitation， the redox behavior of $\mathrm { M n } ^ { 2 + }$ ion in sulfuric acid electrolytes with and without HCl additive was scrutinized.The electrolyte without HCl was prepared by dissolving $0 . 1 \mathrm { m o l } \mathrm { L } ^ { - 1 } \mathrm { M n } \mathrm { S O } _ { 4 } ^ { ' }$ in $1 . 0 \mathrm { m o l }$ $\mathrm { L } ^ { - 1 } \ \mathrm { H } _ { 2 } \mathrm { S } \hat { \mathrm { O } } _ { 4 }$ solution whereas the electrolyte with HCl was made by dissolving $0 . 1 \ \mathrm { m o l } \ \mathrm { L } ^ { - 1 } \ \mathrm { M n } S \mathrm { O } _ { 4 }$ in $1 . 0 \ \mathrm { m o l \ L ^ { - 1 } }$ HCl and $1 . 0 \mathrm { \ m o l { \ L } ^ { - 1 } \ \bar { H } _ { 2 } S O _ { 4 } }$ solution. Cyclic voltammetry (CV) measurements were carried out in those electrolytes using a standard three-electrode electrochemical cell. CV curves collected in ${ \mathrm { H } } _ { 2 } { \mathrm { S O } } _ { 4 }$ solution without HCl showed a pair of redox peaks centered at $1 . 1 7 \mathrm { ~ V ~ }$ vs SCE (Figure S1).

Furthermore,flakes of $\mathbf { M n O } _ { 2 }$ were observed at the bottom of the three-electrode cell after 10 cycles (Figure S2). This implied that the oxidized $\mathrm { M n } ^ { 3 + }$ ion had transformed into $\mathbf { M n O } _ { 2 }$ and $\mathrm { M n } ^ { 2 + }$ ion through a disproportionation reaction, which is consistent with previous works.24,28,29 In contrast, CV measurements performed in the electrolyte with HCl showed a shift in redox potential to $1 . 1 4 \mathrm { ~ V ~ }$ vs SCE (Figure 2a) and no formation of $\mathbf { M n O } _ { 2 }$ was observed. Instinctively， this suggests the suppression of $\mathbf { M n O } _ { 2 }$ formation due to the presence of HCl.

To further confirm our theory that disproportionation of $\mathrm { M n } ^ { 3 + }$ ion had been inhibited, galvanostatic polarization at a current of $1 0 ~ \mathrm { \ m A }$ was performed in electrolytes with and without HCl.As shown in Figure 2b,the polarization voltage in the electrolytes with and without HCl is 1.14 and $1 . 1 7 \mathrm { V }$ vs SCE respectively. After $^ { 1 \mathrm { ~ h ~ } }$ of polarization, the carbon felt working electrodes were collected and characterized using Xray diffraction (XRD).As expected, XRD patterns of $\mathbf { M n O } _ { 2 }$ were observed on the carbon felt electrodes polarized in the electrolyte without HCl whereas no traces of $\mathbf { M n O } _ { 2 }$ were detected in electrodes using the electrolyte with HCl (Figure S3)．Scanning electron microscopy (SEM） was used to examine the morphology of the electrodes,and the results are presented in Figure 2c and Figure 2d. Figure 2c showed pristine carbon fibers due to inhibition of $\mathbf { M n O } _ { 2 }$ precipitation while Figure 2d showed aggregates of $\mathbf { M n O } _ { 2 }$ particles.

A reasonable explanation is that the presence of HCl in $\mathrm { M n S O _ { 4 } }$ solution changes the coordination environment of $\mathrm { M n } ^ { 3 + }$ in the catholyte. Theoretically, $\mathrm { M n } ^ { 3 + }$ ion prefers to form a $[ \mathrm { M n C l } _ { 4 } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 2 } ] ^ { - }$ complex with $\mathrm { C l ^ { - } }$ and $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ in the electrolyte with HCl while $\mathrm { M n } ^ { 3 + }$ formsa $[ \mathrm { M n } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 6 } ] ^ { 3 + }$ complex with $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ in the electrolyte without HCl. The calculated Gibbs free energy of $[ \mathrm { M n C l } _ { 4 } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 2 } ] ^ { - }$ $( - 4 4 . 7 5 1 $ eV） is lower than that of the $\mathrm { [ M n ( H _ { 2 } O ) _ { 6 } ] ^ { 3 + } }$ $\left( - 2 8 . 1 0 4 \ \mathrm { e V } \right)$ complex which suggests that $[ \mathrm { M n C l } _ { 4 } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 2 } ] ^ { - }$ is more stable than $\mathrm { [ M n ( H } _ { 2 } O \mathrm { ) } _ { 6 } ] ^ { 3 + }$ (Figure S4). The above results indicate that disproportionation of $\mathrm { M n } ^ { 3 + }$ can be inhibited by simply adding HCl to modify its coordination environment. The proposed oxidation processes of $\mathrm { M n } ^ { 2 + }$ in the electrolyte with and without HCl were displayed in Figure 3.

A flow battery with $\mathrm { M n } ^ { \hat { 3 } + } / \mathrm { M n } ^ { 2 + }$ as catholyte and $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ as anolyte was constructed.The separator used was sulfonated polyether ether ketone (SPEEK） membrane with a conductivity of $0 . 1 0 2 \ \mathrm { ~ s ~ } \ \mathrm { c m } ^ { - 1 }$ in $1 . 0 \mathrm { m o l } \mathrm { L } ^ { - 1 } \mathrm { H } _ { 2 } \mathrm { S O } _ { 4 }$ solution (Figure S5).The SPEEK membrane was homemade by sulfonating polyether ether ketone (PEEK) as described in our previous work.30 In the first flow battery, $5 . 0 \mathrm { m L }$ of $1 . 0 \mathrm { m o l L } ^ { - 1 }$ $\mathrm { M n S O _ { 4 } }$ in $3 . 0 \mathrm { \ m o l \ L ^ { - 1 } \ H _ { 2 } S O _ { 4 } }$ solution was pumped through the cathodic chamber while $5 . 0 ~ \mathrm { m L }$ of $1 . 0 \mathrm { m o l } \mathrm { L } ^ { - 1 } \mathrm { \tilde { F } e C l } _ { 3 }$ in 3.0 mc $\mathrm { { 1 L ^ { - 1 } H C l } }$ flows through the anodic chamber.In the second flow battery, $5 . 0 ~ \mathrm { m L }$ of $\mathrm { \Delta \stackrel { - } { 1 . 0 } ~ m o l ~ L ^ { - 1 } ~ M n S O _ { 4 } }$ in $3 . 0 \mathrm { ~ m o l ~ L ^ { - 1 } }$ $\mathrm { H } _ { 2 } \mathrm { S O } _ { 4 }$ and $3 . 0 \ \mathrm { m o l \ L ^ { - 1 } H C l }$ solution was used as the catholyte while the anolyte used was the same as the first.Both flow batteries were charge-discharged at a constant current of 100 mA between a voltage of 0.2 to $1 . 2 \ \mathrm { V }$ ，The voltage profiles displayed in Figure 4a show that the discharge curve of the battery without HCl has two segments，which suggests two redox reaction processes.However, the discharge curve of the battery with HCl additive exhibits only one oblique line which is due to a single redox reaction occurring in the catholyte. After charging to $1 . 2 \mathrm { V } ,$ the carbon felt of the battery with and without HCl was characterized by XRD and the results were consistent with that of galvanostatic polarization (Figure 4b).

Electrochemical impedance spectroscopy (EIS） was used to quantify the overall resistance in the flow battery in operation. Analysis of its EIS spectrum in Figure Sc showed three constant phase elements (R2,R3,R4) and one ohmic element (R1）contributing to its overall resistance.R1，R2，R3，R4 elements are ascribed to proton transport $\left( 0 . 7 2 ~ \Omega \right)$ ，cathodic electrical double layer $\left( 0 . 4 4 ~ \Omega \right)$ ,anodic electrical double layer $\left( 0 . 4 5 ~ \Omega \right)$ ,and charge transfer resistance $\left( 0 . 1 4 \Omega \right)$ ,respectively. Since ohmic resistance accounts for $4 1 \%$ of overall resistance, improving the conductivity of the electrolyte and reducing proton transport distance can reduce overall resistance.

The cycling performance of the flow cell with mixed electrolyte was evaluated,and a capacity retention rate of $1 0 0 \%$ after 280 cycles was achieved (Figure Sd). The coulumbic efficiency was also maintained at $1 0 0 \%$ throughout the whole test (Figure Sd). The other advantage of a Mn-Fe flow battery is its high volumetric capacity. We found that the concentration of $\mathrm { M n S O _ { 4 } }$ could be increased to above 3.0 mol $\mathrm { L } ^ { - 1 }$ (Figure S8). This value corresponds to a volumetric capacity of 80.4 Ah $\mathrm { L } ^ { - 1 }$ which is higher than that of vanadium flow batteries.Although the volumetric capacity of the Mn-Fe flow battery is higher than that of VFB,its equilibrium output voltage is only $0 . 7 \ \mathrm { V } .$ ，To increase the output voltage, a $3 . 0 \mathrm { ~ V ~ }$ battery stack was constructed by connecting S cells in tandem (Figure S9).The battery stack demonstrates the scalability and feasibility of a $_ \mathrm { M n - F e }$ all-flow battery for large-scale energy storage.

Compared with other metalic ions and organic molecules, the main advantage of a Mn-Fe flow battery is its low cost. The calculated mass of $\mathrm { M n S O } _ { 4 } { \cdot } \mathrm { H } _ { 2 } \mathrm { O }$ and $\mathrm { F e C l } _ { 3 } { \cdot } 6 \mathrm { H } _ { 2 } \mathrm { O }$ for1 kWh capacity is 5.3 and $^ { 1 7 } \mathrm { \ k g } ,$ respectively. Even the output voltage is a little bit low (0.7 V)，the calculated total mass multiplied by its price delivers a cost lower than $1 0 . 3 \mathrm { ~ \$ ~ }$ per kWh,which is the lowest among all metallic ion-based flow batteries (Table S1).Another advantage of the Mn-Fe flow battery is that the catholyte and anolyte can be mixed together to form a symmetric battery. This means that ion crossover can be minimized by rebalancing the electrolyte during practical operation.In the future, the output voltage could be increased to $1 . 6 5 \mathrm { ~ V ~ }$ by replacing $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ with the $\mathrm { C r } ^ { 3 + } / \mathrm { C r } ^ { 2 + }$ redox couple (Figure S10).

# CONCLUSION

In summary, disproportionation of $\mathrm { M n } ^ { 3 + }$ has been successfully inhibited by adding HCl into the $\mathrm { M n } ^ { 2 + }$ catholyte. This was attributed to the formation of a stable redox-active complex $[ \mathrm { M n C l } _ { 4 } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 2 } ] ^ { - }$ ，A HCl enabled Mn-Fe flow battery was constructed using soluble $\mathrm { M n } ^ { 3 + } / \mathrm { M n } ^ { 2 + }$ and $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ redox couples as catholyte and anolyte which achieved an output voltage of $_ { 0 . 7 \mathrm { ~ V ~ } }$ and a current density of up to $1 6 0 \mathrm { \ m A \ c m } ^ { - 2 }$ Because of utilization of abundant and cheap $\mathrm { M n S O } _ { 4 }$ and $\mathrm { F e C l } _ { 3 }$ as cathodic and anodic materials, the active materials cost of a Mn-Fe all-flow battery is lower than $1 0 . 3 \mathrm { ~ \AA ~ }$ per kWh. Not only has this work introduced a new method to stabilize $ { \mathrm { M n } } ^ { 3 + }$ ，it has also shown that Mn-Fe flow batteries are inexpensive options for long-term energy storage.
