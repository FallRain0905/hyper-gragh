ABSTRACT: The low energy density and narrow operating temperature window besides the relatively high cost of the vanadium redox-flow battery (VRB) severely hinder its commercial deployment. Herein, in conjunction with low-concentration $\mathbf { V O } ^ { 2 + } / \mathbf { V O } _ { 2 } ^ { + }$ catholyte， we introduce a redox targeting-based VRB (RT-VRB) system in which a Prussian blue analogue (PBA), $\bf \bar { ( } v \bf { O ) } _ { 6 } [ F e ( C N ) _ { 6 } ] _ { 3 } ,$ is employed as a capacity booster to address the above issues. The charges are reversibly stored in the PBA loaded in the cathodic tank via a redox-targeting reaction with the $\mathbf { V O } ^ { 2 + } / \mathbf { V O } _ { 2 } ^ { + }$ · Therefore， the concentration of catholyte has been reduced to $\mathbf { 0 . 6 \ M }$ without sacrificing the capacity. This provides ample room to broaden the operating temperature window of a RT-VRB relative to a conventional VRB. The theoretical volumetric capacity of the PBA could reach $1 3 5 \ : \mathbf { A h } / $ L, which is more than 3 times that of VRB. We anticipate that the RT-VRB system demonstrated here would give credible impetus for VRB chemistry for robust and high-density energy storage applications.

$$
C _ { \mathrm { t h e o r e t i c a l } } = \frac { F { \cdot } c _ { \mathrm { P B A } } } { 3 6 0 0 }
$$

where $c _ { \mathrm { P B A } }$ is the concentration of pure PBA at $100 \%$ utilization and $F$ is the Faraday constant. The concentration of PBA $\left( c _ { \mathrm { P B A } } , \ m o 1 / \mathrm { L } \right)$ is calculated by using the following formula

$$

where $C ^ { \prime }$ discharge $= 0 . 5 8$ Ah is the actual discharge capacity obtained from the battery measurement of the RT-VRB loaded with $_ { 5 \mathrm { ~ g ~ } }$ of PBA granules. $V _ { \mathrm { \ c a t h o d i c \ t a n k } } ^ { \prime }$ is the catholyte volume (solution and PBA granules, $1 3 ~ \mathrm { m L }$ ）in the tank of the RT-VRB.It should be noted that for the calculation of volumetric capacity we consider only the total volume of electrolyte and PBA solid material in the tank ( $[ 1 3 \ \mathrm { m L } ]$ ).This isreasonable considering for a large system most of the active materials is stored in the tank and the amount of electrolyte in the cell stack and tubing is marginal. $C _ { \mathrm { a c t u a l , R T - V R B } }$ is then determined to be $4 4 . 6 \ \mathrm { A h } / \mathrm { L } ,$ fairly comparable to the conventional VRB cell $\left( 4 0 . 2 ~ \mathrm { A h / L } \right)$ using $1 . 5 \mathrm { \ : M \ : V O ^ { 2 + } / V O _ { 2 } } ^ { + }$ .Therefore,despite that the catholyte concentration of RT-VRB is only $0 . 6 \textbf { M }$ ，the cathodic volumetric capacity is not compromised with the contribution of the PBA solid material through the redoxtargeting reactions.We believe the capacity could be further enhanced by optimizing the microstructures (i.e., porosity and tortuosity) of the PBA granules in the tank.

It has been noticed that the potential of PB via the redox reaction of $\mathrm { N - C - F e ^ { \mathrm { I I / I I I } } }$ to Berlin green is fairly comparable to that of PBA. However, the redox-targeting reaction between PB and $\mathrm { V O } ^ { 2 + } / \mathrm { V O } _ { 2 } ^ { + }$ is sluggish and the contribution of PB is unsatisfactorily low (Figure S6). In contrast, the vanadiumbased PBA presents superior reaction kinetics toward $\mathrm { V O } ^ { 2 + } /$ ${ \mathrm { V O } } _ { 2 } ^ { + }$ and thus is much more efficient in boosting the capacity. In addition,the PBA remains in the catholyte tank during operation and reversibly hosts and releases protons, buffering the $\mathrm { p H }$ changes of the catholyte without having any adverse effect on other components of the cell. While it remains an open question why PBA performs better than PB for the reactions with $\mathrm { V O } ^ { 2 + } / \mathrm { V O } _ { 2 } ^ { + }$ and considering the inflated cost of PBA due to the presence of vanadium, we further synthesized a PBA material with reduced $\mathrm { v }$ content in which $4 0 \%$ of the $\mathrm { v }$ in the pristine PBA was replaced by Fe.Interestingly, the new PBA material also demonstrated similarly swift reaction kineticswith $\mathrm { V O } ^ { 2 + } / \mathrm { V O } _ { 2 } ^ { + }$ .The capacity enhancement is comparable to that of the pristine material despite the presence of a $40 \%$ less reactive PB component in the material (Figure S7),revealing an intriguing synergy between the two. Considering the inertness of $\mathrm { v }$ in PBA in the redox-targeting reaction,it is anticipated that the amount of $\mathrm { v }$ can be further reduced or replaced by other elements with an insightful understanding of the underlying role of vanadium in the PBA in improving the redox-targeting reaction kinetics.

In summary,we have demonstrated a RT-VRB system with enhanced cathodic volumetric capacity and potentially improved thermal stability on the basis of a Nernstian potential-driven redox-targeting concept. The RT-VRB, built upon the most developed VRB chemistry，employs a PBA $( \bar { ( } \mathrm { V O ) } _ { 6 } [ \mathrm { F e ( C N ) } _ { 6 } ] _ { 3 } )$ material loaded in the cathodic tank to effectively boost the capacity.Through the redox-targeting reactions between the PBA and $\mathrm { V O } ^ { 2 + } / \mathrm { V O } _ { 2 } ^ { + }$ redox species, which share an identical redox potential, the charges are reversibly stored in PBA during the charging/discharging processes. More prominently,the concentration of $\mathrm { V O } ^ { 2 + } / \mathrm { V O } _ { 2 } ^ { \mp }$ in the catholyte can be significantly reduced to around $_ { 0 . 6 \mathrm { ~ M ~ } }$ without sacrificing the capacity. As a result, the operating temperature of the $\mathrm { V O } ^ { 2 + } / \mathrm { \bar { V } O } _ { 2 } ^ { + }$ catholyte can be broadened to over $7 0 ~ ^ { \circ } \mathrm { C }$ ，The theoretical volumetric capacity of the PBA material is as high as $1 3 5 \mathrm { { A h } / L , }$ and with the PBA granules as a capacity booster, a catholyte capacity density of $4 4 . 6 \ : \mathrm { A h / L }$ has been achieved in the RT-VRB. There is ample room for RT-VRB to further enhance its capacity by optimizing the microstructures of PBA granules and more effectively by applying the redox-targeting concept to both the anodic and cathodic sides for a more balanced battery chemistry.We anticipate that this work opens up a credible approach to the development of high capacity and stability RFB systems for large-scale energy storage.

# EXPERIMENTAL SECTION

Synthesis of PBA. The PBA was synthesized at room temperature by adding $1 0 0 ~ \mathrm { \ m L }$ of $\mathrm { i } 0 0 \mathrm { ~ \ m M }$ $\mathrm { K } _ { 4 } \mathrm { F e } ( \mathrm { C N } ) _ { 6 }$ solution dropwise into $1 0 0 ~ \mathrm { m L }$ of $3 0 0 \ \mathrm { m M } \ \mathrm { V O S O _ { 4 } }$ solution in $2 \mathrm { ~ M ~ H } _ { 2 } S { \mathrm O } _ { 4 }$ .The mixed solution was then aged overnight at room temperature. The product was separated by centrifugation and washed with DI water five times.The collected solid was then dried at $6 0 ~ ^ { \circ } \mathrm { C }$ to obtain the PBA powder.

The high energy synchrotron XRD experiments of the PBA were carried out using an X-ray with a wavelength of 0.4321 A at 13-BM-C of the Advanced Photon Source (APS）of Argonne National Laboratory (ANL).

Rotating disk electrode (RDE) measurements were conducted on the Modulated Speed Electrode Rotator (AFMSRCE, PINE): The paste of PBA was first prepared as following: $\mathrm { 5 ~ m g }$ of as-prepared PBA powder and $5 ~ \mathrm { m g }$ of ${ \mathrm { V O } } _ { 2 } { } ^ { + }$ -oxidized PBA powder were mixed in $1 ~ \mathrm { m L }$ of Nafion solution in DI water. To prepare the PBA-modifed GC disk electrode (PBA/GC),60 $\mu \mathrm { L }$ of PBA paste was then dripped onto the GC electrode and dried in air overnight. The CV measurements were first conducted with GC and PBA/GC in 2 M ${ \mathrm { H } } _ { 2 } { \mathrm { S O } } _ { 4 }$ as the control.To verify the redox-targeting reaction between PBA and $\mathrm { V O } ^ { 2 + } / \mathrm { V O } _ { 2 } ^ { + }$ ,the CV measurements were conducted with GC and PBA/GC in $5 \mathrm { \ m M } \mathrm { V O ^ { 2 + } } + 5 \mathrm { \ m M } \mathrm { V O _ { 2 } } ^ { + }$ in 2 M $\mathrm { H } _ { 2 } \mathrm { S O } _ { 4 }$ electrolyte.All of the RDE measurements were performed at a rotating speed of $1 6 0 0 ~ \mathrm { r p m }$ and a scan rate of $\bar { \varsigma _ { \mathrm { { m V } } \cdot { s } ^ { - 1 } } }$ . All of the above electrochemical measurements were performed with a three-electrode system （ $\mathrm { \Delta P t }$ as the counter and $\mathrm { \ A g / A g C l }$ as the reference） on an Autolab electrochemical workstation (Metrohm Autolab,PGSTAT302N).

Inductively Coupled Plasma (ICP) Measurement.PBA powder （ $\langle 5 \mathrm { m g } \rangle$ was dissolved in $5 ~ \mathrm { m L }$ of mixed acid $\left( \mathrm { H N O } _ { 3 } { \mathrm { : H C l : H F } } \right.$ $\begin{array} { r l } { = } & { { } 1 { : } 3 { : } 1 } \end{array}$ ）to perform the ICP measurement. Fourier Transform Infrared (FTIR） Spectroscopic Measurement. FTIR spectra of the as-prepared PBA, ${ \mathrm { V O } } _ { 2 } ^ { + }$ -oxidized PBA, and $\mathrm { V O } ^ { \hat { 2 } + }$ -reduced PBA were recorded from 4000 to 400 $\mathrm { c m } ^ { - 1 }$ on the PerkinElmer Frontier MIR/FIR system by 16 scans with a nominal resolution of $1 ~ \mathrm { c m ^ { - 1 } }$ through an attenuated total reflection (ATR) mode.

The X-ray absorption near-edge structure (XANES）of PBA in the RT-VRB catholyte symmetric cell was performed at the Singapore Synchrotron Light Source.
