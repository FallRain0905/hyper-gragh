The vanadium redox flow battery (VRFB) has significant potential as a large-scale renewable energy storage technology,butthe highcostof the electrolytelimits its commercialization proces.Thecostofthe electrolyte is primarily determined by the purity of the raw materials used in vanadium extraction.Vanadium-titanium magnetite is the main source of vanadium,and itscore resource elements Ti,Fe,and Cr could be introduced in the form of $\mathrm { T i } ^ { 4 + }$ , $\mathrm { F e } ^ { 3 + }$ ,and $\mathrm { C r } ^ { 3 + }$ during the preparation of the electrolyte. It is therefore critical to understand how impurity ions affect the performance of VRFB.In this work, the effects of $\mathrm { T i } ^ { 4 + }$ ， $\mathrm { F e } ^ { 3 + }$ ，and $\mathrm { C r } ^ { 3 + }$ on the electrochemical performance of electrolyte were studied.The study found that an appropriate amount of $\mathrm { T i } ^ { 4 + }$ can improve the electrochemical activity and kinetics of $\mathrm { V O } ^ { 2 + } / \mathrm { \ ' { V O } _ { 2 } ^ { + } }$ redox reaction and reduce the charge transfer resistance.The incorporation of $\mathrm { T i } ^ { 4 + }$ leads to a slight improvement in the electrochemical performance of the $\mathsf { V } ^ { 2 + } / \mathsf { V } ^ { 3 + }$ redox couple,although the enhancement is not pronounced. When $\mathrm { T i } ^ { 4 + }$ is introduced into $\scriptstyle \mathrm { V O } ^ { 2 + }$ electrolytes containing $\mathrm { F e } ^ { 3 + }$ ， $\mathrm { C r } ^ { 3 + }$ ,ormixed $\mathrm { F e } ^ { 3 + } / \mathrm { C r } ^ { 3 + }$ impurities，experimental results indicatethat $\mathrm { T i } ^ { 4 + }$ effctively mitigates thedetrimental effects of $\mathrm { F e } ^ { 3 + }$ ， $\mathrm { C r ^ { 3 + } }$ ,and $\mathrm { F e } ^ { 3 + } / \mathrm { C r } ^ { 3 + }$ on the electrochemical properties of the electrolyte. Charge-discharge tests further demonstrate that VRFB employing electrolytes with $\mathrm { T i } ^ { 4 + }$ together with $\mathrm { F e } ^ { 3 + }$ and $\mathrm { C r } ^ { 3 + }$ impurities exhibit higher discharge capacity,energy eficiency,and cycling stability compared with those containing only $\mathrm { F e } ^ { 3 + }$ and $\mathrm { C r ^ { 3 + } }$ impurities.This study provides new insights into the development of low-cost, high-performance vanadium electrolytes.

# 1．Introduction

In recent years,with the continuous consumption of fossil fuels and the increasingly stringent environmental protection policies,the demand for renewable energy has been growing [1].However, these renewable energy sources encounter problems related to intermittency and instability,especially wind and solar energy.This situation highlights the importance of developing large-scale energy storage technologies to enhance the integration of renewable energy sources [2]. Currently,electrochemical capacitors,vanadium redox flow battery (VRFB),high-temperature solid oxide electrolysis battery/solid oxide fuel battery,and lithium-ion batteries are attracting considerable attention in the energy storage market[3-11].In the field of chemical energy storage technology,especially VRFB are considered a new and efficient electrochemical energy storage device due to their good environmental sustainability,high safety,long cycle life,flexible power and capacity design,and environmental friendliness [l2-16].

Vanadium electrolyte is a key component of VRFB,and its performance directly determines the performance and cycle life of VRFB [17-22]. Vanadium concentration,acidity,and purity have significant effects on vanadium electrolyte. The complex preparation process results in high electrolyte costs,which account for approximately $5 0 \% { - } 7 0 \%$ of the total system cost and have become a significant bottleneck, restricting the commercial application of vanadium batteries [23]. $8 8 \%$ of theworld's vanadium production comesfrom vanadium-titanium magnetite.This resource distribution feature provides an important basis for the selection of raw materials for vanadium electrolyte,and helps to optimize the preparation process and production costs [18,19].

However,during the extraction or recovery of vanadium from vanadium-titanium magnetite beds,impurities such as Na, Si,Fe,Cr,Ti, etc.may persist or be introduced into vanadium products [2O].Unlike the impurities such as Li, Na, Si,which are low abundance or easy to separate in the process of mineral processing,Fe,Ti,Cr are tightly combined with the vanadium in the ore structure,which are unavoidable and difficult to remove in the industrial vanadium products [21-25].Battery developers often favor high-purity electrolyte to prevent unwanted effects of impurities on system performance.However, this dramatically increases the cost of VRFB systems and hinders their large-scale development.Therefore,it is crucial to comprehend the impact of inorganic impurities in electrolyte on the performance of VRFB,thereby facilitating the commercialization process of VRFB.

Extensive studies have investigated the effects of various potential cations and anions in the VRFB electrolyte on its stability,electrochemical activity,vanadium-ion diffusivity,and charge discharge performance.Increasing concentrations of the metal cations $\mathrm { L i ^ { + } }$ ， $\mathrm { N a ^ { + } }$ ,and $\mathrm { K } ^ { + }$ lead to an increase in viscosity and a decrease in conductivity,which undoubtedly hinders the diffusion of $\mathrm { V O } ^ { 2 + } / \mathrm { V O } _ { 2 } ^ { + }$ and thus reduces the performance of VRFB [23-25]. Transition metal ions, such as ${ \mathsf { C o } } ^ { 2 + }$ ， $\bar { \bf N i } ^ { 2 + }$ ， $\mathrm { { C u } ^ { 2 + } }$ and $\scriptstyle { \mathrm { Z n } } ^ { 2 + }$ ,lead to a decrease in the stability of the $\mathrm { V O } _ { 2 } ^ { + }$ electrolyte.A certain concentration of $\mathrm { M n ^ { 2 + } }$ facilitates the diffusion of vanadium ions.However, elevated concentrations of $\mathrm { M n ^ { 2 + } }$ uncontrollably increase the interfacial impedance,which in turn compromises the energy density of the battery [22].Impurity ions,such as $\mathrm { N H } _ { 4 } ^ { + }$ ， $\mathrm { M g } ^ { 2 + }$ ， and $\mathsf { A l } ^ { 3 + }$ ,reduce the deposition phenomenon of the electrolyte within a certain range,and at concentrations above a certain threshold,they also reduce the electrochemical performance of the VRFB,as well as the stability of theelectrolyte [26-32]. $\mathbf { B i } ^ { 3 + }$ ， $\mathrm { { s b } ^ { 3 + } }$ ， $\mathrm { I n } ^ { 3 + }$ ，etc.can help improve the energy eficiency of the battery and promote the diffusion of vanadium ions,making them considered for use as electrolyte additives [33-35]. Cl and $\mathsf { P O } _ { 4 } ^ { 3 - }$ can be coordinated with vanadium ions to form more stable intermediates,which can effectively reduce the formation of V-O-V and improve the stability of the electrolyte and the energy efficiency [34,36-41]. $\mathrm { S i O } _ { 3 } ^ { 2 \cdot }$ , $\mathrm { A l O _ { 2 } ^ { - } , N O _ { 3 } ^ { - } , C r _ { 2 } O _ { 7 } ^ { 2 - } }$ ，and $\mathrm { M n O } _ { 4 } ^ { - }$ would drastically reduce the stability of vanadium electrolyte at low concentrations. $\mathrm { S i O } _ { 3 } ^ { 2 \cdot }$ caused a significant decrease in voltage eficiency,energy efficiency,and electrode reaction activity and accelerated the decay of battery capacity [42].When the $\mathrm { S i } ^ { 4 + }$ content in the electrolyte exceeded $0 . 0 3 0 { \ g } { \mathrm { L } } ^ { - 1 }$ ,the diffusion coefficient of $\scriptstyle \mathrm { V O } ^ { 2 + }$ decreased, and the reaction charge transfer resistance increased,resulting in a decrease in the electrochemical activity of the electrolyte and the reversibility of the $\mathrm { V O } ^ { 2 + } / \mathrm { V O } _ { 2 } ^ { + }$ electro-pair reaction. In addition, the capacity decay rate and energy decay rate of the VRFB increased significantly [43,44].

While these studies provide valuable insights into the impact of various impurities on VRFB performance,critical gaps remain in research on the most relevant contaminants in vanadium's primary raw materials.Vanadium-titanium magnetite,the main raw material for vanadium electrolytes,is characterized by its high iron content and natural co-occurrence of vanadium with Ti and $\mathrm { c r }$ (element composition shown in Fig. la). Consequently, $\mathrm { F e } ^ { 3 + }$ ， $\mathrm { C r ^ { 3 + } }$ ，and $\mathrm { T i } ^ { 4 + }$ are the predominant impurities in industrial-grade electrolytes.Their close association with vanadium during extraction makes complete removal both technically challenging and economically unfeasible,further highlighting the necessity to study their individual and combined effects. In contrast,other potential impurities (such as ${ \mathsf { C o } } ^ { 2 + }$ ， $\mathrm { N i ^ { 2 + } }$ ， $\mathrm { N H } _ { 4 } ^ { + }$ etc.）are less abundant in vanadium-titanium magnetite and easier to remove.Therefore, this study strategically selected $\mathrm { F e } ^ { 3 + }$ ， $\mathrm { C r ^ { 3 + } }$ ,and $\mathrm { T i } ^ { 4 + }$ as key impurity ions, filling critical data gaps in industrial-grade electrolyte production. Currently,numerous studies have been conducted on the performance of $\mathrm { F e } ^ { 3 + }$ and $\mathrm { C r ^ { 3 + } }$ alone in VRFB electrolyte [34,45-47]. The study by Ding et al.[34] showed that too high a concentration of $\mathrm { F e } ^ { 3 + }$ may compete with vanadium ions for the reaction sites on the electrode surface,leading to a decrease in the electrode activity and affecting the $\mathrm { V O } ^ { 2 + } / \mathrm { V O } _ { 2 } ^ { + }$ redox pair reversibility，thus negatively affecting the battery performance.The thermodynamic analysis of the reaction between Fe impurity ions and vanadium ions in the electrolyte showed thatFe impurity ions can only exist stably in the form of $\mathrm { F e } ^ { 2 + }$ in the $\mathrm { V } ^ { 2 + }$ electrolyte and $\mathrm { V } ^ { 3 + }$ electrolyte,so the effect of $\mathrm { F e } ^ { 3 + }$ on the electrochemical performance of the $\mathrm { V } ^ { 3 + }$ electrolyte cannot be investigated.The study by Huang et al.[48] further pointed out that when the concentration was more than $0 . 3 0 \mathrm { ~ g ~ L ^ { - 1 } }$ ，the diffusion resistance increased significantly and the diffusion coefficient decreases,which has a hindering effect on ion migration.Jong Ho Park et al.[23] pointed out that among the transition metal ions, $\mathrm { C r ^ { 3 + } }$ exerted a significant negative effect on the kinetics of the redox reaction of $\mathrm { V } ^ { 3 + } / \mathrm { V } ^ { 2 + }$ .However, there is no literature report on the effects of $\mathrm { T i } ^ { 4 + }$ ， $\mathrm { F e } ^ { 3 + }$ ，and $\mathrm { C r } ^ { 3 + }$ multiple inorganic ions on the electrochemical performance of VRFB electrolyte. In addition, the concentration limit of $\mathrm { T i } ^ { 4 + }$ in the electrolyte is unknown, and its influence on the electrolyte performance is unclear. Given this, this paper investigates the influence law of $\mathrm { T i } ^ { 4 + }$ on the physicochemical properties of the electrolyte.It uses cyclic voltammetry test,electrochemical impedance spectroscopy test,and charge-discharge test to explore the effects of $\mathrm { T i } ^ { 4 + }$ ， $\mathrm { F e } ^ { 3 + }$ and $\mathrm { C r } ^ { 3 + }$ on the electrochemical performance of electrolyte.This study can further standardize the use conditions of electrolyte,provide an essential theoretical basis and practical guidance for the preparation and regeneration of electrolyte.

# 3．Results and discussion

# 3.1. Effect of $\scriptstyle { { \cal T } } i ^ { 4 + }$ on physicochemical properties of VRFB electrolyte

# 3.1.1. UV-Vis spectroscopy

The UV absorption peak position and absorbance can reflect the coordination state and valence state of vanadium ions.From as shown in Fig.lc,after the introduction of $\mathrm { T i } ^ { 4 + }$ ,the UV spectral absorption peak position and absorbance of the electrolyte changed less,and the characteristic absorption peaks of $\mathrm { V } ^ { 3 + }$ and $\scriptstyle \mathrm { V O } ^ { 2 + }$ appeared at $4 0 0 \ \mathrm { n m }$ and $7 7 0 ~ \mathrm { n m }$ ,respectively.It indicates that in the absence of charging and discharging,the interaction between $\mathrm { T i } ^ { 4 + }$ and vanadium ions is weak, thus there is no significant effect on the vanadium ion coordination state and valence state, and $\mathrm { T i } ^ { 4 + }$ can be stabilized in the VRFB electrolyte.

# 3.1.2. Effect of $T i ^ { 4 + }$ concentration on electrolyteviscosity

The viscosity of the electrolyte can influence ion-transport behavior within the VRFB.A higher viscosity may hinder ion migration to some extent and potentially increase concentration polarization, thereby affecting the electrochemical performance of the system.Moreover, variations in viscosity can modify the flow characteristics of the electrolyte,which may influence the required pumping power and consequently impact the overall energy efficiency of the battery.In the $\scriptstyle \mathrm { V O } ^ { 2 + }$ electrolyte shown in Fig.ld,the viscosity shows a gradual increase with increasing $\mathrm { T i } ^ { 4 + }$ concentration, but the overall change is small. As a highvalence cation, $\mathrm { T i } ^ { 4 + }$ readily forms complex coordination interactions with the hydrated ligands of $\scriptstyle \mathrm { V O } ^ { 2 + }$ or alters the solvation structure of vanadium ions through electrostatic attraction. These effects enhance intermolecular friction and consequently lead to an increase in the solution viscosity,which is consistent with the typical oxygen-ligand coordination behavior of vanadium species in aqueous solutions [46]. Compared with the absence of $\mathrm { T i } ^ { 4 + }$ , its introduction reduces the viscosity of the $\mathsf { V } ^ { 3 + }$ electrolyte (Fig.le). The $\mathsf { V } ^ { 3 + }$ electrolyte possesses a more compact and strongly coordinated solvation structure.The introduction of $\mathrm { T i } ^ { 4 + }$ may disrupt the original $\mathrm { V } ^ { 3 + }$ centered clusters and weaken the intermolecular associations within the solution.This disruption decreases the extent of ion aggregation,resulting in reduced intermolecular friction and ultimately a lower viscosity.

The opposite viscosity trends observed for the positive and negative electrolytes can be rationalized by the fundamentally different hydration and coordination structures of $\mathrm { V O } ^ { 2 + } / \mathrm { V O } _ { 2 } ^ { + }$ and $\mathrm { V } ^ { 3 + } / \mathrm { V } ^ { 2 + }$ species. First-principles molecular dynamics simulations have shown that $\mathrm { V } ^ { 2 + }$ and $\bar { \mathsf { V } } ^ { 3 + }$ possess strongly hydrated octahedral coordination shells, whereas oxovanadium species $\mathrm { ( V O ^ { 2 + } }$ ， $\mathrm { V O } _ { 2 } ^ { + } )$ exhibit distinct hydration numbers and ligand exchange dynamics [49].This leads to diferent ion-ion association and hydrogen-bonding networks in the corresponding electrolytes.In addition,previous measurements of vanadium electrolyte viscosity have demonstrated that the physicochemical properties of the positive and negative electrolytes respond differently to changes in state of charge,vanadium concentration and temperature. Our results therefore indicate that the introduction of $\mathrm { T i } ^ { 4 + }$ perturbs these intrinsic structures in opposite ways in the positive and negative electrolytes,giving rise to the contrasting viscosity trends [50].

# 3.1.3. Effect of $T i ^ { 4 + }$ concentration on electrolyte conductivity

The conductivity of the electrolyte directly affects the internal resistance of the VRFB during application.As shown in Fig.1f, the conductivity of the $\scriptstyle \mathrm { V O } ^ { 2 + }$ electrolyte exhibits a non-monotonic trend with increasing $\mathrm { T i } ^ { 4 + }$ concentration $\left( 0 { \cdot } 0 . 0 4 \mathrm { m o l } \mathrm { L } ^ { - 1 } \right)$ , first rising and then declining. It reaches a maximum value of $4 7 6 . 1 9 \ \mathrm { m S \ c m ^ { - 1 } }$ at a concentration of $0 . 0 2 \mod \mathrm { L } ^ { - 1 }$ ，representing an enhancement of $1 . 1 9 \%$ compared to the undoped electrolyte.The low concentration of $\mathrm { T i } ^ { 4 + }$ optimized the ion migration through the charge compensation effect, whereas at high concentration $\mathrm { ( { > } 0 . 0 2 m o l { L } ^ { - 1 } }$ ),the conductivity showed a slight decrease due to the enhanced ionic interactions,but it was still higher than that of the pristine electrolyte.In contrast, the conductivity of the $\mathsf { V } ^ { 3 + }$ electrolyte responded more moderately to $\mathrm { T i } ^ { 4 + }$ doping (Fig. 1g).

# 3.1.4.Effect of $T i ^ { 4 + }$ on the stability of $V O _ { 2 } ^ { + }$ electrolyte

In order to investigate the effect of $\mathrm { T i } ^ { 4 + }$ on the thermal stability of the $\mathrm { V O } _ { 2 } ^ { + }$ electrolyte,the electrolyte with and without $\mathrm { T i } ^ { 4 + }$ were tested comparatively.As shown in Fig.1h, the vanadium ion concentration of both electrolytes decreased with the increase of the standing time,but the concentration of $\mathrm { V O } _ { 2 } ^ { + }$ in the electrolyte containing $\mathrm { T i } ^ { 4 + }$ was always higher than that of the pristine electrolyte.It indicates that $\mathrm { T i } ^ { 4 + }$ improves the thermal stability of the $\mathrm { V O } _ { 2 } ^ { + }$ electrolyte.A possible explanation is that $\mathrm { T i } ^ { 4 + }$ hydrolyzes in the acidic solution to form $\mathrm { T i - O H _ { x } }$ species,which can interact with $\mathrm { V O } _ { 2 } ^ { + }$ through electrostatic attraction or weak coordination.These interactions help disperse $\mathrm { V O } _ { 2 } ^ { + }$ more uniformly in the solution,lowering local supersaturation and reducing the chance of $\mathrm { V } _ { 2 } \mathrm { O } _ { 5 }$ nucleation. In addition, the hydrolyzed Ti species may adsorb on the surface of early $\mathrm { V } _ { 2 } \mathrm { O } _ { 5 }$ nuclei, blocking active growth sites and slowing the formation of solid $\mathrm { V } _ { 2 } \mathrm { O } _ { 5 }$ .Such a nucleation-inhibition effect has been widely observed in metal-ion-modified precipitation systems [51].

To further understand the effect of $\mathrm { T i } ^ { 4 + }$ on the stability of the VRFB electrolyte,Fig.S1 shows the microstructural characteristics of the graphite felts electrodes before and after 50 times multiplicity chargedischarge test for the pristine electrolyte and the electrolyte containing $\mathrm { T i } ^ { 4 + }$ . As can be seen from Figs.Sla and Slc,after the addition of $\mathrm { T i } ^ { 4 + }$ to the electrolyte,a uniform distribution of substances appears on the surface of the cathode graphite felts.EDS elemental analysis (Fig.Sle-Slh) showed that the composition of the electrode surface changed,and titanium and vanadium were found on the surface of the positive graphite felts of the electrolyte containing $\mathrm { T i } ^ { 4 + }$ . The comparative analysis of Figs.S1b and S1d shows that there are a large number of solid deposits on the surface of the graphite felts at the negative electrode of the pristine electrolyte.However,the surface deposits of the negative electrode graphite felts of the electrolyte containing $\mathrm { T i } ^ { 4 + }$ were significantly reduced.EDS analysis shows that solid sediments are mainly composed of elements O and $\mathrm { v }$ ，which are confirmed to be vanadium oxides.Therefore, the introduction of $\mathrm { T i } ^ { 4 + }$ effectively inhibits the precipitation of vanadium oxides at high temperature.

# 3.2.Effect of $T i ^ { 4 + }$ on the electrochemical performance of VRFB cathode electrolyte

# 4．Conclusion

In this paper,the effects of different contents of $\mathrm { T i } ^ { 4 + }$ on the physicochemical and electrochemical properties of VRFB electrolyte were investigated. The effects of $\mathrm { T i } ^ { 4 + }$ as an inorganic additive on the elec-trochemical performance of $\scriptstyle \mathrm { V O } ^ { 2 + }$ electrolyte containing $\mathrm { F e } ^ { 3 + }$ ， $\mathrm { C r ^ { 3 + } }$ ,and $\mathrm { F e } ^ { 3 + } / \mathrm { C r } ^ { 3 + }$ were also investigated. The experimental results show that $0 . 0 2 \mathrm { \ m o l \ L ^ { - 1 } \ T i ^ { 4 + } }$ can increase the conductivity of the electrolyte to $4 7 6 . 1 9 \ m S \ \mathrm { c m ^ { - 1 } }$ ,and enhance the reactivity and reversibility of the $\mathrm { V O } ^ { 2 + } / \mathrm { V O } _ { 2 } ^ { + }$ pair, the $\mathbf { j } _ { \mathrm { { p a } } } / \mathbf { j } _ { \mathrm { { p c } } }$ is increased by $9 . 6 6 \%$ and $1 1 . 5 1 \%$ respectively,and the diffusion coefficients of $\scriptstyle \mathrm { V O } ^ { 2 + }$ and $\mathrm { V O } _ { 2 } ^ { + }$ reach the peak values of $1 . 7 2 \times 1 0 ^ { - 6 } \mathrm { c m } ^ { 2 } s ^ { - 1 }$ and $0 . 5 7 \times 1 0 ^ { - 6 } \mathrm { c m } ^ { 2 } s ^ { - 1 }$ ,respectively, and the diffusion coefficient increases by $1 8 . 5 2 \% - 2 5 . 4 2 \%$ The $\operatorname { R } _ { \operatorname { c t } }$ was reduced to $4 . 2 9 8 ~ \Omega ~ \mathrm { c m } ^ { - 2 }$ $\mathrm { T i } ^ { 4 + }$ had litle effect on the electrochemical performance of $\mathrm { V } ^ { 3 + } / \mathrm { V } ^ { 2 + }$ redox. In the mixed impurity electrolyte, the addition of $\mathrm { T i } ^ { 4 + }$ can effectively ofset part of the negative effects of $\mathrm { F e } ^ { 3 + } /$ $\mathrm { C r ^ { 3 + } }$ impurity ions on the $\scriptstyle \mathrm { V O } ^ { 2 + }$ electrolyte,so that the inhibited peak current can be restored by $6 { \cdot } 1 6 \%$ ,the diffusion coefficient of $\scriptstyle \mathrm { V O } ^ { 2 + }$ and $\mathrm { V O } _ { 2 } ^ { + }$ can be increased by $5 . 5 6 \% - 1 2 . 5 0 \%$ ,and the $\mathrm { R _ { c t } }$ can be reduced to $0 . 6 0 9 4 ~ \Omega ~ \mathrm { c m } ^ { - 2 }$ ，VRFB containing $\mathrm { F e ^ { 3 + } }$ ， $\mathrm { C r ^ { 3 + } }$ and $\mathrm { T i } ^ { 4 + }$ electrolyte exhibited higher discharge capacity,energy efficiency and cycle stability than those containing only $\mathrm { F e } ^ { \mathbf { \bar { 3 } } + }$ and $\mathrm { C r ^ { 3 + } }$ electrolyte.The mechanism of the effect may be the hydrolysis of $\mathrm { T i } ^ { 4 + }$ in acidic electrolyte to generate hydroxylated particles,which enhances the adsorption capacity of $\mathrm { V O } _ { 2 } ^ { + }$ and promotes the charge transfer of $\mathrm { V O } ^ { 2 + } / \mathrm { V O } _ { 2 } ^ { + }$ redox reaction. At the same time, $\mathrm { T i } ^ { 4 + }$ and $\mathrm { V O } _ { 2 } ^ { + }$ can form a stable complex, preventing $\mathrm { V O } _ { 2 } ^ { + }$ from generating precipitation,enhancing the electrode activity and reducing the diffusion resistance.This multiple-action mechanism enables the batteries assembled with $\mathrm { T i } ^ { 4 + }$ containing electrolyte to exhibit better charge-discharge performance and higher energy efficiency, providing a new idea for the development of low-cost and highperformance VRFB electrolyte.
