# ABSTRACT

Keywords: Energy storage Organic flow batteries Viologen-based anolyte Configuration control π-π Interaction

The aqueous organic redox flow batteries (AORFBs)are recognized as the most promising large-scale storage technology for long-duration energy storage (LDES).Although viologen derivatives are widelyused as anolyte materials for AORFBs,their practical application is strongly limited by weak conjugation and unstable radicals. Here,we present a novel thienoviologen derivative, $\begin{array} { r } { [ ( \mathbf { N P r } ) _ { 2 } \mathbf { S V } ] \mathbf { C l } _ { 4 } , } \end{array}$ achieved utilizing a meta-substitution approach based on the pristine viologen derivatives ( $\mathbf { \nabla } [ ( \mathbf { N P r } ) _ { 2 } \mathbf { V } ] \mathbf { C l } _ { 4 } )$ .Compared to other ortho-and para-substitution methods,this strategy features a locked plane configuration $( 0 . 1 4 ^ { \circ } )$ ,effectively regulating $\pi { - } \pi$ interactions and suppressing reactivity between radical and oxygen,which is confirmed via $\mathbf { X }$ -raysingle-crystal structural analyses,spectroscopy techniques,molecular dynamics simulation accompanied by linear ion trap mass spectrometry experiments.Additionally,the meta-substituted $\scriptstyle { \mathrm { [ ( N P r ) _ { 2 } } } S \mathbf { V } ] \mathbf { C } 1 _ { 4 }$ significantly improves water solubility $( 2 . 3 9 ~ \mathrm { ~ M ~ } )$ ，enhances aromaticity，and extends radical lifetime compared with para-substituted $\mathsf { I } ( \mathbf { N P r } ) _ { 2 } \mathbf { T V } \mathbf { l } \mathbf { C l } _ { 4 }$ Consequently,the cycling stability of the $\scriptstyle { [ ( \mathbf { N P r } ) _ { 2 } \mathbf { S V } ] \mathbf { C l } _ { 4 } }$ -based AORFB over 2500 cycles is 4.1 times higher than that of $\mathrm { [ ( N P r ) _ { 2 } T V ] } \mathrm { C l } _ { 4 }$ .Furthermore,the $\mathbf { 0 . 5 \ M }$ battery delivers an impressive $9 9 . 8 3 ~ \%$ capacity retention during 2Oo cycles and a power density of $1 4 7 \mathrm { \ m W \ c m ^ { - 2 } }$

# 1． Introduction

The global environmental degradation caused by excessive carbon emissions has aroused the thinking of all mankind[1].Action to reduce carbon emissions is therefore essential.The future of energy is predicted to be dominated by clean energy sources like solar and wind [2]. However,managing their randomness,intermittency,and volatility has become a pressing global concern [3].Neutral AORFBs have emerged as the best option for LDES technology，owing to the advantages of large-scale capabilities of up to MW/MWh,high safety,long life, affordability,environmentally friendly,and sustainable characteristics [4,5].

The redox-active materials are regarded as the core components of AORFBs,and their molecular design has generated significant attention from researchers worldwide [6-8].Recently,various organic compounds with excellent performance have been widely employed in developing electrolyte materials for AORFBs [9-11].For instance,the anolyte materials include viologen [12-15], ketones [16,17],quinone [18-20],diimide [21,22],and phenazine [23,24].Particularly, viologen derivatives have emerged as a promising research focus due to their easy structural regulation, rich redox properties,and other advantages [25]. Froma molecular engineering perspective,there are various substitution schemes available for viologen derivatives.Firstly,hydrophilic groups are introduced through end $N _ { ☉ }$ -alkylation to boost solubility,such as pristine viologen, $[ ( \mathbf { N P r } ) _ { 2 } \mathbf { V } ] \mathbf { C l } _ { 4 }$ [26]．However,it's difficult to overcome the inherent defects of weak conjugation and unstable radicals.Previous works suggested that ortho-and para-substitution strategies are beneficial to further improve the performance of viologen derivatives.Adding electron-donating groups (methyl) via an ortho-- substituted approach extended the steric hindrance of pyridine,further protecting radicals,for example,a rod-like sulfonated viologen $( ( \mathbf { S P r } ) _ { 2 } \mathbf { V }$ ）[27].The para-substituted method of introducing $\pi$ -conjugated groups between dipyridines was used to delocalize electron cloud density of viologen derivatives,i.e.thiazolo [5,4-d]thiazol[28,29],phenyl [30], five-membered heterocyclic groups (furan,thiophene,selenophene) [31-33]，namely $[ ( \mathbf { N P r } ) _ { 2 } \mathbf { T T z } ] \mathbf { C l } _ { 4 }$ ，[APBPy] $\mathbf { C l } _ { 4 }$ ， $[ ( \mathbf { N P r } ) _ { 2 } \mathbf { E V } ] \mathbf { C l } _ { 4 }$ ， respectively.While the above-mentioned defects have been properly improved by both substitution methods,many new problems have arisen.Incorporating electron-donating groups leads to an elevated molecular weight and a decreased molecular polarity,accompanied by reduced water solubility and bulk energy density [34].Moreover,unregulated rotation between bipyridines may cause deformation or torsion of the molecular structure,ultimately leading to compromised performance.Therefore,it's a great challenge to improve the chemical structural stability of viologen derivatives while ensuring their excellent water solubility.

It is noteworthy that the mechanism of $\pi { - } \pi$ interactions on radicals has been redefined [35-37].Scherman et al.indicated that $\pi$ -dimerization effectively inhibits the reactivity between radicals and dissolved oxygen [38].Therefore,a rational $\pi { - } \pi$ interaction modulation is expected to enhance molecular conformation stability as well as the performance of AORFB.Recently,the meta-substitution strategy has been employed to combine elements from the main group elements S,Se,Te, andBi[39-41]withviologenderivatives $( \mathbf { R } \mathbf { V } ^ { 2 + } )$ ，yielding five-membered heterocyclic viologens $( \mathrm { E V } ^ { 2 + } )$ containing main group elements with a planar rigid skeleton structure [42,43]. This strategy achieves the planar conformational locking of the pyridine ring, significantly increasing the electron cloud density of the molecular skeleton, and further enhancing electron transfer efficiency. Given the importance of solubility and cost, targeting sulfur atoms with low molecular weight and abundant in nature seems to be the best option.According to Pauling's scale,the $p$ -blockSatom $( \chi = 2 . 5 9 )$ displayed strongerelectronegativity and electron-withdrawing properties compared to the C atom $( \chi = 2 . 5 6 )$ [44].Therefore,sulfur-bridged compounds,with high electron mobility,superior conductivity,and electrochemical properties,were frequently used in polysulfides $( \mathrm { L i } _ { 2 }  { \mathbf { S } } _ { \mathrm { n } } )$ [45] and lithium-sulfur batteries [46] and significantly enhanced battery performance.It can be envisioned that introducing the S atom into the viologen's framework by meta-substitution strategy will lock planar configuration and form $\pi { - } \pi$ stacking,further disturbing the electron cloud distribution.

Based on the consideration，a meta-substituted thienoviologen, $\scriptstyle { \mathrm { [ ( N P r ) _ { 2 } s V ] } } \mathbf { C } \mathbf { l } _ { 4 }$ ，with highly polar and water-soluble,was successfully prepared building upon chalcogenoviologens [47].Through meta-substitution strategy,the planar configuration of viologens is successfully locked accompanied by decreased dihedral angle and increased aromaticity,allowing for efficient regulation of intermolecular $\pi { - } \pi$ interactions.This characteristic was further validated through X-ray single-crystal structural analyses (SC-XRD),molecular dynamics (MD) simulations,and linear ion trap mass spectrometry (LTQ-XL） tests. Theoretical simulations and UV/Vis spectroscopy techniques revealed the mechanism of action of $\pi { - } \pi$ interactions on molecular conformation and radical stability.Paired with well-known catholyte material ferrocene,the assembled meta-substituted $\mathrm { [ ( N P r ) _ { 2 } } S \mathbf { V } ] \mathbf { C } \mathbf { l } _ { 4 }$ -based AORFB demonstratessuperior battery performance compared to para-- substituted $\mathrm { [ ( N P r ) _ { 2 } T V ] } \mathbf { C l } _ { 4 }$ ，manifesting a 4.1 times improvement in capacity retention.The regulation of $\pi { - } \pi$ interactions by meta-substitution effectively alleviates the inherent defects of traditional viologens,such as poor conjugation and unstable radicals,advancing the development of high-performance neutral AORFBs.

# 3.4.Molecular dynamics (MD) simulations

The intermolecular conjugation relationships of meta-substituted thienoviologen in oxidized and radical states were investigated through MD simulations.The snapshot comparisons before and after 100 ns revealed significant aggregation among the molecules (Fig. 2d).Root mean square deviation (RMSD) was utilized to quantify structural differences over the simulation time (Fig.2e).It was observed that the RMSD values of the entire system gradually increased,and then stabilized around 25 ns for $\mathrm { [ ( N P r ) _ { 2 } } S \mathbf { V } ] \mathbf { C } \mathbf { l } _ { 4 }$ and 3 ns for $[ ( \mathbf { N P r } ) _ { 2 } \mathbf { S V } ] \mathbf { C l _ { 3 } }$ dynamically,indicating that the molecules have aggregated to form stable clusters. Owing to the robust positive charge of quaternary ammonium salt, electrostatic interactions are unfavorable for molecular binding,whereas van der Waals interactions between molecules counteract this efect.The results in Fig.2f indicate that van der Waals interactions primarily facilitate the aggregation and binding of molecules. The difference in RMSD values and energy suggests that $[ ( \mathbf { N P r } ) _ { 2 } \mathbf { S V } ] \mathbf { C l _ { 3 } }$ possesses stronger intermolecular interaction forces than $\left[ ( \mathbf { N P r } ) _ { 2 } \mathbf { S V } \right]$ $\mathbf { C l } _ { 4 }$ .Furthermore,statistical analyses were conducted to examine the intermolecular conjugation during the aggregation process of molecules. The stacking number increased rapidly during the initial stage and then stabilized around $5 \sim 1 0$ ns.The average stacking number of both are $3 4 . 4 3 \pm 3 . 8 0$ and $2 9 . 9 8 \pm 1 . 2 8$ ,respectively (Fig.2g).The abundance of conjugation results suggests that $\scriptstyle [ ( \mathbf { N P r } ) _ { 2 } \mathbf { S V } ] \mathbf { C l } _ { 4 }$ and $[ ( \mathbf { N P r } ) _ { 2 } \mathbf { S V } ] \mathbf { C l _ { 3 } }$ rapidly aggregate and form stable cluster structures through $\pi { - } \pi$ interactions at an average distance of $3 . 7 \sim 3 . 9 \mathring \mathrm { \textrm { A } }$

The SC-XRD of $\mathrm { [ ( N P r ) _ { 2 } } S \mathbf { V } ] \mathbf { C } \mathbf { l } _ { 4 }$ was obtained with a solvent diffusion method and yielded deep insights into its structural characteristics. # 4.Conclusion

In summary,this work successfully designed and synthesized a novel meta-substituted thienoviologen, $\scriptstyle [ ( \mathbf { N P r } ) _ { 2 } \mathbf { S V } ] \mathbf { C l } _ { 4 }$ .Compared to other ortho-and para-conjugated viologens,meta-thienoviologen significantly improves water solubility,reaching $2 . 3 9 \mathrm { ~ M ~ }$ (theoretical capacity of $1 2 8 . 1 0 \mathrm { \ A h \ L ^ { - 1 } }$ .The DFT results indicate that $\scriptstyle [ ( \mathbf { N P r } ) _ { 2 } \mathbf { S V } ] \mathbf { C l } _ { 4 }$ exhibits a locked plane configuration,with the dihedral angle of the pyridine rings reduced to $0 . 1 4 ^ { \circ }$ ，while enhancing the aromaticity. The planar configuration implies strong intermolecular $\pi { - } \pi$ interactions,as corroborated by MD simulations,and LTQ-XL measurements,which promotes molecular structure stability.The UV/Vis spectra confirm that the $\left[ \left( \mathbf { N P r } \right) _ { 2 } \mathbf { S V } \right] ^ { 3 + \bullet }$ extendsexhibitshigherair-tolerantthan $\mathrm { [ ( N P r ) _ { 2 } T V ] } ^ { 3 + \bullet }$ ,regardless of whether in air or argon atmosphere. The constructed battery exhibits extraordinary stability,with a capacity retention rate over 25oO cycles that is 4.1 times higher than that of para-$\mathsf { I } ( \mathbf { N P r } ) _ { 2 } \mathbf { T V } ] \mathbf { C l } _ { 4 }$ ,a daily decay rate of only $0 . 0 7 \%$ ,and a power density of $1 4 7  { \mathrm { \ m W } }  { \mathrm { \ c m } } ^ { - 2 }$ at $0 . 5 \mathrm { ~ M ~ }$ ，This work employs a meta-substitution strategy to regulate $\pi { - } \pi$ interactions for the first time,not only providing insights into the development of high-performance viologen-based electrolyte materials but also laying a solid foundation for further exploration of large-scale AORFB technologies.
