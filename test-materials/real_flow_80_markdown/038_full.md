A high-performance ion-exchange membrane (IEM) for an iron-chromium redox flow battery (ICRFB) was fabricated by zirconium dioxide $\left( \mathrm { Z r O _ { 2 } } \right)$ with sulfonated poly (ether ketone) (SPEEK, with a degree of sulfonation: $5 7 \ \%$ .A series of physical and chemical tests such as water uptake (WU),swelling ratio (SR),ion exchange capacity (IEC),proton conductivity,strength characteristics and permeability were performed.Additionaly,it was notable that the $\mathrm { Z r O _ { 2 } }$ -SPEEK $\mathrm { { ( Z r / S _ { \it } ) } }$ IEM with the optimal reference ratio $( 7 . 5 \% )$ showed higher coulombic efficiency $\left( { \mathrm { C E } } { : 9 7 } . 7 4 \ { \% } \right)$ and energy efficiency $( \mathrm { E E } { : } 8 2 . 8 5 ~ \% )$ at $1 0 0 \mathrm { \ m A } { \cdot } \mathrm { c m } ^ { - 2 }$ than Nafion-212 IEM( $\mathrm { C E } { : } 9 6 . 7 \ \%$ ， $\operatorname { E E } { : 8 2 . 5 5 \% }$ and SPEEK-57IEM $( \mathrm { C E } { : } 9 6 . 8 6 \%$ ， $\mathrm { E E } { : } 7 6 . 8 4 \ \%$ in the ICRFB single-cell test.In the first cycle,the $\mathrm { Z r / }$ $S { \mathrm { - } } 7 . 5 ~ \%$ IEMdelivereda higher discharge capacity $( 7 0 8 \mathrm { m A h }$ than the Nafion-212IEM $\mathtt { 7 0 8 } \mathtt { m A h } $ and SPEEK-57 IEM $3 7 3 \mathrm { m A h }$ ).Moreover, the composite membrane could maintain $_ { 1 . 2 \mathrm { ~ V ~ } }$ open-circuit voltage for $^ { 5 6 . 5 \mathrm { h } }$ in the self-discharge experiment, surpassing Nafion-212 IEM (4.617 h) and SPEEK-57 IEM (14.783 h).

# 1． Introduction

The serious trend of global warming was compelling a shift from fossil fuel reliance to renewable energy sources,such as solar and wind [1].The discontinuity in the supply of renewable energy sources required us to enhance energy storage technologies to ensure their effective integration into the power system [2].Within the spectrum of contemporary energy storage technologies,vanadium redox flow batteries(VRBs) exhibited prohibitive costs [3] and lithium-ion batteries were subject to safety apprehensions,which collectively impeded their suitability for extensive energy storage deployment [4]. Iron-chromium redox flow battery (ICRFB) emerged as the forefront of energy storage technology，which was attributed to their safety,economical cost, environmental benignity,extended cycle life and temperature adaptability.The redox reactions equations of ICRFB were as follows [5].

$$
\begin{array} { r l } & { C \mathrm { r } ^ { 3 + } + \mathrm { e } ^ { - } + F \mathrm { e } ^ { 2 + }  \xrightarrow [ \mathrm { d i s c h a r g e } ] { \mathrm { c h a r g e } } + C \mathrm { r } ^ { 2 + } + F \mathrm { e } ^ { 2 + } } \\ & { F \mathrm { e } ^ { 2 + } + C \mathrm { r } ^ { 3 + }  \xrightarrow [ \mathrm { d i s c h a r g e } ] { \mathrm { c h a r g e } }  F \mathrm { e } ^ { 3 + } + C \mathrm { r } ^ { 3 + } + \mathrm { e } ^ { - } } \end{array}
$$

To solve these problems,many solutions have been proposed. For instance,SE Waters et.al utilized diethylenetriaminepentaacetic acid (DTPA) to form a chelated-Fe electrolyte,enhancing flow battery performance at $\mathtt { p H } { = } 9$ [9].Wang et al.added indium ions to the electrolyte to suppress the competing hydrogen evolution reaction [1O]. Zhang et.al developed a multifunctional carbon cloth electrode with abundant vacancies that significantly improved battery performance [11].Although previous studies had greatly optimized the electrode and electrolyte components in the ICRFB system,there was little research on the modification of IEMs suitable for ICRFB.IEMs were crucial for the operation of ICRFB and greatly influenced the cel's efficiency and service life.

At present, the IEMs used in ICRFB are mainly based on Nafion-212 IEM produced by DuPont.However,Nafion IEM's high solubilitylowcapacity retention rate and high cost limited the commercial viability of ICRFB [12].SPEEK IEM was considered as an alternative to Nafion

Many researchers have made considerable efforts to modify SPEEK IEM.Vidhyeswari.D et al.utilized carbon nanotubes to enhance water behaviors of membrane [14].Peng Wei et al. used porous titanium dioxide nanotubes to optimize membrane structure and electrochemical properties [15].Although there have been related modification studies, these experiments still had some limitations such as high swelling rate, fast efficiency decay,high permeability,etc. Therefore,there was an urgent need to develop alternatives to SPEEK IEM for ICRFB applications to effectively address the swelling and permeability issues while maintaining high cell performance.

$\mathrm { Z r O _ { 2 } }$ was widely used in electrical device materials due to its corrosion resistance,excellent temperature conductivity and chemical stability.K.Rambabu et al. modified poly sulfone anion exchange membranes with zirconium dioxide and applied them to fuel cells to enhance the maximum power density of the cells [l6].Yunfei Yang et al. doped zirconium dioxide into poly (2,6-dimethyl-1,4-phenylene oxide) to improve the electrochemical performance of the membrane [17]. Leticia G.da Trindade et.al found that added $7 ~ \mathrm { w t } \%$ of Zr-BDC-MOF to SPEEK resulted in 2.5-fold higher proton conductivity than pristine SPEEK IEM[18].Fatemeh Gashoul prepared zirconium dioxide/SPEEK IEM by solution casting and concluded that the modified membranes had better oxidative and hydrolytic stability [19].

These IEM were not applied to practical battery applications in the previous study,and they were not well tested in terms of physicochemical properties.Meanwhile, the different degrees of sulfonation of SPEEK fibers,the preparation methods of membranes and the thickness of membranes greatly affected the physicochemical and electrochemical properties of composite membranes.

Hereby,we utilized SPEEK fibers with optimal degree of sulfonation $( 5 7 ~ \% )$ [20] as matrix and doped into $\mathrm { z r O } _ { 2 }$ ，then hybrid IEMs with various reference ratios (Zr/S-2.5,Zr/S-5,Zr/S-7.5,Zr/S-10) for ICRFB were prepared.The hydrophilicity of the composite IEM was greatly elevated by the formation of intermolecular hydrogen bonds with water through the hydroxyl groups on the surface of zirconium dioxide [21], which would improve the hydrophilicity of IEM. Zirconium dioxide acted as a selective barrier for iron and chromium ions through the curved pathway effect by partially blocking the polar structure on the SPEEK IEM through electrostatic interactions [22] which would reduce the permeability of the membrane and suppress the swelling and deformation problems of IEMin electrolyte.To investigate the optimal reference ratio of zirconium dioxide nanoparticles,the physicochemical properties of IEC,proton conductivity,water behavior,and mechanical properties were determined.In addition，we performed ICRFB single-cell comparative assays of pristine SPEEK-57 IEM and best performing Nafion-212 IEM [23] with ${ \mathrm { Z r } } / { \mathrm { S } } { - } 7 . 5$ .Our study suggested that ${ \bf z r / s }$ IEM showed great potential for the commercial application of ICRFB.

# 2.5.Water behaviors and IEC

Prior to testing,the samples underwent vacuum drying at $9 0 ^ { \circ } \mathrm { C }$ for a duration of $^ { 1 2 \mathrm { h } }$ .Following this,the initial mass and length of the IEMs were recorded.Subsequently,the IEMs were placed in water at $6 5 ^ { \circ } \mathrm { C }$ for a duration of $^ { 1 2 \mathrm { ~ h ~ } }$ 、Afterward, they were rapidly weighed,and their lengths were measured again. To ensure accuracy, the entire process was conducted three times,and the mean values were determined.The water uptake (WU) and swelling ratio (SR) of the membranes were ascertained through Eqs. (3) and (4),respectively.

$$
W U ( \% ) = \frac { W _ { w e t } - W _ { d r y } } { W _ { d r y } } \times 1 0 0 \%
$$

$$
S R ( ^ { 0 } / 0 ) = \frac { L _ { w e t } - L _ { d r y } } { L _ { d r y } } \times 1 0 0 \%
$$

where $L _ { w e t }$ and $L _ { d r y }$ denoted the lengths of the membranes in their wet and dry states,respectively. $W _ { w e t }$ and $W _ { d r y }$ were the masses of wet and dried membranes.

The membrane was chopped into small pieces and immersed in ${ 2 5 } \mathrm { m l }$ of saturated NaCl,mechanically stiring for $^ { 1 2 \mathrm { ~ h ~ } }$ .Afterwards, $2 5 ~ \mathrm { m l }$ of fresh saturated NaCl was added and stirred for $^ { \textrm { \scriptsize 1 2 h } }$ 、With phenolphthalein signaling the endpoint, the titration was executed using a 0.01 M sodium hydroxide solution. The ion exchange capacity (IEC) value was determined by applying Eq. (5).

$$
I E C = \frac { V _ { N a O H } \times C _ { N a O H } } { W _ { d r y } }
$$

where $W _ { d r y }$ was the weight of the dry membrane. $V _ { N a O H }$ was the NaOH volume consumed to reach the end point of the titration and $C _ { N a O H }$ was the concentration of NaOH standard solution.

$$
\sigma = \frac { \alpha } { S \times R }

where o was the proton conductivity of the IEM,S represented the crosssectional area of the test membrane, $\alpha$ indicated the distance between the two platinum electrodes,and $R$ signified the resistance of the IEM.

# 2.7. Ionic permeability

A dual-compartment electrolytic cell was employed to simulate realworld battery operating conditions at $6 5 ~ ^ { \circ } \mathrm { C }$ ，The right compartment contained $2 5 \mathrm { m L }$ of test solution(3 MHCl+1M $\mathrm { \Phi . \ A l C l _ { 3 } / M g C l _ { 2 } }$ mixture) to balance osmotic pressure,while the left compartment held $2 5 \mathrm { m L }$ of3 $\mathrm { M \ H C l + 1 \ M \ C r C l _ { 3 } / F e C l _ { 2 } }$ solution. $$
V _ { R } \frac { d _ { c _ { R } } ( t ) } { d t } = A \frac { P } { L } [ c _ { L } - c _ { R } ( t ) ]
$$

where $C _ { R } ( t )$ and $\mathrm { C _ { L } }$ were $\mathrm { F e } ^ { 2 + } / \mathrm { C r } ^ { 3 + }$ concentrations of the right and left solutions. $P$ was the $\mathrm { F e } ^ { 2 + } / \mathrm { C r } ^ { 3 + }$ permeation, $A$ and $L$ were the area and thickness of the IEM, $V _ { R }$ was the volume of the right-side solution.

# 3.5.Mechanical properties

The mechanical property test data for various IEMs are detailed in Table 2 and Fig.4.We observed a gradual increase in both tensile strength and Young's modulus of the IEMs as the reference ratio increased,which indicated the enhancements of mechanical stability, rigidity,and hardness.This improvementwas attributed to the addition of inorganic nanofillers,which effectively ameliorated the surface defects present in SPEEK-57 IEM.Despite these enhancements,there was a noted decrease in the percentage elongation with an increment in the $\mathrm { Z r O _ { 2 } }$ reference ratio.This decrement was believed to stem from the incorporation of inorganic nanoparticles,which constrained the relative motion between molecular chains [33]. # 3.6. Ionic permeability

The concentration variations of $\mathrm { F e ^ { 2 + } }$ and $\mathrm { C r ^ { 3 + } }$ were monitored over a 12-hour period to determine membrane permeability and ion selectivity. As illustrated in Fig.5,the Nafion membrane exhibited the highest permeability,which can be attributed to its relatively limited hydrophilic/hydrophobic phase separation structure.The incorporation of $\mathrm { Z r O _ { 2 } }$ nanoparticles resulted in reduced permeability acrossall composite membranes.This phenomenon stems from the interaction between oxygen-containing functional groups on the $\mathrm { Z r O _ { 2 } }$ fillers and sulfonic acid groups in the SPEEK matrix,which creates tortuous pathways that effectively hinder $\mathrm { F e } ^ { 2 + } / \mathrm { C r } ^ { 3 + }$ transport [22]. Notably，the ${ \bf Z r } / { \bf S } – 7 . 5$ membrane demonstrated the lowest permeability, significantly lower than that of pristine Nafion.However,when the $\mathrm { Z r O _ { 2 } }$ content increased to $1 0 \ \mathrm { w t } \%$ ,a slight increase in permeability was observed, likely due to inferior nanoparticle dispersion within the polymer matrix.

Ion selectivity represents a crucial performance metric for IEMs.As shown in Fig.5,the modified membranes exhibited enhanced ion selectivity.For ICRFB,IEMs with superior ion selectivity contribute to improved single-cell performance,as evidenced by our testing results.

Table 3 presented the electric stack group values of various IEMs,showing an increase in these values with the increasing $\mathrm { Z r O _ { 2 } }$ reference ratio.

# 4. Conclusion

This study assessed the physicochemical properties of $\mathrm { Z r O _ { 2 } }$ -doped SPEEK IEM to identify the optimal doping level,which was established as $7 . 5 \mathrm { w t } \%$ .The ${ \bf Z r } / { \bf S } – 7 . 5$ IEM demonstrated superior stability and wellbalanced mechanical properties,leading to enhanced performance in ICRFB single-cell tests.Furthermore,the ${ \bf Z r } / { \bf S } – 7 . 5$ IEM's reduced permeability to Fe and Cr ions translated into a significantly extended self-discharge time compared to other IEMs.After 1O0 charge/discharge cycles, the ${ \bf Z r } / { \bf S } – 7 . 5$ IEM showed minimal EE attenuation and discharge capacity loss.These findings indicated that the Zr/S-7.5 IEM offered substantial cost and performance benefits over the Nafion-212 IEM and held promise as a replacement.Future research would focus on evaluating the performance of hybrid IEMs in pilot-scale ICRFB and refining their properties to address emerging challenges.
