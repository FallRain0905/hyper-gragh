Solar redox flow batteries (SRFBs) have gained considerable concern in recent years due to their capability to simultaneouslyconvert,store and distribute intermitent sun energy with high eficiency.In this research,we have developed an integrated anthraquinone-based SRFB device that consists of 2,6-DBEAQ and ${ \bf K } _ { 4 } [ \mathrm { F e } ( \mathrm { C N } ) _ { 6 } ]$ redox couples paired with a single triple-junction amorphous silicon photoelectrode.This integrated device can be directly photo-charged without requiring any external bias and stably discharged for ${ > } 1 5$ cycles. It achieves an average solar-to-electricity conversion efficiency of $4 . 2 ~ \%$ ，which is a high efficiency reported to date for SRFBs using anthraquinone-based electrolytes.The successful fabrication of this SRFB device paves the way for the continued advancement of innovative solar-to-chemical energy conversion technologies.

# 1． Introduction

To address the increasing depletion of fossil fuels and the environmental pollution caused by their use,the conversion and storage of solar energy is an inevitable choice for the future development of clean energy [1,2].Among existing solar energy utilization technologies,photovoltaic technology，which directly converts solar energy into electrical energy，has been commercialized,but large-scale electrical energy storage technology still requires further development [3].Photoelectrocatalytic water splitting and carbon dioxide reduction can directly convert solar energy into storable and transportable chemical fuels,but due to their inherently slow reaction kinetics,they have not yet achieved large-scale commercialization [4,5].As a solution that can directly store solar energy as chemical energy and then convert it into electrical energy，solar redox flow batteries (SRFBs） have gained considerable attention in recent years [6-l2].These SRFBs combine semiconductor photoelectric conversion and redox flow battery (RFB) technologies to create an innovative device that integrates solar energy conversion and electrochemical storage functions.SRFBs have opened new avenues for the development of solar energy utilization technology and are expected to be applied in the domain of massive solar energy conversion and storage.

The concept of solar-rechargeable redox batteries was originally proposed in 1976 [13], while the earliest solar-rechargeable redox flow batteries, which utilized flowing electro-active species as energy storage media and are known as SRFBs,were developed in 2013 [14,15]. Since then,there have been significant advances in several aspects of SRFB technology，including photoelectrode materials,redox couples,and ion-selective membranes [16-2O].In terms of redox couples,aqueous organic anthraquinone derivatives have gained recognition as the favored materials for energy storage in SRFBs,owing to their adjustable electrochemical potentials,non-flammability,widespread availability, and cost-effectiveness [21-28].Initially,anthraquinone-based SRFBs used anthraquinone-2,7-disulfonate (AQDS) as the electrolyte in an acidic environment [22-25].These SRFB devices utilized dye-sensitized $\mathrm { T i O } _ { 2 }$ or silicon-based semiconductor materials as photoelectrodes,and the solar-to-output electricity efficiencies (SOEE) remained relatively low,with values of $1 . 7 \%$ [23], $3 . 2 \%$ [24],and $4 . 9 \%$ [25],respectively. To prevent corrosion of the photoelectrodes by the strongly acidic environment,researchers developed anthraquinone-based SRFBs that operate in alkaline conditions.For example,Mendes etal.showed the possibility of alkaline SFRBs using AQDS and ${ \mathrm { K } } _ { 4 } [ { \mathrm { F e } } ( { \mathrm { C N } } ) _ { 6 } ]$ redox couples and a hematite photoanode,achieving a SOEE of $0 . 4 4 ~ \%$ [26,27]. Additionally,Wang et al.utilized another anthraquinone derivative, 2, 6-dihydroxyanthraquinone (2,6-DHAQ),as the electrolyte operating in a strong alkaline environment at $\mathrm { \ p H } { = } 1 4$ ，achievinga SOEE of $3 . 0 ~ \%$ [28].In such a strong alkaline environment, due to the corrosion of the photoelectrode and the instability of ${ \mathrm { K } } _ { 4 } [ \mathrm { F e } ( \mathrm { C N } ) _ { 6 } ]$ ，this SRFB cannot sustain continuous cyclic charging and discharging.Despite these progresses,research on anthraquinone-based SRFBs still faces significant challenges in creating a high-efficient,sustainable,and low-cost SRFB device.

In recent studies on organic anthraquinone derivatives as energy storage media,Aziz et al.demonstrated a long-lifetime aqueous redox flow battery that can operate at a pH as low as 12 [29]. They functionalized 2,6-DHAQ with highly alkali-soluble carboxylate terminal groups,resulting in an electrolyte material, $^ { 4 , 4 ^ { \prime } }$ (9,10-anthraquinone-2,6-diyl)dioxy)dibutyrate (2,6-DBEAQ),which is six times more soluble than 2,6-DHAQ at $\tt p H 1 2$ .By pairing 2,6-DBEAQ with a [Fe $\mathrm { ( C N ) _ { 6 } ] ^ { 4 - } / [ F e ( C N ) _ { 6 } ] ^ { 3 - } }$ electrolyte,this flow battery exhibits reduced a capacity fade rate while maintaining an open-circuit voltage of over $_ { 1 \mathrm { ~ V ~ } }$ This work provides an alternative for the selection of redox pairs in the field of anthraquinone-based SRFBs.

In this study,we have developed an anthraquinone-based SRFB device powered by a single triple-junction amorphous silicon (3jn-a-Si) photocathode.The device utilizes an aqueous electrolyte composed of 2,6-DBEAQ and ${ \mathrm { K } } _ { 4 } [ \mathrm { F e } ( \mathrm { C N } ) _ { 6 } ]$ as its energy storage components,which functions efficiently in an alkaline environment $\left( \mathrm { p H } = 1 2 \right)$ 0.Thisalkaline environment ensures the stability of ${ \mathrm { K } } _ { 4 } [ \mathrm { F e } ( \mathrm { C N } ) _ { 6 } ]$ ，andeffectivelyreduces the corrosion of the photoelectrode.The SRFB device can be photo-charged without an external bias and discharged over15 cycles. The SOEE of the device reached approximately $4 . 2 \%$ ,which is currently a high efficiency reported for SRFBs using anthraquinone-based electrolytes.This demonstrated device system opens up avenues toward the development of low-cost,durable,and easy-to-implement solar-tochemical energy conversion technologies.

# 2.Experimental

# 2.1． Electrochemical measurements of redox couples

The electrochemical performances of the redox couples 2,6-DBEAQ/ 2, $6 { \cdot } \mathrm { D B E A Q } ^ { 2 - }$ and $\mathrm { K } _ { 4 } \mathrm { [ F e ( C N ) _ { 6 } ] / K _ { 3 } [ F e ( C N ) _ { 6 } ] }$ were evaluated through cyclic voltammetry (CV) using a three-electrode cell linked to a CH Instrument 66oE potentiostat. In the experiment,a glassy-carbon electrode with a $3 \ \mathrm { m m }$ diameter was served as the working electrode, whereas a platinum tablet ( $\mathrm { ~  ~ \mathcal ~ { ~ \phi ~ } ~ } _ { 1 } \mathrm { c m } ^ { 2 }$ area)and $\mathrm { A g / A g C l }$ electrode (filled with $3 . 5 ~ \mathrm { m o l } ~ L ^ { - 1 }$ KCl) used as the auxiliary and reference electrodes, respectively.The electrolytes were $1 0 \mathrm { \ m m o l \ } L ^ { - 1 }$ 2,6-DBEAQ and 10 mmol $L ^ { - 1 }$ ${ \mathrm { K } } _ { 4 } [ \mathrm { F e } ( \mathrm { C N } ) _ { 6 } ]$ solutions respectively,with the addition of 10 mmol $L ^ { - 1 } \mathrm { K O H } + 0 . 5 \mathrm { m o l } L ^ { - 1 } \mathrm { K C l }$ as a supporting electrolyte. The pH of the electrolytes was accurately regulated to $\mathrm { \ p H } { = } 1 2$ .Prior to measurements,the electrolytes were purged with Ar for $3 0 \mathrm { { m i n } }$ to eliminate the dissolved oxygen. The potential data recorded were measured against the $\mathbf { A g / A g C l }$ electrode,and were converted to the potentials versus the normal hydrogen electrode (NHE) using the equation: $E ( \mathrm { N H E } ) = E ( \mathrm { A g } /$ $\mathrm { A g C l ) } + 0 . 2 0 5 \ : \mathrm { V }$

The redox flow battery (RFB) was made by using 2,6-DBEAQ and ${ \mathrm { K } } _ { 4 } [ \mathrm { F e } ( \mathrm { C N } ) _ { 6 } ]$ redox couples as anolyte and catholyte in a twocompartment cell separated by a Nafion 117 ion exchange membrane (DuPont). The concentration of 2, 6-DBEAQ and ${ \mathrm { K } } _ { 4 } [ { \mathrm { F e } } ( { \mathrm { C N } } ) _ { 6 } ]$ was 40 mmol $L ^ { - 1 }$ ,with a flow rate of $5 0 \ \mathrm { m L } \ \mathrm { m i n } ^ { - 1 }$ .The cycle performance testing of the RFB was carried out using a LANHE CT3OO1 battery test system.In the measurement,the current density during charging and discharging in the RFB's constant current cycle was maintained at 20 mA $\mathrm { c m } ^ { - 2 }$ ,while the cut-off voltages for charging and discharging were set at $_ { 1 . 6 \mathrm { ~ V ~ } }$ and $0 . 3 \mathrm { V } _ { : }$ ,respectively.

# 2.2.Photoelectrochemical measurements of the photoelectrode

Commercial triple-junction amorphous silicon (3jn-a-Si) photovoltaic cells,purchased from UNIsOLAR,served as the photoelectrode. These cels are equipped with stainless steel as their substrate,offering excellent flexibility.Prior to use,the cells were cut into $2 \ \mathrm { c m } \ \times 2 \ \mathrm { c m }$ pieces by the manufacturer.We used epoxy resin to securely bond the photoelectrode with the fluororubber gasket.A conductive copper foil was used to establish an electrical connection from the back of the photoelectrode to the conductive wire,running along the upper edge of the photoelectrode.After assembly,the samples were rinsed multiple times with anhydrous ethanol and ultra-pure water,and then dried with Ar to prepare them for use.

The photoelectrochemical performance of the 3jn-a-Si photocathode was evaluated using linear sweep voltammetry (LsV). The measurements were conducted in two different setups:a three-electrode configuration in a single-chamber cell for half-cell reactions,and a two-electrode configuration in a two-compartment cell separated by a membrane.In the three-electrode configuration,the 3jn-a-Si photocathode acted as the working electrode, while,a platinum tablet and Ag/ AgCl served as the auxiliary and reference electrodes,respectively.The electrolyte was a $4 0 \mathrm { m m o l } L ^ { - 1 } \bar { 2 }$ ,6-DBEAQ solution, with a supporting electrolyte of 10 $) \mathrm { m m o l } L ^ { - 1 } \mathrm { K O H } + 0 . 5 \mathrm { m o l } L ^ { - 1 } \mathrm { K C l }$ solution. In the twoelectrode configuration,the 3jn-a-Si photocathode was again used as the working electrode in 2,6-DBEAQ solution,and carbon felt used as the auxiliary electrode in ${ \mathrm { K } } _ { 4 } [ \mathrm { F e } ( \mathrm { C N } ) _ { 6 } ]$ solution.A Nafion 117 ion exchange membrane (DuPont) was used as the membrane to separate the anolyte and the catholyte.All LsV measurements were performed at a scanning rate of $1 0 \mathrm { m V } s ^ { - 1 }$ .

# 2.3.Preparation and measurements of the SRFB device

The custom-built SRFB device,as depicted in Fig.S1,consisted of two symmetrical compartments.The front section served as the photocathode chamber,which had a window for light illumination and a groove for positioning the photocathode.The 3jn-a-Si photocathode was fastened and sealed in the gasket using silicone glass glue.A strip conductive copper foil stretched out from the photocathode to provide outer link.The underlying section included the electrolyte distributor and the carbon felt electrode.The electrolyte distributor facilitated the electrolyte to flow in and out,enabling it to circulate viaa peristaltic pump.The carbon felt served as an inert electrode,making contact with the titanium current collector to conduct current.In the center domain of the SRFB device,the anode and the cathode electrolytes were separated by a Nafion 117 ion exchange membrane.Fluororubber gaskets were used as a sealing and insulating barrier between each of the two sections.The integrated device was assembled using four bolts to tightly fix the components together.The electrolyte preparation and the device assembly in the aforementioned steps were conducted within a glove bag filled with Ar.

The performance of the SRFB device was assessed by cyclic test.The catholyte and anolyte were $4 0 \ \mathrm { m m o l } \ L ^ { - 1 }$ 2,6-DBEAQ in $1 0 { \mathrm { ~ m m o l ~ } } L ^ { - 1 }$ $\mathrm { K O H } + 0 . 5 \mathrm { m o l } L ^ { - 1 }$ KCl solution and 40 mmol $L ^ { - 1 }$ ${ \mathrm { K } } _ { 4 } [ \mathrm { F e } ( \mathrm { C N } ) _ { 6 } ]$ in 10 mmol $\mathsf { z } ^ { - 1 } \ \mathrm { K O H } \ + \ 0 . 5 \ \mathrm { i }$ mol $L ^ { - 1 }$ KCl solution,respectively.Both the catholyte and anolyte were maintained ata flow rate of $5 0 \mathrm { m L } \mathrm { m i n } ^ { - 1 }$ .A Nafion 117 ion exchange membrane served as the separator.Prior to the measurements,the electrolytes were purged with Ar for $3 0 \ \mathrm { m i n }$ to eliminate the dissolved oxygen.In the design of the electrolytic cell, it is crucial to position the carbon felt and the photoelectrode as close as possible during photo-charging.This arrangement aims to minimize the mass transfer limitations of 2,6-DBEAQ and reduce the intrinsic resistance of the battery.During photo-charging,the 3jn-a-Si photocathode was irradiated by a xenon lamp simulating 1 sun ( $( 1 0 0 \mathrm { \ m W \ c m } ^ { - 2 } )$ intensity,and no external bias was applied.During discharging,functioning as a conventional RFB,the device was discharged at a current density of $1 0 \mathrm { \ m A \ c m ^ { - 2 } }$ until the battery voltage dropped to $0 . 2 \mathrm { ~ V ~ }$

# 3．Results and discussion

As depicted in Fig.1,we have successfully integrated the 3jn-a-Si photocathode with 2,6-DBEAQ and ${ \mathrm { K } } _ { 4 } [ { \mathrm { F e } } ( { \mathrm { C N } } ) _ { 6 } ]$ redox couples to develop an efficient SRFB device. This device comprises of a photoelectrochemical cell that converts solar energy into chemical energy,coupled with an RFB that transforms the stored chemical energy into electricity.At the interface where the photoelectrode comes into contact with the redox substance,a semiconductor- solution junction is formed.Upon illumination,the semiconductor absorbs photons and generates electron-hole pairs.The photogenerated electrons can facilitate the reduction of the 2,6-DBEAQ in the catholyte,while the corresponding holes migrate via the external circuit to the carbon felt auxiliary electrode,where they promote the oxidation of ${ \mathrm { K } } _ { 4 } [ { \mathrm { F e } } ( { \mathrm { C N } } ) _ { 6 } ]$ in the anolyte. Using a pump,the electrolytes are continuously circulated between the integrated device and external storage tanks,enabling photo-charging of the SRFB device.During the discharge process, similar to conventional RFBs,the positive and negative electrodes are linked to an external load,enabling the stored chemical energy to be released through the reverse reaction of the redox couples.The battery's charge balance is sustained during charge and discharge cycles by ion exchange through a membrane that separates the catholyte and anolyte compartments.Thus,the system's complete operational cycle effectively achieves the conversion of solar energy to chemical energy and subsequently to electrical energy.

# 3.2.Photoelectrochemical performance of the 3jn-a-Si photocathode

A 3jn-a-Si photovoltaic cell is selected as the photocathode,and its basic structure is illustrated in Fig.3a.The cell is composed of stacked amorphous silicon and amorphous silicon-germanium alloy junctions, which are deposited on a stainless-steel substrate and topped with a coating of indium tin oxide (ITO).It offers several advantages, including superior optical absorption,high photovoltage,high photoelectric conversion efficiency and robust corrosion resistance when exposed to alkaline electrolytes.The measured open-circuit voltage of the cell can reach up to $1 . 8 5 \mathrm { ~ V ~ }$ (Fig.S3),a value significantly higher than the maximum voltage of the aqueous RFB utilizing the 2,6-DBEAQ and ${ \mathrm { K } } _ { 4 } [ \mathrm { F e } ( \mathrm { C N } ) _ { 6 } ]$ redox couples.To minimize the impact of the electrolyte on light absorption by the photocathode,a design was implemented where only the stainless-steel side of the 3jn-a-Si solar cell is exposed to and makes contact with the electrolyte,while the ITO-coated side is subjected to illumination (Fig. 3b).

The photoelectrochemical behavior of the 3jn-a-Si photocathode was assessed using a three-electrode configuration,where a half-cell reaction was conducted (Fig.3c).From the LSV curves of the 3jn-a-Si photocathode,it can be observed that the photocurrent gradually increases as the applied potential is varied from 1.0 to $- 0 . 5 \mathrm { V }$ vs.NHE.Within this potential range,there are negligible current responses in the absence of light. # 3.3.Property of anthraquinone solar redox flow battery

The performance of the integrated SRFB device during the photocharge/discharge cycles was tested using the architecture shown in Fig. S1.The curves for photocurrent during unbiased photo-charge, photo-charge voltage,discharge voltage and SOEE are presented in Fig.4.The device successfully underwent 1O continuous cycles,maintaining effective performance throughout its operation (Fig.4a).The photovoltage generated by the photoelectrode significantly exceeded the open circuit voltage of the RFB itself, ensuring that the photocurrent during photo-charging remained stable.As the photo-charging reaction progresses,the charge of the SRFB device gradually approaches saturation.Simultaneously,the open-circuit voltage increases rapidly until it reaches the cutoff voltage of $1 . 2 \mathrm { V _ { \it \cdot } }$ ,at which point the photo-charging process is considered complete (Fig.4b).During the discharging process at a current density of $1 0 \ \mathrm { m A } \ \mathrm { c m } ^ { - 2 }$ ,the reverse chemical reaction occurred,enabling the release of the stored chemical energy (Fig.4c).

The enduring charge-discharge performance further demonstrates the successful preparation of an integrated SRFB device capable of directly transforming solar energy into chemical energy without the need for any external electrical bias.

To further assess the efficiency of the integrated device,the SOEE for each cycle is quantitatively determined.The SOEE is defined as the ratio of the output electrical energy to the input sun energy using the following formula:

$$
S O E E = \frac { \int V _ { o u t } d t _ { 2 } \times I _ { o u t } } { P _ { i n } \times S \times t _ { 1 } } \times 1 0 0 \%
$$

where $V _ { \mathrm { o u t } }$ is the output voltage, $\boldsymbol { I _ { \mathrm { o u t } } }$ is the output current, $P _ { \mathrm { i n } }$ is the input power from the light source, $s$ is the photoelectrode area,and $t _ { 1 }$ and $t _ { 2 }$ are times for the photo-charging and discharge,respectively.The average SOEE of the integrated device over 15 cycles is found to be approximately $4 . 2 ~ \%$ (Fig.4d),which is a high recorded value for an SRFB utilizing anthraquinone electrolyte to date (Table S1) [22-28]. This exceptional cycling performance is largely attributed to the swift redox reactions occurring at the interface between the photoelectrode and the electrolyte.The charge-discharge capacity exhibited a noticeable decline over the cycles.One possible reason for this decline could be the cross-contamination resulting from activated species from the electrolyte on one side permeating through the ion-selective membrane into the opposing side.Another reason might be the presence of residual dissolved oxygen within the electrolyte.It is anticipated that enhancements in performance can be achieved by employing an ion exchange membrane with reduced cross-contamination propensity or by conducting operations within an oxygen-depleted environment.

# 4.Conclusions

In conclusion,we have designed and demonstrated an integrated solar energy conversion and storage device that utilizes 2, 6-DBEAQ and ${ \mathrm { K } } _ { 4 } [ \mathrm { F e } ( \mathrm { C N } ) _ { 6 } ]$ redox couples and a single 3jn-a-Si photocathode.This energy storage system composed of 2,6-DBEAQ and ${ \mathrm { K } } _ { 4 } [ \mathrm { F e } ( \mathrm { C N } ) _ { 6 } ]$ redox couples can function effectively in a $\mathrm { \ p H } { = } 1 2$ environment and delivers high round-trip energy efficiency. The sufficient photogenerated voltage of the 3jn-a-Si photocathode enables the photo-charging of the device without requiring an external electrical bias.This device achieves the direct conversion of input solar energy to output electrical energy with an efficiency of $4 . 2 \%$ ,which is a high recorded value for an SRFB utilizing anthraquinone-based electrolytes to date.The successful fabrication of this quinone SRFB device opens up new possibilities for the further development of advanced solar-to-chemical energy conversion technologies.
