Vanadium-based redox flow batteries,characterized by no cross-contamination isue,are considered as one of the most promising candidates for large-scale energy storage.However,due to vanadium ions show relatively low solubilityandare easy to precipitate atextreme temperatures,the battery sufers from the long challnge of low energy density and poor temperature adaptability.In this work,by introducing vanadium and bromine dual activespecies into the positive electrolyte,a novel V/V-Brredox flow battery(VBrRFB)is developed toboost the energy density and temperature window of vanadium-based flow bateries.The bromine,not only acts as the secondary redox couple to enhance the overall concentration of active species,but also disrupts the hydrogen bond network while optimizing the solvation structure of vanadium. As a result, the VBrRFB achieves an energy density of as high as 152.4 Wh $\mathrm { L } _ { \mathrm { c a t h o l y t e } } ^ { - 1 }$ (38.1 Wh $\mathrm { L _ { c a t h o l y t e + a n o l y t e } ^ { - 1 } ) }$ ,which is $2 6 5 . 9 ~ \%$ higher than traditional allvanadium redox flow batteries,while maintaining stable cycling over 250 cycles with an energy efciency of $8 2 . 5 \%$ Additionally, the VBrRFB exhibited excellentstabilityand performancefrom ${ \bf \nabla } \cdot 1 0 ^ { \circ } \mathrm { C }$ to ${ 5 0 } ^ { \circ } \mathrm { C } ,$ with energy densities of 107.6 Wh $\mathbf { L } _ { \mathrm { c a t h o l y t e } } ^ { - 1 }$ at $5 0 ~ ^ { \circ } \mathrm { C }$ and 88.8 Wh $\mathrm { L } _ { \mathrm { c a t h o l y t e } } ^ { - 1 }$ at ${ } ^ { - 1 0 ~ ^ { \circ } \mathrm { C } }$ ,demonstrating its strong potential for practical energy storage.

# 1． Introduction

Amid the growing concerns over environmental pollution and energy depletion,the development of renewable energy has gained significant attention.However, the large-scale deployment of renewable energy is constrained by challenges such as intermittency,instability,and uneven temporal and spatial distribution [1-3].Overcoming these obstacles necessitates the advancement of energy storage system technologies to enhance the reliability and efficiency of renewable energyutilization [4-6].In this context,redox flow batteries (RFBs） have attracted increasing interest due to their unique advantages,including the decoupling of power and energy capacity,long service life,effective thermal management,rapid response,and resilience to power fluctuations[7-l2].Among various RFB systems,the vanadium-based redox flow battery stands out as one of the most commercially developed and extensivelystudiedtechnologies，whichnotonlyprevents cross-contamination between electrolytes but also allows for convenient electrolyte regeneration [13-17].However,the low energy density and poor temperature adaptability remain the key challengesfor cost-effective and long-term deployment [18-21].

The electrolyte,a key component of flow batteries,comprises active species and supporting electrolytes,which directly influence the energy density of the battery [22-27].Achieving high energy density requires the active species concentration to approach the saturation and solubility limits.However,in conventional sulfuric acid systems,the solubility of vanadium species is highly sensitive to supporting electrolyte concentration.Consequently,their typical solubility remains limited to $1 . 5 { - } 1 . 7 ~ \mathrm { ~ M ~ }$ ，leaving significant potential for further enhancement. Moreover，vanadium species demonstrate pronounced sensitivity to temperature fluctuations, $\mathrm { V O } _ { 2 } ^ { + }$ with high vanadium concentration are prone to thermal precipitation to form $\mathrm { V } _ { 2 } \mathrm { O } _ { 5 }$ at elevated temperatures (above $4 0 ^ { \circ } \mathrm { C } )$ [28-33], while the $\mathrm { V } ^ { 2 + }$ ions tend to precipitate as ${ \mathrm { V S O } } _ { 4 }$ at low temperatures (below $1 0 ~ ^ { \circ } \mathrm { C } )$ due to the reduced solubility as temperature decreases [34,35]. Thus, simultaneous enhancement of energy density and temperature adaptability emerges as a crucial strategy for advancing high-performance vanadium-based redox flow batteries. Given that supporting electrolyte provides essential conditions for the storage and reaction of active species,studies have shown that optimizing supporting electrolytes can enhance the energy density by increasing solubility and improve temperature adaptability by modifying the solvation structure,making it a key research focus for the synergistic improvement of both parameters in vanadium-based redox flow batteries.In earlier studies,Pacific Northwest National Laboratory (PNNL) enhanced vanadium solubility to $2 . 3 \mathrm { M }$ and achieved an energy densityof 77.4 WhLatoye38.7Wh $\mathrm { L _ { c a t h o l y t e + a n o l y t e } ^ { - 1 } ) }$ by using $^ { 1 0 \mathrm { ~ M ~ } }$ HCl as the supporting electrolyte,where chloride stabilized ${ \mathrm { V O } } _ { 2 } { } ^ { + }$ as $\mathrm { [ V _ { 2 } O _ { 3 } . 4 H _ { 2 } O ] } ^ { 4 + }$ and $\mathrm { \Delta [ V _ { 2 } O _ { 3 } C l { \cdot } 3 H _ { 2 } O ] ^ { 3 + } }$ and suppressed $\mathrm { V } _ { 2 } \mathrm { O } _ { 5 }$ precipitation, extending the operating temperature range to $0 { - } 5 0 ^ { \circ } \mathrm { C }$ [36]. Li et al. developed a 2.5 M $\mathrm { H } _ { 2 } S 0 _ { 4 }$ and $6 \mathrm { ~ M ~ }$ HCl mixed electrolyte,which successfully dissolved $2 . 5 \mathrm { M }$ vanadium,achieving an energy density of 78.4 Wh $\mathrm { L } _ { \mathrm { c a t h o l y t e } } ^ { - 1 }$ (39.2 Wh $\mathrm { L _ { c a t h o l y t e + a n o l y t e } ^ { - 1 } ) }$ and expanding the operational temperature range to $5 { - } 5 0 ~ ^ { \circ } \mathrm { C }$ [37]. He et al. used methanesulfonic acid as the supporting electrolyte and found that the formation of VO $\mathrm { ( C H _ { 3 } S O _ { 3 } ) _ { 2 } }$ increased the solubility of $\mathrm { V O } _ { 2 } ^ { + }$ from $1 . 1 5 \mathrm { M }$ (in sulfuric acid) to $1 . 4 2 \mathrm { M }$ at $6 0 ^ { \circ } \mathrm { C }$ [38]. Despite advancements in supporting electrolyte optimization, high-concentration of supporting electrolytes often trigger side reactions like hydrogen and chlorine evolution,leading to increased polarization and degraded cycling performance.Additionally,challenges such as the limited solubility of single active species system and instability-induced short cycle life at extreme temperatures still hinder further performance improvements.Therefore,developing novel electrolyte systems that mitigate side reactions and overcome the solubility limitations of single active species is crucial for simultaneously enhancing the energy density and temperature adaptability of vanadium-based flow batteries.

In addition to optimizing the supporting electrolyte to enhance the solubility of single active species,some studies indicate that incorporating an additional active species alongside vanadium to form a multiactive species system can increase active species concentration and electron transfer number, thereby improving energy density [39]. Wang et al. studied a dual active V/V-Fe redox flow battery,achieving an energy density of 33.4 WhLcatholyte (16.7 Wh Lcatholyte+anolyte), which is $6 6 ~ \%$ higher than that of single active Fe-V batteries [4O].Park et al. reported a dual active V/V-Mn redox flow battery with an energy density of 70.4 Wh Lcatholyte (35.2 Wh $\mathrm { L _ { c a } ^ { - 1 } }$ tholyte+anolyte), $6 6 . 8 ~ \%$ higher than VRFBs,atributable to the high operating potential of $\mathrm { M n } ^ { 2 + } / \mathrm { M n } ^ { 3 + }$ reaction (1.51 V vs. SHE) [41].Park et al. developed a novel V-Ti/V-Mn dual active redox flow battery,achieving an energy density of 78.6 Wh Leatholyte (39.3 Wh $\mathrm { L _ { c a t h o l y t e + n e g a l y t e } ^ { - 1 } ) }$ , representing an increase of $8 6 ~ \%$ and $2 7 \ \%$ compared to the conventional V/V and V/Mn single active speciessystems，respectively[42]．Taken together，whilethe multi-active material system has proven effective in significantly enhancing the energy density of vanadium-based flow batteries,multiple challenges remain to be addressed.For example, the low redox potential of $\mathrm { F e } ^ { 2 + } / \mathrm { F e } ^ { 3 + }$ limits further energy density improvements,and $\mathrm { M n ^ { 3 + } }$ is prone to disproportionation into $\mathbf { M n O } _ { 2 }$ [43],which impairs redox reversibility and cycling stability.More importantly,most active species introduced into vanadium-based multi-active species redox flow battery systems are metal cations.However,due to the common ion effect between vanadium ions and the secondary electroactive species, the solubility and stability of each are suppressed, limiting the energy density and cycling stability of the battery [44-46].Therefore,further enhancing the energy density of multi-active species redox flow battery systems requires the development of novel systems with high operating potential while eliminating side reactions and mitigating the common ion effect.

Herein, this work develops a novel V/V-Br redox flow battery using hydrogen bromide as the supporting electrolyte,achievinga synergistic enhancement of energy density and temperature adaptability.As displayed in Fig.1,bromine participates as another active species with vanadium in the positive electrolyte,effectively mitigating the common ion effect and ensuring high solubility for both active species.Additionally,the introduction of bromine further optimizes the solvation structure of vanadium species,transforming pentavalent and divalent vanadium from $\mathrm { [ V O _ { 2 } ( H _ { 2 } O ) _ { 3 } ] ^ { + } }$ and $\mathrm { [ V ( H _ { 2 } O ) _ { 6 } ] ^ { 2 + } }$ to $\mathrm { [ V O _ { 2 } B r _ { 2 } ( H _ { 2 } O ) ] ^ { - } }$ and $\mathrm { [ V B r _ { 2 } ( H _ { 2 } O ) _ { 4 } ] }$ ，suppressing $\mathrm { { V S O _ { 4 } } }$ and $\mathrm { V } _ { 2 } \mathrm { O } _ { 5 }$ precipitation.Simultaneously,hydrogen bromide serves as a supporting electrolyte that enhances the electrochemical reactivity and diffusion rate of vanadium ions.Consequently,the VBrRFB exhibits an energy density of 152.4 Wh Lcatholyte (38.1 Wh Lcatholyte+anolyte) and achieves an energy efficiency of $8 2 . 5 ~ \%$ at a current density of $\mathrm { 8 0 \ m A \ c m ^ { - 2 } }$ .The battery demonstrates exceptional cyclic stability,maintaining stable cycling performance for over 25O cycles with a minimal efficiency decay of only $0 . 0 0 4 ~ \%$ per cycle.Furthermore,the performance of the VBrRFB was evaluated across a temperature range from $- 1 0 \mathrm { ~ } ^ { \circ } \mathrm { C }$ to $5 0 ~ ^ { \circ } \mathrm { C }$ ，demonstrating excellent stability and charge-discharge behavior.The battery reached a peak power density of $0 . 6 3 \mathrm { W } \mathrm { c m } ^ { - 2 }$ at $5 0 ~ ^ { \circ } \mathrm { C }$ and $0 . 3 0 \mathrm { W } \mathrm { c m } ^ { - 2 }$ at $- 1 0 ^ { \circ } \mathrm { C } ,$ while maintaining energy densities of 107.6 Wh $\mathrm { L } _ { \mathrm { c a t h o l y t e } } ^ { - 1 }$ and 88.8 Wh L 1catholyte,respectively,under these extreme conditions.These results highlight the exceptional potential of the VBrRFB for practical applications in energy storage systems.

# 3．Conclusion

In this work,we developed a novel V/V-Br redox flow battery (VBrRFB) by employing hydrogen bromide as a multifunctional electrolyte,enabling high concentrations of vanadium (1.7 M) and bromine (6 M) in the positive electrolyte and significantly increasing the density of active species.The VBrRFB exhibits outstanding electrochemical performance, delivering a energy density of 152.4 Wh $\mathrm { L } _ { \mathrm { c a t h o l y t e } } ^ { - 1 }$ (38.1 Wh $\mathrm { L _ { c a t h o l y t e + a n o l y t e } ^ { - 1 } ) }$ while achieving an energy eficiency of $8 2 . 5 0 ~ \%$ ata current density of $8 0 \mathrm { \ m A \ c m ^ { - 2 } }$ .The system demonstrates exceptional cyclic stability,maintaining consistent performance over 25O cycles with only $0 . 0 0 4 ~ \%$ efficiency decay per cycle.Across a broad temperature range from $- 1 0 ^ { \circ } \mathrm { C }$ to $5 0 ^ { \circ } \mathrm { C }$ ,the battery maintains excellent chargedischarge behavior,achieving peak power densities of $0 . 6 3 \mathrm { W } \mathrm { c m } ^ { - 2 }$ at 50 $^ \circ \mathrm { C }$ and $0 . 3 0 \mathrm { W } \mathrm { c m } ^ { - 2 }$ at $- 1 0 ^ { \circ } \mathrm { C } ,$ while sustaining energy densities of 107.6 Wh $\mathrm { L } _ { \mathrm { c a t h o l y t e } } ^ { - 1 }$ and 88.8 Wh Lcatholyte, respectively. Mechanistic studies supported by DFT calculations reveal that bromine incorporation mod-ifies the solvation structures of $\mathrm { V O } _ { 2 } ^ { + }$ and $\mathrm { V } ^ { 2 + }$ , transforming $\mathrm { [ V O _ { 2 } ( H _ { 2 } O ) _ { 3 } ] }$ + and $\mathrm { [ V ( H _ { 2 } O ) _ { 6 } ] ^ { 2 + } }$ to $\mathrm { [ V O _ { 2 } B r _ { 2 } ( H _ { 2 } O ) ] ^ { - } }$ and $\mathrm { [ V B r _ { 2 } ( H _ { 2 } O ) _ { 4 } ] }$ ,respectively. This structural change effectively inhibits the formation of $\mathrm { V } _ { 2 } \mathrm { O } _ { 5 }$ and $\mathrm { V S O } _ { 4 }$ precipitates,thereby enhancing the system's temperature adaptability.This work underscores the effectiveness of dual active species engineering and electrolyte optimization in addressing the limitations of conventional VRFBs,offering a promising pathway toward highperformance,temperature-resilient redox flow batteries for grid-scale energy storage systems.Lookingahead,to further enhance the full-cell energy density，improvements can be achieved through capacity matching,electrolyte optimization,and system-level engineering.At the same time,the relatively high corrosivity and irreversible loss of bromine at high SOC may affect cycle life. Therefore,future efforts may also focus on synergistically enhancing the stability of vanadium and bromine active species，developing corrosion-resistant materials, designing bifunctional adsorption-catalysis catalysts,and screening stable complexing agents,which will provide a solid foundation for the broader deployment of this technology.
