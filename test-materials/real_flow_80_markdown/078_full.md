Theperformance of iron-chromium redox flow batteries is significantly influenced by the electrochemical activity of chromiumand iron ions,with aparticular emphasis on the reactivityofchromium.However,the impact of the chemical properties of chromium ions on the eficiency of electrochemical reactions remains largely unexplored.In this study,we introduced $\mathrm { P b C l } _ { 2 }$ into the electrolyte and achieved in-situ electrodeposition of the lead-based catalyst. Our findings indicate thatthe incorporation of lead ions efectively enhances the chromium half-reaction while inhibiting hydrogen evolution.Experimental analyses and molecular dynamics simulations reveal that $\mathrm { { \bf P b } C l _ { 2 } }$ does not significantly afect the electrochemical performance of the electrolyte,its influence is mainly due to the electrochemical deposition on the electrode surface.The observed performance improvement is ascribed to the combined effects of $\mathbf { P b }$ and $\operatorname { P b } ( \mathbf { C l O } _ { 3 } ) _ { 2 } .$ ,which catalyze the redox reaction of $\mathrm { C r } ^ { 3 + } / \mathrm { C r } ^ { 2 + }$ . In situ diferential electrochemical mass spectrometry monitoring of the hydrogen evolution signal demonstrates a clear inhibition of the hydrogen evolution reaction.Notably,the addition of $4 0 \ \mathrm { m M } \ \mathrm { P b } ^ { 2 + }$ significantly reduces the overpotential of the reaction,allowing the energy efficiency of the battery to reach $8 3 . 9 0 \%$ at a current density of $1 4 0 \mathrm { \ m A } / \mathrm { c m } ^ { 2 }$ ，which represents a $5 . 6 8 \%$ increase compared to the original electrolyte $( 7 8 . 2 2 \% )$ .Furthermore, this configuration enables long-term stable operation over 40o cycles.This research presents an innovative approach to enhancing the performance of iron-chromium redox flow bateries,characterized by its simplicity and cost-effectiveness.

# 1．Introduction

With the continuous expansion of the scale of the new energy industry,energy storage technology[1,2],as one of the key technologies, has huge market potential. Among many energy storage technologies, iron-chromium redox flow battery (ICRFB) is a large-scale energy storage technology with great development potential [3-5]. It has the advantages of high power density,long cycle life,strong safety and low cost of raw materials,which utilizes low-cost,high-abundance iron and chromium chlorides as redox active materials [6,7].However, the efficiency of batteries is seriously affected by the low reactivity of $\mathrm { C r } ^ { 3 + } / \mathrm { C r } ^ { 2 + }$ and the side reaction ofhydrogen evolution [8,9], which imit its commercial application.

Many methods have been proposed to improve the reaction kinetics of the $\dot { \mathrm { C r } } ^ { 3 + } / \mathrm { C r } ^ { 2 + }$ redox couples and inhibit hydrogen evolution. The electrochemical behaviors of $\mathrm { C r } ^ { 3 + } / \mathrm { C r } ^ { 2 + }$ redox couples were investigated in detail [10-12]. $\mathrm { C r } ^ { 3 + }$ exists as the types of $\mathrm { C r ( H _ { 2 } O ) } _ { 6 } ^ { 3 + }$ ， $\mathrm { C r } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 5 } \mathrm { C l } ^ { 2 + }$ and $\mathrm { C r ( H _ { 2 } O ) _ { 4 } C 1 _ { 2 } ^ { + } }$ in HCl aqueous solution. $\mathrm { C r } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 5 } \mathrm { C } 1 ^ { 2 + }$ and Cr $\mathrm { ( H _ { 2 } O ) } _ { 4 } \mathrm { C } 1 _ { 2 } ^ { + }$ own the good electrochemical activity due to the inner-sphere coordinated structure of $\mathrm { C l ^ { - } }$ [13-15].It is important to enhance the content of $\mathrm { C r } ( \mathrm { H } _ { 2 } \mathrm { O } ) _ { 5 } \mathrm { C } 1 ^ { 2 + }$ and $\mathrm { C r ( H _ { 2 } O ) _ { 4 } C 1 _ { 2 } ^ { + } }$ and reduce Cr $\mathrm { ( H _ { 2 } O ) } _ { 6 } ^ { 3 + }$ ions in the system. Therefore, the capacity loss mechanism and the efect of electrolyte concentration on the electrochemical and cyclic performance of iron-chromium flow battery were investigated recently [15,16].Wu etal.utilized the improved electrolyte of $1 \mathrm { M F e C l } _ { 2 } + 1 . 3 \mathrm { M }$ $\mathrm { C r C l } _ { 3 } + 3$ MHCl(E-1.3Cr) exhibits an energy efficiency (EE) of $8 4 . 5 1 \%$ ， which is much higher than the original one of $1 \mathrm { M F e C l } _ { 2 } + 1 \mathrm { M C r C l } _ { 3 } + 3$ M HCl (E-1Cr) $( 8 2 . 3 2 \% )$ at a current density of $8 0 \mathrm { m A } / \mathrm { c m } ^ { 2 }$ .It provides an effective way to accelerate engineering applications.In addition, chelation is also a valuable method to improve the reversibility of reaction [17,18].Molecular armor engineering has been widely studied. Fan et al.[19] proposed a molecular-armor design to create pyrroline nitroxides based inclusions.The inclusion catholyte exhibits a high capacity retention rate up to $9 9 . 7 6 7 \%$ /day.The stability mechanism stems from the cavity limitation protection effect,avoiding the primary defect of insufficient stability due to ring-opening side reactions.This also provides a new idea for the design of the electrolyte of ICRFB.

The design of electrodes and catalysts has received extensive attention in the field of flow batteries.The surface and structural properties of the electrode is the main reason affecting the battery performances [20]. Low cost，thinness,lightness and high performance are the main research directions for the development of electrode materials at present [21].Wu et al.[21] introduce an ultrathin and lightweight CME electrode for using in pH-universal aqueous flow batteries.The loose woven structure of carbon microtube endows the CME with the combined advantages of excellent conductivity,abundant active sites,and enhanced electrolyte transport performance.The development of 3D electrodes has expanded the types of traditional electrodes,including foam, biomass,and electrospun fibers,etc.The structure of 3D electrodes can be adjusted to enhance charge transfer and ion diffusion [22].However, it still needs to further reduce the cost and update the technology to become amature commercial electrode.

The modification of electrodes by introducing catalysts has become an important research direction,such as carbon-based,metal oxidebased and metal catalysts [23].The metal oxides and carbon-based materials derived from MOF are widely used as electrocatalysts, featuring abundant active sites and excellent catalytic effects [24].Perovskites with tunable electronic structures are also used as highly active catalysts in flow batteries. Jiang et al.[25] proposed a B-site management strategy of $\mathrm { S r B O _ { 3 } }$ （ $\mathbf { \Delta B = T i }$ ，Zr,Hf) perovskites was proposed to promote the anode reaction jointly explored by experiments and first-principle calculations. $\bf { S r Z r O _ { 3 } }$ stands out in catalysis,owing to its outstanding combination of high hydrophilicity,large surface area,and desired crystal structure.In-situ construction of catalysts on electrodes by directly incorporating metal salts into the electrolyte is a low-cost and promising approach.Nie et al.[26] showed an in situ constructed $\mathrm { C u } @ \mathrm { C u } _ { 6 } S \mathrm { n } _ { 5 }$ core-shell catalyst by incorporating metal ions into the electrolyte.The catalyst enhanced redox kinetics and selectively inhibit hydrogen evolution side reaction,achieving stable operation over1,200 cycles and enabling subzero capacity unlocking for cost-effective vanadium flow batteries.This strategy can also be applied to $\mathrm { Z n }$ -based flow batteries [27].The above ideas and methods can provide references for theresearch on electrodes and catalysts of ICRFB.

In the current research on ICRFB, the introduction of metal catalysts such as In Refs.[28,29],Bi [30-33],Pb [32,34,35]and Sn [36,37] has a significant impact on the catalysis of the redox reaction of $\mathrm { C r } ^ { 3 + } / \mathrm { C r } ^ { 2 + }$ and the inhibition of hydrogen evolution.For example,Niu et al.[29] showed a novel precisely controlled preparation of a novel thermal-treated carbon cloth electrode with a uniform deposit of low-cost indium catalyst particles.The In catalyst has a significant adsorption effect on the reactants and improves the redox reaction activity of $\mathrm { C r } ^ { 3 + } / \mathrm { C r } ^ { 2 + }$ .Moreover, His more easily absorbed on the surface of the catalyst with a high migration energy barrier,thereby inhibiting the occurrence of HER.Xie et al.[32] designed a bimetallic Pb/Bi electrocatalyst and fabricated it on carbon felt electrode,which synergistically boosts $\mathrm { C r } ^ { 3 + } / \mathrm { C r } ^ { 2 + }$ kinetics and alleviates hydrogen evolution. Furthermore,the hydrogen-ferric ion rebalance cell can also eliminate the adverse impacts of hydrogen evolution on the capacity of ICRFB during the long-term operation and ensure the safe operation of the battery [38].However,due to the tedious treatment procedures,these methods cannot demonstrate their superiorities in commercial applications.It is essential to develop an easy and facile method to significantly improve batteryperformance andcyclingstabilityof ICRFB simultaneously.

In this work, we used low-cost lead as a catalyst and add $\mathrm { P b C l } _ { 2 }$ as an additive to the electrolyte.The operation is simple and there is no complex preparation process.The electrochemical behavior of lead ions in the electrolyte was studied.It was innovatively discovered that the amount of hydrogen gas evolved during the battery reaction was significantly reduced,and the effect of suppressing hydrogen evolution was remarkable.We discussed the mechanism of lead ion to improve the performance of ICRFB,and further determined the catalytic effects of Pb and $\mathrm { P b } ( \mathrm { C l O } _ { 3 } ) _ { 2 }$ on the reaction. The ICRFB with $\mathrm { P b } ^ { 2 + }$ additive showed good output performance: a current eficiency (CE) of $9 7 . 4 \%$ ,voltage efficiency (VE) of $8 6 . 1 \%$ ,and energy efficiency (EE) of $8 3 . 9 \%$ at the current density of $1 4 0 \mathrm { \ m A } / \mathrm { c m } ^ { 2 }$ 、This work is highly beneficial to the development of next-generation low-cost ICRFB for energy storage applications.

# 2．Experimental

# 2.1.Preparation of electrolytes

The chemicals used in this work including $\mathrm { C r C l } _ { 3 } { \cdot } 6 \mathrm { H } _ { 2 } 0$ ， $\mathrm { F e C l } _ { 2 }$ $4 \mathrm { H } _ { 2 } \mathrm { O }$ and HCl were all analytically pure agents,including $\mathrm { C r C l } _ { 3 } { \cdot } 6 \mathrm { H } _ { 2 } 0$ and HCl from Shanghai Aladdin Biochemical Technology Co.,Ltd., $\mathrm { F e C l } _ { 2 } { \cdot } 4 \mathrm { H } _ { 2 } 0$ from Xilong Scientific Co.,Ltd.，and $\mathrm { P b C l } _ { 2 }$ from Shanghai Macklin Biochemical Co.,Ltd.The pristine electrolyte was prepared as follows: Firstly a certain stoichiometric $\mathrm { C r C l } _ { 3 } { \cdot } 6 \mathrm { H } _ { 2 } 0$ and $\mathrm { F e C l } _ { 2 } { \cdot } 4 \mathrm { H } _ { 2 } 0$ were dissolved in an appropriate amount of deionized water,and then quantitative concentration hydrochloric acid was added into the saline solution,lastly the acidic solution was quantitatively diluted with deionized water to volume with volumetric flask at room temperature, the electrolyte consisting of 1.4 M $\mathrm { C r C l } _ { 3 } { \cdot } 6 \mathrm { H } _ { 2 } 0$ 1.2M $\Omega \ \mathrm { F e C l } _ { 2 } { \cdot } 4 \mathrm { H } _ { 2 } 0$ and $2 . 5 \ \mathrm { M }$ HCl was obtained. The electrolyte with $\mathrm { P b } ^ { 2 + }$ was prepared by adding small quantities of $\mathrm { P b C l } _ { 2 }$ to the pristine electrolyte in the process of mixing.1.4 MCrCl3-6H2O+1.2M $\mathrm { F e C l _ { 2 } } { \cdot } 4 \mathrm { H _ { 2 } O } + 2 . 5 \mathrm { M H C l } + x \mathrm { m M }$ $\mathrm { P b C l } _ { 2 }$ $( x = 0$ ,10,20,30,40,50,60) were used as electrolytes.To keep experimental consistency,the electrolytes for the tests were prepared on the same day.And all were left to stand for $^ { 3 \mathrm { ~ h ~ } }$ before testing to ensure complete dissolution of the active substance and achieve a stable coordination structure.

# 2.3.Molecular dynamic simulation

Molecular Dynamics (MD） simulations were performed using LAMMPS software.Among them,this article mainly uses the classical OPLSAA force field to describe the structure of electrolyte solvents,and obtains the parameters of the electrolytic fluid field from literature.The potential energy parameter of ions adopts 12-6LJ potential energy parameter,as shown in Eq. (1)

$$
U _ { i j } { \left( r _ { i j } \right) } = \frac { e ^ { 2 } Q _ { i } Q _ { j } } { r _ { i j } } + \varepsilon _ { i j } \left[ { \left( \frac { R _ { \mathrm { m i n } , i j } } { r _ { i j } } \right) } ^ { 1 2 } - 2 { \left( \frac { R _ { \mathrm { m i n } , i j } } { r _ { i j } } \right) } ^ { 6 } \right]
$$

The mixing rule of potential function follows Eq. (2)

$$
\varepsilon _ { i j } = \sqrt { \varepsilon _ { i } \varepsilon _ { j } } , \sigma _ { i j } = \sqrt { \sigma _ { i } \sigma _ { j } }
$$

Use Material Studio and Packmol software packages to model the electrolyte, and then convert it into an executable topology file using Moltemplate software.Due to the approximate assumption of complete ionization in aqueous solvents,the electrolyte system is modeled as completely decomposed into ionic states,while water molecules are fixed using the fix shake algorithm to save computational complexity. The initial box size of the electrolyte is 31 $\mathring { \mathbb { A } } \times \bar { 3 } 1 \mathring { \mathbb { A } } \times 3 1 \mathring { \mathbb { A } } ,$ and each electrolyte simulation first completes an energy minimization process with an energy and tolerance of $1 0 ^ { - 4 }$ .Due to the battery operating at 60 ${ } ^ { \circ } \mathrm { C } ,$ the overall simulation was conducted for MD simulation at $6 0 ~ ^ { \circ } \mathrm { C }$ (333 K).Firstly，the NVT ensemble was used, followed by hightemperature simulation at $1 , 0 0 0 ~ \mathrm { K } ,$ and then step annealing to $3 3 3 \mathrm { ~ K ~ }$ forrelaxation under the NPT ensemble.Subsequently，the NVT ensemble was used to simulate for over 1O ns at the required temperature to obtain trajectory files.Finally,the radial distribution function (RDF) was obtained using visualization software (Visual Molecular Dynamics,VMD).The calculation rule is based on Eq.(3)

$$
N = 4 \pi \rho \int _ { 0 } ^ { r } r ^ { 2 } g ( r ) \mathrm { d } r
$$

where $\rho$ represents the number density of the substance,r represents the ionic radius of the central substance,and $g ( r )$ represents the distance between the coordination substance and the central substance.When the radial distribution function is taken,the last ten frames of the trajectory file are sampled after averaging,and the solvation structure is selected by using python code.

Due to the optimal addition concentration of $4 0 ~ \mathrm { m M }$ ， $3 \mathrm { P b C l } _ { 2 }$ molecules were added to the original electrolyte to characterize the concentration of $4 0 \mathrm { m M }$ .The calculation rule is as follows:First,keep the total number of water molecules at 4,Ooo,and on this basis,every $7 2 \ \mathrm { P b C l _ { 2 } }$ molecules represent a concentration of $1 \mathrm { m o l } / \mathrm { k g } \mathrm { H } _ { 2 } \mathrm { O }$ ,Due to the density of the basic electrolyte being approximately $1 . 3 3 ~ \mathrm { g / m L }$ ，three $\mathrm { { \bf P } b } { \mathrm { C l } } _ { 2 }$ molecules are equivalent to a concentration of approximately $4 0 \mathrm { m M }$

# 3．Discussion

The working principle of ICRFB and the action mechanism of $\mathrm { P b } ^ { 2 + }$ are shown in Fig.1.The ICRFB system is composed of electrolyte, electrode,ion exchange membrane,bipolar plate,peristaltic pump and other structures.The specific disassembly structure can be seen in Fig.S1.Through the circulation of electrolyte, redox reaction occurs on the electrode to achieve energy storage and release.In this study, $\mathrm { P b } ^ { 2 + }$ was added into the electrolyte to comprehensively study the effect of $\mathrm { P b ^ { 2 + } }$ as an additive on the performance of ICRFB. The results show that the addition of $\mathrm { P b } ^ { 2 + }$ can improve the reaction kinetics of $\mathrm { C r } ^ { 3 + } / \mathrm { C r } ^ { 2 + }$ and inhibit the side reaction of hydrogen evolution.Lead ions can achieve catalyst deposition and dissolution during the negative electrode reaction process,thereby catalyzing the reaction,promoting mass and electron transfer,and significantly improving the efficiency and cycling stability of ICRFB.

In order to explore the influence of $\mathrm { P b } ^ { 2 + }$ on the existence form of $\mathrm { C r ^ { 3 + } }$ and electrolyte characteristics,the physical and chemical properties of the original electrolyte and the electrolyte with different content of $\mathrm { P b } ^ { 2 + }$ were analyzed.Fig. 2(a) showed the UV-vis spectrogram. It can be observed that there are two characteristic peaks corresponding to chromium ions at 436 and $6 2 0 \ \mathrm { n m }$ .The absorbance did not change significantly with the change of $\mathrm { P b ^ { 2 + } }$ content,and the peak position did not shift, indicating_that the addition of $\mathrm { P b } ^ { 2 + }$ would not change the existence form of $\mathrm { C r ^ { 3 + } }$ .The viscosity of the electrolyte showed a slight upward trend,as shown inFig.2(b),and the trend of density change was also the same.It indicated that the addition of lead ions slightly increased the flow resistance of the electrolyte.Fig.2(c) showed the change of conductivity with the concentration of lead ions.Adding different concentrations of $\mathrm { P b } ^ { 2 + }$ can improve the conductivity of the electrolyte to a certain extent,and promote the charging and discharging process of ICRFB.

Figs.2(d) and (e) shows the hydrogen evolution signal diagram of the iron chromium flow battery reaction. The effect of $\mathrm { P b } ^ { 2 + }$ on the hydrogen evolution side reaction was analyzed by combining in situ differential electrochemical mass spectrometry (DEMS） with an electrochemical workstation. Fig.2(d) shows the hydrogen evolution signal of an electrolyte with or without $\mathrm { P b } ^ { 2 + }$ during the negative electrode chromium reduction reaction.The reaction process was controlled using cyclic voltammetry with a voltage range of $- 1 . 0 - 0 \mathrm { V } .$ It could be seen that the hydrogen evolution signal of the electrolyte with $4 0 \ \mathrm { m M }$ lead ions is significantly reduced compared to the original electrolyte.Fig.2(e) corresponds to hydrogen evolution reaction signals at different voltages.The original electrolyte had obvious hydrogen evolution at $- 0 . 6 \mathrm { V }$ ,and with the increase of negative voltage,the hydrogen evolution signal gradually became stronger, reaching $1 . 3 4 \times { { 1 0 } ^ { - 9 } }$ at $- 1 . 0 \mathrm { V }$ 、The electrolyte with $4 0 \mathrm { m M P b } ^ { 2 + }$ had no obvious hydrogen evolution at $- 0 . 6 \mathrm { V }$ .The hydrogen evolution signal increased slowly with the increase of voltage,rising to $2 . 1 9 \times 1 0 ^ { - 1 0 }$ at $- 1 . 0 \mathrm { V }$ , which was an order of magnitude lower than the original electrolyte.The hydrogen evolution rate was significantly lower than that of the original electrolyte.It could be seen that $\mathrm { P b } ^ { 2 + }$ had a significant effect on inhibiting hydrogen evolution.

In order to understand the electrochemical behavior of lead ions in hydrochloric acid solution,cyclic voltammetry tests were conducted on solutions of $2 . 5 \mathrm { M }$ HCl and $2 . 5 \mathrm { M H C l } + 2 \mathrm { m M P b } ^ { 2 + } .$ In Fig. 3(a), it could be seen that during the testing process of 2.5 M HCl, there were no obvious oxidation and reduction peaks,while a pair of oxidation and reduction peaks appeared at $- 0 . 5 3$ and $- 0 . 6 2 \mathrm { ~ V ~ }$ after the addition of lead ions,corresponding to the dissolution and deposition processes of lead,respectively.It can also be observed that the reduction peak current of hydrogen evolution reaction decreases obviously after the addition of lead ion,which indicates that lead ion has the effect of inhibiting hydrogen evolution.

In order to evaluate the effect of $\mathrm { P b } ^ { 2 + }$ on the redox reaction of the positive and negative electrodes,the electrochemical properties of the electrolytes with and without $\mathrm { P b ^ { 2 + } }$ were measured by cyclic voltammetry(CV) in a three-electrode system.First of all,the curve obtained by scanning at the rate of $1 5 ~ \mathrm { m V } / s$ in the range of $0 { - } 0 . 8 \mathrm { ~ V ~ }$ is shown in Fig.3(b),corresponding to the redox reaction of $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ . The redox peak currents measured in the original electrolyte were O.oo3,28 and $- 0 . 0 0 2 , 8 0 \mathrm { A }$ ,respectively,with the peak potential difference of $0 . 1 7 1 \mathrm { V }$ After adding $\mathrm { P b C l } _ { 2 }$ additive,the redox peak currents of the positive electrode increased slightly,with the effect of adding $4 0 \mathrm { m M }$ being more significant.The measured redox peak currents were O.oo3,68 and $- 0 . 0 0 3 , 1 1 \mathrm { ~ A ~ }$ ,respectively,which were higher than the original electrolyte.The peak potential difference was $0 . 1 5 3 \mathrm { V }$ ,and the decrease in this value reflects the enhanced reversibility of the reaction.Therefore, adding $\mathrm { P b C l } _ { 2 }$ can improve the redox reaction of $\mathrm { F e } ^ { 3 + } / \mathrm { F e } ^ { 2 + }$ in the positive electrode.

Fig. 3(c) shows the curve scanned at the rate of $1 5 \mathrm { m V } / s$ in the range of 0 to $- 1 . 0 0 \mathrm { V }$ ,corresponding to the redox reaction of $\mathrm { C r } ^ { 3 + } / \mathrm { C r } ^ { 2 + }$ at the negative electrode.Due to the slow reaction kinetics of $\mathrm { C r } ^ { 3 + } / \mathrm { C r } ^ { 2 + }$ and the side reaction of hydrogen evolution, the oxidation peak of the original electrolyte is small in the CV curve,and there is no obvious reduction peak.After adding $4 0 \ \mathrm { m M } \ \mathrm { P b C l _ { 2 } }$ ，the oxidation peak and reduction peak increase significantly,the peak potential difference decreases,and the reactivity and reversibilityare significantly enhanced, indicating that adding $\mathrm { P b } ^ { 2 + }$ to the electrolyte can not only increase the overpotential of HER,but also promote the redox reaction of $\mathrm { C r } ^ { 3 + } / \mathrm { C r } ^ { 2 + }$ In addition, the process will be accompanied by lead oxidation and reduction reactions, $\mathrm { P b } ^ { 2 + }$ will be deposited and dissolved on the electrode surface,forming a lead-based catalyst deposition layer, reducing the loss of active substances.

The deposition of catalysts promotes the reaction kinetics of chromium and inhibits the evolution of hydrogen gas.

The battery efficiencies including CE,VE and EE were measured under the current density of $1 4 0 \mathrm { m A } / \mathrm { c m } ^ { 2 }$ ,as shown in Figs.5(c)-(e).It is obvious that the CEof the battery is maintained ata relatively high level, all values are above $9 7 \%$ ,indicating that the battery is not damaged during assembly and is well sealed. Batteries with $4 0 \mathrm { m M } \mathrm { P b } ^ { 2 + }$ have the highest VE $( 8 6 . 1 0 \% )$ ，which is $5 . 7 2 \%$ higher than that of the battery assembled with the original electrolyte $( 8 0 . 3 8 \% )$ .EEis obtained by multiplying CE and VE,and the battery with $4 0 \ \mathrm { m M } \ \mathrm { P b } ^ { 2 + }$ achieve the highest EE,maintaining an average of $8 3 . 9 0 \%$ ,which is significantly higher than that of the original electrolyte $( 7 8 . 2 2 \% )$ ， $2 0 \mathrm { \ m M \ P b ^ { 2 + } }$ $( 8 2 . 6 9 \% )$ and $6 0 \mathrm { \ m M \ P b ^ { 2 + } \ ( 8 1 . 0 7 \% ) } .$ Fig.5(f) shows the discharge capacity retention of batteries with different concentration of $\mathrm { P b } ^ { 2 + }$ ，and the discharge capacity attenuation with $4 0 \ \mathrm { \ m M \ P b } ^ { 2 + }$ is also minimal. Figs.5(g)-(i) showed the cell efficiencies including CE,VE and EE, which were measured under the current density varied from 8O to 200 $\mathrm { \ m A } / \mathrm { c m } ^ { 2 }$ at $2 0 \mathrm { m A } / \mathrm { c m } ^ { 2 }$ intervals.The CE of the battery is basically stable at different current densities,and the VE tends to decrease with the increasing current density due to the increase of overpotential.The EE of the batteries showed the same trend as the VE,and the highest EE was found in the cells assembled with the electrolyte supplemented with 40 $\mathrm { { m M P b } } ^ { 2 + }$ ,which could reach to $7 6 . 3 2 \%$ even at the current density of $2 0 0 \mathrm { m A } / \mathrm { c m } ^ { 2 }$

In order to study the cycle stability of the battery with $4 0 \mathrm { \ m M P b } ^ { 2 + }$ , we investigated the long-term cycle behavior of the battery.As shown in Fig. 5(j),the battery system remains stable at a current density of 140 ${ \mathrm { m A } } / { \mathrm { c m } } ^ { 2 }$ ,with an average current efficiency of $9 8 . 1 6 \%$ and a capacity degradation rate of $0 . 2 \%$ .The energy efficiency remains at $7 4 . 7 9 \%$ after cycling,with an average energy efficiency decay of $0 . 0 2 5 \%$ per cycle. This is because the introduction of $\mathrm { P b C l } _ { 2 }$ enhances the reaction kinetics of the negative electrode,and the higher hydrogen evolution overpotential suppresses the hydrogen evolution side reaction.This reduces polarization loss and improves the utilization efficiency of active substances.Therefore,the battery exhibits good long-term cycle stability.

The X-ray photoelectron spectroscopy (XPS) revealed the bonding configurations of carbon,oxygen,and lead on the surface of the TCC and Pb/TCC electrodes.In Fig.7(b),the wide-scan XPS spectrum revealed that the carbon content is reduced due to the residual electrolyte on the surface of the electrode after the charge-discharge cycle.After adding $\mathrm { P b } ^ { 2 + }$ to the electrolyte and electrodeposition, the signal of lead can be seen on the Pb/TCC electrode.The C1s spectra are deconvoluted into C-C $2 8 6 . 3 \ \mathrm { e V } ,$ ， $\mathrm { c } { = } \mathrm { c }$ $2 8 4 . 0 ~ \mathrm { e V } )$ ， $0 { \mathrm { - C } } { \mathrm { = } } 0$ (288.3 eV)and C-O (286.0 eV) peaks,while the O1s spectra are deconvoluted into C-O $( 5 3 2 . 5 \mathrm { e V } )$ ， $\scriptstyle \mathrm { C = } 0$ (531.1 eV) and -OH (534.0 eV) (Fig.S8) [41,42]. The resistance and resistivity of carbon cloth were obtained by using the four-probe resistance tester. It can be seen that Pb/TCC has lower resistance and higher conductivity in Fig.7(e).The contact angles of TCC electrode is $5 4 . 5 ^ { \circ }$ ，and the Pb/TCC electrodes is $4 3 . 0 ^ { \circ }$ (Fig.7(f)). During the deposition process, the catalyst introduces additional oxygen-containing functional groups onto the carbon cloth surface.Moreover,lead chlorate itself exhibits inherent polarity,which can promote the adsorption of water molecules via polar interactions,thereby enhances hydrophilicity.The results showed that the electrolyte could quickly penetrate the Pb/TCC electrodes,promoting ion conduction and mass transfer processes.

# 4.Conclusion

In this study,the in-situ electrodeposition of lead-based catalysts on carbon cloth electrodes is achieved by directly introducing lead ions into the electrolyte. This method is low-cost and does not require complex steps,which is beneficial for industrial applications.Cycling experiments of the battery based on this electrolyte demonstrate that the battery containing $\dot { 4 } 0 \mathrm { \ m M \ P b } ^ { 2 + }$ can achieve an energy efficiency of $8 3 . 9 0 \%$ at the current density of $1 4 0 \ \mathrm { m A / c m ^ { 2 } }$ ，which is $5 . 6 8 \%$ higher than that of the original electrolyte $( 7 8 . 2 2 \% )$ .The voltage efficiency of the battery is $5 . 4 9 \%$ higher than that of the original electrolyte.Moreover,it can operate stably for 4Oo cycles.The results of molecular dynamics simulation show that $\mathrm { P b C l } _ { 2 }$ has no significant effect on the electrochemical performance of the electrolyte,and its effect is mainly attributed to the electrochemical deposition on the electrode surface. The carbon cloth electrode was characterized during the operation of the battery.Lead was uniformly deposited on the surface of the carbon cloth in the form of lead particles and lead chlorate particles when the battery was fully charged,and dissolved in the electrolyte during the discharge process.In this process,lead particles and lead chlorate particles play the role of catalysts,which can improve the reaction kinetics of chromium ions,effectively inhibit the hydrogen evolution reaction of the negative electrode,reduce the polarization,and improve the energy efficiency. In situ differential electrochemical mass spectrometry was used to further confirm the inhibition of hydrogen evolution reaction. Therefore,lead-based catalysts in situ electrodeposition can effectively improve the performance of ICRFBs,and this method is expected to be applied to the scale-up experiment of ICRFBs.
