# INTRODUCTION

In view of the growing demand for lithium-ion batteries, intensive research is pursued to develop cost-effective highenergy-density electrode materials without compromising on environmental issues，materials availability，and safety.For next-generation lithium-ion batteries， nickel-rich Li-$\mathrm { N i _ { 0 . 8 } M n _ { 0 . 1 } C o _ { 0 . 1 } O _ { 2 } }$ (NMC811） is especially promising as a cathode material due to its high gravimetric capacity of ${ \sim } 1 6 0 -$ $2 0 0 \ \mathrm { m A h / g } ,$ high average potential of ${ \sim } 3 . 8 \mathrm { ~ V ~ }$ vs $\mathrm { L i / L i ^ { + } }$ and the reduction in cost resulting from the lower content of critical cobalt. Despite the advantages,NMC811 still displays poor cyclability,mainly attributed to the oxidation of organic electrolyte at the surface of delithiated NMC811 at high voltages， transition metal dissolution aggravated by acidic species resulting from electrolyte decomposition, irreversible structural rearrangements that lead to the formation of a highly resistive NiO rock-salt phase，and microcrack generation induced by the large strain caused by the delithiation/lithiation process during prolonged cycling.1 Moreover, a certain degree of $\mathrm { L i } ^ { + } / \mathrm { N i } ^ { 2 + }$ exchange often occurs between the transition metal sites and the $\mathrm { L i ^ { + } }$ sites due to the close ionic radii of ${ \mathrm { L i } ^ { + } }$ (76 $\mathrm { p m } ,$ and $\mathrm { N i } ^ { 2 + }$ $\left( 6 9 \ \mathrm { p m } \right)$ ), which can significantly decrease the ${ \mathrm { L i } ^ { + } }$ diffusion rate and reduce the amount of active ${ \mathrm { L i } ^ { + } }$ participating in the charge-discharge process. Finally, NMC811 materials possess high surface reactivity that can lead to the formation of $\mathrm { L i } _ { 2 } \mathrm { C O } _ { 3 }$ and LiOH upon reaction with $\mathrm { C O } _ { 2 }$ and $_ { \mathrm { H } _ { 2 } \mathrm { O } }$ when stored under ambient conditions.

Among different strategies to enhance the cycling performance of lithium-ion batteries,the use of electrolyte additives is a promising approach.A prominent example is the use of vinylene carbonate (VC)as electrolyte additive promoting the formation of a protective interphase layer, the so-called solid electrolyte interphase (SEI),at the graphite anode/electrolyte interface.4-6B Electrolyte additives,such as tris(trimethylsilyl)- phosphite $( \mathrm { T M S P i } ) ^ { 7 - 9 }$ and tris(trimethylsilyl)borate (TMSB),10-13 tend to decompose and form a protective cathode electrolyte interphase (CEI） layer at the cathode/ electrolyte interface，which prevents excessive oxidative electrolyte decomposition，transition metal dissolution，and other parasitic side reactions.14 In particular， it was demonstrated that the long-term cycling performance of NMC11l/graphite cells improves combining TMSPi with VC.15,16 Qui et al. reported an extension of this study to NMC811/graphite cels using a combination of TMSPi VC, and 1,5,2,4-dioxadithiane-2,2,4,4-tetraoxide (MMDS） electro-lyte additives but did not observe improved long-term cycling performance.17 Furthermore, it was reported that TMSPi can serve as an effective electrolyte additive for graphite anodes in lithium-ion batteries， improving capacity retention and Coulombic efficiency.18

To better understand how TMSPi and VC additives interact in the NMC811/graphite cells，TOF-SIMS analysis was performed on the cycled graphite anodes vs NMC811 cathodes in the discharged state after 2OO cycles at $\mathrm { C } / 3$ Figure 6a shows that the peaks corresponding to $\mathrm { M n } ^ { + }$ ， ${ { \mathrm { C o } } ^ { + } }$ $^ { 5 8 } \mathrm { \bar { N i } ^ { + } }$ and $^ { 6 0 } \mathrm { { N i } ^ { + } }$ ions (natural abundance $6 8 \%$ and $2 6 \%$ for the latter two,respectively)are less intense for the graphite cycled with a mixture of 1 vol. $\%$ TMSPi and 1 vol. $\%$ VC additives than for the graphite cycled with only 1 vol. $\%$ VC. This result suggests that the addition of TMSPi inhibits transition metal dissolution from the NMC811 cathode and subsequent deposition on the graphite surface.Note,however, that these spectra were collected from the very top surface of the solid electrolyte interphase and do not provide information about the transition metal content in the bulk of the anode.However, a depth-resolved TOF-SIMS analysis on extensively cycled graphite electrodes was published by Li et al. indicating that transition metals tend to accumulate in the frst $1 0 { - } 2 0 \ \mathrm { n m }$ from the surface，which is approximately within the depth probed in this work by TOF-SIMS.41

The TOF-SIMS spectrum of the graphite electrode in Figure 6a cycled without TMSPi also shows intense additional peaks that are mainly associated with $\mathrm { L i } _ { 3 } \mathrm { F } _ { 2 } ^ { + }$ fragments,which differ by their lithium isotope content $^ { \prime 6 } \mathrm { L i } _ { 2 } ^ { 7 } \mathrm { L i F } _ { 2 } ^ { + }$ ， $\mathrm { ^ 6 L i 7 L i _ { 2 } F _ { 2 } } ^ { + }$ ，and $^ \mathrm { 7 L i } _ { 3 } \mathrm { F } _ { 2 } ^ { + } )$ .These peaks are significantly suppressed when TMSPi is added in the electrolyte. Similarly, TOF-SIMS spectra from the very top surface of the CEI of the cycled NMC811 electrodes depicted in Figure S6 also reveal a significant suppression of the peaks corresponding to the $\mathrm { L i } _ { 3 } \mathrm { F } _ { 2 } ^ { + }$ fragments when TMSPi is used. The intensity of the peaks corresponding to the transition metals is strongly reduced， suggesting a decrease in transition metal deposition over the very top surface of the CEI when TMSPi is present. It was shown experimentally that TMSPi promotes the decomposition of the $\mathrm { L i P F } _ { 6 }$ salt in the electrolyte, the primary source of fluorine in the cell, by reacting with fluorine ions and forming $\mathrm { M e } _ { 3 } \mathrm { S i F }$ 42 Han et al. studied the decomposition reaction of TMSPi and its reactivity with HF and LiF using first-principle calculations.8 Their results indicate that the reactivity of TMSPi with LiF is even higher than with HF suggesting that LiF may be scavenged directly from the electrodes，consistent with our TOF-SIMS results.

The removal of HF from the electrolyte by TMSPi is also consistent with the noticeable reduction of the $^ { 5 6 } { \mathrm { F e } } ^ { + }$ (natural abundance $9 2 \%$ and $\mathsf { A l } ^ { + }$ peaks shown in Figure 6a and Figure $\mathrm { S 7 a } ,$ ，respectively，indicating reduced corrosion of the cell's steel casing and aluminum current collector.

Figure 6b depicts the TOF-SIMS peaks of $^ { 6 } \mathrm { L i } ^ { + }$ correspond-ing not necessarily to metallc lithium, but potentially coming from the fragmentation of any lithium-containing compound. The measurements were performed on electrodes extracted from discharged cells,i.e. the anode is in the delithiated state. Consequently TOF-SIMS measures lithium that is no longer electrochemically active,but trapped at the surface of the graphite electrodes. Figure 6b and Figure S7b (this one showing the signal corresponding to ${ \mathrm { L i O } } ^ { + }$ fragments) demonstrates that TMPSi causes a significant reduction of such trapped lithium at the surface of the anode and can explain,at least partially, the improved capacity retention in the cell during prolonged cycling.

To further investigate the effect of TMSPi,we analyzed the electrode surfaces by FT-IR. The FT-IR spectra of the cycled graphite electrodes show no substantial differences when adding TMSPi (Figure 7a).More interesting are the FT-IR spectra from the cycled NMC811 electrodes depicted in Figure $7 \mathbf { b }$ ，where a more intense peak centered at $1 1 9 5 ~ \mathrm { { \ c m } ^ { - 1 } }$ corresponding to $\mathrm { ~ \bf ~ P ~ } = \mathrm { ~ \bf ~ O ~ }$ stretching vibration’is observed for the NMC811 electrode cycled with TMSPi. This indicates that the surface layer of the NMC811 cycled with TMSPi is richer in $\mathrm { \bf P } = \mathrm { \bf O }$ containing products. Similar observations have been reported in FT-IR spectra of $\mathrm { L i _ { 1 . 2 } M n _ { 0 . 5 4 } N i _ { 0 . 1 3 } C o _ { 0 . 1 3 } O _ { 2 } }$ electrodes after cycling with and without TMSPi-containing electrolytes.9 Furthermore，our FT-IR results correlates well with recent investigations conducted by Tornheim et al. showing that trimethylsilyl-containing phosphite and phosphate com-pounds form passivating layers with elevated phosphorus and oxygen contents.43

Our results show that the combination of 1 vol. $\%$ of TMSPi and 1 vol. $\%$ of VC electrolyte additives is highly effective in enhancing the cycling stability of NMC811/graphite cells.We showed that TMSPi is able to mitigate transition metal dissolution from NMC811 and reduce the active lithium loss in the electrodes, improving capacity retention during longterm cycling.The use of such electrolyte additives also affects cell impedance growth，a subject of future investigations. Furthermore,the TMSPi additive displays high reactivity with $\mathrm { L i P F } _ { 6 } ,$ which limits its effective lifetime in the electrolyte mixture when used as an additive in $\mathrm { L i P F } _ { 6 }$ -based carbonate electrolytes.42 Comparable long-term cycling performance of NMC811/graphite full cels was recently reported by Beltrop et al.using 0.5 wt. $\%$ of triphenylphosphine oxide as an electrolyte additive，which may exhibit a different reactivity with $\mathrm { L i P F } _ { 6 }$ 3 32

# CONCLUSIONS

In summary, the synthesis and characterization of NMC811 powders were presented,and the effect of several electrolyte additives on the cycling performance of NMC811/graphite full cells was investigated. In particular,a combination of 1 vol. $\%$ of TMSPi and 1 vol. $\%$ of VC additives with a standard electrolyte( ${ \mathrm { ~ M ~ L i P F } } _ { 6 }$ in EC:DMC）greatly enhances the cell performance， resulting in higher discharge capacities， an increased Coulombic efficiency，and a remarkable improvement in the capacity retention ( $91 \%$ after 200 cycles at $\mathrm { C } / 3$ ). Surface analysis of the cycled electrode using TOF-SIMS demonstrated that TMSPi can effectively lower the amount of active lithium trapped in the SEI of the graphite electrode and reduce transition metal dissolution from the NMC811 electrodes.Furthermore，our observations confirm that TMSPi can act as an HF scavenger and consequently reduce Al and Fe dissolution from the current collector and cell casing. This study provides a valuable understanding of the effect of TMSPi in NMC811/graphite full cells and gives further insight for future development and optimization of suitable electrolyte formulations used in combination with Nirich NMC cathodes.
