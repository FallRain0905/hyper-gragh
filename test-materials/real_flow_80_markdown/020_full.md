Rechargeable zinc-air bateries are promising candidates for next-generation energy storage systems due to their high theoretical energy density,cost-effectiveness,and environmental compatibility.However,conventional aqueous alkaline electrolytes suffer from drawbacks,including hydrogen evolution,electrode corrosion,and limited electrochemical windows,hindering theirlong-term stability and application.We reporta zinc-air flow battery using a non-aqueous acetonitrile (ACN)-based electrolyte with $\mathrm { Z n ( C l O _ { 4 } ) _ { 2 } }$ salt.The low viscosity and moderate dielectric constant of ACN promote fast ${ \mathrm { Z n } } ^ { 2 + }$ transport and facile desolvation, while spectroscopic analyses reveal strong ${ \mathrm { Z n } } ^ { 2 + }$ -ACN interactions forming a stable solvation structure.The dendritic Zn anode and carbon-based air cathode enhance interfacial kinetics,enabling reversible Zn plating/stripping and oxygen electrochemistry. In coin-cell tests, the $\mathrm { Z n ( C l O _ { 4 } ) _ { 2 } }$ -ACN electrolyte showsa low polarization gap $\Delta \mathrm { V } \approx 0 . 9 2 \mathrm { V }$ at $0 . 1 \mathrm { \ m A } \mathrm { c m } ^ { - 2 } )$ and durable cycling over $3 6 0 { \mathrm { ~ h } } .$ A Flow-cell architecture allows evaluation under high-current and application-relevant conditions.The optimized flow battery delivers a peak power density of $5 3 . 3 \mathrm { \ m W \ c m ^ { - 2 } }$ and stable operation for $2 0 0 { \mathrm { ~ h ~ } }$ with a nearly ideal coulombic efficiency.These results demonstrate that ACN-based organic electrolytescan overcome the limitations of aqueous systems,offering a scalable pathway for developing practical Zn-air flow batteries with ACN-based organic electrolytes.

# 1．Introduction

The damage caused by climate change owing to global warming is becoming increasingly severe each year.In addition, energy demand is increasing worldwide,resulting in a continuous increase in fossil fuel consumption,which remains the dominant energy source [1,2].The combustion of fossil fuels increases the emission of carbon dioxide,a greenhouse gas,thereby accelerating global warming [3,4]. Consequently,interest in clean alternative energy sources,such as hydropower,wind power,and solar power,has increased [5].

However,these alternative energy sources have drawbacks,such as the discontinuity of energy production,leading to the need for energy storage systems (ESS) [6,7].In particular, lithium-ion batteries (LIBs), which currently dominate ESS technology,have limitations such as high costs,resource scarcity,and safety concerns,which limit their ability to meet the future demands of the rapidly expanding ESS market [8,9].In this context,rechargeable zinc-air batteries (ZABs) are gaining attention as next-generation energy storage devices owing to their high theoretical energy density (1086 Wh $\mathbf { k g } ^ { - 1 } .$ ),cost-effectiveness,and environmental friendliness [1O-12]. Specifically,the growing global demand for clean energy storage technologies has increased interest in ZABs, which can overcome the limitations of LIBs,as mentioned above [13, 14].Additionally,the rapid growth of the electric vehicle market and the need for large-scale power grid storage devices are driving the development of battery technologies with higher energy densities and superior safety [15].Conventional aqueous alkaline electrolyte-based ZABs have limitations,such as the hydrogen evolution reaction (HER), electrode corrosion,dendrite formation,and a narrow potential window,which impose constraints on their cycle life, energy efficiency,and practical applications [16,17]. To address these issues,non-aqueous organic electrolytes that minimize the HER and corrosion,enhance the reversibility of zinc metal anodes,and provide broader electrochemical stability have recently gained attention [18-20].

In zinc-ion batteries,various organic electrolytes,such as N,Ndimethylformamide (DMF) [21,22],dimethyl sulfoxide (DMSO) [23], propylene carbonate (PC) [24],ethylene glycol (EG) [25],and acetonitrile (ACN) [26],have been extensively investigated to overcome the limitations of aqueous electrolytes.In the case of ZABs,Yu et al. demonstrated the stable operation over $4 8 0 \mathrm { ~ h ~ }$ using a non-aqueous electrolyte composed of $\mathrm { Z n ( O T F ) _ { 2 } }$ and DMF and a reaction pathway in which ${ \mathrm { Z n } } ^ { 2 + }$ migrates to the cathode and precipitates as $\mathrm { Z n O }$ rather than relying primarily on ORR/OER.The overall reaction pathway was reported as reaction (1) [27].

$$

Cui et al. demonstrated a long-life non-aqueous ZAB using $\mathrm { Z n C l } _ { 2 }$ in EG with an $\mathrm { I } _ { 3 } ^ { - } / \mathrm { I } ^ { - }$ redox mediator,where $\bar { \mathrm { I } _ { 3 } }$ accelerated the decomposition of $\mathrm { Z n _ { 5 } ( O H ) _ { 8 } C l _ { 2 } }$ during charging and $\Gamma ^ { - }$ lowered the ORR overpotential during discharging，achieving enhanced kineticsand exceptional storage stability with more than $2 6 0 0 \mathrm { ~ h ~ }$ of cycling [28].

In this study,we adopted the same reaction (1） mechanism to describe the electrochemical process in our system.We selected ACN as the solvent based on transport and interfacial considerations.At ${ 2 5 } ^ { \circ } \mathrm { C } ,$ ACN has a much lower viscosity $( \boldsymbol { \eta } \approx 0 . 3 7 \ : \mathrm { c P } )$ than DMF $( \approx 0 . 8 4 ~ \mathrm { c P } )$ and DMSO $_ { ( \approx 1 . 9 9 ~ \mathrm { c P } ) }$ ,while maintainingamoderate dielectric constant (ε $\approx 3 7 – 3 8 $ ）[29,30]. Low viscosity facilitates ion transport by increasing the diffusion coefficient of $\mathrm { Z n ^ { 2 + } }$ ,thereby lowering the solution resistance and mitigating concentration polarization during operation [31]. A moderate dielectric constant ensures sufficient salt dissociation without excessively strong ion-solvent interactions,which promotes efficient $\mathrm { Z n ^ { 2 + } }$ desolvation at the cathode [3O,32]. Together, these solvent properties enable fast ion mobility and facile desolvation,both of which are essential for achieving stable $\mathrm { Z n O }$ formation and high-power density in ZABs.However,despite these achievements,technical and practical issues,such as electrolyte evaporation,limited scalability,and the maintenance of stable performance under prolonged operating conditions,have hindered the commercialization and large-scale application of ZABs [33,34].In particular,a system that can support efficient scale-up while maintaining stable long-term performance needs to be developed.Here,we demonstrate a Zn-air flow battery employing a non-aqueous ACN- $\mathrm { Z n ( C l O _ { 4 } ) _ { 2 } }$ electrolyte,which addresses the key limitations of conventional aqueous systems and provides a promising pathway toward stable and scalable energy storage (Fig.1).

# 2.2.Fabrication of electrode

The Zn electrode was fabricated on Ni mesh substrate with dimensions of $1 \times 1 ~ \mathrm { c m } ^ { 2 }$ .Prior to $\mathrm { Z n }$ deposition,the Ni mesh was thoroughly cleaned to ensure surface purity and enhanced adhesion. Subsequently, the Ni mesh was rinsed thoroughly with deionized (DI) water and subjected to an additional ultrasonication step in 6 MHCl solution for $3 0 \mathrm { { m i n } }$ to eliminate the oxide films present on the surface.After the pretreatment process,both surfaces of the Ni mesh were coated with Au utilizing an ion sputter coater (Hoyeon-Tech, Korea) at a constant current of $1 0 \mathrm { m A }$ for a duration of $1 0 \mathrm { { m i n } }$ per side. This Au layer was deposited on each side of the Ni mesh to enhance its conductivity and adhesion characteristics.Electrodeposition of dendritic Zn onto the prepared Au-coated Ni mesh was executed using an electrochemical workstation (Zennium, Zahner, Germany).Ni mesh of 2 $\times 2 \mathrm { c m } ^ { 2 }$ served as the working electrode,while a Pt plate measuring $1 \times$ $7 ~ \mathrm { c m } ^ { 2 }$ served as the counter electrode.The electrolyte solution was composed of $1 0 0 ~ \mathrm { { m L } }$ of DI water containing 0.1 M $\mathrm { Z n S O _ { 4 } }$ and $2 . 0 \ \mathrm { M }$ NaOH. Zn was electrodeposited by applying a constant potential of $- 4 \mathrm { V }$ for ${ \mathsf { 5 } } \operatorname* { m i n }$ ,resulting in a Zn plating density of approximately $1 0 \mathrm { m g } \mathrm { c m } ^ { - 2 }$ under these specified conditions.

The air cathode was fabricated using carbon paper (Sigracet 39BB,9 $\mathrm { c m } ^ { 2 \cdot }$ with an integrated microporous layer (MPL) and gas diffusion layer (GDL).For the catalytic coating,carbon black (Ketjen Black EC-60OJD, $1 8 ~ \mathrm { m g }$ ,Nafion solution( $5 \mathrm { \ w t \% }$ ,36 mg),and isopropyl alcohol (IPA,5 mL) were dispersed using a tip sonicator for $^ { 1 \mathrm { ~ h ~ } }$ to obtain a homogeneous suspension. # 3.1. Characterization of the electrode and electrolyte solvation structure

In conventional Zn-based batteries,a Zn foil is typically employed as the anode [35].However,its direct use in electrolytes is limited by its intrinsically low surface area,which restricts the number of active sites [36,37].To overcome this limitation,Zn electrodes with a dendritic morphology have been fabricated, thereby enhancing mass transport and electrical conductivity by providing a larger electrochemically active surface for Zn oxidation [38,39].For the preparation of dendritic Zn electrodes,a potential of $- 4 \mathrm { V }$ was applied to a bare Ni mesh (Fig. 2a and b).Under these conditions,Zn deposition occurred alongside the HER,resulting in the formation of a highly porous dendrite-like structure with an enlarged surface area (Fig.2c and d).In parallel,carbon paper substrates (Fig.S2a) were uniformly coated with carbon black,as shown in Fig.S2b and c.The presence of the carbon black layer further increased the density of the electroactive sites,thereby facilitating the $\mathrm { Z n O }$ reduction reaction [27].

The XRD patterns presented in Fig. S3 were used to evaluate the crystallinities of both the anode and cathode materials.The diffraction pattern of the Zn anode is shown in Fig.S3a,clearly exhibits characteristic peaks associated with the crystalline Zn structure.Specifically, the diffraction peaks were indexed to the $\mathrm { Z n } ( 0 0 2 )$ ， $\mathrm { Z n } ( 1 0 0 )$ ， $\mathrm { Z n } ( 1 0 1 )$ ,Zn (102), $\mathrm { Z n } ( 1 0 3 )$ ， $\mathrm { Z n } ( 1 1 0 )$ ，and $\mathrm { Z n } ( 0 0 4 )$ planes at 20 values of $3 6 . 5 1 ^ { \circ }$ ， $3 9 . 2 1 ^ { \circ }$ ， $4 3 . 4 3 ^ { \circ }$ ， $5 4 . 5 2 ^ { \circ }$ ， $7 0 . 2 4 ^ { \circ }$ ， $7 0 . 8 2 ^ { \circ }$ ,and $7 7 . 2 3 ^ { \circ }$ ,respectively.This peak data is consistent with the standard reference card PDF#96-901- 2436,confirming the crystalline nature of the zinc anode.In Fig. S3b, the diffraction peaks of the cathode were indexed to the C(Oo2) and C (101) planes at 20 values of $2 6 . 5 4 ^ { \circ }$ and $4 4 . 5 1 ^ { \circ }$ ,respectively.This peak data is consistent with the standard reference card PDF#96-9O1-1578.

The Raman spectra demonstrated significant alterations following the addition of $\mathrm { Z n ( C l O _ { 4 } ) _ { 2 } }$ (Fig.3a). The C-C stretching band shifted from 920.84 to $9 3 3 . 2 1 ~ \mathrm { c m } ^ { - 1 }$ $\left( + 1 2 . 3 7 ~ \mathrm { c m } ^ { - 1 } \right)$ ,reflecting strong ion-solvent interactions and redistribution of electron density,which enhances bond polarizability (Fig.3b). The $\mathrm { { C } \equiv N }$ stretching vibration showed only a minor shift from 2253.41 to $2 2 5 5 . 3 4 ~ \mathrm { c m } ^ { - 1 }$ $( + 1 . 9 3 ~ \mathrm { c m } ^ { - 1 } )$ ， consistent with the fact that Raman spectroscopy is less sensitive to dipole moment changes than IR spectroscopy (Fig.3c).Notably,a new band near $2 3 1 3 ~ \mathrm { c m } ^ { - 1 }$ was observed,which was absent in pure ACN, providing direct evidence for the coexistence of free ACN molecules and $\scriptstyle { \mathrm { Z n } } ^ { 2 + }$ -coordinated ACN species [26,4O]. This observation confirms that $\scriptstyle { \mathrm { Z n } } ^ { 2 + }$ induces the formation of a distinct coordination environment, rather thana simple uniform bond shift.

The FT-IR spectra provided complementary evidence for the $\scriptstyle { \mathrm { Z n } } ^ { 2 + }$ ACN interactions (Fig.4a). In the C-C stretching region (Fig.4b),slight peak shifts and intensity variations were observed compared with pure ACN, indicating that ${ \mathrm { Z n } } ^ { 2 + }$ coordination affects not only the $\mathrm { C } \equiv \mathrm { N }$ bond but also the C-C backbone of the ACN molecules.Although these changes are relatively subtle owing to the weak dipole activity of this mode,they still reflect the redistribution of electron density within the molecular framework.The $\mathbf { C } \equiv \mathbf { N }$ stretching band (Fig.4c) shifted from $2 2 5 3 . 4 ~ \mathrm { c m } ^ { - 1 }$ in pure ACN to $2 2 5 6 . 2 \ : \mathrm { c m } ^ { - 1 }$ in the $\mathrm { Z n ( C l O _ { 4 } ) _ { 2 } }$ -ACN $( + 2 . 8$ $\mathrm { c m } ^ { - 1 } )$ ,indicating bond stiffening and the formation of arobust solvation structure between ${ \mathrm { Z n } } ^ { 2 + }$ ions and ACN molecules [37,41]. In addition to tiite ${ \sim } 2 3 1 0 ~ \mathrm { c m } ^ { - 1 }$ consistent with the Raman observation of the $2 3 1 3 ~ \mathrm { c m } ^ { - 1 }$ band, further supporting the coexistence of free and ${ \mathrm { Z n } } ^ { 2 + }$ coordinated ACN species. Together with the Raman results,the emergence of distinct vibrational features highlights the presence of multiple coordination environments that stabilize the $\mathrm { Z n ^ { 2 + } }$ solvation shell. The more prominent shift in the Raman-active C-C mode compared to the IR-active $\mathrm { { C } \equiv N }$ mode underscores the different sensitivities of these two techniques.While the C $\equiv \mathbf { N }$ bond serves as the primary coordination site,the redistribution of electron density also affects the C-C bond.Furthermore,the weakly coordinating $\mathrm { C l O } _ { 4 } ^ { - }$ anion minimizes competition for $\mathrm { Z n ^ { 2 + } }$ ,allowing the strong ion-solvent interactions to be clearly resolved [38].This unique solvation structure of $\mathrm { Z n ^ { 2 + } }$ in the ACN-based electrolyte plays a pivotal role in determining the electrochemical performance. The strong coordination between $\scriptstyle { \mathrm { Z n } } ^ { 2 + }$ and the nitrogen atoms of ACN leads to a stable solvation sheath that effectively restricts the reactivity of the solvent and any unavoidable trace moisture.By tightly binding the $\scriptstyle { \mathrm { Z n } } ^ { 2 + }$ ions, this specific coordination environment is expected to lower the desolvation energy barrier at the electrode interface,thereby facilitating faster interfacial charge transfer [21,42]. Furthermore,the robust ${ \mathrm { Z n } } ^ { 2 + }$ -ACN interaction increases the energy barrier for potential parasitic reactions, such as solvent decomposition or hydrogen evolution from trace water. This 'weakly-solvating' characteristic is essential for ensuring long-term electrochemical integrity,providing a mechanistic rationale for the high stability and efficiency observed in the subsequent battery performance tests [43].

# 3.2. Coin cell testing and performance evaluation

Prior to flow cell testing,we tested the electrolyte in a conventional rechargeable $\mathrm { Z n }$ -air coin cell (CR2032) at room temperature.Galvanostatic cycling was performed using the air-breathing cathode described above and a Zn foil anode with a glass fiber separator (GF/A) soaked in $1 \mathrm { M Z n } ( \mathrm { C l O } _ { 4 } ) _ { 2 }$ in ACN and $\begin{array} { r } { { 1 } \mathbf { M } \mathbf { Z n } ( \mathbf { B } \mathbf { F } _ { 4 } ) _ { 2 } } \end{array}$ electrolyte. To assess durability, we evaluated the voltage gap $( \Delta \mathsf { V } )$ ,which is defined as the difference between the terminal charge voltage at the end of a cycle and the onset of the discharge plateau at the same current density (Fig. 5a). At $0 . 1 \mathrm { m A }$ $\mathrm { c m } ^ { - 2 }$ ,the $\mathrm { Z n ( C l O _ { 4 } ) _ { 2 } }$ -ACN cell exhibited a low △Vof $0 . 9 2 \mathrm { V }$ Increasing the current density to 0.2 and $0 . 5 \operatorname { m A } \mathrm { c m } ^ { - 2 }$ resulted in△V values of 0.94 and $1 . 1 7 \mathrm { ~ V ~ } _ { : }$ ，respectively,indicating onlya modest increase in kinetic polarization over this range.The smooth charge/discharge profiles without abnormal voltage excursions further suggest that the electrolyte remained chemically stable under these operating conditions.For comparison,a $\mathrm { Z n } ( \mathrm { B F } _ { 4 } ) _ { 2 }$ -ACN electrolyte was evaluated under identical coin cell conditions (Fig.5a). In contrast to the $\mathrm { Z n ( C l O _ { 4 } ) _ { 2 } }$ -based system, the $\mathrm { Z n ( B F _ { 4 } ) _ { 2 } }$ electrolyte exhibited a larger voltage gap and significantly increased polarization with increasing current density. The chargedischarge plateaus became progressively unstable at higher currents, indicating inferior interfacial kinetics and reduced tolerance to high-rate operation.Fig.5b-d shows the long-term cycling stability of the Zn-air coin cell. The test was conducted at a constant current density of 0.1 $\mathbf { m A c m } ^ { - 2 }$ and a limited capacity of $0 . 1 \mathrm { m A h } \mathrm { c m } ^ { - 2 }$ per cycle. Under these conditions, the cell operated consistently for over $3 6 0 \mathrm { ~ h ~ }$ ,corresponding to 180 charge-discharge cycles.Such extended cycling is a stringent measure of electrolyte robustness,as even small amounts of parasitic side reactions,electrolyte decomposition,or electrode degradation would typically lead to progressive changes in polarization or premature failure.Throughout the entire cycling period,△V remained nearly constant,resembling the behavior observed in the initial cycles.This constancy demonstrates that kinetic polarization did not accumulate over time,which is indicative of a chemically and electrochemically stable electrolyte environment.In contrast, the $\mathrm { Z n ( B F _ { 4 } ) _ { 2 } }$ -based cell exhibited severe voltage fluctuations and premature failure after approximately $^ \mathrm { ~ 1 0 0 ~ h ~ }$ of cycling. Such rapid degradation suggests accelerated parasitic reactions and an unstable $\mathtt { Z n }$ /electrolyte interface, which hinders sustained reversible cycling.

Importantly,the voltage profiles in Fig.5c show smooth and repetitive charge-discharge curves without signs of increasing overpotential, sudden voltage drops,or irregular oscillations,all of which indicate side reactions such as hydrogen evolution or $\mathrm { Z n }$ corrosion [32,47]. Instead, the voltage profiles exhibited highly reproducible characteristics from cycleto cycle, confirming the steady-state operation ofthe Zn-electrolyte interface.

By comparison，the $\mathrm { Z n } ( \mathrm { B F } _ { 4 } ) _ { 2 }$ electrolyte displayed pronounced voltage hysteresis and irregular charge-discharge behavior during the initial cycling stage.These fluctuations reflect non-steady-state interfacial reactions and insufficient stabilization of the Zn plating/stripping process.

A closer examination of the cycling curves (Fig.5d) further highlights the reproducibility of the system over 18O cycles.Excluding the initial activation cycle,the charge and discharge potentials exhibited significant overlap across the representative cycles,indicating that the Zn plating/stripping process demonstrated high reversibility in the ACNbased medium.Taken together,the long-term cycling results in Fig.5b-d confirm that the $\mathrm { Z n ( C l O _ { 4 } ) _ { 2 } }$ -ACN electrolyte not only supports low polarization at short timescales but also maintains its electrochemical integrity over an extended period.This endurance underscores its suitability for further testing in flow cell structure,where continuous operation and electrolyte circulation place even greater demands on stability.

To clarify the electrochemical origin of the distinct cycling behaviors,EIS was conducted for coin cells employing $\mathrm { Z n ( C l O _ { 4 } ) _ { 2 } }$ -ACN and $\mathtt { Z n }$ $\mathrm { ( B F _ { 4 } ) _ { 2 } }$ -ACN electrolytes under identical initial coin cell conditions prior to long-term cycling (Fig. S6). The $\mathrm { Z n ( C l O _ { 4 } ) _ { 2 } }$ -ACN electrolyte exhibited a relatively low $\mathrm { R } _ { s }$ and a small $\mathrm { R } _ { \mathrm { c t } } ,$ indicating favorable ionic transport and facile $\mathrm { Z n } ^ { 2 + } / \mathrm { Z n }$ interfacial kinetics at the pristine $\mathrm { Z n }$ -electrolyte interface.

In contrast, the $\mathrm { Z n ( B F _ { 4 } ) _ { 2 } }$ -ACN electrolyte showed substantially higher resistance values,with $\ R _ { s } = 6 6 . 5 \ \Omega$ and $\mathrm { R _ { c t } } = 1 5 5 \Omega$ ，reflecting intrinsically hindered charge-transfer processes at the Zn/electrolyte interface (Table S2).The markedly larger $\operatorname { R } _ { \operatorname { c t } }$ is consistent with the increased polarization and voltage instability observed during galvanostatic cycling.

These results demonstrate that the inferior cycling stability of the Zn $( \mathrm { B F } _ { 4 } ) _ { 2 }$ -ACN system originates from less favorable initial interfacial kinetics，whereas the $\mathrm { Z n ( C l O _ { 4 } ) _ { 2 } }$ -ACN electrolyte providesa more conductive and kinetically favorable interfacial environment from the outset.

Following the long-term stability test,EIS analysis revealed distinct changes in the resistance components (Fig.S7). The $\mathrm { R } _ { s }$ increased from 1.84 to $1 1 . 1 \Omega$ ,which was primarily attributed to the evaporation of the volatile ACN solvent during the extended $3 6 0 \ \mathrm { h }$ operation in a nonsealed coin cell. This solvent loss leads to an increase in electrolyte viscosity and salt concentration,subsequently reducing the bulk ionic conductivity-a trend consistent with our concentration-dependent conductivity study (Fig. S4).

In contrast, the $\operatorname { R } _ { \operatorname { c t } }$ significantly decreased from 248.7 to $3 6 . 8 \ \Omega$ ， reflecting an 'activation' or 'conditioning' effectat the electrode interface.This reduction in $\operatorname { R } _ { \operatorname { c t } }$ is likely due to improved electrolyte wetting of the porous carbon cathode and enhanced $\mathrm { Z n ^ { 2 + } }$ transport kinetics through the matured interfacial layer.Furthermore,the continuous plating and stripping process facilitates the formation of a stable Zn interphase,effectively suppressing the formation of insulating passivation layers.These results highlight the efficiency of the $\mathrm { Z n ( C l O _ { 4 } ) _ { 2 ^ { - } } A C N }$ system in maintaining high electrochemical reactivity and interfacial stability over extended cycling.

To verify the reversible reaction mechanism,FESEM and EDS analyses were performed (Fig. S8). Upon discharge,a film-like $\mathrm { Z n O }$ layer was observed on the cathode surface (Fig.S8a-c),as confirmed by EDs analysis (Fig.S8d).After subsequent recharging, this surface layer was effectively decomposed, restoring the original porous structure of the carbon cathode (Fig.S8e-h).This reversible process provides direct evidence for the mechanism in reaction (1).

Also we checked anode to further elucidate the origin of the pronounced performance difference between the two electrolytes,the morphology of the Zn anodes after cycling was examined by FESEM (Fig.S9).The pristine Zn electrode exhibited a relatively smooth surface prior to cycling.After prolonged cycling in the $\mathrm { Z n ( C l O _ { 4 } ) _ { 2 } }$ -ACN electrolyte,the Zn anode largely retained its original morphology,showing no evidence of severe corrosion,dendrite growth,or insulating byproduct accumulation. This morphological stability indicates effective suppression of parasitic reactions,particularly the hydrogen evolution reaction typically encountered in aqueous electrolytes,and is fully consistent with the stable $\Delta \mathsf { V }$ and highly reproducible cycling behavior observed in

# Fig. 5 [37,48].

In contrast, the Zn anode cycled in the $\mathrm { Z n ( B F _ { 4 } ) _ { 2 } }$ -ACN electrolyte exhibited pronounced surface degradation,indicative of non-uniform Zn stripping/plating and unstable interfacial reactions.These morphological features provide direct physical evidence that the superior cycling stability of the $\mathrm { Z n ( C l O _ { 4 } ) _ { 2 } }$ -ACN electrolyte originates from its enhanced ability to stabilize the Zn-electrolyte interface.

# 3.3. Flow cell performance test

Next,we evaluated whether the $\mathrm { Z n ( C l O _ { 4 } ) _ { 2 ^ { - } } A C N }$ electrolyte could sustain operation under more practical high-current conditions relevant to large-capacity and commercial energy storage applications. The coin cell configuration shown in Fig.6a is suitable for probing the fundamental electrochemical stability and Zn plating/stripping reversibility; however,its air-breathing cathode inherently relies on passive oxygen diffusion through the gas-diffusion layer.Consequently，coin cells cannot adequately represent the mass-transport environment encountered in real devices,particularlywhen the current density is increased. Indeed,as the applied current was increased from 1 to $1 0 \mathrm { m A } \mathrm { c m } ^ { - 2 }$ ,the coin cell exhibited increasing voltage fluctuations and unstable discharge plateaus,reflecting the limitations associated with oxygen availability and the static cell design.In contrast, the flow cell configuration (Fig.6b) enabled continuous circulation of the liquid anolyte and forced $\mathrm { O } _ { 2 }$ feedingat controlled flowrates,thereby mimicking more realistic and scalable battery conditions.Under identical current steps, the flow cell maintained significantly more stable voltage profiles than the coin cell,even at the highest current density tested.This result demonstrates that the combination of active gas supply and electrolyte flow is critical for sustaining high-rate operations [49-51].More importantly,it highlights that the ACN-based electrolyte is not only chemically and electrochemically stable at the laboratory scale,butalso compatible with practical flow architectures that demand higher current densities.Therefore,the flow cell serves as a more appropriate platform for evaluating long-term durability and power performance under application-relevant operating conditions,which we investigate in the following sections.

# 3.4. Power density and polarization analysis

Polarization and power density curves were obtained to optimize the gas-liquid reactant delivery conditions.With the anolyte flow fixed at $1 0 ~ \mathrm { m L } \mathrm { m i n } ^ { - 1 }$ ,increasing the $\mathrm { O } _ { 2 }$ flow from 5 to $1 0 \ s c c \mathbf { m }$ increased the maximum power density from 22.797 to $3 8 . 4 3 7 ~ \mathrm { m W ~ c m } ^ { - 2 }$ ,whereasa further increase to $2 0 \ s { \mathrm { c c m } }$ yielded a similar value of $3 7 . 1 5 4 \mathrm { ~ m W ~ c m } ^ { - 2 }$ (Fig.7a).The observed near-plateau beyond $1 0 \ s { \mathrm { c c m } }$ suggests that oxygen transport was no longer the rate-limiting factor,and the system performance was instead determined by processes occurring on the anolyte side.To probe the anolyte contribution, the $\mathrm { O } _ { 2 }$ flow was maintained at $1 0 \ s c c \mathrm { { c m } }$ ,whereas the anolyte flow was varied to 10,15,and 20 mL $\operatorname* { m i n } ^ { - 1 }$ (Fig.7b). The peak power density showed a single-peak response of 38.437,53.291,and $4 9 . 0 9 0 \ \mathrm { m W \ c m ^ { - 2 } }$ ,indicating a balance between improved reactant replenishment and wetting (from 10 to $1 5 \mathrm { m L } \mathrm { m i n } ^ { - 1 }$ and the diminishing benefits at higher flow rates ( $2 0 ~ \mathrm { m L }$ $\operatorname* { m i n } ^ { - 1 }$ ,where reduced residence time and increased hydraulic losses hinder effective conversion. Taken together,these results identify $\mathrm { O } _ { 2 }$ flow of $1 0 \ s c { \mathrm { c m } }$ and anolyte flow of $1 5 \ \mathrm { m L } \ \mathrm { m i n } ^ { - 1 }$ as the optimum operating rate,delivering $5 3 . 2 9 1 ~ \mathrm { m W } \mathrm { c m } ^ { - 2 }$ power density. Beyond this point, increasing $\mathrm { O } _ { 2 }$ does not improve output because the limitation shifts to the anolyte side,while an excessively high anolyte flow reduces utilization by curtailing the residence time.Practically,co-tuning the gas and liquid flows within this window minimizes the mass transfer overpotential while preserving sufficient reaction time at the electrodes. Toassess the role of cathode catalysis,the carbon black cathode was replaced with a commercial Pt/C( $( 4 0 \mathrm { w t \% } )$ layer $( 1 . 0 \mathrm { m g } \mathrm { c m } ^ { - 2 } )$ ,and the cell power density was evaluated under the same operating conditions Ceig:10).Themaximum powerdensityreached $5 2 . 6 5 2 \mathrm { \ m W \ c m } ^ { - 2 }$ which is comparable to that obtained with our non-noble catalyst, indicating no measurable performance benefit from the use of $\mathrm { P t } / \mathrm { C }$ in this reaction. Given the lack of catalytic advantages and the substantially higher material costs, these results underscore the costeffectiveness of the proposed catalyst system.

# 3.5.Long term stability and cycling performance of the flow battery

To investigate the long-term stability of the flow system,long-term cycling was evaluated in a flow cell setup using the operating parameters optimized above.The $\mathrm { O } _ { 2 }$ flowrate was fixed at $1 0 \ s c c \mathbf { m }$ ,and the anolyte flow rate was maintained at $1 5 \mathrm { m L } \mathrm { m i n } ^ { - 1 }$ . As shown in Fig. 8a, the $\mathtt { Z n }$ -air flow cell sustained a stable charge-discharge operation for approximately $^ { 2 0 0 \mathrm { ~ h ~ } }$ at a constant current density of $1 \ \mathrm { m A } \ \mathrm { c m } ^ { - 2 }$ demonstrating that the $\mathrm { Z n ( C l O _ { 4 } ) _ { 2 } }$ -ACN electrolyte is durable under continuous operation.A magnified view of the initial $^ { 5 0 \mathrm { ~ h ~ } }$ (Fig.8b) shows smooth and reproducible galvanostatic profiles without abnormal voltage fluctuations or irregular polarization growth,suggesting that a stable Zn-electrolyte interface was established from the beginning of cycling.

The charge-discharge data were further analyzed in terms of coulombic and energy efficiencies (Fig.8c). The coulombic efficiency is ${ \sim } 9 9 . 8 7 ~ \%$ throughout 1oo cycles,confirming the highly reversible Zn plating/stripping process in the ACN-based electrolyte.Although a temporary decrease in coulombic efficiency was observed at certain cycles,the efficiency quickly recovered,which was attributed to transient fluctuations in the $\mathrm { O } _ { 2 }$ supply when the gas flow was occasionally hindered by anolyte circulation in the flow system.In contrast, the energy efficiency was lower and exhibited moderate fluctuations, primarily reflecting the voltage gap between the charge and discharge imposed by kinetic polarization.Nevertheless,the nearly ideal coulombic efficiency underscores that parasitic reactions,such as hydrogen evolution or Zn corrosion, were effectively suppressed during prolonged cycling.

# 4.Conclusion

In this study,we demonstrated a rechargeable zinc-air flow battery employing a non-aqueous $\mathrm { Z n ( C l O _ { 4 } ) _ { 2 } }$ -acetonitrile electrolyte.The dendritic Zn anode and carbon-based air cathode enabled efficient charge transfer and stable electrochemical interfaces.Spectroscopic analysis revealed strong $\scriptstyle { \mathrm { Z n } } ^ { 2 + }$ ACN interactions,suggesting the formation of a stable solvation structure that can suppress parasitic side reactions and enhance interfacial stability during electrochemical operations.The electrolyte exhibited high reversibility in coin cell testing with stable cycling over $3 6 0 \mathrm { h }$ ,and the flow battery achieved a peak power density of $5 3 . 3 \mathrm { m W } \mathrm { c m } ^ { - 2 }$ under optimized operating conditions. These findings collectively demonstrate that the robust $\scriptstyle { \mathrm { Z n } } ^ { 2 + }$ -ACN solvation structure successfully suppresses parasitic reactions like hydrogen evolution, confirming the system's durability with stable operation over $^ { 2 0 0 \mathrm { h } }$ and a nearly ideal coulombic efficiency.This robust performance highlights the potential of acetonitrile-based electrolytes to provide a scalable and promising pathway for next-generation $\mathrm { Z n }$ -air flow battery technology.
