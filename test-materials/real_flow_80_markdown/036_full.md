Highlyactive single-atom electrocatalysts can effectively enhance the power density of vanadium flow bateries by forming hybrid orbitals between metal atoms and heteroatoms.However,the mechanism through which hybrid orbitals boost the activity of vanadium ions remains unclear.Herein,we report the Bi single atoms electrocatalysts (XBi, $X = N _ { ; }$ P,S,B) with different heteroatoms coordination,while catalytic activity towards [V $\mathrm { ( H _ { 2 } O ) _ { 6 } J ^ { 3 + } / [ V ( H _ { 2 } O ) _ { 6 } ] ^ { 2 + } i }$ sproved to be $\mathrm { N B i { > } P B i { > } S B i { > } B B i }$ .The results demonstrated that PBi, SBi,and BBi display the electron cloud distributions of Bi atoms near the fermi level towards the planar direction $( \mathsf { p } _ { \mathrm { { x } } } , \mathsf { p } _ { \mathrm { { y } } } )$ ， while NBi exhibits an axial orbital $\left( \mathtt { p } _ { \mathtt { Z } } \right)$ distribution and a more pronounced Bi-N p-orbital hybridization due to the high electronegativityof N,thereby promoting vanadium ion dehydration.In consequence,a VFB single cell equipped with NBi decorated graphite felt (GF)electrode demonstrates the most superior batery performance among all fabricated electrodes,achieving a $7 \%$ increase in energy efficiency at a current density of $2 4 0 ~ \mathrm { \ m A }$ $\mathrm { c m } ^ { - 2 }$ compared to the BBi-loaded counterpart. # 1．Introduction

Vanadium flow batteries (VFBs) have garnered significant attention in large-scale energy storage due to their high safety,efficiency,and stability [1-3].However, the low reaction rate of vanadium ions at the electrode interface results ina low power density and further high stack costs (\$400-600 per kW accounts for $2 5 \mathrm { - } 4 0 \%$ of the system capital cost) [4,5].Therefore,it's imperative to develop highly active electrocatalysts to improve the power density of VFBs.

Single-atom electrocatalysts,due to their high atomic utilization, well-defined active sites,and stable electronic structure,have been proven effective in the field of vanadium flow batteries [6-8].Not only they can effectively promote the dehydration of vanadium ions through forming hybrid orbital by the central metal atom and surrounding heteroatoms,but also enhance the stability of metal atoms,avoiding their deposition and dissolution[7-11].The introduction of heteroatoms with varying electronegativity into the first shell layer of metal atoms can effectively regulate the electron cloud distribution of central metal atoms,therebyachievingarelatively excellent electrocatalytic effect [12-19]. Single-atom catalysts have recently been introduced into VFBs, yet their potential in modulating hybrid orbital configurations remains underexplored[7-9].Regulating these configurations is expected to effectively improve the redox kinetics toward vanadium ions.Therefore, the structure-activity relationship between specific orbital hybridization and catalystic activity towards vanadium ions still need to be systematically explored.

Herein,we report Bi single-atom electrocatalysts with different heteroatom coordination (XBi, $X = N _ { : }$ ,P,S,B) onto carbon nanosheets with a honeycomb-array structure.Utilizing electronegativity of heteroatoms to reasonably regulate the axial $\left( \mathfrak { p } _ { \mathtt { Z } } \right)$ electron cloud distribution of Bi atoms,thereby effectively promoting the dehydration of vanadium ions (Fig.1).Their catalytic activity towards $\mathrm { [ V ( H _ { 2 } O ) _ { 6 } ] ^ { 3 + } / [ V }$ $\mathrm { ( H _ { 2 } O ) _ { 6 } ] ^ { 2 + } i s }$ proved to be $\mathrm { N B i { > } P B i { > } S B i { > } B B i }$ .The electrochemical insitu characterization combined theoretical calculations revealed that PBi,SBi,and BBi display the electron cloud distributions of Bi atoms near the fermi level towards the planar direction $( \mathfrak { p } _ { \mathrm { { x } } } , \mathfrak { p } _ { \mathrm { { y } } } )$ ，while NBi exhibits an axial orbital $\left( \mathfrak { p } _ { \mathtt { Z } } \right)$ distribution due to the high electronegativity of N, thereby promoting vanadium ion dehydration.Additionally, the NBi exhibits a more pronounced Bi-N p-orbital hybridization,with N-dominated empty orbitals facilitating vanadium ion adsorption and

Bi-dominated occupied orbitals enhancing dehydration and charge transfer.As a result,a VFB single cell assembled with NBi decorated graphite felt (GF) electrode delivers the most superior battery performance among all fabricated electrodes,achieving a $7 \%$ increase in energy efficiency at a current density of $2 4 0 \ \mathrm { m A } \ \mathrm { c m } ^ { - 2 }$ and a $2 1 8 ~ \mathrm { m W }$ $\mathrm { c m } ^ { - \bar { 2 } }$ increase in peak power density compared to the BBi-loaded counterpart. Moreover, the VFB single cell can run stably for 1000 cycles at $2 4 0 \mathrm { \ m A \ c m ^ { - 2 } }$ without obvious performance degradation. This work highlights the crucial role of heteroatoms and provides valuable insights into hybrid orbitals design for single-atom catalysts in VFBs.

# 2．Results and discussion

# 2.1．Synthesis and structure of XBi

The NBi modified graphite felt electrode $( \mathrm { N B i @ G F } )$ was synthesized through a carbonization-adsorption-annealing strategy (Fig.1).Firstly, the heteroatom-free honeycomb-arrayed carbon nanomaterial loaded on GF electrode was synthesized using sodium citrate as the precursor. Subsequently,Bi and N atoms are anchored on it via adsorption from a mixed solution of $\mathrm { B i } ^ { 3 + }$ and dicyandiamide,followed by an annealing treatment.The obtained $\mathrm { N B i @ G F }$ shows regular carbon nanosheets with a honeycomb-like array structure,featuring an inner diameter of approximately $5 0 0 \ \mathrm { n m }$ (Fig.2a).High-resolution transmission electron microscopy (HRTEM) reveals that only the (Oo2) crystal plane of carbon with an interlayer distance of $0 . 3 4 \mathrm { n m }$ appears in NBi,without metalic Bi nanoparticles (Fig.2b).This is consistent with the XRD results for NBi,which show only two broad reflections at approximately $2 6 ^ { \circ }$ and $4 4 ^ { \circ }$ ，corresponding to the(Oo2）and(1o1） crystal planes of carbon (Fig.S1).The aberration-corrected high-angle annular dark-field scanning transmission electron microscopy (HAADF-STEM) clearly reveals isolated bright spots distributed on the carbon support surface (Fig.2c). Energy dispersive spectroscopy (EDS)analysis reveals the distribution of Bi,N,and C elements on the carbon substrate,which verifies the successful loading of N-doped Bi single atoms onto the carbon support (Figure S2). Using the same preparation method,only dicyandiamide was replaced byphytic acid,sulfur,and boric acid,and the PBi, SBi,and BBi electrocatalysts were successfully prepared.All these catalysts exhibit carbon nanomaterials with a honeycomb-like array structure of similar size,the results also show the successful loading of P-doped, Sdoped,and B-doped Bi single atoms on the carbon substrate (Fig.S3).

To further investigate the impact of heteroatom doping on the structure of the carbon support, XRD,Raman,and BET analyses were conducted. The XRD results indicate that all Bi single-atom electrocatalysts doped with different heteroatoms display two carbon diffraction peaks at approximately $2 6 ^ { \circ }$ and $4 4 ^ { \circ }$ ,with similar peak intensities across the samples (Fig.S1). Raman spectroscopy reveals similar $\mathrm { I _ { D } / I _ { G } }$ ratios,indicating that the introduction of different heteroatoms does not have a significant effect on the graphitization and disorder degree of the carbon support (Fig.2d).BET analysis further confirms that Bi singleatom electrocatalysts doped with various heteroatoms exhibit minimal changes in specific surface area and pore structure (Fig.S4 and Table S1). Overall, doping with different heteroatoms does not result in significant changes to the structure of the carbon support.Moreover, inductively coupled plasma mass spectrometry (ICP-MS) analysis showed that the four samples have similar Bi atomic loading amounts (Table S2).

X-ray absorption near edge structure (XANES) and extended X-ray absorption fine structure (EXAFS) spectra were used to analyze the chemical environments of Bi atoms in the synthesized samples.As depicted in Fig.2e,the edge positions of BiL3-edge forNBi,PBi, SBi,and BBi almost overlap each other and lie in the middle of Bi foil and $\mathbf { B i } _ { 2 } \mathbf { O } _ { 3 } ,$ ， indicating the same valence of Bi that is between O and $+ 3$ $\mathbf { B i } ^ { \delta + }$ ， $0 < \delta <$ 3).In the EXAFS spectra (Fig.2f),all samples show a distinct characteristic peak around $1 . 7 \mathrm { ~ \AA ~ }$ ，which is primarily attributed to the Bi-X coordination bond $( X = N$ ，P,S,B).Additionally,the absence of a characteristic peak for Bi-Bi coordination at $3 . 1 \mathrm { ~ \AA ~ }$ rules out the formation of Bi nanoparticles,further confirming the atomic dispersion of isolated Bi atoms.According to the fittng results (Fig. S5 and Table S3), the average coordination number of Bi-N in NBi,Bi-P in PBi,Bi-S in SBi, and Bi-B in BBi are determined to be 3.86,2.38,2.22,and 3.52, respectively,indicating that their coordination structures are Bi- $\mathbf { \cdot N _ { 4 } }$ ,Bi-$\mathrm { P } _ { 2 }$ Bi $. s _ { 2 } ,$ andBi ${ \bf \cdot B } _ { 4 }$ .EXAFS wavelet transform (WT) analysis suggests a similar Bi-X coordination at around $4 . 8 \mathring { A } ^ { - 1 }$ in four samples (Fig. S6), excluding the contribution of Bi-Bi coordination (9.1 $\mathring { A } ^ { - 1 }$ )，which further verified that Bi atoms mainly exist as an atomic-level dispersion center.

# 2.2.Electrocatalytic activity of XBi

The electrocatalytic activity of XBi for the $\mathrm { V } ^ { 3 + } / \mathrm { V } ^ { 2 + }$ redox reaction was evaluated by cyclic voltammetry (CV). Compared to PBi, SBi,and

BBi (Fig.3a and Table S4),the NBi displays the highest anodic and cathodic peak current $( I _ { \mathrm { p a } } = 1 2 . 2 7 \ : \mathrm { m A }$ ， $I _ { \mathrm { p c } } = - 1 3 . 0 4 \ : \mathrm { m A } )$ as well as the lowest peak potential separation $( \Delta E _ { \mathrm { p } } = 1 1 2 ~ \mathrm { m V } )$ at $5 ~ \mathrm { m V } ~ s ^ { - 1 }$ . Especially,the NBi,PBi,and SBi demonstrate significantly enhanced electrochemical activity for the reduction of $\mathrm { V } ^ { 3 + } / \mathrm { V } ^ { 2 + }$ compared to BBi. To further explore the mass transfer behavior and reaction kinetics of XBi, the variable scan rate CV of $\mathrm { V } ^ { 3 + } / \mathrm { V } ^ { 2 + }$ was performed. According to the Randles-Sevcik equation (Eq.S1) [22,23],a higher slope indicates a fastermass transfer process.The calculated diffusion coefficients $( D )$ for the XBi toward the $\mathrm { V } ^ { 3 + } / \mathrm { V } ^ { 2 + }$ redox reaction are in the order of $\mathrm { N B i > P } .$ $\mathbf { B i } { > } \mathbf { S B i } { > } \mathbf { B B i }$ (Fig.3b,S9,and Table S5),implying that NBi is more favorable for the adsorption of $\mathrm { V } ^ { 3 + } / \mathrm { V } ^ { 2 + }$ .Moreover,compared to PBi, SBi, and BBi (Fig.S9-10, Table S5,and Eq.S2)[22-24],NBi demonstrates the highest reaction rate constant $( k , 1 . 4 3 \times 1 0 ^ { - 2 } \mathrm { c m } s ^ { - 1 }$ ， $8 . 2 2 \times 1 0 ^ { - 3 }$ $\mathrm { c m } s ^ { - 1 } \mathrm { \ : }$ ,highlighting its superior ability to facilitate the charge transfer process for the redox reaction of $\mathrm { V } ^ { 3 + } / \mathrm { V } ^ { 2 + }$ . In addition, NBi shows a lower Tafel slope,charge transfer resistance,and limited diffusion resistance (Fig.S11 and Table S6) [8,2O],further confirming its excellent electrocatalytic activity. In summary,the incorporation of heteroatoms, particularly N atoms,can enhance both the adsorption and charge transfer of vanadium ions.

# 2.3.Reaction mechanism of XBi

To gain a deeper understanding of reaction mechanism in different catalysts toward vanadium ions,the electrochemical in-situ attenuated total reflection-infrared spectroscopy (ATR-IR) under various potentials was performed. The $\mathrm { O - H }$ peak at $3 2 2 1 ~ \mathrm { { c m } ^ { - 1 } }$ for NBi exhibits a more pronounced increase,while other peaks at 748,838,and $8 7 8 \mathrm { c m } ^ { - 1 }$ show slight peak increase during the reaction process (Fig.3c-d), indicating that the accumulation of water that can be related to the dehydration of vanadium ions[8,25-27]. During the oxidation reaction for $\dot { \mathsf { V } } ^ { 3 + } / \mathsf { V } ^ { 2 + }$ of NBi (Fig.3c), the O—H peak intensity rises progressively with increasing potential from $^ { - 1 . 1 }$ to $0 \mathrm { V }$ ,possibly driven by vanadium ion desolvation [8,10,11].And the two characteristic peaks of V-O-S at $7 4 8 ~ \mathrm { c m } ^ { - 1 }$ and S-O at $8 3 8 ~ \mathrm { c m } ^ { - 1 }$ show analogous changes, demonstrating that $S O _ { 4 } { } ^ { 2 - }$ participates in the reaction and forms a new coordination bond with vanadium ions after their desolvation[27,28].Conversely,the S-OH peak at $8 7 8 ~ \mathrm { c m } ^ { - 1 }$ originated from $\mathrm { H S O _ { 4 } ^ { - } }$ emerges and intensifies while the S-O peak weakens (Fig.3d),demonstrating the $\mathrm { H S O } _ { 4 } ^ { - }$ participates in the reduction reaction.In summary,vanadium ion desolvation was speculated to serve as the rate-limiting step,occurring before charge transfer,followed by the participation of $\mathrm { H S O _ { 4 } ^ { - } }$ or $S O _ { 4 } { } ^ { 2 - }$ in the electrochemical reaction.

The PBi,SBi,and BBi also displayed similar trends in ATR-IR during electrochemical processes (Fig.3e-f and S12).Notably, the variation in $\mathrm { O - H }$ vibrational peak intensity follows the order $\mathrm { N B i { > } P B { > } S B i { > } B B i }$ ， which closely correlates with their electrochemical activity.Moreover, since the changes in $\mathrm { O - H }$ vibrational intensity vary among the four catalysts under the same electric field,and combined with previous studies [8,9],the possibility that the enhancement of the $\mathrm { O - H }$ vibrational peak arises from proton adsorption can be excluded.The minimal $\mathrm { O - H }$ peak change observed in BBi directly correlates with its inferior catalytic performance in the reduction reaction.

# 2.4. Theoretical calculations analysis

The theoretical calculations were adopted to analyze the effect in the electronic properties of Bi atoms induced by heteroatoms and its mechanistic correlation with the electrocatalytic activity toward vanadium ions.Prior to this investigation,we conducted geometric optimization of the Bi-P4 and Bi-S4 structures,revealing significant lattice distortions due to the large atomic radius of Pand S(Fig.S13).Based on combined XAs fitting results,we subsequently identified Bi $\mathbf { \nabla } \cdot \mathrm { N } _ { 4 }$ Bi $\mathbf { \cdot P } _ { 2 }$ ,Bi-$\mathbf { S } _ { 2 } ,$ ${ \tt B i - B _ { 4 } }$ as the optimal configurations for further computational investigations.As shown in Fig.4a and S14,the charge distribution patterns of the above four composites exhibit symmetric characteristics for charge distributions around the Bi sites.And the electron density distribution on Bi surfaces demonstrates pronounced dopant-dependent behavior due to the high electronegativity of heteroatoms.The Bi sites of NBi exhibit a pronounced loss of electron density,marked by the extensive blue regions,whereas the Bi sites coordinated by P,S,and B are predominantly characterized by yellow regions,reflectinga higher degree of electron localization.This can also be furtherillustrated by the Bader charge results (Table S7),the Bi of NBi lost more electrons (1.56 $\mathbf { e ^ { - } }$ due to the strongest electronegativity than that of PBi, SBi,and BBi. This enhanced electron depletion increases the Lewis acidity of Bi, thereby promoting the adsorption of $\mathrm { V } ^ { 3 + } / \mathrm { V } ^ { 2 + }$ species.This indicates that the interaction between N and Bi is stronger,which can result in a stronger electron delocalization effect of Bi atom and easier interaction with vanadium ions[8,29].

The models of adsorption configuration $\mathrm { { ( [ V ( H _ { 2 } O ) _ { 6 } ] } ^ { 3 + } }$ ， $\mathrm { [ V ( H _ { 2 } O ) _ { 5 } ] } ^ { 3 + } )$ on different catalysts were established to further analyze the dehydration process (Figs.4b and S15),the valence states of vanadium ions were regulated through $\mathrm { H S O } _ { 4 } ^ { - }$ and $S O _ { 4 } ^ { 2 - }$ to ensure accuracy.The calculated dehydration free energy barriers reveals that NBi exhibits the lowest energy barrier $( - 0 . 3 2 \ \mathrm { \ e V } )$ among NBi,PBi,SBi,and BBi systems (Fig.4c),indicating that the NBi can more easily promote the dehydration of vanadium ions.

Density of states (DOS) analysis was employed to elucidate the influence of heteroatoms on hybridized orbitals of Bi atoms and explored the inherent advantages of catalysts on promoting vanadium dehydration. As shown in Fig.4d, the $\mathbf { p _ { z } }$ orbital of Bi in NBi exhibits a dominant peak near the Fermi level,which facilitates the adsorption and activation of $\mathrm { [ V ( H _ { 2 } O ) _ { 6 } ] ^ { 3 + } / [ V ( H _ { 2 } O ) _ { 6 } ] ^ { 2 + } }$ ，thereby promoting the dehydration of vanadium ions[29-33]. In PBi, SBi,and BBi (Fig. $\scriptstyle 4 \mathbf { e } - \mathbf { g } )$ ,the $\mathtt { p _ { x } }$ and $\mathtt { p _ { y } }$ orbitals of Bi dominate the DOS,indicating that the electron distribution of Bi is primarily localized within the catalyst plane.This spatial confinement may weaken the interaction with vanadium ions and hinder their electrochemical activity[16,29].

Moreover,compared with PBi and SBi, the NBi and BBi show more pronounced spin polarization,as revealed by the total density of states analysis (Fig.4h and S16).In the NBi system, the Bi $\mathbf { p _ { z } }$ orbital exhibitsa high electron density in the occupied states,while the $\mathbf { p _ { X } }$ orbital of $_ \mathrm { N }$ forms a chemical bond with Bi and contributes to the unoccupied $\mathbf { p _ { X } }$ and $\mathtt { p _ { z } }$ hybrid orbitals.This orbital configuration increases the number of unpaired electrons,inducing more pronounced spin polarization. Consequently,the active site becomes coordinatively unsaturated, which is favorable for the adsorption and activation of $\mathrm { \Delta [ \dot { V } ( H _ { 2 } O ) _ { 6 } ] ^ { 3 + } / [ V }$ $\mathrm { ( H _ { 2 } O ) _ { 6 } } ] ^ { 2 + }$ . The electron occupation peak near the Fermi level is primarily dominated by B in BBi, it hinders both the dehydration of vanadium ions and the subsequent electron transfer process due to the relatively weak electronegativity of B.In contrast, the NBi exhibits significant Bi contribution near the Fermi level,with the DOS distribution of Bi spanning the entire energy range, suggesting a pronounced hybridization effect between Bi and N atoms,leading to higher electron delocolization and facilitating electron transfer[34,35].The empty orbitals are primarily contributed by N,facilitating the adsorption of vanadium ions intermediates.And the electron-occupied states below the Fermi level are dominated by Bi,promoting the dehydration process and the valence state transition.In the S- and P-coordinated systems, no significant spin polarization is observed,and the peaks of DOS remain largely symmetrical.Moreover，the peak orbital contributions are considerably lower than NBi, suggesting that P/S coordination is less effective in activating the catalytic activity of Bi. Compared with PBi, S in SBi plays a more dominant role in the electron occupation state, which also means that it hasa poorer ability to promote the dehydration of vanadium ions[36-38]. In summary, the introduction of heterogeneous atoms can regulate the distribution of $\mathbf { p }$ orbitals of Bi atoms, especially the N atom can activate its $\mathbf { p } _ { \mathbf { Z } }$ orbitals and its orbital hybrid effect with Bi is stronger,thereby promoting vanadium ion dehydration and electron transfer.

# 2.5.VFB single cell performance test

Asdepicted in Fig.5a, the VFB assembled with NBi decorated electrodes exhibits the highest initial discharge voltages and specific capacity (1.31 V, 22.27 Ah $L ^ { - 1 }$ ）atacurrent density of $2 4 0 \mathrm { \ m A \ c m ^ { - 2 } }$ Moreover,it achieves higher coulombic efficiency and voltage efficiency compared to PBi, SBi,and BBi (Fig.5b). Therefore,it delivers the most superior battery performance among all fabricated electrodes,achieving a $7 \%$ increase in energy efficiency at a current density of $2 4 0 \mathrm { m A c m } ^ { - \bar { 2 } }$ and a $2 1 8 \ \mathrm { m W \ c m ^ { - 2 } }$ increase in peak power density compared to the BBi-loaded counterpart (Fig.5c-d).Compared with other electrode modification approaches [35,39-41],the NBi still exhibits superior battery performance.Moreover, the electrochemical impedance spectroscopy (EIS) indicates that the VFB single cell with NBi decorated GF electrodes exhibits the lowest ohmic resistance $\left( \operatorname { R } _ { \mathrm { O R } } \right)$ ，charge transfer resistance $\scriptstyle ( \mathrm { { R } } _ { \mathrm { { C T R } } } )$ ,and finite diffusion resistance $\left( \mathrm { R } _ { \mathrm { F D R } } \right)$ among all tested electrodes (Fig.S17)[8,2O].Long-term cycling stability test shows that the VFB assembled with the NBi decorated electrodes can run stably for 1000 cycles at $2 4 0 \mathrm { m A c m } ^ { - 2 }$ without obvious performance degradation (Fig.5e).The mass loading of Bi atoms on the electrode remained at 93 $\%$ after cycling，as confirmed by ICP analysis (Table S8).This is attributed to the stronger vanadium ion dehydration, thereby improving battery performance and stability.

# 3．Conclusion

In summary,Bi single-atom electrocatalysts with different heteroatom coordination have been successfully synthesized.Multiple techniques confirm the specific coordination structure of XBi $\mathrm { ( B i \mathrm { - N } _ { 4 } }$ ， $\mathrm { B i } { \cdot } \mathrm { P } _ { 2 }$ ， Bi- $s _ { 2 } ,$ $\mathrm { B i - B } _ { 4 , }$ ,with the catalytic activity following the order: $\mathbf { N B i > P }$ $\mathbf { B i } { > } \mathbf { S B i } { > } \mathbf { B B i }$ .The results reveal that the PBi, SBi,and BBi display the electron cloud distributions of Bi atoms near the fermi level towards the planar direction $( \mathsf { p } _ { \mathrm { { x } } } , \mathsf { p } _ { \mathrm { { y } } } )$ ,while NBi exhibits an axial orbital $\left( \mathfrak { p } _ { \mathtt { Z } } \right)$ distribution due to the high electronegativity of N.Furthermore,the pronounced Bi-N orbital hybridization in NBi results in significantly enhanced capability for promoting vanadium ion dehydration.As a result,the VFB single cell assembled with NBi decorated electrodes achieves a $7 \%$ increase in energy efficiency at a current density of 240 $\mathbf { m A c m } ^ { - 2 }$ and a $2 1 8 \mathrm { m W } \mathrm { c m } ^ { - 2 }$ increase in peak power density compared to the BBi-loaded counterpart. This work highlights the crucial role of heteroatoms and offers valuable guidance for the hybrid orbital design in creating highly active single-atom electrocatalysts for VFBs.
